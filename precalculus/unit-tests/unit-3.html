1. For point U, (−3,3)(-3, 3), which angle θ\theta in [0,2π)[0, 2\pi) goes with r=32r = 3\sqrt{2}?

  1. 3π4\frac{3\pi}{4}
  2. −π4-\frac{\pi}{4}
  3. 7π4\frac{7\pi}{4}
  4. π4\frac{\pi}{4}
Show the answer

tan⁡θ\tan\theta=yx= \frac{y}{x}=3−3= \frac{3}{-3}=−1= -1, and tan−1⁡(−1)=−π4\tan^{-1}(-1) = -\frac{\pi}{4}. But U is in Quadrant II (x<0x < 0, y>0y > 0), and tan−1⁡\tan^{-1} only returns angles in Quadrants I and IV. Add π\pi: θ=3π4\theta = \frac{3\pi}{4}.

  • Correct: 3π4\frac{3\pi}{4}: Right: Quadrant II, reference angle π4\frac{\pi}{4}.
  • −π4-\frac{\pi}{4}: That is tan−1⁡(−1)\tan^{-1}(-1), which points into Quadrant IV, and it is not in [0,2π)[0, 2\pi).
  • 7π4\frac{7\pi}{4}: 7π4\frac{7\pi}{4} points into Quadrant IV; with r>0r > 0 that names (3,−3)(3, -3).
  • π4\frac{\pi}{4}: π4\frac{\pi}{4} points into Quadrant I, where both coordinates are positive.

2. Which polar coordinates name point W, (1,−3)\left(1, -\sqrt{3}\right)?

  1. (2,5π3)\left(2, \frac{5\pi}{3}\right)
  2. (2,2π3)\left(2, \frac{2\pi}{3}\right)
  3. (4,5π3)\left(4, \frac{5\pi}{3}\right)
  4. (2,π3)\left(2, \frac{\pi}{3}\right)
Show the answer

r=1+3=2r = \sqrt{1 + 3} = 2. tan⁡θ=−3\tan\theta = -\sqrt{3} with x>0x > 0 and y<0y < 0: Quadrant IV, reference angle π3\frac{\pi}{3}, so θ=2π−π3=5π3\theta = 2\pi - \frac{\pi}{3} = \frac{5\pi}{3}.

  • Correct: (2,5π3)\left(2, \frac{5\pi}{3}\right): Right: r=2r = 2, Quadrant IV.
  • (2,2π3)\left(2, \frac{2\pi}{3}\right): tan⁡2π3=−3\tan\frac{2\pi}{3} = -\sqrt{3} too, but that ray is in Quadrant II; W has x>0x > 0.
  • (4,5π3)\left(4, \frac{5\pi}{3}\right): 44 is r2r^2; take the square root.
  • (2,π3)\left(2, \frac{\pi}{3}\right): π3\frac{\pi}{3} is in Quadrant I; W has a negative yy.

4. The average rate of change of dd is 83π\frac{8\sqrt{3}}{\pi} kilometers per radian on [0,π6]\left[0, \frac{\pi}{6}\right] and 163π\frac{16\sqrt{3}}{\pi} kilometers per radian on [π6,π3]\left[\frac{\pi}{6}, \frac{\pi}{3}\right]. What does this show about dd on [0,π3]\left[0, \frac{\pi}{3}\right]?

  1. The rate of change of dd is increasing, so the graph of dd is concave up
  2. The rate of change of dd is decreasing, so the graph of dd is concave down
  3. dd is decreasing, because the rates are not equal
  4. dd is linear, because both rates are positive
Show the answer

The two input intervals have the same length, π6\frac{\pi}{6}, and the average rate on the later one is larger. Increasing average rates over equal intervals mean the graph of dd is concave up: the spot moves along the shore faster and faster as the beam turns.

  • Correct: The rate of change of dd is increasing, so the graph of dd is concave up: Right: equal intervals, larger rate later, so concave up.
  • The rate of change of dd is decreasing, so the graph of dd is concave down: The rate on the later interval is larger (163π>83π\frac{16\sqrt{3}}{\pi} > \frac{8\sqrt{3}}{\pi}), so the rates increase.
  • dd is decreasing, because the rates are not equal: Both rates are positive, so dd is increasing on the interval.
  • dd is linear, because both rates are positive: A linear function has equal rates on equal intervals; these differ.

5. Which statement explains what happens to d(θ)d(\theta) as θ\theta approaches π2\frac{\pi}{2} from the left, in the context?

  1. limθ→π/2−d(θ)\lim_{\theta \to \pi/2^-} d(\theta)=∞= \infty: the beam turns nearly parallel to the shore, so the spot lands farther and farther away
  2. limθ→π/2−d(θ)\lim_{\theta \to \pi/2^-} d(\theta)=4= 4: the spot approaches the lighthouse's distance from the shore
  3. limθ→π/2−d(θ)\lim_{\theta \to \pi/2^-} d(\theta)=0= 0: the beam points back at the nearest point of the shore
  4. limθ→π/2−d(θ)\lim_{\theta \to \pi/2^-} d(\theta)=−∞= -\infty: the spot moves to the other side of the nearest point

d(θ)=4tan⁡θd(\theta) = 4\tan\theta has a vertical asymptote at θ=π2\theta = \frac{\pi}{2} because cos⁡π2=0\cos\frac{\pi}{2} = 0. From the left tan⁡θ\tan\theta grows without bound, so limθ→π/2−d(θ)\lim_{\theta \to \pi/2^-} d(\theta)=∞= \infty. In context, a beam almost parallel to the shore meets it very far away.

  • Correct: limθ→π/2−d(θ)\lim_{\theta \to \pi/2^-} d(\theta)=∞= \infty: the beam turns nearly parallel to the shore, so the spot lands farther and farther away: Right: an asymptote at π2\frac{\pi}{2}, approached from the left, gives outputs growing without bound.
  • limθ→π/2−d(θ)\lim_{\theta \to \pi/2^-} d(\theta)=4= 4: the spot approaches the lighthouse's distance from the shore: d(π4)=4d\left(\frac{\pi}{4}\right) = 4 is one table value; dd keeps growing past it.

  1. No: d(π3)=43d\left(\frac{\pi}{3}\right) = 4\sqrt{3}, which is 33 times d(π6)=433d\left(\frac{\pi}{6}\right) = \frac{4\sqrt{3}}{3}

  3. No: d(π3)d\left(\frac{\pi}{3}\right) is 44 times d(π6)d\left(\frac{\pi}{6}\right), because tan⁡\tan squares the angle
  4. Yes: tan⁡(2⋅π6)=2tan⁡(π6)\tan\left(2\cdot\frac{\pi}{6}\right) = 2\tan\left(\frac{\pi}{6}\right)

From the table, d(π3)=43d\left(\frac{\pi}{3}\right) = 4\sqrt{3} and d(π6)=433d\left(\frac{\pi}{6}\right) = \frac{4\sqrt{3}}{3}, so the ratio is 4343/3=3\frac{4\sqrt{3}}{4\sqrt{3}/3} = 3. Tangent is not linear: doubling the input does not double the output.

  • Correct: No: d(π3)=43d\left(\frac{\pi}{3}\right) = 4\sqrt{3}, which is 33 times d(π6)=433d\left(\frac{\pi}{6}\right) = \frac{4\sqrt{3}}{3}: Right: the ratio of the table values is 33, not 22.

  • No: d(π3)d\left(\frac{\pi}{3}\right) is 44 times d(π6)d\left(\frac{\pi}{6}\right), because tan⁡\tan squares the angle: The ratio from the table is 33; tangent does not square its input.

7. The brightness b(t)b(t) of a lighthouse light seen from a boat repeats every 12 seconds. At t=3t = 3 seconds the brightness is 8080 units. Which statement must be true?

  1. b(27)=80b(27) = 80
  2. b(9)=80b(9) = 80
  3. b(6)=160b(6) = 160
  4. b(36)=80b(36) = 80
Show the answer

27=3+2⋅1227 = 3 + 2 \cdot 12, two full periods after t=3t = 3, so b(27)=b(3)=80b(27) = b(3) = 80.

  • Correct: b(27)=80b(27) = 80: Adding two periods to t=3t = 3 gives t=27t = 27, with the same brightness.
  • b(9)=80b(9) = 80: 9=3+69 = 3 + 6 is only half a period later; the light could be at any brightness then.
  • b(6)=160b(6) = 160: Doubling the input does not double the output; nothing says b(6)b(6) is 160160.
  • b(36)=80b(36) = 80: 3636 is three periods after t=0t = 0, so b(36)=b(0)b(36) = b(0), which need not equal b(3)b(3).

11. What are the amplitude and midline of y=4sin⁡θ+1y = 4\sin\theta + 1?

  1. Amplitude 44, midline y=1y = 1
  2. Amplitude 11, midline y=4y = 4
  3. Amplitude 88, midline y=1y = 1
  4. Amplitude 55, midline y=0y = 0
Show the answer

4sin⁡θ4\sin\theta goes from −4-4 to 44; adding 1 gives −3-3 to 55. Amplitude 5−(−3)2=4\frac{5 - (-3)}{2} = 4, midline y=5+(−3)2=1y = \frac{5 + (-3)}{2} = 1.

  • Correct: Amplitude 44, midline y=1y = 1: The factor 4 sets the amplitude; the added 1 sets the midline.
  • Amplitude 11, midline y=4y = 4: The roles are swapped: 4 multiplies the heights, 1 lifts them.
  • Amplitude 88, midline y=1y = 1: 8 is max⁡−min⁡\max - \min, twice the amplitude.
  • Amplitude 55, midline y=0y = 0: 5 is the greatest value, not the amplitude, and the graph is lifted off y=0y = 0.
