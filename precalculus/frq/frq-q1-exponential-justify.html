  1. (A(i)) Find the average rate of change of ff over the interval 0≤x≤40 \le x \le 4 and over the interval 4≤x≤84 \le x \le 8. [1 point]

  2. (A(ii)) Based on the results of part A(i), is the graph of ff concave up or concave down on 0≤x≤80 \le x \le 8? Give a reason for your answer. [1 point]

  3. (B(i)) Solve g(x)=4g(x) = 4 for all values of xx. Give your answers correct to three decimal places where needed. [1 point]

  4. (B(ii)) Express the end behavior of gg, as xx decreases without bound and as xx increases without bound, using the mathematical notation of limits. [1 point]

  5. (C(i)) Is a linear function or an exponential function a better model for the values in the table? Justify your answer, using the input and output values in the table. [1 point]

  6. (C(ii)) Write an expression for an exponential function that matches every value in the table. [1 point]
