Function lab

Drag a parameter and watch every representation change at once.

About this tool

Every parent function the course transforms, on one stage: g(x)=af(b(x−h))+kg(x) = a\,f(b(x - h)) + k. Drag the two handles on the graph, or move one parameter at a time, and the graph, the table of key points, the formula and the sentence in words change together. The parent ff stays as a faint ghost, so you see what each parameter did. Zeros, asymptotes, the domain and range, and the end behavior in limit notation are marked as you go.

How the lab works

  • Inside and outside. bb and hh act on the input (inside ff), so they move the graph sideways: first a horizontal dilation by a factor of 1|b|\frac{1}{|b|} (a reflection over the yy-axis if b<0b < 0), then a horizontal translation by hh. aa and kk act on the output (outside ff): a vertical dilation by a factor of |a||a| (a reflection over the xx-axis if a<0a < 0), then a vertical translation by kk.
  • Key points. Each point (x,y)(x, y) on ff goes to (xb+h,ay+k)\left(\frac{x}{b} + h, a y + k\right) on gg. The table lists them, in the same colors as the dots on the graph.
  • The handles. The square handle is (h,k)(h, k), where the parent's origin goes: drag it to translate. The round handle is one key point: drag it to change aa (up and down) and bb (sideways).
  • Play the steps shows the four changes one after another, in the order they act.
  • Keyboard: each handle takes the arrow keys (Shift for bigger steps); the parameter slider takes the arrow keys, Home and End.
  • Zeros come from solving af(b(x−h))+k=0a\,f(b(x - h)) + k = 0 with the parent's inverse; end behavior and asymptotes from the parent's own limits.
