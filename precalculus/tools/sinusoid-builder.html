Sinusoid builder

Build a sinusoid from its highs, lows and one cycle.

About this tool

A Ferris wheel, a tide, a spring and a day of temperatures: each repeats. Set the amplitude, the midline, the period and the phase shift, and watch your model over the data. Every point your curve passes through turns green. The scene moves in time with the graph, on the same vertical scale.

How a sinusoid is built

  • Amplitude a = (max − min) / 2: how far the value swings from the midline.
  • Midline y = d, with d = (max + min) / 2.
  • Period: the time for one full cycle, for example from one maximum to the next. Then b = 2π / period. The frequency, cycles per unit of time, is 1 / period.
  • Phase shift: in a sin(b(t + c)) + d the graph is shifted left by c (right when c is negative). With sine a cycle starts on the midline going up at t = −c; with cosine it starts at a maximum.
  • Five labeled points: one cycle from a starting point, a quarter period apart: the maximum, midline and minimum values in turn.
  • Rate of change: where the graph is concave down (above the midline) the rate of change is decreasing; where it is concave up (below the midline) it is increasing.
  • Keyboard: the handles on the graph move with the arrow keys; each parameter also has its slider.
