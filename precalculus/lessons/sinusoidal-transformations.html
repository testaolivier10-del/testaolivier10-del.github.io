Unit 3 · Topic 3.6

Sinusoidal Function Transformations

In f(θ) = asin (b(θ + c)) + d , |a| is the amplitude, 2π/(|b|) the period, c the phase shift (left by c ) and y = d the midline; cosine works the same way.

Practice 1: Procedural and Symbolic FluencyPractice 2: Multiple Representations

Part 1 · Hook

Why this matters

A music app draws a sound wave, and an engineer needs its formula to filter it: how tall, how fast, how far along. Every sinusoid you will ever meet is y=sin⁡θy = \sin\theta stretched, squeezed and slid. Four constants, aa, bb, cc and dd, record exactly how, and reading them correctly is the heart of the periodic modeling question on the exam.

Part 5 · Step by step

How it works, step by step

  1. Multiply by aa: asin⁡θa\sin\theta→a vertical dilation: the amplitude becomes |a||a|, and a negative aa also reflects the graph across the midline
  2. Multiply the input by bb: sin⁡(bθ)\sin(b\theta)→a horizontal dilation: one cycle now takes 2π|b|\frac{2\pi}{|b|}, so the period is 2π|b|\frac{2\pi}{|b|} and b=2πperiodb = \frac{2\pi}{\text{period}}
  3. Add cc inside, after factoring out bb: sin⁡(b(θ+c))\sin(b(\theta + c))→a phase shift: the graph moves left cc units if c>0c > 0, right if c<0c < 0
  4. Add dd outside: asin⁡(b(θ+c))+da\sin(b(\theta + c)) + d→a vertical translation: the midline becomes y=dy = d

Part 6 · Key ideas

Key ideas

  • For f(θ)f(\theta)=asin⁡(b(θ+c))+d= a\sin(b(\theta + c)) + d or acos⁡(b(θ+c))+da\cos(b(\theta + c)) + d: amplitude |a||a|, period 2π|b|\frac{2\pi}{|b|}, phase shift −c-c (left by cc), midline y=dy = d.
  • Factor bb out before reading the shift: sin⁡(2θ+π)\sin(2\theta + \pi)=sin⁡(2(θ+π2))= \sin\left(2\left(\theta + \frac{\pi}{2}\right)\right) moves left π2\frac{\pi}{2}, not π\pi.
  • Building from a graph: dd from the midline, |a||a| from the amplitude, b=2πperiodb = \frac{2\pi}{\text{period}}, then cc from one landmark (a rising midline crossing for sine, a highest point for cosine).
  • Many formulas give the same graph: cos⁡θ=sin⁡(θ+π2)\cos\theta = \sin\left(\theta + \frac{\pi}{2}\right), and cc can change by any whole number of periods.

Part 7 · Misconception

A common mistake

The wrong idea: In f(θ)=sin⁡(2θ−π)f(\theta) = \sin(2\theta - \pi) the graph moves right π\pi, and the period is 2⋅2π=4π2 \cdot 2\pi = 4\pi.

What actually happens: Factor first: sin⁡(2θ−π)\sin(2\theta - \pi)=sin⁡(2(θ−π2))= \sin\left(2\left(\theta - \frac{\pi}{2}\right)\right), a shift right π2\frac{\pi}{2}. Multiplying the input by 2 makes each cycle shorter, so the period is 2π2=π\frac{2\pi}{2} = \pi.

2. The function can be written g(θ)=3sin⁡(θ+c)+1g(\theta) = 3\sin(\theta + c) + 1. Which value of cc works?

  1. c=−π2c = -\frac{\pi}{2}
  2. c=π2c = \frac{\pi}{2}
  3. c=πc = \pi
  4. c=0c = 0
Show the answer

The sine pattern starts (rising midline crossing) at θ=−c\theta = -c. On the graph that is θ=π2\theta = \frac{\pi}{2}, so c=−π2c = -\frac{\pi}{2}.

  • Correct: c=−π2c = -\frac{\pi}{2}: Start of the cycle at θ=π2\theta = \frac{\pi}{2} means θ+c=0\theta + c = 0 there.
  • c=π2c = \frac{\pi}{2}: This moves the graph left; it would rise through the midline at −π2-\frac{\pi}{2} and fall through it at π2\frac{\pi}{2}.
  • c=πc = \pi: With c=πc = \pi the graph would have a lowest point at π2\frac{\pi}{2}, but gg is at its midline there.
  • c=0c = 0: With no shift the graph would be at its midline at θ=0\theta = 0, but g(0)=−2g(0) = -2.

3. Which is also a formula for gg?

  1. g(θ)=−3cos⁡θ+1g(\theta) = -3\cos\theta + 1
  2. g(θ)=3cos⁡θ+1g(\theta) = 3\cos\theta + 1
  3. g(θ)=−3sin⁡θ+1g(\theta) = -3\sin\theta + 1
  4. g(θ)g(\theta)=3cos⁡(θ−π2)+1= 3\cos\left(\theta - \frac{\pi}{2}\right) + 1
Show the answer

−3cos⁡θ+1-3\cos\theta + 1 is −3+1=−2-3 + 1 = -2 at θ=0\theta = 0 and 3+1=43 + 1 = 4 at θ=π\theta = \pi: a reflected cosine starts at a lowest point, as gg does.

  • Correct: g(θ)=−3cos⁡θ+1g(\theta) = -3\cos\theta + 1: A reflected cosine: lowest at 00, highest at π\pi.
  • g(θ)=3cos⁡θ+1g(\theta) = 3\cos\theta + 1: This has its highest point at θ=0\theta = 0; gg has its lowest point there.
  • g(θ)=−3sin⁡θ+1g(\theta) = -3\sin\theta + 1: This is 11 at θ=0\theta = 0, but g(0)=−2g(0) = -2.
  • g(θ)g(\theta)=3cos⁡(θ−π2)+1= 3\cos\left(\theta - \frac{\pi}{2}\right) + 1: cos⁡(θ−π2)=sin⁡θ\cos\left(\theta - \frac{\pi}{2}\right) = \sin\theta, so this is 11 at θ=0\theta = 0.

6. How is the graph of f(θ)=sin⁡(2θ+π2)f(\theta) = \sin\left(2\theta + \frac{\pi}{2}\right) shifted, compared with y=sin⁡(2θ)y = \sin(2\theta)?

  1. Left π4\frac{\pi}{4}
  2. Left π2\frac{\pi}{2}
  3. Right π4\frac{\pi}{4}
  4. Right π2\frac{\pi}{2}
Show the answer

Factor out bb: 2θ+π2=2(θ+π4)2\theta + \frac{\pi}{2} = 2\left(\theta + \frac{\pi}{4}\right), so c=π4c = \frac{\pi}{4}: a shift left π4\frac{\pi}{4}.

  • Correct: Left π4\frac{\pi}{4}: After factoring out 2, the shift is π4\frac{\pi}{4} to the left.
  • Left π2\frac{\pi}{2}: This reads the shift before factoring out b=2b = 2.
  • Right π4\frac{\pi}{4}: A plus sign inside moves the graph left, not right.
  • Right π2\frac{\pi}{2}: Wrong direction, and bb was not factored out.

Part 9 · Summary

Summary

In f(θ)f(\theta)=asin⁡(b(θ+c))+d= a\sin(b(\theta + c)) + d, |a||a| is the amplitude, 2π|b|\frac{2\pi}{|b|} the period, cc the phase shift (left by cc) and y=dy = d the midline; cosine works the same way. To build a formula from a graph, read dd and |a||a|, get b=2πperiodb = \frac{2\pi}{\text{period}}, then find cc from a landmark point. Factor out bb before reading a shift.
