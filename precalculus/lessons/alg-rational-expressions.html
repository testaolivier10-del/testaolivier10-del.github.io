Rational Expressions

A rational expression is a quotient of polynomials, undefined where its denominator is 0 .

Practice 1: Procedural and Symbolic Fluency

Part 1 · Hook

Why this matters

If xx friends split a $120 bill and a $30 tip, each pays 150x\frac{150}{x} dollars. Expressions with the variable in a denominator show up whenever something is shared or divided. Topic 1.7 studies functions built from them, so first the algebra: simplify, combine, split, and keep track of the inputs that are not allowed.

Part 5 · Step by step

How it works, step by step

  1. A denominator has a factor that is 00 at x=ax = a→aa is excluded from the domain, before and after any simplifying
  2. The numerator and denominator share a factor→it cancels, but the excluded input stays excluded
  3. Two fractions are added or subtracted→rewrite both over a common denominator, then combine the numerators
  4. A numerator is a sum→each term can be divided by the denominator separately: 2x2+3x=2x+3x\frac{2x^2 + 3}{x} = 2x + \frac{3}{x}

Part 6 · Key ideas

Key ideas

  • A rational expression is a quotient of two polynomials, like x−3x−2\frac{x - 3}{x - 2}. It is undefined where its denominator is 00.
  • Factor first, then cancel common factors, never terms. Keep the excluded inputs of the original.
  • Add with a common denominator; multiply straight across; divide by multiplying by the reciprocal.

Part 7 · Misconception

A common mistake

The wrong idea: x+6x+3=2\frac{x + 6}{x + 3} = 2, cancelling the xx's and 6÷36 \div 3.

What actually happens: Only factors of the whole top and bottom cancel. At x=1x = 1, 74≠2\frac{7}{4} \ne 2. x+6x+3\frac{x + 6}{x + 3} does not simplify.

Part 8 · Check yourself

Check yourself

Exam-style questions. Anything you miss goes into your review queue.

1. Simplify x2−9x2+x−6\frac{x^2 - 9}{x^2 + x - 6}, and state the inputs that must be left out.

  1. x−3x−2\frac{x - 3}{x - 2}, with x≠2x \ne 2
  2. x−3x−2\frac{x - 3}{x - 2}, with x≠−3x \ne -3 and x≠2x \ne 2
  3. −9x−6\frac{-9}{x - 6}, with x≠6x \ne 6
  4. x+3x−2\frac{x + 3}{x - 2}, with x≠2x \ne 2
Show the answer

(x−3)(x+3)(x+3)(x−2)\frac{(x - 3)(x + 3)}{(x + 3)(x - 2)}=x−3x−2= \frac{x - 3}{x - 2} for x≠−3x \ne -3 and x≠2x \ne 2. The original expression is undefined at both, so both stay excluded.

  • x−3x−2\frac{x - 3}{x - 2}, with x≠2x \ne 2: The cancelled factor still counts: x=−3x = -3 makes the original denominator 00.
  • Correct: x−3x−2\frac{x - 3}{x - 2}, with x≠−3x \ne -3 and x≠2x \ne 2: Right: both zeros of the original denominator stay excluded.
  • −9x−6\frac{-9}{x - 6}, with x≠6x \ne 6: Only factors cancel, never terms: x2x^2 cannot be cancelled from a sum.
  • x+3x−2\frac{x + 3}{x - 2}, with x≠2x \ne 2: x2−9=(x−3)(x+3)x^2 - 9 = (x - 3)(x + 3); the factor that cancels is x+3x + 3, leaving x−3x - 3.

3. Which inputs make x+2x2−4x\frac{x + 2}{x^2 - 4x} undefined?

  1. x=0x = 0 and x=4x = 4
  2. x=−2x = -2
  3. x=4x = 4
  4. x=2x = 2 and x=−2x = -2
Show the answer

A fraction is undefined where its denominator is 00: x(x−4)=0x(x - 4) = 0 at x=0x = 0 and x=4x = 4. The numerator's zeros do not matter for the domain.

  • Correct: x=0x = 0 and x=4x = 4: Right: x2−4x=x(x−4)x^2 - 4x = x(x - 4) is 00 at both.
  • x=−2x = -2: At x=−2x = -2 the numerator is 00, which is allowed: the value is 00.
  • x=4x = 4: x=0x = 0 also makes x(x−4)x(x - 4) zero.
  • x=2x = 2 and x=−2x = -2: These solve x2−4=0x^2 - 4 = 0; the denominator is x2−4xx^2 - 4x.

4. x2−4x−2\frac{x^2 - 4}{x - 2} and x+2x + 2 have the same value at every input except one. Which?

  1. x=−2x = -2
  2. x=4x = 4
  3. x=0x = 0
  4. x=2x = 2
Show the answer

x2−4x−2\frac{x^2 - 4}{x - 2}=(x−2)(x+2)x−2= \frac{(x - 2)(x + 2)}{x - 2}=x= x+2+ 2 only when x≠2x \ne 2. At x=2x = 2 the fraction has no value; its graph is the line y=x+2y = x + 2 with that one point missing.

  • x=−2x = -2: Both are 00 at x=−2x = -2: 0−4=0\frac{0}{-4} = 0 and −2+2=0-2 + 2 = 0.
  • x=4x = 4: At x=4x = 4 both give 66.
  • x=0x = 0: At x=0x = 0 both give 22.
  • Correct: x=2x = 2: Right: x2−4x−2\frac{x^2 - 4}{x - 2} is undefined at x=2x = 2, while x+2=4x + 2 = 4 there.

5. Which simplification is correct?

  1. x+6x+3=2\frac{x + 6}{x + 3} = 2
  2. 3x+63=x+6\frac{3x + 6}{3} = x + 6
  3. x2+xx=x+1\frac{x^2 + x}{x} = x + 1, for x≠0x \ne 0
  4. x+1x=1\frac{x + 1}{x} = 1, for x≠0x \ne 0
Show the answer

Cancel only common factors of the whole numerator and denominator: x(x+1)x=x+1\frac{x(x + 1)}{x} = x + 1. Terms of a sum cannot be cancelled.

  • x+6x+3=2\frac{x + 6}{x + 3} = 2: xx and 33 are terms of a sum, not factors; check x=1x = 1: 74≠2\frac{7}{4} \ne 2.
  • 3x+63=x+6\frac{3x + 6}{3} = x + 6: Divide both terms by 33: x+2x + 2.
  • Correct: x2+xx=x+1\frac{x^2 + x}{x} = x + 1, for x≠0x \ne 0: Right: xx is a factor of the top, x(x+1)x(x + 1), so it cancels.
  • x+1x=1\frac{x + 1}{x} = 1, for x≠0x \ne 0: Check x=1x = 1: 21=2\frac{2}{1} = 2, not 11.

6. Which is equal to x2+2x+3x+1\frac{x^2 + 2x + 3}{x + 1} for x≠−1x \ne -1?

  1. x+2+3x+1x + 2 + \frac{3}{x + 1}
  2. x+1+2x+1x + 1 + \frac{2}{x + 1}
  3. x+3x + 3
  4. x+1+3x+1x + 1 + \frac{3}{x + 1}
Show the answer

Write the top around the denominator: x2+2x+3x^2 + 2x + 3=(x+1)2+2= (x + 1)^2 + 2. Then (x+1)2+2x+1\frac{(x + 1)^2 + 2}{x + 1}=x= x+1+ 1+2x+1+ \frac{2}{x + 1}.

  • x+2+3x+1x + 2 + \frac{3}{x + 1}: Check x=0x = 0: 33 on the left but 55 here.
  • Correct: x+1+2x+1x + 1 + \frac{2}{x + 1}: Right: x2+2x+3x^2 + 2x + 3=(x+1)2+2= (x + 1)^2 + 2, so divide each part by x+1x + 1.
  • x+3x + 3: Check x=0x = 0: 3=33 = 3, but at x=1x = 1 the left is 33 and this is 44.
  • x+1+3x+1x + 1 + \frac{3}{x + 1}: (x+1)2=x2+2x+1(x + 1)^2 = x^2 + 2x + 1, so the leftover is 22, not 33.

Part 9 · Summary

Summary

A rational expression is a quotient of polynomials, undefined where its denominator is 00. Factor, then cancel common factors only, keeping the original exclusions. Add with a common denominator, multiply across, divide by the reciprocal, and split a sum in the numerator term by term.
