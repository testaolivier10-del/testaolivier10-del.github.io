Function Model Construction and Application

Build a model from data points (a system), from features and transformations, or by regression; store its constants; use it to predict and to find average rates of change with units, only for inputs the context allows.

Part 1 · Hook

Why this matters

A garden center tracks how many of a new spring plant it sells each month. Three numbers from last year are enough to build a model, predict next spring, and say when the model stops making sense.

Part 5 · Step by step

How it works, step by step

  1. Choose the model type from the data and the context→a form with unknown constants, such as at2+bt+cat^2 + bt + c
  2. Substitute data points, or run a regression on the calculator→the constants, stored at full precision
  3. Evaluate the model and its average rates of change→predictions with units, inside the domain the context allows

Part 6 · Key ideas

Key ideas

  • A model is built from points (a system), from a known feature and transformations (vertex form), or from all the data at once (a regression).
  • Inverse proportion: y=kxy = \frac{k}{x}; inverse-square laws: y=kx2y = \frac{k}{x^2}. One data point gives kk.
  • Report predictions and rates with units: an average rate of change is output units per input unit, such as hundred plants per month.

Part 7 · Misconception

A common mistake

The wrong idea: Once a model fits the data, it can predict any input.

What actually happens: A model is supported only near its data and only where the context allows; past that, its predictions can be impossible, such as negative sales.
