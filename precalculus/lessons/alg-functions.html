Functions, Graphs and Notation

A function gives each input one output, written f(input) = output .

Practice 2: Multiple Representations

Part 1 · Hook

Why this matters

Press B4 on a vending machine and you always get the same snack. That one-button, one-snack rule is what makes a function: every input gives exactly one output. Precalculus is the study of functions, so this page sets up the words and notation the whole course uses.

Part 3 · Step by step

How it works, step by step

  1. Each input of a function has exactly one output→f(3)=7f(3) = 7 names one point (3,7)(3, 7) on the graph of ff
  2. A formula divides by an expression or takes its square root→the domain leaves out inputs that make a denominator 00 or a square root's inside negative
  3. An input aa gives the output 00→aa is a zero of ff and the graph meets the xx-axis at (a,0)(a, 0)
  4. A piecewise-defined function is evaluated→first find the piece whose condition holds for the input, then use only that piece

Part 4 · Key ideas

Key ideas

  • Function: each input gives exactly one output. f(3)=7f(3) = 7 means the input 33 gives the output 77.
  • Domain: the inputs a function accepts. Range: the outputs it produces.
  • Zero: an input with output 00, an xx-intercept of the graph. yy-intercept: the point (0,f(0))(0, f(0)).
  • To evaluate, replace every xx with the input in parentheses: f(−2)f(-2), f(x+1)f(x + 1).

Part 5 · Misconception

A common mistake

The wrong idea: f(x+1)f(x + 1) is the same as f(x)+1f(x) + 1.

What actually happens: f(x+1)f(x + 1) changes the input: replace every xx with x+1x + 1. f(x)+1f(x) + 1 changes the output: add 11 after evaluating. For f(x)=x2f(x) = x^2 they are (x+1)2(x + 1)^2 and x2+1x^2 + 1, which differ.

1. For f(x)=x2−3x+1f(x) = x^2 - 3x + 1, what is f(−2)f(-2)?

  1. 1111
  2. 33
  3. −1-1
  4. −9-9
Show the answer

Put −2-2 in for every xx, inside parentheses: f(−2)f(-2)=(−2)2−3(−2)= (-2)^2 - 3(-2)+1+ 1=4= 4+6+ 6+1+ 1=11= 11.

  • Correct: 1111: Right: (−2)2−3(−2)+1(-2)^2 - 3(-2) + 1=4+6+1= 4 + 6 + 1=11= 11.
  • 33: This squares only the 22, as if (−2)2(-2)^2 were −4-4. With parentheses, (−2)2=4(-2)^2 = 4.
  • −1-1: This uses −3(−2)=−6-3(-2) = -6. A negative times a negative is positive: −3(−2)=6-3(-2) = 6.
  • −9-9: Two sign slips: (−2)2(-2)^2 read as −4-4 and −3(−2)-3(-2) read as −6-6.

3. What is the domain of g(x)g(x)=x−2x−5= \frac{\sqrt{x - 2}}{x - 5}?

  1. x≥2x \ge 2 and x≠5x \ne 5
  2. x≥2x \ge 2
  3. x≠5x \ne 5
  4. x>2x > 2 and x≠5x \ne 5
Show the answer

Two rules: the expression under a square root cannot be negative (x≥2x \ge 2), and a denominator cannot be 00 (x≠5x \ne 5). Both must hold.

  • Correct: x≥2x \ge 2 and x≠5x \ne 5: Right: the square root needs x−2≥0x - 2 \ge 0, and the denominator needs x−5≠0x - 5 \ne 0.
  • x≥2x \ge 2: This misses the denominator: at x=5x = 5 it is 00, and division by 00 is undefined.
  • x≠5x \ne 5: This misses the square root: for x<2x < 2, x−2x - 2 is negative and has no real square root.
  • x>2x > 2 and x≠5x \ne 5: x=2x = 2 is allowed: 0=0\sqrt{0} = 0, and 0−3=0\frac{0}{-3} = 0 is a real number.

5. Which table does NOT define yy as a function of xx?

  1. xx: 1,2,2,31, 2, 2, 3 and yy: 4,5,6,74, 5, 6, 7
  2. xx: 1,2,3,41, 2, 3, 4 and yy: 5,5,5,55, 5, 5, 5
  3. xx: −1,0,1,2-1, 0, 1, 2 and yy: 1,0,1,41, 0, 1, 4
  4. xx: 0,3,6,90, 3, 6, 9 and yy: 9,6,3,09, 6, 3, 0
Show the answer

A function gives each input exactly one output. Look for a repeated input with different outputs; repeated outputs are fine.

  • Correct: xx: 1,2,2,31, 2, 2, 3 and yy: 4,5,6,74, 5, 6, 7: Right: the input 22 has two outputs, 55 and 66, so this is not a function.
  • xx: 1,2,3,41, 2, 3, 4 and yy: 5,5,5,55, 5, 5, 5: Every input has one output. Several inputs may share an output.
  • xx: −1,0,1,2-1, 0, 1, 2 and yy: 1,0,1,41, 0, 1, 4: Each input appears once, so each has exactly one output. −1-1 and 11 sharing 11 is allowed.
  • xx: 0,3,6,90, 3, 6, 9 and yy: 9,6,3,09, 6, 3, 0: Each input appears once with one output: a function.

Show the answer

Part 7 · Summary

Summary

A function gives each input one output, written f(input)=outputf(\text{input}) = \text{output}. The domain is every allowed input (no zero denominators, no square roots of negatives); the range is every output. Zeros are inputs with output 00; the yy-intercept is (0,f(0))(0, f(0)). Piecewise-defined functions use the piece whose condition the input meets.
