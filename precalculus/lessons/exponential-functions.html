Unit 2 · Topic 2.3

Exponential Functions

f(x) = ab^x is monotonic with one concavity and a horizontal asymptote, written in limit notation.

Practice 2: Multiple RepresentationsPractice 3: Communication and Reasoning

Part 1 · Hook

Why this matters

A cup of tea cools, a savings account grows, a medicine leaves the bloodstream. Each changes by the same factor every hour or year, and each levels off toward a value it never quite reaches. The function that does this is f(x) = ab^x.

Part 5 · Step by step

How it works, step by step

  1. b>1b > 1 (growth) or 0<b<10 < b < 1 (decay), with a>0a > 0→the function is increasing or decreasing everywhere, and concave up
  2. a<0a < 0→the graph is reflected across the xx-axis: concave down
  3. The output is multiplied by bb forever→one side approaches the asymptote: limx→∞abx=0\lim_{x \to \infty} ab^x = 0 for decay, limx→−∞abx=0\lim_{x \to -\infty} ab^x = 0 for growth
  4. Add kk: abx+kab^x + k→the asymptote moves to y=ky = k

Part 6 · Key ideas

Key ideas

  • f(x)=abxf(x) = ab^x (a≠0a \ne 0, b>0b > 0, b≠1b \ne 1) is always increasing or always decreasing, has one concavity, and has no extrema or points of inflection.
  • Its graph has a horizontal asymptote; write the end behavior in limit notation, such as limx→−∞3(2)x\lim_{x \to -\infty} 3(2)^x=0= 0.
  • The base is the growth factor: a 4%4\% increase is b=1.04b = 1.04; a 15%15\% decrease is b=0.85b = 0.85. The natural base e≈2.718e \approx 2.718 is a base used in many models.

Part 7 · Misconception

A common mistake

The wrong idea: h(x)=2(12)x+1h(x) = 2\left(\frac{1}{2}\right)^x + 1 approaches 00 as x→∞x \to \infty.

What actually happens: The +1+1 shifts the asymptote: limx→∞h(x)=1\lim_{x \to \infty} h(x) = 1. Find the limit of the exponential part, then add the shift.

1. Which statement describes the end behavior of hh as xx increases without bound?

  1. limx→∞h(x)=0\lim_{x \to \infty} h(x) = 0
  2. limx→∞h(x)=1\lim_{x \to \infty} h(x) = 1
  3. limx→∞h(x)=∞\lim_{x \to \infty} h(x) = \infty
  4. limx→1h(x)=∞\lim_{x \to 1} h(x) = \infty
Show the answer

As xx grows, (12)x\left(\frac{1}{2}\right)^x shrinks toward 00, so h(x)h(x) approaches 2⋅0+1=12 \cdot 0 + 1 = 1: limx→∞h(x)=1\lim_{x \to \infty} h(x) = 1. The line y=1y = 1 is a horizontal asymptote.

  • limx→∞h(x)=0\lim_{x \to \infty} h(x) = 0: This is the limit of 2(12)x2(\frac{1}{2})^x alone; the +1+1 shifts the asymptote up.
  • Correct: limx→∞h(x)=1\lim_{x \to \infty} h(x) = 1: The term 2(12)x2(\frac{1}{2})^x goes to 00 and 11 remains.
  • limx→∞h(x)=∞\lim_{x \to \infty} h(x) = \infty: The graph falls as xx increases; it does not grow.
  • limx→1h(x)=∞\lim_{x \to 1} h(x) = \infty: This describes the input approaching 11, which is not end behavior.

2. Which statement describes hh as xx decreases without bound?

  1. limx→−∞h(x)=1\lim_{x \to -\infty} h(x) = 1
  2. limx→−∞h(x)=−∞\lim_{x \to -\infty} h(x) = -\infty
  3. limx→−∞h(x)=∞\lim_{x \to -\infty} h(x) = \infty
  4. limx→∞h(x)=−∞\lim_{x \to \infty} h(x) = -\infty
Show the answer

For negative xx, (12)x=2−x\left(\frac{1}{2}\right)^x = 2^{-x} grows without bound: h(−10)=2⋅1024+1h(-10) = 2 \cdot 1024 + 1. So limx→−∞h(x)=∞\lim_{x \to -\infty} h(x) = \infty.

  • limx→−∞h(x)=1\lim_{x \to -\infty} h(x) = 1: The asymptote y=1y = 1 is on the right side, as x→∞x \to \infty.
  • limx→−∞h(x)=−∞\lim_{x \to -\infty} h(x) = -\infty: The outputs are all above 11, so they cannot go to −∞-\infty.
  • Correct: limx→−∞h(x)=∞\lim_{x \to -\infty} h(x) = \infty: Going left, the outputs grow without bound.
  • limx→∞h(x)=−∞\lim_{x \to \infty} h(x) = -\infty: This is about the right side, and the outputs there approach 11.

3. Which statement about hh on the interval (−3,5)(-3, 5) is true?

  1. hh is decreasing, and the rate of change of hh is increasing
  2. hh is decreasing, and the rate of change of hh is decreasing
  3. hh is increasing, and the graph is concave up
  4. hh is decreasing until x=0x = 0, then increasing
Show the answer

The outputs fall as xx increases, so hh is decreasing. The graph is concave up: the average rates of change over equal intervals are negative but closer to 00 each time (hh drops 44, then 22, then 11 from x=−2x = -2 to x=1x = 1), so the rate of change of hh is increasing.

  • Correct: hh is decreasing, and the rate of change of hh is increasing: Falling, and falling less steeply: rates increasing toward 00.
  • hh is decreasing, and the rate of change of hh is decreasing: Rates like −4,−2,−1-4, -2, -1 are increasing, which means concave up.
  • hh is increasing, and the graph is concave up: The base 12\frac{1}{2} makes hh decrease.
  • hh is decreasing until x=0x = 0, then increasing: An exponential function has no turning point.

4. The outputs 7,11,19,357, 11, 19, 35 do not have a constant ratio. Which statement shows that kk is still an exponential function shifted vertically?

  1. The differences 4,8,164, 8, 16 between outputs show that kk is linear
  2. The outputs increase faster and faster, so kk is exponential
  3. The values k(x)−3k(x) - 3 are 4,8,16,324, 8, 16, 32: they double each step
  4. The ratio of the last output to the first, 357=5\frac{35}{7} = 5, is constant
Show the answer

Subtract 33 from every output: 4,8,16,324, 8, 16, 32. Over equal steps these have a constant ratio of 22, so k(x)−3=4(2)xk(x) - 3 = 4(2)^x and k(x)=4(2)x+3k(x) = 4(2)^x + 3, an exponential function shifted up 33.

  • The differences 4,8,164, 8, 16 between outputs show that kk is linear: Linear needs constant differences; these double.
  • The outputs increase faster and faster, so kk is exponential: Increasing outputs fit many functions.
  • Correct: The values k(x)−3k(x) - 3 are 4,8,16,324, 8, 16, 32: they double each step: Shifted outputs that are proportional.
  • The ratio of the last output to the first, 357=5\frac{35}{7} = 5, is constant: One ratio across the table does not show a pattern over equal steps.

6. Why does an exponential function f(x)=abxf(x) = ab^x have no local maximum or minimum?

  1. Its outputs are all positive, so the graph stays above the xx-axis
  2. Its graph has a horizontal asymptote that it never reaches
  3. It is concave up, so the graph bends the same way everywhere
  4. Each unit step multiplies the output by bb, so it moves one way only
Show the answer

Over every unit step the output is multiplied by bb. If b>1b > 1 every step moves the output away from 00 in the same direction; if 0<b<10 < b < 1, every step moves it toward 00. The function is increasing everywhere or decreasing everywhere, so it never turns.

  • Its outputs are all positive, so the graph stays above the xx-axis: If a<0a < 0 the outputs are negative, and there is still no extremum.
  • Its graph has a horizontal asymptote that it never reaches: Many functions with asymptotes have extrema.
  • It is concave up, so the graph bends the same way everywhere: Concave-up functions such as x2x^2 can have a minimum.
  • Correct: Each unit step multiplies the output by bb, so it moves one way only: One fixed factor, one direction.

Part 9 · Summary

Summary

f(x)=abxf(x) = ab^x is monotonic with one concavity and a horizontal asymptote, written in limit notation. The base is the growth factor (1+1 + the percent change as a decimal). Adding kk moves the asymptote to y=ky = k; the natural base ee is one choice of bb.
