Formulas and identities to know

The exam gives no formula sheet. These are the formulas and identities to know by heart, what each is for and when to use it.

Three habits that save points

  • Use the numbers you are given. A reason earns the point when it cites specific values of the function (two inputs with the same output), not a rule such as "it fails the horizontal line test".
  • Three decimal places, never partway. On a calculator question, write the equation you solve, store every value, and round or truncate only the final answer, to three places after the decimal point.
  • Radian mode and exact values. Every angle is in radians. Without a calculator, give exact values (fractions, roots, π, e, logarithms) and combine to one logarithm or one trigonometric term when asked.

Easy to forget

  • Three decimal places, never partway. Store every constant and intermediate value in the calculator and round only the final answer. A model built from rounded constants often misses the third decimal place. Function Model Construction and Application
  • Every solution in the interval. A calculator or inverse function gives one solution. Widen the window, use symmetry or add a period, and list every solution in the stated interval, with no extras. Trigonometric Equations and Inequalities
  • sin−1⁡x\sin^{-1} x is not 1sin⁡x\frac{1}{\sin x}. The −1-1 means the inverse function, whose outputs are in [−π2,π2]\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]. The reciprocal is csc⁡x\csc x. Inverse Trigonometric Functions
  • logb⁡(m+n)\log_b(m + n) has no rule. Only products, quotients and powers inside a logarithm can be split. ln⁡(x2)=2ln⁡x\ln(x^2) = 2\ln x only for x>0x > 0. Logarithmic Function Manipulation
  • exe^x is never 0 or negative. In an equation quadratic in exe^x, reject the root where exe^x would be 0 or negative, and say why. Exponential and Logarithmic Equations and Inequalities
  • bb is not the period. The period of sin⁡(bx)\sin(bx) is 2πb\frac{2\pi}{b}, so b=2πperiodb = \frac{2\pi}{\text{period}}. Factor bb out before reading the phase shift. Sinusoidal Function Transformations
  • Both sides of a vertical asymptote. Write each one-sided limit with its sign: limx→c−\lim_{x \to c^-} and limx→c+\lim_{x \to c^+}. Rational Functions and Vertical Asymptotes
  • Invertible needs values. Show two inputs with the same output (not invertible), or explain why every output comes from one input. "Fails the horizontal line test" alone earns nothing. Inverse Functions
