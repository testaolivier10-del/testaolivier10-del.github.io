An exponential function $f(x) = ab^x$, with $a \ne 0$, $b > 0$ and $b \ne 1$, multiplies its output by $b$ for every unit of input. That one fact decides the shape of every exponential graph: which way it goes, how it bends, and the line it creeps toward. This page reads those features off the formula and writes them the way the exam scores them.

Growth and decay

The number $a$ is the output at $x = 0$, since $b^0 = 1$. The base $b$ decides the direction:

  • $b > 1$: each step multiplies by more than $1$. With $a > 0$, the function is increasing: exponential growth.
  • $0 < b < 1$: each step multiplies by less than $1$. With $a > 0$, the function is decreasing: exponential decay.

Because every step multiplies by the same $b$, the outputs never turn around. An exponential function is increasing everywhere or decreasing everywhere, so it has no local maximum or minimum. It also has one concavity: concave up when $a > 0$, concave down when $a < 0$ (a reflection across the $x$-axis). So it has no point of inflection either.

In the figure, $g$ is decreasing and concave up. Its average rates of change over equal intervals are negative but get closer to $0$: the graph falls, more and more gently. In precalculus words: $g$ is decreasing, and the rate of change of $g$ is increasing.

Horizontal asymptotes and limit notation

Multiplying by $\frac{1}{2}$ again and again makes a number as close to $0$ as you like, without reaching it. So one side of every exponential graph approaches a horizontal asymptote. The readers expect limit notation, written in full:

FunctionOne sideOther side
$f(x) = 3(2)^x$ (growth)$\lim_{x \to -\infty} f(x) = 0$$\lim_{x \to \infty} f(x) = \infty$
$g(x) = 3\left(\frac{1}{2}\right)^x$ (decay)$\lim_{x \to \infty} g(x) = 0$$\lim_{x \to -\infty} g(x) = \infty$

Adding a constant moves the asymptote. For $h(x) = ab^x + k$, the exponential part approaches $0$, so $h$ approaches $k$, and the asymptote is $y = k$.

Worked example 1. Describe $h(x) = 2\left(\frac{1}{2}\right)^x + 1$.

The base $\frac{1}{2}$ and $a = 2 > 0$: $h$ is decreasing and concave up.

Right side: $2\left(\frac{1}{2}\right)^x \to 0$, so $\lim_{x \to \infty} h(x) = 1$. Left side: $\left(\frac{1}{2}\right)^x = 2^{-x}$ grows without bound, so $\lim_{x \to -\infty} h(x) = \infty$.

The exponential part takes every positive value, so the range of $h$ is $(1, \infty)$. The asymptote value $1$ itself is never reached.

Spotting a shifted exponential in a table

If the outputs do not have a constant ratio, try subtracting a constant first. The outputs $7, 11, 19, 35$ at $x = 0, 1, 2, 3$ have ratios that change, but $7 - 3, 11 - 3, 19 - 3, 35 - 3$ are $4, 8, 16, 32$, which double each step. So $k(x) = 4(2)^x + 3$: an exponential function shifted up $3$, with asymptote $y = 3$.

Growth factors and percent change

In context, the base is called the growth factor (or decay factor). A percent change of $r$ (written as a decimal) gives $b = 1 + r$.

Worked example 2. A town of $8{,}000$ people grows $4\%$ a year; a $\$20{,}000$ car loses $15\%$ of its value a year. Write each model.

Town: each year is $104\%$ of the last, so $b = 1 + 0.04 = 1.04$ and $P(t) = 8000(1.04)^t$.

Car: each year keeps $85\%$ of the value, so $b = 1 - 0.15 = 0.85$ and $V(t) = 20{,}000(0.85)^t$.

Read it backward too: $Q(t) = 300(0.92)^t$ has $b = 0.92 = 1 - 0.08$, an $8\%$ decrease each unit.

The natural base $e$

One base turns up so often in science and finance that it has its own letter: $e \approx 2.71828$, the natural base. $f(x) = e^x$ is an exponential function like any other, increasing and concave up with $\lim_{x \to -\infty} e^x = 0$. Your calculator has an $e^x$ key; use it rather than typing $2.7$, which changes the third decimal place.
