Unit 2 begins with lists of numbers in order. A loyalty card that adds $4$ stamps per visit and a video whose shares triple every hour both make lists, but one adds the same amount each time and the other multiplies by the same amount. That one difference, adding versus multiplying, runs through the whole unit.

Sequences are functions

A sequence is an ordered list of numbers, called terms. The position is the input and the term is the output, so a sequence is a function whose inputs are whole numbers. We write the terms $a_0, a_1, a_2, \ldots$ (or start at $a_1$; the problem will say). Because there is no term at position $1.5$, the graph of a sequence is a set of separate dots, not a connected curve.

Arithmetic sequences: add the same amount

In an arithmetic sequence, each term is the previous term plus a fixed number $d$, the common difference. Starting from $a_0$, after $n$ steps you have added $d$ exactly $n$ times:

$$a_n = a_0 + dn$$

If you know some other term $a_k$, count the steps from it: $a_n = a_k + d(n - k)$. The terms change by equal amounts, so the dots lie on a line with slope $d$.

Worked example 1. An arithmetic sequence has $a_4 = 19$ and $a_{10} = 43$. Find $d$ and a formula for $a_n$.

From $n = 4$ to $n = 10$ is $10 - 4 = 6$ steps, and the terms rise by $43 - 19 = 24$.

Each step adds the same amount, so $d = \frac{24}{6} = 4$.

From the known term: $a_n = 19 + 4(n - 4)$. Check: $a_{10} = 19 + 4(6) = 43$.

Geometric sequences: multiply by the same amount

In a geometric sequence, each term is the previous term times a fixed number $r$, the common ratio. After $n$ steps from $g_0$ you have multiplied by $r$ exactly $n$ times:

$$g_n = g_0 r^n$$

From a known term $g_k$: $g_n = g_k r^{n - k}$. To find $r$, divide a term by the one before it.

Worked example 2. A geometric sequence has $g_2 = 12$ and $g_5 = 96$. Find $r$ and $g_n$.

From $n = 2$ to $n = 5$ is $3$ steps, so $g_5 = g_2 r^3$.

Substitute: $96 = 12r^3$. Divide by $12$: $r^3 = 8$. Take the cube root: $r = 2$.

So $g_n = 12(2)^{n - 2}$. Check: $g_5 = 12 \cdot 2^3 = 96$.

Watch the exponent. If the first term is $g_1$, then $g_n = g_1 r^{n - 1}$, because getting from position $1$ to position $n$ takes $n - 1$ steps. Writing $g_1 r^n$ is the most common slip.

An arithmetic sequence changes by equal amounts. An increasing geometric sequence changes by increasing amounts, and the changes themselves are multiplied by $r$ each step. That is why the geometric sequence, though it starts lower, passes the arithmetic one at $n = 5$ and then pulls away. With $0 < r < 1$ the terms shrink instead, by smaller and smaller amounts, as in $48, 24, 12, 6, 3$.
