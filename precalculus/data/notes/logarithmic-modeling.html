Some quantities rise quickly at first and then more and more slowly, without stopping: skill with practice, a sapling's height, sales after a launch. When the input has to multiply to give equal increases in the output, a logarithmic model fits. This page shows how to recognize that pattern, build the model from points or by regression, use it to predict, and say where it stops making sense.

Recognizing logarithmic data

Compare the three patterns side by side.

The logarithmic row is the exponential row with inputs and outputs swapped, which is what you would expect from inverse functions.

Worked example 1. Typing speed $y$ after $x$ hours: $(1, 20)$, $(3, 26)$, $(9, 32)$, $(27, 38)$, $(81, 44)$. Which model fits, and why?

The inputs are not equally spaced ($2$, $6$, $18$, $54$ apart), so equal differences in $y$ do not mean linear.

The inputs are each $3$ times the one before, and the outputs each increase by $6$. Equal ratios in, equal differences out: logarithmic.

Building the model from points

For $y = a + b\log_c x$, a point with $x = 1$ gives $a$ at once, because $\log_c 1 = 0$. A second point gives $b$.

Worked example 2. Fit $y = a + b\log_3 x$ to the typing data.

At $x = 1$: $a = 20$.

At $x = 3$: $20 + b \cdot 1 = 26$, so $b = 6$. The model is $y = 20 + 6\log_3 x$; every other point checks, for example $20 + 6 \cdot 4 = 44$ at $x = 81$.

With base $e$ and no point at $x = 1$, write two equations, $a + b\ln x_1 = y_1$ and $a + b\ln x_2 = y_2$, and solve the system.

Logarithmic regression

Real data are never exact. A graphing calculator's logarithmic regression fits $y = a + b\ln x$. Store $a$ and $b$ with full precision; rounding them first can change the third decimal place of every later answer. Check the fit with a residual plot: residuals scattered with no pattern support the model.

Using the model

Worked example 3. With $y = 20 + 6\log_3 x$, when does the speed reach $35$ words per minute?

$6\log_3 x = 15$, so $\log_3 x = 2.5$.

Exponential form: $x = 3^{2.5} = 9\sqrt{3} \approx 15.6$ hours.

The same idea with a regression model: $a + b\ln x = 60$ gives $x = e^{(60 - a)/b}$.

Rate of change and its meaning

For $b > 0$, a logarithmic model is increasing and concave down. Average rates of change over later intervals are smaller: in context, each extra unit of input adds less than the one before. And doubling the input always adds the same amount, $b\ln 2$. For $y = 52 + 18\ln x$, each doubling of weeks adds about $12.5$ words per minute.

Where the model stops working

  • Near $x = 0$. $\lim_{x \to 0^+}(a + b\ln x) = -\infty$, so the model eventually gives negative speeds or heights. The context rules those inputs out.
  • Far past the data. The model keeps rising without bound, but nothing in the data says the real quantity does. Past the last data point there is no evidence for the model, so error can grow.

When you explain either one, name the specific values and say what goes wrong in context.
