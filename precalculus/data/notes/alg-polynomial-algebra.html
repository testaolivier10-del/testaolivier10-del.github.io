Unit 1 studies functions built from powers of $x$: their zeros, their turning points, how fast they change. The zeros come from factors, so this page collects the algebra: multiplying polynomials and factoring them.

Polynomials

A polynomial is a sum of terms of the form $ax^n$, where $n$ is a whole number: $x^3 + x^2 - 7x + 2$, $4x^2 - 25$, $x^4 - 5x^2 + 4$. No variables in denominators, no square roots of $x$. Writing the terms from the highest power to the lowest makes them easy to compare.

Multiplying

Multiply each term of one factor by each term of the other, then combine like terms.

Worked example 1. Multiply $(x - 2)(x^2 + 3x - 1)$.

$x \cdot (x^2 + 3x - 1) = x^3 + 3x^2 - x$.

$-2 \cdot (x^2 + 3x - 1) = -2x^2 - 6x + 2$.

Add: $x^3 + (3 - 2)x^2 + (-1 - 6)x + 2 = x^3 + x^2 - 7x + 2$.

Squares of sums have a middle term: $(2x + 1)^2 = 4x^2 + 4x + 1$, never $4x^2 + 1$. When subtracting a product, put it in parentheses so the minus sign reaches every term.

Factoring: the order to try

Factoring undoes multiplying. Work through these in order:

  1. Common factor. $x^3 - 9x = x(x^2 - 9)$.
  2. Patterns. Check each factor against the table below.
  3. Grouping for four terms: pair them so each pair shares a binomial.
  4. Quadratic-style trinomials, including ones in $x^2$, like $x^4 - 5x^2 + 4$.
PatternFactoredExample
difference of squares $a^2 - b^2$$(a - b)(a + b)$$4x^2 - 25 = (2x - 5)(2x + 5)$
difference of cubes $a^3 - b^3$$(a - b)(a^2 + ab + b^2)$$x^3 - 27 = (x - 3)(x^2 + 3x + 9)$
sum of cubes $a^3 + b^3$$(a + b)(a^2 - ab + b^2)$$x^3 + 8 = (x + 2)(x^2 - 2x + 4)$

A sum of squares, like $x^2 + 9$, does not factor with real numbers.

Worked example 2. Factor $x^3 + 2x^2 - 4x - 8$.

Group: $(x^3 + 2x^2) + (-4x - 8) = x^2(x + 2) - 4(x + 2)$.

Take out $(x + 2)$: $(x^2 - 4)(x + 2)$. Then $x^2 - 4 = (x - 2)(x + 2)$.

Result: $(x - 2)(x + 2)^2$.

Worked example 3. Factor $x^4 - 5x^2 + 4$.

It is a quadratic in $x^2$. With $u = x^2$: $u^2 - 5u + 4 = (u - 1)(u - 4)$.

Put $x^2$ back: $(x^2 - 1)(x^2 - 4) = (x - 1)(x + 1)(x - 2)(x + 2)$.

Factors and zeros

If a product is $0$, one of its factors is $0$. So the solutions of $x(x - 3)(x + 3) = 0$ are $x = 0$, $3$ and $-3$. The connection also runs backward: if $p(a) = 0$, then $x - a$ is a factor of $p(x)$. For $p(x) = x^3 - 4x^2 + x + 6$, $p(2) = 0$, so $x - 2$ is a factor, and $p(x) = (x - 2)(x - 3)(x + 1)$.

Do not divide an equation by $x$ to simplify it. Dividing assumes $x \ne 0$ and silently drops the solution $x = 0$.
