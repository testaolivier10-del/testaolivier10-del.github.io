3Trigonometric and Polar Functions

Unit 2 begins with lists of numbers in order. A loyalty card that adds 44 stamps per visit and a video whose shares triple every hour both make lists, but one adds the same amount each time and the other multiplies by the same amount. That one difference, adding versus multiplying, runs through the whole unit.

Sequences are functions

A sequence is an ordered list of numbers, called terms. The position is the input and the term is the output, so a sequence is a function whose inputs are whole numbers. We write the terms a0,a1,a2,…a_0, a_1, a_2, \ldots (or start at a1a_1; the problem will say). Because there is no term at position 1.51.5, the graph of a sequence is a set of separate dots, not a connected curve.

Arithmetic sequences: add the same amount

In an arithmetic sequence, each term is the previous term plus a fixed number dd, the common difference. Starting from a0a_0, after nn steps you have added dd exactly nn times:

an=a0+dna_n = a_0 + dn

If you know some other term aka_k, count the steps from it: an=ak+d(n−k)a_n = a_k + d(n - k). The terms change by equal amounts, so the dots lie on a line with slope dd.

Worked example 1. An arithmetic sequence has a4=19a_4 = 19 and a10=43a_{10} = 43. Find dd and a formula for ana_n.

From n=4n = 4 to n=10n = 10 is 10−4=610 - 4 = 6 steps, and the terms rise by 43−19=2443 - 19 = 24.

Each step adds the same amount, so d=246=4d = \frac{24}{6} = 4.

From the known term: an=19+4(n−4)a_n = 19 + 4(n - 4). Check: a10=19+4(6)=43a_{10} = 19 + 4(6) = 43.

Geometric sequences: multiply by the same amount

In a geometric sequence, each term is the previous term times a fixed number rr, the common ratio. After nn steps from g0g_0 you have multiplied by rr exactly nn times:

gn=g0rng_n = g_0 r^n

From a known term gkg_k: gn=gkrn−kg_n = g_k r^{n - k}. To find rr, divide a term by the one before it.

Worked example 2. A geometric sequence has g2=12g_2 = 12 and g5=96g_5 = 96. Find rr and gng_n.

From n=2n = 2 to n=5n = 5 is 33 steps, so g5=g2r3g_5 = g_2 r^3.

Substitute: 96=12r396 = 12r^3. Divide by 1212: r3=8r^3 = 8. Take the cube root: r=2r = 2.

So gn=12(2)n−2g_n = 12(2)^{n - 2}. Check: g5=12⋅23=96g_5 = 12 \cdot 2^3 = 96.

Watch the exponent. If the first term is g1g_1, then gn=g1rn−1g_n = g_1 r^{n - 1}, because getting from position 11 to position nn takes n−1n - 1 steps. Writing g1rng_1 r^n is the most common slip.

Equal changes versus growing changes

An arithmetic sequence changes by equal amounts. An increasing geometric sequence changes by increasing amounts, and the changes themselves are multiplied by rr each step. That is why the geometric sequence, though it starts lower, passes the arithmetic one at n=5n = 5 and then pulls away. With 0<r<10 < r < 1 the terms shrink instead, by smaller and smaller amounts, as in 48,24,12,6,348, 24, 12, 6, 3.
