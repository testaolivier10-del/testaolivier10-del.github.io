3Trigonometric and Polar Functions

The same exponential function can wear many outfits. 2x+32^{x + 3}, 8(2)x8(2)^x and 4(2)x+14(2)^{x + 1} are one function. 5(4)x5(4)^x and 5(2)2x5(2)^{2x} are one function. The exponent rules from "Algebra you need" turn one form into another, and each form has a graphical meaning. This page shows both, because the exam asks you to rewrite exponential expressions exactly and to explain what the rewriting says about the graph.

The rules you use

RuleRewriteWhat it says about the graph
Product: bm+n=bmbnb^{m + n} = b^m b^nbx+k=bk⋅bxb^{x + k} = b^k \cdot b^xA horizontal translation is a vertical dilation by bkb^k
Power: bmn=(bm)nb^{mn} = (b^m)^nbcx=(bc)xb^{cx} = (b^c)^xA horizontal dilation is a change of base
Negative: b−n=1bnb^{-n} = \frac{1}{b^n}b−x=(1b)xb^{-x} = \left(\frac{1}{b}\right)^xReflecting growth across the yy-axis gives decay
Rational: b1/n=bnb^{1/n} = \sqrt[n]{b}bx/n=(bn)xb^{x/n} = (\sqrt[n]{b})^xA horizontal stretch by nn takes the nnth root of the base

A horizontal shift is a vertical stretch

For most functions, moving the graph sideways and stretching it upward are different things. For an exponential function they are the same.

Worked example 1. Show that h(x)=2x+3h(x) = 2^{x + 3} is a vertical dilation of y=2xy = 2^x.

The exponent is a sum, so use the product rule backward: 2x+3=2x⋅232^{x + 3} = 2^x \cdot 2^3.

23=82^3 = 8, so h(x)=8(2)xh(x) = 8(2)^x. Every output of 2x2^x is multiplied by 88.

Check one point: h(0)=23=8h(0) = 2^3 = 8 and 8(2)0=88(2)^0 = 8.

In the figure, the point (0,1)(0, 1) on 2x2^x moves to (−3,1)(-3, 1) under the shift, and the point (0,1)(0, 1) also lines up with (0,8)(0, 8) under the stretch. Shifting right instead divides: 5(4)x−1=54(4)x5(4)^{x - 1} = \frac{5}{4}(4)^x.

The trap is reading 2x+32^{x + 3} as 2x+232^x + 2^3. Adding in the exponent means multiplying the powers. Test it: at x=1x = 1, 24=162^4 = 16 but 21+8=102^1 + 8 = 10.

A horizontal dilation is a new base

Worked example 2. Rewrite g(x)=5(4)xg(x) = 5(4)^x with base 22, and 23x2^{3x} with a single base.

4=224 = 2^2, so 4x=(22)x=22x4^x = (2^2)^x = 2^{2x}. Then g(x)=5(2)2xg(x) = 5(2)^{2x}: the graph of 5(2)x5(2)^x compressed horizontally by a factor of 12\frac{1}{2}.

23x=(23)x=8x2^{3x} = (2^3)^x = 8^x: compressing 2x2^x by a factor of 13\frac{1}{3} gives base 88.

It works with fractions too. 25x/225^{x/2}=(251/2)x= (25^{1/2})^x=5x= 5^x, and (13)x\left(\frac{1}{3}\right)^x=(3−1)x= (3^{-1})^x=3−x= 3^{-x}.

Rewriting with every step shown

Rewrite each base as a power of a common base, apply the power rule to the whole exponent, then combine.

Worked example 3. Write 4x+12x\frac{4^{x + 1}}{2^x} as a single power of 22.

Common base: 4x+1=(22)x+14^{x + 1} = (2^2)^{x + 1}.

Power rule on the whole exponent: (22)x+1(2^2)^{x + 1}=22(x+1)= 2^{2(x + 1)}=22x+2= 2^{2x + 2}. (Writing 22x+12^{2x + 1} forgets to double the 11.)

Divide, same base, subtract exponents: 22x+22x\frac{2^{2x + 2}}{2^x}=22x+2−x= 2^{2x + 2 - x}=2x+2= 2^{x + 2}.

These rewrites also let you use a known value. If 3x=73^x = 7, then 3x+2=3x⋅32=633^{x + 2} = 3^x \cdot 3^2 = 63, and 32x=(3x)2=493^{2x} = (3^x)^2 = 49.

On the exam, a "single power" answer means one base raised to one exponent, with no sums or quotients left over. Stopping at 22x+22x\frac{2^{2x + 2}}{2^x} is not finished.
