Some quantities rise quickly at first and then more and more slowly, without stopping: skill with practice, a sapling's height, sales after a launch. When the input has to multiply to give equal increases in the output, a logarithmic model fits. This page shows how to recognize that pattern, build the model from points or by regression, use it to predict, and say where it stops making sense.

Recognizing logarithmic data

Compare the three patterns side by side.

ModelInputsOutputs
Linearequal differencesequal differences
Exponentialequal differencesequal ratios
Logarithmicequal ratiosequal differences

The logarithmic row is the exponential row with inputs and outputs swapped, which is what you would expect from inverse functions.

Worked example 1. Typing speed yy after xx hours: (1,20)(1, 20), (3,26)(3, 26), (9,32)(9, 32), (27,38)(27, 38), (81,44)(81, 44). Which model fits, and why?

The inputs are not equally spaced (22, 66, 1818, 5454 apart), so equal differences in yy do not mean linear.

The inputs are each 33 times the one before, and the outputs each increase by 66. Equal ratios in, equal differences out: logarithmic.

Building the model from points

For y=a+blogc⁡xy = a + b\log_c x, a point with x=1x = 1 gives aa at once, because logc⁡1=0\log_c 1 = 0. A second point gives bb.

Worked example 2. Fit y=a+blog3⁡xy = a + b\log_3 x to the typing data.

At x=1x = 1: a=20a = 20.

At x=3x = 3: 20+b⋅1=2620 + b \cdot 1 = 26, so b=6b = 6. The model is y=20+6log3⁡xy = 20 + 6\log_3 x; every other point checks, for example 20+6⋅4=4420 + 6 \cdot 4 = 44 at x=81x = 81.

With base ee and no point at x=1x = 1, write two equations, a+bln⁡x1=y1a + b\ln x_1 = y_1 and a+bln⁡x2=y2a + b\ln x_2 = y_2, and solve the system.

Logarithmic regression

Real data are never exact. A graphing calculator's logarithmic regression fits y=a+bln⁡xy = a + b\ln x. Store aa and bb with full precision; rounding them first can change the third decimal place of every later answer. Check the fit with a residual plot: residuals scattered with no pattern support the model.

Using the model

Worked example 3. With y=20+6log3⁡xy = 20 + 6\log_3 x, when does the speed reach 3535 words per minute?

6log3⁡x=156\log_3 x = 15, so log3⁡x=2.5\log_3 x = 2.5.

Exponential form: x=32.5=93≈15.6x = 3^{2.5} = 9\sqrt{3} \approx 15.6 hours.

The same idea with a regression model: a+bln⁡x=60a + b\ln x = 60 gives x=e(60−a)/bx = e^{(60 - a)/b}.

Rate of change and its meaning

For b>0b > 0, a logarithmic model is increasing and concave down. Average rates of change over later intervals are smaller: in context, each extra unit of input adds less than the one before. And doubling the input always adds the same amount, bln⁡2b\ln 2. For y=52+18ln⁡xy = 52 + 18\ln x, each doubling of weeks adds about 12.512.5 words per minute.

Where the model stops working

  • Near x=0x = 0. limx→0+(a+bln⁡x)\lim_{x \to 0^+}(a + b\ln x)=−∞= -\infty, so the model eventually gives negative speeds or heights. The context rules those inputs out.
  • Far past the data. The model keeps rising without bound, but nothing in the data says the real quantity does. Past the last data point there is no evidence for the model, so error can grow.

When you explain either one, name the specific values and say what goes wrong in context.
