When the unknown sits in an exponent or inside a logarithm, the usual algebra moves are not enough. The fix is the inverse pair from earlier topics: a logarithm undoes an exponential, and an exponential undoes a logarithm. This page solves both kinds of equations exactly, shows where extraneous solutions come from, handles equations that are quadratic in exe^x, and solves inequalities.

Exponential equations

An exponential equation has the unknown in an exponent. First isolate the power. Then either write both sides with the same base and set the exponents equal, or take a logarithm of both sides.

Worked example 1 (common base). Solve 4x+1=8x4^{x + 1} = 8^x.

Both are powers of 22: 4x+14^{x + 1}=22(x+1)= 2^{2(x + 1)}=22x+2= 2^{2x + 2} and 8x=23x8^x = 2^{3x}.

Equal powers of 22 have equal exponents: 2x+2=3x2x + 2 = 3x, so x=2x = 2.

Worked example 2 (take a logarithm). Solve 5e3x−2=335e^{3x} - 2 = 33 exactly.

Isolate the power: 5e3x=355e^{3x} = 35, so e3x=7e^{3x} = 7.

Take ln⁡\ln of both sides: 3x=ln⁡73x = \ln 7, so x=ln⁡73x = \frac{\ln 7}{3}.

On a no-calculator question, leave the answer exact, as ln⁡73\frac{\ln 7}{3}. Rounding it loses the point.

Logarithmic equations and extraneous solutions

A logarithmic equation has the unknown inside a logarithm. Use the properties of logarithms to get a single logarithm, then rewrite in exponential form.

Worked example 3. Solve log3⁡x+log3⁡(x−8)\log_3 x + \log_3(x - 8)=2= 2.

Product property: log3⁡(x(x−8))=2\log_3(x(x - 8)) = 2.

Exponential form: x(x−8)=32=9x(x - 8) = 3^2 = 9, so x2−8x−9=0x^2 - 8x - 9 = 0 and (x−9)(x+1)=0(x - 9)(x + 1) = 0.

Check in the original. x=9x = 9: log3⁡9+log3⁡1\log_3 9 + \log_3 1=2+0= 2 + 0=2= 2. It works. x=−1x = -1: log3⁡(−1)\log_3(-1) is undefined. It is an extraneous solution.

Answer: x=9x = 9.

Why do extra roots appear? The original equation needs x>0x > 0 and x−8>0x - 8 > 0. The combined form log3⁡(x(x−8))\log_3(x(x - 8)) only needs the product to be positive, which also happens when both factors are negative. Combining logarithms quietly widened the domain.

Equations quadratic in exe^x

Since e2x=(ex)2e^{2x} = (e^x)^2, an equation such as e2x−ex−12=0e^{2x} - e^x - 12 = 0 is a quadratic in disguise.

Worked example 4. Solve e2x−ex−12=0e^{2x} - e^x - 12 = 0.

Let u=exu = e^x: u2−u−12=0u^2 - u - 12 = 0, so (u−4)(u+3)=0(u - 4)(u + 3) = 0 and u=4u = 4 or u=−3u = -3.

ex=4e^x = 4 gives x=ln⁡4x = \ln 4.

ex=−3e^x = -3 has no solution, because ex>0e^x > 0 for every real xx. Say so in words when you reject it.

Inverses of transformed functions

The same moves find inverses. For f(x)=5e2x−1f(x) = 5e^{2x} - 1: swap to x=5e2y−1x = 5e^{2y} - 1, undo the outer steps in reverse order (e2y=x+15e^{2y} = \frac{x + 1}{5}), then take ln⁡\ln: f−1(x)f^{-1}(x)=12ln⁡x+15= \frac{1}{2}\ln \frac{x + 1}{5}. For f(x)=log2⁡(x+1)f(x) = \log_2(x + 1): x=log2⁡(y+1)x = \log_2(y + 1) gives y+1=2xy + 1 = 2^x, so f−1(x)=2x−1f^{-1}(x) = 2^x - 1.
