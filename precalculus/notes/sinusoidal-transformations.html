Every sinusoidal function can be written with one formula,

f(θ)f(\theta)=asin⁡(b(θ+c))+d= a\sin(b(\theta + c)) + d or f(θ)f(\theta)=acos⁡(b(θ+c))+d= a\cos(b(\theta + c)) + d,

where aa and bb are not zero. Each constant is one of the transformations from Unit 1 applied to the sine graph. This page shows what each one does, then how to run the process backward: read a graph and write its formula.

What each constant does

ConstantTransformationFeature it sets
aavertical dilation by |a||a|; reflection across the midline if a<0a < 0amplitude |a||a|
bbhorizontal dilation by 1|b|\frac{1}{|b|}period 2π|b|\frac{2\pi}{|b|}
cchorizontal translation by −c-cphase shift: left cc if c>0c > 0
ddvertical translation by ddmidline y=dy = d

Why the period is 2π|b|\frac{2\pi}{|b|}. sin⁡(bθ)\sin(b\theta) completes one cycle while bθb\theta runs from 00 to 2π2\pi, which happens while θ\theta runs from 00 to 2πb\frac{2\pi}{b}. A bigger bb squeezes more cycles into the same space, so the period shrinks. Turned around, this is the rule the exam asks for again and again:

b=2πperiodb = \frac{2\pi}{\text{period}}.

In context the period is often hidden in a frequency. A spring that bounces 2 times per second has period 12\frac{1}{2} second, so b=2π1/2=4πb = \frac{2\pi}{1/2} = 4\pi, not 2π2\frac{2\pi}{2}.

Why the shift is −c-c. The sine graph starts a cycle (crosses its midline going up) where its input is 00. For sin⁡(b(θ+c))\sin(b(\theta + c)) that is where θ+c=0\theta + c = 0, at θ=−c\theta = -c. So c>0c > 0 moves the graph left. This is the same rule as f(x+3)f(x + 3) moving a graph left 3.

Worked example 1. Describe f(θ)f(\theta)=−3sin⁡(2θ+π)+4= -3\sin(2\theta + \pi) + 4.

Factor bb out of the input first: 2θ+π=2(θ+π2)2\theta + \pi = 2\left(\theta + \frac{\pi}{2}\right), so c=π2c = \frac{\pi}{2}.

Amplitude |−3|=3|-3| = 3, reflected across the midline. Period 2π2=π\frac{2\pi}{2} = \pi. Phase shift π2\frac{\pi}{2} to the left. Midline y=4y = 4, so the values run from 11 to 77.

Sine and cosine are shifts of each other

Cosine is sine moved π2\frac{\pi}{2} to the left: cos⁡θ=sin⁡(θ+π2)\cos\theta = \sin\left(\theta + \frac{\pi}{2}\right). So every sinusoid has a sine formula and a cosine formula. A reflection gives more: −cos⁡θ=sin⁡(θ−π2)-\cos\theta = \sin\left(\theta - \frac{\pi}{2}\right). On the exam, any correct formula earns the points; choose the one that makes cc easiest to read.

From a graph to a formula

  1. Midline: d=max⁡+min⁡2d = \frac{\max + \min}{2}.
  2. Amplitude: |a|=max⁡−min⁡2|a| = \frac{\max - \min}{2}.
  3. Period: measure one cycle, then b=2πperiodb = \frac{2\pi}{\text{period}}.
  4. Shift: pick a landmark. For sine with a>0a > 0, use a midline crossing where the graph is rising: c=−(its input)c = -(\text{its input}). For cosine with a>0a > 0, use a highest point. For cosine with a<0a < 0, use a lowest point.

Worked example 2. A sinusoid has a highest point at (π,4)(\pi, 4) and lowest points at (0,−2)(0, -2) and (2π,−2)(2\pi, -2). Write a formula.

Midline d=4+(−2)2=1d = \frac{4 + (-2)}{2} = 1. Amplitude 4−(−2)2=3\frac{4 - (-2)}{2} = 3. Period 2π2\pi (lowest to lowest), so b=1b = 1.

With cosine and a=3a = 3, the highest point should sit where the input is 00; here it is at θ=π\theta = \pi, a shift right π\pi: f(θ)=3cos⁡(θ−π)+1f(\theta) = 3\cos(\theta - \pi) + 1.

With cosine and a=−3a = -3 (a reflected cosine starts at a lowest point), the lowest point at θ=0\theta = 0 needs no shift: f(θ)=−3cos⁡θ+1f(\theta) = -3\cos\theta + 1. With sine and a=3a = 3: the graph crosses the midline going up halfway between (0,−2)(0, -2) and (π,4)(\pi, 4), at θ=π2\theta = \frac{\pi}{2}, so f(θ)f(\theta)=3sin⁡(θ−π2)+1= 3\sin\left(\theta - \frac{\pi}{2}\right) + 1. All three are the same function.

Worked example 3. Write a sinusoid with amplitude 2, period π\pi and midline y=−1y = -1 whose graph crosses its midline going up at θ=0\theta = 0.

b=2ππ=2b = \frac{2\pi}{\pi} = 2. A sine with a>0a > 0 already rises through its midline at 00, so c=0c = 0: f(θ)=2sin⁡(2θ)−1f(\theta) = 2\sin(2\theta) - 1.

Common slips

  • Reading the shift before factoring: sin⁡(3θ−π)\sin(3\theta - \pi) shifts right π3\frac{\pi}{3}, not π\pi.
  • Using the period as bb, or the frequency as the period: bb is 2π2\pi divided by the period.
  • Using max⁡−min⁡\max - \min as the amplitude: it is half of that.
  • Forgetting the sign of the shift: θ−2\theta - 2 moves right, θ+2\theta + 2 moves left.
