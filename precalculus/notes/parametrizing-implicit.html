SAlgebra you need

Beyond the exam. The AP® Precalculus exam does not test this unit. Many classes teach it, and it prepares you for calculus.

You can now describe curves two ways: as an equation in xx and yy (an implicitly defined curve) and as a parametric function (x(t),y(t))(x(t), y(t)). This page turns the first kind into the second, and back. Turning an equation into parametric equations is called finding a parametrization.

Graphs of functions

The easiest case: if the curve is y=f(x)y = f(x), let xx itself be the parameter.

x(t)=t,y(t)=f(t).x(t) = t, \qquad y(t) = f(t).

For y=x2−3xy = x^2 - 3x, use (t,t2−3t)(t, t^2 - 3t); it traces the parabola from left to right as tt increases. If the curve is x=g(y)x = g(y), a function of yy, use yy as the parameter instead: x=y2+1x = y^2 + 1 becomes (t2+1,t)(t^2 + 1, t), traced from bottom to top.

Ellipses: the Pythagorean identity

For (x−h)2a2+(y−k)2b2\frac{(x - h)^2}{a^2} + \frac{(y - k)^2}{b^2}=1= 1, the two fractions are squares that add to 11, just like cos2⁡t+sin2⁡t=1\cos^2 t + \sin^2 t = 1. So set

x−ha=cos⁡t,y−kb=sin⁡t⇒x(t)=h+acos⁡t,y(t)=k+bsin⁡t.\frac{x - h}{a} = \cos t, \quad \frac{y - k}{b} = \sin t \qquad\Rightarrow\qquad x(t) = h + a\cos t, \quad y(t) = k + b\sin t.

Worked example 1. Parametrize (x−1)29+(y−2)24\frac{(x - 1)^2}{9} + \frac{(y - 2)^2}{4}=1= 1.

h=1h = 1, k=2k = 2, a=3a = 3, b=2b = 2: x(t)=1+3cos⁡tx(t) = 1 + 3\cos t, y(t)=2+2sin⁡ty(t) = 2 + 2\sin t, 0≤t≤2π0 \le t \le 2\pi.

Check: (3cos⁡t)29\frac{(3\cos t)^2}{9}+(2sin⁡t)24+ \frac{(2\sin t)^2}{4}=cos2⁡t= \cos^2 t+sin2⁡t+ \sin^2 t=1= 1. The trip starts at (4,2)(4, 2) when t=0t = 0 and goes once around counterclockwise.

As with circles, k−bsin⁡tk - b\sin t reverses the direction, and cos⁡(2t)\cos(2t) and sin⁡(2t)\sin(2t) go around twice as fast. The parameter tt is not the angle of the point from the center unless a=ba = b.

Hyperbolas: the other Pythagorean identity

Divide sin2⁡t+cos2⁡t=1\sin^2 t + \cos^2 t = 1 by cos2⁡t\cos^2 t to get tan2⁡t+1=sec2⁡t\tan^2 t + 1 = \sec^2 t, so sec2⁡t−tan2⁡t=1\sec^2 t - \tan^2 t = 1. A difference of squares equal to 11 is exactly the hyperbola's form:

x(t)=h+asec⁡t,y(t)=k+btan⁡t.x(t) = h + a\sec t, \qquad y(t) = k + b\tan t.

Worked example 2. Parametrize x24−y29=1\frac{x^2}{4} - \frac{y^2}{9} = 1 and say which branch −π2<t<π2-\frac{\pi}{2} < t < \frac{\pi}{2} gives.

x(t)=2sec⁡tx(t) = 2\sec t, y(t)=3tan⁡ty(t) = 3\tan t. Check: 4sec2⁡t4−9tan2⁡t9\frac{4\sec^2 t}{4} - \frac{9\tan^2 t}{9}=sec2⁡t−tan2⁡t= \sec^2 t - \tan^2 t=1= 1.

For −π2<t<π2-\frac{\pi}{2} < t < \frac{\pi}{2}, cos⁡t>0\cos t > 0, so sec⁡t≥1\sec t \ge 1 and x≥2x \ge 2: the right branch. As tt increases, tan⁡t\tan t increases, so the point moves up the branch, from far below to far above. The values t=±π2t = \pm\frac{\pi}{2} are left out, where sec⁡t\sec t and tan⁡t\tan t are undefined; π2<t<3π2\frac{\pi}{2} < t < \frac{3\pi}{2} gives the left branch.

Going back: removing the parameter

To find the equation a parametric curve satisfies, solve each coordinate for the trig function and use the matching identity. For x=1+3cos⁡tx = 1 + 3\cos t, y=2+2sin⁡ty = 2 + 2\sin t: cos⁡t=x−13\cos t = \frac{x - 1}{3} and sin⁡t=y−22\sin t = \frac{y - 2}{2}, so (x−13)2+(y−22)2\left(\frac{x - 1}{3}\right)^2 + \left(\frac{y - 2}{2}\right)^2=1= 1. For polynomials, solve one coordinate for tt and substitute: (t2−1,t)(t^2 - 1, t) gives t=yt = y and x=y2−1x = y^2 - 1.

None of these is the only choice. (t3,t6)(t^3, t^6) also traces all of y=x2y = x^2, because t3t^3 takes every real value. But (t2,t4)(t^2, t^4) traces only the right half, since t2≥0t^2 \ge 0. Always check that the parameter interval covers the whole curve you want, and nothing more.
