A system of equations is a set of equations that share unknowns and must all be true at once. In this course you meet systems every time you build a model from data: each data point gives one equation, and the model's constants are the unknowns. This page shows the two hand methods one step at a time, then how to use a calculator without losing accuracy.

What a solution is

A solution makes every equation true. For two lines, it is the point on both lines: where they cross.

Two lines can also be parallel (same slope, different intercepts), so there is no solution, or be the same line, so every point on it is a solution.

Substitution

Use substitution when one equation already says what a variable equals.

Worked example 1. Solve y=x−1y = x - 1 and 3x+2y=133x + 2y = 13.

Replace yy in the second equation with x−1x - 1, in parentheses: 3x+2(x−1)=133x + 2(x - 1) = 13.

Distribute: 3x+2x−2=133x + 2x - 2 = 13. Combine: 5x−2=135x - 2 = 13. Add 22: 5x=155x = 15. Divide: x=3x = 3.

Back-substitute: y=3−1=2y = 3 - 1 = 2. Check in the other equation: 3(3)+2(2)=9+4=133(3) + 2(2) = 9 + 4 = 13. The solution is (3,2)(3, 2).

Elimination

Use elimination when adding or subtracting the equations makes a variable cancel. Multiply an equation first if the coefficients do not match.

Worked example 2. Solve 2x+3y=122x + 3y = 12 and 4x−3y=64x - 3y = 6.

The yy terms are 3y3y and −3y-3y, so add the equations: 6x=186x = 18, and x=3x = 3.

Substitute into the first: 2(3)+3y=122(3) + 3y = 12, so 3y=63y = 6 and y=2y = 2.

Three unknowns: a quadratic through three points

To find y=ax2+bx+cy = ax^2 + bx + c through three points, substitute each point. The input is squared in the aa term, so write the powers out.

Worked example 3. Find the quadratic through (1,6)(1, 6), (2,11)(2, 11) and (3,18)(3, 18).

(1,6)(1, 6): a(1)2+b(1)+c=6a(1)^2 + b(1) + c = 6, so a+b+c=6a + b + c = 6.

(2,11)(2, 11): a(2)2+b(2)+c=11a(2)^2 + b(2) + c = 11, so 4a+2b+c=114a + 2b + c = 11.

(3,18)(3, 18): a(3)2+b(3)+c=18a(3)^2 + b(3) + c = 18, so 9a+3b+c=189a + 3b + c = 18.

Eliminate cc. Second minus first: 3a+b=53a + b = 5. Third minus second: 5a+b=75a + b = 7.

Eliminate bb. Subtract those two: 2a=22a = 2, so a=1a = 1.

Work back up: 3(1)+b=53(1) + b = 5 gives b=2b = 2; then 1+2+c=61 + 2 + c = 6 gives c=3c = 3. The model is y=x2+2x+3y = x^2 + 2x + 3. Check (2,11)(2, 11): 4+4+3=114 + 4 + 3 = 11.

With a calculator: store, do not round

Real data give messy decimals, and the calculator part of the exam expects you to use the calculator's system solver. The rule the readers enforce: keep every constant at full precision until the final answer, then give that answer correct to three decimal places. If you round aa to two places and then use it to find bb, both bb and every prediction made with the model can come out wrong in the third decimal place, and lose the point.
