3Trigonometric and Polar Functions

In the last topic a logarithm answered the question "which exponent?". This page turns that into a statement about functions: an exponential function and the logarithm with the same base are inverse functions. That one fact explains their graphs, their domains and asymptotes, and the way each one changes.

Two functions that undo each other

Take f(x)=bxf(x) = b^x and g(x)=logb⁡xg(x) = \log_b x, with the same base b>0b > 0, b≠1b \ne 1. If f(a)=cf(a) = c, then ba=cb^a = c, which means logb⁡c=a\log_b c = a, so g(c)=ag(c) = a. Each function sends the other's outputs back to its inputs. They are inverses: g=f−1g = f^{-1}.

Composing them gives the identity function:

  • logb⁡(bx)=x\log_b(b^x) = x for every real number xx;
  • blogb⁡x=xb^{\log_b x} = x for every x>0x > 0 (the logarithm needs a positive input).

The pair used most is exe^x and ln⁡x\ln x: ln⁡(ex)=x\ln(e^x) = x and eln⁡x=xe^{\ln x} = x.

Worked example 1. Evaluate 2log2⁡92^{\log_2 9} and ln⁡e−4\ln e^{-4}.

2x2^x undoes log2⁡x\log_2 x, so 2log2⁡9=92^{\log_2 9} = 9.

ln⁡\ln undoes exe^x, so ln⁡e−4=−4\ln e^{-4} = -4.

How each one changes

An exponential function turns adding to the input into multiplying the output: bx+k=bk⋅bxb^{x + k} = b^k \cdot b^x. For f(x)=2xf(x) = 2^x, each increase of 33 in xx multiplies f(x)f(x) by 23=82^3 = 8.

Its inverse does the reverse: multiplying the input of a logarithm adds to the output. Multiplying xx by 1,000=1031{,}000 = 10^3 adds 33 to log⁡x\log x.

Worked example 2. A table gives h(x)=log4⁡xh(x) = \log_4 x at xx=116,14,1,4,16,64= \frac{1}{16}, \frac{1}{4}, 1, 4, 16, 64. Describe the pattern.

Each input is 44 times the one before, and the outputs are −2,−1,0,1,2,3-2, -1, 0, 1, 2, 3.

So equal factors of 44 in the input give equal steps of 11 in the output. Swap the rows and you get 4x4^x: equal steps of 11 in the input give equal factors of 44 in the output.

Inverting a stretched exponential

When an exponential has other steps around it, undo those steps first, in reverse order, and use the logarithm for the exponential step.

Worked example 3. Find the inverse of f(x)=2exf(x) = 2e^x.

Swap: x=2eyx = 2e^y.

Undo the factor 22: ey=x2e^y = \frac{x}{2}.

Undo ee: y=ln⁡x2y = \ln \frac{x}{2}. So f−1(x)=ln⁡x2f^{-1}(x) = \ln \frac{x}{2}, defined for x>0x > 0, the range of ff.

Reading the inverse in context

If N(t)=500⋅2tN(t) = 500 \cdot 2^t counts bacteria after tt hours, the inverse answers "when?": t=log2⁡N500t = \log_2 \frac{N}{500}. The count 4,0004{,}000 is reached at t=log2⁡8=3t = \log_2 8 = 3 hours. The exponential takes a time and gives a count; its inverse takes a count and gives a time.
