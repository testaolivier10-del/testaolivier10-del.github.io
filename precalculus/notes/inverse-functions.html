3Trigonometric and Polar Functions

A function turns inputs into outputs. Often you need to go the other way: from a Celsius reading back to Fahrenheit, from a price with tax back to the price before tax. The function that runs a process backward is its inverse function. This page shows what an inverse is, when one exists, how to justify that with specific values, and how to find it from a table, a graph or a formula.

What an inverse does

If f(a)=bf(a) = b, the inverse function f−1f^{-1} sends bb back to aa: f−1(b)=af^{-1}(b) = a. Input and output trade places. Read f−1(x)f^{-1}(x) as "f inverse of x".

The −1-1 is part of the name. It does not mean a reciprocal: f−1(x)f^{-1}(x) and 1f(x)\frac{1}{f(x)} are different things. If f(x)=x−5f(x) = x - 5, then f−1(x)=x+5f^{-1}(x) = x + 5, while 1f(x)=1x−5\frac{1}{f(x)} = \frac{1}{x - 5}.

Undoing and redoing gets you back where you started, so composing a function with its inverse gives the identity function: f(f−1(x))=xf(f^{-1}(x)) = x and f−1(f(x))=xf^{-1}(f(x)) = x. This is the best way to check an inverse.

When does an inverse exist?

An inverse must send each output back to one input. If two inputs share an output, say h(1)=1h(1) = 1 and h(3)=1h(3) = 1, then h−1(1)h^{-1}(1) would have to be both 11 and 33. A rule that does that is not a function, so hh has no inverse.

A function in which every output comes from exactly one input is called one-to-one, or invertible. Functions that are always increasing, or always decreasing, are invertible.

Worked example 1 (justify with values). Is f(x)=x2−4xf(x) = x^2 - 4x, defined for every real number, invertible?

Look for two inputs with the same output: f(0)=0f(0) = 0 and f(4)=16−16=0f(4) = 16 - 16 = 0.

Write the reason with those values: "f(0)=f(4)=0f(0) = f(4) = 0, so two inputs share the output 00, and ff has no inverse."

Exam readers give no credit for a bare phrase such as "it fails the horizontal line test" or "it is not one-to-one". Name the inputs and the shared output. And say "ff has no inverse", not "ff is not an inverse".

Inverses from tables and graphs

From a table, swap the rows: the outputs of ff become the inputs of f−1f^{-1}. If f(3)=5f(3) = 5, then f−1(5)=3f^{-1}(5) = 3. The inputs you can use in f−1f^{-1} are exactly the outputs of ff.

On a graph, swapping coordinates turns each point (a,b)(a, b) into (b,a)(b, a). That is a reflection across the line y=xy = x. To read f−1(b)f^{-1}(b) from the graph of ff, find bb on the output axis, go across to the graph, and read the input below it.

Inverses from formulas

Write y=f(x)y = f(x), swap xx and yy, and solve for yy. Another way to think of it: list what ff does to xx, then undo the steps in reverse order.

Worked example 2. Find the inverse of f(x)=x−53f(x) = \frac{x - 5}{3}.

ff subtracts 55, then divides by 33. Undo in reverse: multiply by 33, then add 55.

f−1(x)=3x+5f^{-1}(x) = 3x + 5. Check: f(f−1(x))f(f^{-1}(x))=(3x+5)−53= \frac{(3x + 5) - 5}{3}=x= x.

Worked example 3. Find the inverse of f(x)=2x+1x−3f(x) = \frac{2x + 1}{x - 3}.

Swap: x=2y+1y−3x = \frac{2y + 1}{y - 3}. Multiply by y−3y - 3: xy−3x=2y+1xy - 3x = 2y + 1.

Collect the yy terms on one side: xy−2y=3x+1xy - 2y = 3x + 1, so y(x−2)=3x+1y(x - 2) = 3x + 1.

Divide: f−1(x)f^{-1}(x)=3x+1x−2= \frac{3x + 1}{x - 2}.

Restricting the domain

A function that is not invertible can become invertible on part of its domain. A parabola rises on one side of its vertex and falls on the other, so on either side alone no output repeats.

Worked example 4. Make f(x)=(x−2)2+1f(x) = (x - 2)^2 + 1 invertible and find the inverse.

The vertex is at x=2x = 2. Keep x≥2x \ge 2, where ff is increasing.

Swap: x=(y−2)2+1x = (y - 2)^2 + 1, so (y−2)2=x−1(y - 2)^2 = x - 1. Because y≥2y \ge 2, take the positive root: y−2=x−1y - 2 = \sqrt{x - 1}.

f−1(x)=2+x−1f^{-1}(x) = 2 + \sqrt{x - 1}, for x≥1x \ge 1, the range of ff.
