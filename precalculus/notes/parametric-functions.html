Most graphs you have drawn so far show one quantity against another: yy against xx. A parametric function adds a third quantity that is not drawn at all. It is the clock that tells each point when to appear. This page shows how to read and draw such curves, and why they can do things an ordinary graph cannot.

A parameter runs the show

A parametric function is a pair of functions of one input, written f(t)=(x(t),y(t))f(t) = (x(t), y(t)). The input tt is called the parameter. For each allowed tt, the function x(t)x(t) gives a horizontal position and y(t)y(t) gives a vertical position, so the pair is one point of the plane.

Think of tt as time. A drone's log might say that after tt seconds it is x(t)x(t) meters east and y(t)y(t) meters north of where it took off. The flight path is the set of all points (x(t),y(t))(x(t), y(t)). Time does not show on the picture, but it decides the order of the points.

From a table to a curve

The surest way to sketch a parametric curve is a table. Choose several values of tt, compute x(t)x(t) and y(t)y(t), plot the points, and join them in order of increasing tt.

Direction of travel

A parametric curve comes with a direction: the order in which the points are traced as tt increases. Mark it with arrows. You can read the direction from the two functions separately:

  • where x(t)x(t) is increasing, the point moves right; where it is decreasing, the point moves left;
  • where y(t)y(t) is increasing, the point moves up; where it is decreasing, the point moves down.

In Worked example 1, y(t)=2t−1y(t) = 2t - 1 increases for every tt, so the point climbs the whole time, while x(t)x(t) falls and then rises.

Curves that are not graphs of functions

Both x(t)x(t) and y(t)y(t) are functions of tt: one input, one output. The curve they make is a different matter. In Worked example 1, x=0x = 0 happens at t=0t = 0 and at t=2t = 2, with y=−1y = -1 and y=3y = 3. One xx-value has two yy-values, so the curve is not the graph of a function of xx. A parametric curve may also cross itself, when two different values of tt land on the same point.

Same path, different parameter

Different parametric functions can trace the same set of points. The functions (t,t2)(t, t^2) for 0≤t≤20 \le t \le 2 and (2s,4s2)(2s, 4s^2) for 0≤s≤10 \le s \le 1 both trace the parabola y=x2y = x^2 from (0,0)(0, 0) to (2,4)(2, 4). The second one just gets there with smaller parameter values. Replacing tt with −t-t (and adjusting the interval) traces the same path backward.

Writing yy as a function of xx

When x(t)x(t) is simple to solve for tt, you can remove the parameter and get an equation in xx and yy alone.

Worked example 2. Write yy as a function of xx for x(t)=2t+1x(t) = 2t + 1, y(t)=t2y(t) = t^2.

Solve x=2t+1x = 2t + 1 for tt: subtract 1, then divide by 2, so t=x−12t = \frac{x - 1}{2}.

Substitute into y=t2y = t^2: y=(x−12)2y = \left(\frac{x - 1}{2}\right)^2. The curve is a parabola with vertex at (1,0)(1, 0), the point where t=0t = 0.
