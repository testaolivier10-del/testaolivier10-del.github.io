Rectangular coordinates say how far to go right and how far to go up. Polar coordinates say how far to go and in which direction. Both name the same points; each is easier for some jobs. This page sets up the polar system, converts in both directions, and uses it to write complex numbers in polar form.

The polar grid

Start at a point called the pole (the origin) and draw a ray to the right, the polar axis (the positive xx-axis). The point (r,θ)(r, \theta) is found in two moves:

  1. Turn to the angle θ\theta, measured counterclockwise from the polar axis, as for an angle in standard position.
  2. Move rr units along that ray. If rr is negative, move |r||r| units in the opposite direction, backward through the pole.

The grid has circles (all points with the same rr) and rays (all points with the same θ\theta), as in Figure 1.

One point, many names

In rectangular coordinates every point has one name. In polar coordinates it has infinitely many:

  • Adding a full turn changes nothing: (r,θ)(r, \theta) and (r,θ+2π)(r, \theta + 2\pi) are the same point.
  • Reversing direction twice changes nothing: (r,θ)(r, \theta) and (−r,θ+π)(-r, \theta + \pi) are the same point.
  • The pole is (0,θ)(0, \theta) for every θ\theta.

For example, Q =(2,5π6)= \left(2, \frac{5\pi}{6}\right)=(2,−7π6)= \left(2, -\frac{7\pi}{6}\right)=(−2,11π6)= \left(-2, \frac{11\pi}{6}\right).

Converting between the systems

The point (r,θ)(r, \theta) lies on a circle of radius |r||r|, so the circle facts from Topic 3.3 give the conversions.

Worked example 1. Convert (−4,5π6)\left(-4, \frac{5\pi}{6}\right) to rectangular coordinates.

xx=−4cos⁡5π6= -4\cos\frac{5\pi}{6}=−4⋅(−32)= -4\cdot\left(-\frac{\sqrt{3}}{2}\right)=23= 2\sqrt{3}.

yy=−4sin⁡5π6= -4\sin\frac{5\pi}{6}=−4⋅12= -4\cdot\frac{1}{2}=−2= -2.

The point is (23,−2)\left(2\sqrt{3}, -2\right), in Quadrant IV: the ray 5π6\frac{5\pi}{6} points into Quadrant II, and the negative rr sends the point the other way.

Worked example 2. Convert (−2,−2)(-2, -2) to polar coordinates with r>0r > 0 and 0≤θ<2π0 \le \theta < 2\pi.

r=4+4=22r = \sqrt{4 + 4} = 2\sqrt{2}.

tan⁡θ=−2−2=1\tan\theta = \frac{-2}{-2} = 1. The inverse gives tan−1⁡1=π4\tan^{-1} 1 = \frac{\pi}{4}, in Quadrant I. But (−2,−2)(-2, -2) is in Quadrant III, so add π\pi: θ=5π4\theta = \frac{5\pi}{4}.

The point is (22,5π4)\left(2\sqrt{2}, \frac{5\pi}{4}\right). Check: 22cos⁡5π42\sqrt{2}\cos\frac{5\pi}{4}=22⋅(−22)= 2\sqrt{2}\cdot\left(-\frac{\sqrt{2}}{2}\right)=−2= -2.

Equations convert the same way. The circle x2+y2=25x^2 + y^2 = 25 becomes r2=25r^2 = 25, or just r=5r = 5. The line y=3y = 3 becomes rsin⁡θ=3r\sin\theta = 3, so r=3sin⁡θ=3csc⁡θr = \frac{3}{\sin\theta} = 3\csc\theta.

Complex numbers in polar form

The complex plane plots a+bia + bi as the point (a,b)(a, b): real part across, imaginary part up. Any point has polar coordinates, so

a+bi=r(cos⁡θ+isin⁡θ),r=a2+b2,tan⁡θ=baa + bi = r(\cos\theta + i\sin\theta), \qquad r = \sqrt{a^2 + b^2}, \quad \tan\theta = \frac{b}{a}

This is the polar form of a complex number. rr is its distance from 00.

Worked example 3. Write z=3−iz = \sqrt{3} - i in polar form.

The point is (3,−1)\left(\sqrt{3}, -1\right), in Quadrant IV. r=3+1=2r = \sqrt{3 + 1} = 2. tan⁡θ=−13\tan\theta = -\frac{1}{\sqrt{3}}, reference angle π6\frac{\pi}{6}, so θ=11π6\theta = \frac{11\pi}{6} (or −π6-\frac{\pi}{6}).

zz=2(cos⁡11π6+isin⁡11π6)= 2\left(\cos\frac{11\pi}{6} + i\sin\frac{11\pi}{6}\right).

Common slips

  • Writing (θ,r)(\theta, r) instead of (r,θ)(r, \theta).
  • Trusting tan−1⁡yx\tan^{-1}\frac{y}{x} in Quadrants II and III. Draw the point and add π\pi when it is on the left.
  • Reporting r2r^2 instead of rr.
