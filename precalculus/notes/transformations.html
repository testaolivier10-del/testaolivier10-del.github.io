2Exponential and Logarithmic Functions

Once you know the graph of one function well, you know a whole family. Shift it, stretch it, flip it, and you get new functions whose graphs you can draw without plotting a single point. The original is the parent; the new one is its transformation, written in terms of the parent, such as g(x)=2f(x−3)−1g(x) = 2f(x - 3) - 1.

Outside changes act on outputs

Anything done to f(x)f(x) after the function has acted changes the outputs, so it moves the graph up or down or stretches it vertically. The inputs stay where they were.

  • Vertical translation: g(x)=f(x)+kg(x) = f(x) + k moves every point kk units up (down if k<0k < 0).
  • Vertical dilation: g(x)=af(x)g(x) = a f(x) multiplies every output by aa. If a>1a > 1 the graph is stretched away from the xx-axis; if 0<a<10 < a < 1 it is compressed toward it.
  • Reflection across the xx-axis: g(x)=−f(x)g(x) = -f(x) changes the sign of every output. A negative aa dilates and reflects at once.

Inside changes act on inputs, in reverse

Anything done to xx before the function acts changes which input produces each output. That is why the direction feels backward.

  • Horizontal translation: g(x)=f(x−h)g(x) = f(x - h) moves the graph hh units right. Check with a value: g(h)=f(0)g(h) = f(0), so the output ff had at 00 now appears at hh.
  • Horizontal dilation: g(x)=f(bx)g(x) = f(bx) multiplies every input by 1b\frac{1}{b}. So f(2x)f(2x) is squeezed toward the yy-axis by a factor of 12\frac{1}{2}, and f(x3)f(\frac{x}{3}) is stretched by a factor of 33.
  • Reflection across the yy-axis: g(x)=f(−x)g(x) = f(-x) changes the sign of every input.

Combining transformations

For g(x)=af(x−h)+kg(x) = a f(x - h) + k, work from the input outward: shift the input, apply ff, multiply by aa, add kk. The order matters on the output side. Multiplying by 22 and then adding 11 is not the same as adding 11 and then multiplying by 22.

Worked example 1. Let f(x)=x2f(x) = x^2 and g(x)=2f(x−3)−1g(x) = 2f(x - 3) - 1. Where does the point (1,1)(1, 1) on ff go, and what is the vertex of gg?

The input moves 33 right: 1→41 \to 4. The output is doubled, then lowered by 11: 1→2→11 \to 2 \to 1. So (1,1)(1, 1) goes to (4,1)(4, 1).

Check with the formula: g(4)g(4)=2f(1)−1= 2f(1) - 1=2(1)−1= 2(1) - 1=1= 1. Correct.

The vertex (0,0)(0, 0) goes to (0+3,2⋅0−1)(0 + 3, 2 \cdot 0 - 1)=(3,−1)= (3, -1).

In the figure, gg looks narrower. That is the vertical stretch: each output, measured from the vertex level, is twice as large.

Writing the new formula

To write gg as an expression in xx, replace every xx in ff with what is inside the parentheses. Missing one is the most common slip.

Worked example 2. Let f(x)=x2−4xf(x) = x^2 - 4x. Write g(x)=f(x−1)+3g(x) = f(x - 1) + 3 in terms of xx.

Replace each xx with (x−1)(x - 1), in parentheses: f(x−1)f(x - 1)=(x−1)2−4(x−1)= (x - 1)^2 - 4(x - 1).

Add 33: g(x)g(x)=(x−1)2−4(x−1)+3= (x - 1)^2 - 4(x - 1) + 3.

Expand if you want standard form: x2−2xx^2 - 2x+1−4x+ 1 - 4x+4+ 4+3+ 3=x2−6x= x^2 - 6x+8+ 8.

How the domain and range change

Because inside changes act on inputs, they change the domain. Because outside changes act on outputs, they change the range.

Worked example 3. ff has domain [0,4][0, 4] and range [−1,3][-1, 3]. Find the domain and range of g(x)=−2f(x−1)g(x) = -2f(x - 1).

Domain: g(x)g(x) needs x−1x - 1 in [0,4][0, 4], so 1≤x≤51 \le x \le 5. The domain is [1,5][1, 5].

Range: multiply the ends by −2-2: −1→2-1 \to 2 and 3→−63 \to -6. Reorder from least to greatest: [−6,2][-6, 2].

Tables work the same way. If n(x)=k(x−3)n(x) = k(x - 3) and the table gives k(2)=6k(2) = 6, then n(5)=k(2)=6n(5) = k(2) = 6. To find where n(x)=6n(x) = 6, solve x−3=2x - 3 = 2.
