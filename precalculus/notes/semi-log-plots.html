3Trigonometric and Polar Functions

Exponential data are hard to read on an ordinary graph: the early values are squashed near the axis and the later ones shoot off the top. A semi-log plot fixes that by putting the vertical axis on a logarithmic scale. This page shows why exponential data then become a straight line, how to read the model from the line, and what other data look like.

One logarithmic axis

On a semi-log plot the horizontal axis is ordinary and the vertical axis is a logarithmic scale with some base n>1n > 1, usually 1010. The labels 11, 1010, 100100, 1,0001{,}000 are equally spaced, so equal vertical distances mean equal factors, not equal differences. Plotting yy on that axis is the same as plotting log⁡y\log y on an ordinary one.

Why exponential data make a line

Take y=a⋅bxy = a \cdot b^x and apply the properties of logarithms:

log⁡y=log⁡a+log⁡(bx)=log⁡a+xlog⁡b.\log y = \log a + \log(b^x) = \log a + x\log b.

That is a linear function of xx, with slope log⁡b\log b and intercept log⁡a\log a. So exponential data lie on a straight line on a semi-log plot. No vertical shift is involved: the form must be exactly a⋅bxa \cdot b^x.

Reading the model from the line

Worked example 1. App users lie on a line through (0,20)(0, 20) and (8,2,000)(8, 2{,}000) on a base-1010 semi-log plot. Find y=a⋅bty = a \cdot b^t.

Slope in powers of 1010: log⁡2,000−log⁡208−0\frac{\log 2{,}000 - \log 20}{8 - 0}=3.301−1.3018= \frac{3.301 - 1.301}{8}=0.25= 0.25.

So log⁡b=0.25\log b = 0.25 and b=100.25≈1.778b = 10^{0.25} \approx 1.778: about 77.8%77.8\% growth per year.

The intercept is log⁡a=log⁡20\log a = \log 20, so a=20a = 20. The model is y=20⋅10t/4y = 20 \cdot 10^{t/4}.

Worked example 2. A table gives log⁡y\log y=0.5,0.8,1.1,1.4,1.7= 0.5, 0.8, 1.1, 1.4, 1.7 at t=0,1,2,3,4t = 0, 1, 2, 3, 4. Find yy.

log⁡y\log y rises 0.30.3 per step, so log⁡y=0.5+0.3t\log y = 0.5 + 0.3t.

Undo the logarithm: yy=100.5+0.3t= 10^{0.5 + 0.3t}=100.5⋅(100.3)t= 10^{0.5} \cdot (10^{0.3})^t≈3.16⋅2.00t\approx 3.16 \cdot 2.00^t.

With a natural-log scale the same steps use ee: the line ln⁡y=1.2+0.05t\ln y = 1.2 + 0.05t gives y=e1.2⋅e0.05ty = e^{1.2} \cdot e^{0.05t}.

Reading values between labels

Halfway up between 200200 and 2,0002{,}000 on the logarithmic axis is not 1,1001{,}100. It is the value whose logarithm is halfway between log⁡200\log 200 and log⁡2,000\log 2{,}000, about 2.8012.801: the value is 200⋅2,000\sqrt{200 \cdot 2{,}000}=400,000= \sqrt{400{,}000}≈632\approx 632. On a log scale, "halfway" means the same factor up from the lower value as down from the upper one.

Comparing models on one plot

Several exponential models drawn on one semi-log plot are all straight lines. The steeper line has the larger growth factor, since slope =log⁡b= \log b. The higher intercept has the larger starting value. Parallel lines grow by the same factor each step.
