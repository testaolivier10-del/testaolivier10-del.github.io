4Functions Involving Parameters, Vectors, and Matrices

Two expressions can look nothing alike and still have the same graph. 1−2sin2⁡x1 - 2\sin^2 x and cos⁡(2x)\cos(2x) are one example. An equation that is true for every input where both sides are defined is an identity. On the exam, identities do three jobs: they turn an angle like π12\frac{\pi}{12} into exact values you know, they rewrite an expression as a single trigonometric function, and they turn a hard equation into one you can solve.

The Pythagorean identity

The point (cos⁡x,sin⁡x)(\cos x, \sin x) is on the unit circle X2+Y2=1X^2 + Y^2 = 1, so

sin2⁡x+cos2⁡x=1\sin^2 x + \cos^2 x = 1

for every xx. (Here sin2⁡x\sin^2 x means (sin⁡x)2(\sin x)^2.) Dividing every term by cos2⁡x\cos^2 x, and then by sin2⁡x\sin^2 x, gives two more forms:

tan2⁡x+1=sec2⁡x1+cot2⁡x=csc2⁡x\tan^2 x + 1 = \sec^2 x \qquad 1 + \cot^2 x = \csc^2 x

Use them to find one value from another. If sin⁡x=35\sin x = \frac{3}{5} and xx is in Quadrant II, then cos2⁡x\cos^2 x=1−925= 1 - \frac{9}{25}=1625= \frac{16}{25}, so cos⁡x=−45\cos x = -\frac{4}{5}, negative because of the quadrant.

Sum and difference identities

sin⁡(a±b)=sin⁡acos⁡b±cos⁡asin⁡b\sin(a \pm b) = \sin a\cos b \pm \cos a\sin b

cos⁡(a±b)=cos⁡acos⁡b∓sin⁡asin⁡b\cos(a \pm b) = \cos a\cos b \mp \sin a\sin b

Watch the signs in the cosine identity: a sum gives a minus, a difference gives a plus. And notice what they say is false: sin⁡(a+b)\sin(a + b) is not sin⁡a+sin⁡b\sin a + \sin b.

Worked example 1. Find sin⁡5π12\sin\frac{5\pi}{12} exactly.

Write 5π12=π4+π6\frac{5\pi}{12} = \frac{\pi}{4} + \frac{\pi}{6}, two angles you know.

sin⁡(π4+π6)\sin\left(\frac{\pi}{4} + \frac{\pi}{6}\right)=sin⁡π4cos⁡π6= \sin\frac{\pi}{4}\cos\frac{\pi}{6}+cos⁡π4sin⁡π6+ \cos\frac{\pi}{4}\sin\frac{\pi}{6}=22⋅32= \frac{\sqrt{2}}{2}\cdot\frac{\sqrt{3}}{2}+22⋅12+ \frac{\sqrt{2}}{2}\cdot\frac{1}{2}=6+24= \frac{\sqrt{6} + \sqrt{2}}{4}.

The difference identities also explain the phase shift between the graphs: cos⁡(x−π2)\cos\left(x - \frac{\pi}{2}\right)=cos⁡x⋅0= \cos x\cdot 0+sin⁡x⋅1+ \sin x\cdot 1=sin⁡x= \sin x.

Double-angle identities

Put b=ab = a in the sum identities:

sin⁡(2a)=2sin⁡acos⁡a\sin(2a) = 2\sin a\cos a

cos⁡(2a)=cos2⁡a−sin2⁡a=2cos2⁡a−1=1−2sin2⁡a\cos(2a) = \cos^2 a - \sin^2 a = 2\cos^2 a - 1 = 1 - 2\sin^2 a

The last two forms come from replacing sin2⁡a\sin^2 a or cos2⁡a\cos^2 a with the Pythagorean identity. Figure 1 shows the first form as heights on a graph.

Rewriting as a single function

When a question says "as a single trigonometric function", the answer is one function like tan⁡x\tan x, not a quotient like sin⁡xcos⁡x\frac{\sin x}{\cos x}. A routine that works:

  1. Write every function in terms of sin⁡\sin and cos⁡\cos, and expand any 2x2x with a double-angle identity.
  2. Use a Pythagorean identity to replace sums of squares.
  3. Cancel common factors.
  4. Name the one function that is left.

Worked example 2. Rewrite 1−cos⁡(2x)sin⁡(2x)\frac{1 - \cos(2x)}{\sin(2x)} as a single trigonometric function.

Choose the form of cos⁡(2x)\cos(2x) that cancels the 11: 1−cos⁡(2x)1 - \cos(2x)=1−(1−2sin2⁡x)= 1 - (1 - 2\sin^2 x)=2sin2⁡x= 2\sin^2 x.

Expand the bottom: sin⁡(2x)=2sin⁡xcos⁡x\sin(2x) = 2\sin x\cos x.

Cancel: 2sin2⁡x2sin⁡xcos⁡x\frac{2\sin^2 x}{2\sin x\cos x}=sin⁡xcos⁡x= \frac{\sin x}{\cos x}=tan⁡x= \tan x, wherever the original expression is defined.

Solving equations with identities

An equation that mixes sin⁡(2x)\sin(2x) and sin⁡x\sin x cannot be solved until both use the same angle.

Worked example 3. Solve cos⁡(2x)=cos⁡x\cos(2x) = \cos x on [0,2π)[0, 2\pi).

Use the form with only cosines: 2cos2⁡x−1=cos⁡x2\cos^2 x - 1 = \cos x, so 2cos2⁡x−cos⁡x−1=02\cos^2 x - \cos x - 1 = 0.

Factor: (2cos⁡x+1)(cos⁡x−1)(2\cos x + 1)(\cos x - 1)=0= 0. So cos⁡x=−12\cos x = -\frac{1}{2} (x=2π3,4π3x = \frac{2\pi}{3}, \frac{4\pi}{3}) or cos⁡x=1\cos x = 1 (x=0x = 0).

Answer: x=0x = 0, 2π3\frac{2\pi}{3}, 4π3\frac{4\pi}{3}.

Common slips

  • Splitting a function over a sum: cos⁡(a+b)≠cos⁡a+cos⁡b\cos(a + b) \ne \cos a + \cos b.
  • Pulling the 22 out of sin⁡(2x)\sin(2x).
  • Stopping at sin⁡xcos⁡x\frac{\sin x}{\cos x} when one function was asked for.
  • Dividing an equation by sin⁡x\sin x and losing the solutions where sin⁡x=0\sin x = 0; factor instead.
