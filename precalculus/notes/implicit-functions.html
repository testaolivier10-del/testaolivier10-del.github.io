So far most functions have come as formulas: y=f(x)y = f(x), or x(t)x(t) and y(t)y(t). Many curves are more natural as a single equation tying xx and yy together. A circle is the clearest case: x2+y2=25x^2 + y^2 = 25 says "the distance from the origin is 5" without ever saying y=…y = \ldots.

The graph of an implicitly defined function is the set of all points (x,y)(x, y) that make its equation true. To check whether a point is on the curve, substitute both coordinates: (1,2)(1, 2) is on x2+xy+y2=7x^2 + xy + y^2 = 7 because 1+2+4=71 + 2 + 4 = 7, and (2,2)(2, 2) is not because 4+4+4=124 + 4 + 4 = 12.

Finding points

Worked example 1. Find every point of x2+xy+y2=7x^2 + xy + y^2 = 7 with x=1x = 1.

Substitute: 1+y+y2=71 + y + y^2 = 7, so y2+y−6=0y^2 + y - 6 = 0.

Factor: (y−2)(y+3)=0(y - 2)(y + 3) = 0, so y=2y = 2 or y=−3y = -3.

The points are (1,2)(1, 2) and (1,−3)(1, -3). One xx, two yy-values: this curve is not the graph of a function of xx.

Splitting a curve into functions

A curve that fails the vertical line test can often be cut into pieces that pass it. For the circle x2+y2=25x^2 + y^2 = 25, solving for yy gives y=±25−x2y = \pm\sqrt{25 - x^2}: the upper half y=25−x2y = \sqrt{25 - x^2} and the lower half y=−25−x2y = -\sqrt{25 - x^2} are each functions of xx.

Worked example 2. Solve x2+xy+y2=7x^2 + xy + y^2 = 7 for yy.

Treat it as a quadratic in yy: y2+(x)y+(x2−7)=0y^2 + (x)y + (x^2 - 7) = 0, with a=1a = 1, b=xb = x, c=x2−7c = x^2 - 7.

The quadratic formula: yy=−x±x2−4(x2−7)2= \frac{-x \pm \sqrt{x^2 - 4(x^2 - 7)}}{2}=−x±28−3x22= \frac{-x \pm \sqrt{28 - 3x^2}}{2}.

The "+" sign gives the upper piece and the "−" sign the lower piece. Check with x=1x = 1: −1±252\frac{-1 \pm \sqrt{25}}{2} gives 22 and −3-3, as before.

The square root also tells you how wide the curve is. Real values of yy exist only when 28−3x2≥028 - 3x^2 \ge 0, that is −283≤x≤283-\sqrt{\frac{28}{3}} \le x \le \sqrt{\frac{28}{3}}. At the two ends the square root is 00 and the two pieces meet.

Symmetry from the equation

You can read symmetry without graphing. Swapping xx and yy in x2+xy+y2=7x^2 + xy + y^2 = 7 gives the same equation, so if (a,b)(a, b) is on the curve, so is (b,a)(b, a): the curve is symmetric about the line y=xy = x. Replacing xx with −x-x and yy with −y-y also gives the same equation, so (−a,−b)(-a, -b) is on it too.

Implicit equations that are functions

Some implicit equations do give one yy for each xx. In y3+y=xy^3 + y = x, the left side increases whenever yy increases, so two different yy-values can never give the same xx. This defines yy as a function of xx, even though solving for yy by hand is hard. A table is easy, though: choose yy, compute xx. From the points (2,1)(2, 1) and (10,2)(10, 2), the average rate of change of yy with respect to xx is 2−110−2=18\frac{2 - 1}{10 - 2} = \frac{1}{8}, the slope of the segment joining them.
