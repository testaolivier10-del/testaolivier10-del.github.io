3Trigonometric and Polar Functions

Arithmetic and geometric sequences are defined only at whole-number positions. Fill in every real input between them and you get two of the most useful function types in the course: linear functions, which extend arithmetic sequences, and exponential functions, which extend geometric ones. This page is about telling them apart from a table, and about justifying your answer the way the exam scores it.

Adding versus multiplying

A linear function f(x)=b+mxf(x) = b + mx adds the same amount mm for each unit of input. An exponential function f(x)=abxf(x) = ab^x (with a≠0a \ne 0, b>0b > 0 and b≠1b \ne 1) multiplies by the same factor bb for each unit of input. If b>1b > 1 the function shows exponential growth; if 0<b<10 < b < 1, exponential decay.

In the figure, the line is ahead at first, but the exponential function's steps keep getting bigger (22, 33, 4.54.5, 6.756.75, ...) and it passes the line between x=5x = 5 and x=6x = 6. An increasing exponential function eventually passes any increasing linear function.

The test, with both halves

Over equal-length input intervals:

What the outputs doFunction typeExample over steps of 22
Change by a constant differenceLinear7,13,19,257, 13, 19, 25: add 66 each time
Change by a constant ratio (not 00 or 11); the outputs are proportionalExponential5,15,45,1355, 15, 45, 135: multiply by 33 each time

A full justification names both halves and uses the numbers: "The input intervals all have length 22, and the outputs over them have a constant ratio, 155\frac{15}{5}=4515= \frac{45}{15}=13545= \frac{135}{45}=3= 3, so an exponential function fits." Readers take the point away if either half is missing. "The outputs grow faster and faster" earns nothing, because a quadratic does that too.

Worked example 1. A culture has 55, 1515, 4545, 135135 and 405405 thousand bacteria at t=0,2,4,6,8t = 0, 2, 4, 6, 8 hours. Choose a model and write it.

Equal intervals: each step is 22 hours. Differences: 10,30,90,27010, 30, 90, 270, not constant, so not linear. Ratios: 3,3,3,33, 3, 3, 3, constant, so exponential.

The output triples every 22 hours, so after tt hours it has tripled t2\frac{t}{2} times: B(t)=5(3)t/2B(t) = 5(3)^{t/2}.

At t=1t = 1, half of a tripling period: B(1)=5(3)1/2=53B(1) = 5(3)^{1/2} = 5\sqrt{3}. The output is multiplied by 3\sqrt{3} each hour, because 3⋅3=3\sqrt{3} \cdot \sqrt{3} = 3. Halfway in time is not halfway in value.

The trap: unequal input steps

If the inputs are 0,1,3,60, 1, 3, 6, the steps are 11, 22 and 33, and raw differences or ratios mean nothing until you account for the step lengths.

Worked example 2. p(x)p(x) is 10,13,19,2810, 13, 19, 28 and q(x)q(x) is 4,8,32,2564, 8, 32, 256 at x=0,1,3,6x = 0, 1, 3, 6. What could each be?

For pp, the differences are 3,6,93, 6, 9. Divide each by its step: 31=62=93=3\frac{3}{1} = \frac{6}{2} = \frac{9}{3} = 3. A constant rate of change: p(x)=10+3xp(x) = 10 + 3x fits.

For qq, the ratios are 2,4,82, 4, 8, which look unequal. But 2=212 = 2^1 over 11 unit, 4=224 = 2^2 over 22 units, 8=238 = 2^3 over 33 units: the output doubles for every unit. q(x)=4(2)xq(x) = 4(2)^x fits.

An exponential function through a known point

If you know one point (x1,y1)(x_1, y_1) and the ratio rr per unit of input, count the steps from that point, just as for a geometric sequence: f(x)=y1rx−x1f(x) = y_1 r^{x - x_1}. With f(2)=18f(2) = 18 and a ratio of 33: f(x)=18(3)x−2f(x) = 18(3)^{x - 2}, so f(3)=54f(3) = 54 and f(0)=2f(0) = 2.

Rates of change

For a linear function the average rate of change is the same on every interval. For an exponential function, the average rates of change over equal-length intervals have the same ratio as the outputs. In the bacteria table, the average rates on [0,2][0, 2], [2,4][2, 4] and [4,6][4, 6] are 55, 1515 and 4545 thousand per hour: each is 33 times the one before, so the rate of change of BB is increasing and the graph is concave up.
