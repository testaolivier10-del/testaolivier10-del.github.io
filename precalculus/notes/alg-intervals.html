Intervals are how precalculus says "these inputs" or "these outputs". You will write them for domains and ranges, for where a function rises or falls, and for the stretch of inputs a question is about. This page covers the notation and how to solve the linear inequalities that produce intervals.

Interval notation

An interval is every real number between two ends. Write the left end, a comma, the right end, and show whether each end is included:

InequalityIntervalEnds
−1≤x≤4-1 \le x \le 4[−1,4][-1, 4]both included (closed interval)
−1<x<4-1 < x < 4(−1,4)(-1, 4)neither included (open interval)
−1≤x<4-1 \le x < 4[−1,4)[-1, 4)−1-1 in, 44 out
x≥2x \ge 2[2,∞)[2, \infty)22 in; no right end
x<5x < 5(−∞,5)(-\infty, 5)no left end; 55 out

A bracket means "included", a parenthesis means "not included". The symbols ∞\infty and −∞-\infty are not numbers you can land on, so they always get a parenthesis. On a graph, an included end gets a closed dot and an excluded end an open dot.

When a set skips a number, write the pieces and join them with the union sign ∪\cup. Every real number except 55 is (−∞,5)∪(5,∞)(-\infty, 5) \cup (5, \infty).

Solving linear inequalities

A linear inequality, such as 5x−4≤2x+115x - 4 \le 2x + 11, is solved like an equation: add, subtract, multiply or divide both sides by the same number. One rule is different. Multiplying or dividing by a negative number flips the inequality. The reason: 2<32 < 3, but −2>−3-2 > -3. Negation turns the number line around.

Worked example 1. Solve 3−2x>73 - 2x > 7.

Subtract 33 from both sides: −2x>4-2x > 4.

Divide by −2-2 and flip: x<−2x < -2. In interval notation, (−∞,−2)(-\infty, -2).

Check one value inside: x=−3x = -3 gives 3+6=93 + 6 = 9, and 9>79 > 7. Check the end: x=−2x = -2 gives 7>77 > 7, false, so the parenthesis is right.

Compound inequalities

A compound inequality has three parts, like −1≤2x+3<9-1 \le 2x + 3 < 9. Do every step to all three parts at once.

Worked example 2. Which inputs of f(x)=2x+3f(x) = 2x + 3 give outputs with −1≤f(x)<9-1 \le f(x) < 9?

Subtract 33 from all parts: −4≤2x<6-4 \le 2x < 6. Divide all parts by 22: −2≤x<3-2 \le x < 3. The answer is [−2,3)[-2, 3).

Domains as intervals

The domain rules from the last topic produce inequalities, so domains come out as intervals. For g(x)=6−2xg(x) = \sqrt{6 - 2x}, the inside must be at least 00: 6−2x≥06 - 2x \ge 0, so −2x≥−6-2x \ge -6 and x≤3x \le 3 (flip). The domain is (−∞,3](-\infty, 3], with a bracket because 0=0\sqrt{0} = 0 is fine.

Read the question for inputs or outputs. "Which inputs give outputs at least 55" wants an interval of xx-values, not [5,∞)[5, \infty).
