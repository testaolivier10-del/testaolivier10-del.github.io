Unit 5 describes how one quantitative variable changes with another using a straight line. Before that, you need to be comfortable reading any line: what its slope says, what its intercept says, and how to find both.

The equation of a line

Statistics writes a line as

y=a+bx,y = a + bx,

with the intercept first. bb is the slope and aa is the y-intercept. (Algebra classes often write y=mx+by = mx + b; it is the same line with different letters.)

Slope

The slope is the change in y for each one-unit increase in x. On a graph it is rise over run: from any point on the line, move 1 unit right, and y changes by bb. A positive slope rises; a negative slope falls.

From two points (x1,y1)(x_1, y_1) and (x2,y2)(x_2, y_2):

b=y2−y1x2−x1.b = \frac{y_2 - y_1}{x_2 - x_1}.

Subtract in the same order on top and bottom. The slope has units: y units per x unit, such as dollars per hour.

Slope and intercept from two points. A line passes through (2,7)(2, 7) and (6,19)(6, 19).

Slope: bb=19−76−2= \frac{19 - 7}{6 - 2}=124= \frac{12}{4}=3= 3.

Intercept: write y=a+3xy = a + 3x and use one point, (2,7)(2, 7): 7=a+3(2)=a+67 = a + 3(2) = a + 6, so a=1a = 1.

Equation: y=1+3xy = 1 + 3x. Check with the other point: 1+3(6)=191 + 3(6) = 19. Correct.

Intercept

The y-intercept is the value of y when x=0x = 0, where the line crosses the vertical axis. For the bike rental y=12+3xy = 12 + 3x, it is the 12 dollar fee charged before any hours. Sometimes x=0x = 0 makes no sense: a line giving adult height from shoe length has an intercept at shoe length 0, which no adult has. Then the intercept is just a number that places the line, with no meaning of its own.

Saying it in context

Interpret a line. A cooling drink’s temperature is y=80−2.5xy = 80 - 2.5x degrees Fahrenheit after xx minutes.

Slope: "For each additional minute, the temperature of the drink decreases by 2.5 degrees."

Intercept: "At 0 minutes, when it is poured, the drink is 80 degrees." Here x=0x = 0 makes sense, so the intercept has a meaning.

A value: after 6 minutes, yy=80−2.5(6)= 80 - 2.5(6)=80−15= 80 - 15=65= 65 degrees.
