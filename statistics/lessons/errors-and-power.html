Unit 3 · Topic 3.8 Beta

Potential Errors When Performing Tests

A Type I error rejects a true H_0 (probability α ); a Type II error fails to reject a false H_0 (probability β , against a specific alternative).

Practice 2: Collect DataPractice 4: Interpret Results

Part 1 · Hook

Why this matters

A city will replace its old water pipes only if a test finds convincing evidence that more than 10% of homes have too much lead. The test can go wrong in two ways: the city spends millions on pipes it did not need, or it leaves families drinking unsafe water. Which mistake is worse, and how can the city make it less likely?

Part 5 · Step by step

How it works, step by step

  1. H0H_0 is true but the sample happens to look extreme→the test rejects H0H_0: a Type I error, with probability α\alpha
  2. HaH_a is true but the sample happens to look ordinary→the test fails to reject H0H_0: a Type II error, with probability β\beta
  3. A specific alternative value is true→the test rejects H0H_0 with probability power =1−β= 1 - \beta
  4. The sample size grows (or α\alpha grows, or the true value is farther from p0p_0)→the curves overlap less or the cutoff is easier to pass, so power rises and β\beta falls

Part 6 · Key ideas

Key ideas

  • Type I: H0H_0 true, but we reject it (a false alarm). Probability α\alpha.
  • Type II: HaH_a true, but we fail to reject H0H_0 (a missed effect). Probability β\beta, which depends on the true value.
  • Describe an error with the condition first: "if the true proportion of all __ is __, but we find (do not find) convincing evidence that ...", then the consequence in context.
  • Power =1−β= 1 - \beta: the probability of rejecting H0H_0 when a specific alternative is true.
  • More power: larger nn (best), larger α\alpha, or a true value farther from p0p_0. For a fixed nn, lowering α\alpha raises β\beta.

Part 7 · Misconception

A common mistake

The wrong idea: A Type I error is when the test gets the answer wrong, and a Type II error is when it gets it wrong a second time.

What actually happens: Each is a specific mistake: Type I rejects a true H0H_0; Type II fails to reject a false H0H_0. After a rejection only a Type I error is possible; after a failure to reject, only a Type II error.

Lead in household water

A city must replace its old water pipes if more than 10% of its homes have lead levels above a safety limit. The water department tests a random sample of 300 of the city's 40,000 homes and will test H0:p=0.10H_0: p = 0.10 against Ha:p>0.10H_a: p > 0.10, where pp is the true proportion of all the city's homes with lead above the limit. If the test finds convincing evidence for HaH_a, the city replaces the pipes.

The four possible outcomes of the test
H0H_0 is true (p=0.10p = 0.10)HaH_a is true (p>0.10p > 0.10)
Reject H0H_0Type I errorCorrect decision
Fail to reject H0H_0Correct decisionType II error

1. Which describes a Type I error in this context?

  1. The proportion is 0.10, but the test finds convincing evidence that it is greater
  2. The proportion is greater than 0.10, but the test does not find convincing evidence
  3. The proportion is greater than 0.10, and the test finds convincing evidence of that
  4. The sample proportion turns out to be greater than 0.10
Show the answer

A Type I error is rejecting a true H0H_0: the true proportion is 0.10, but the test finds convincing evidence that it is greater than 0.10.

  • Correct: The proportion is 0.10, but the test finds convincing evidence that it is greater: Right: H0H_0 is true and we reject it.
  • The proportion is greater than 0.10, but the test does not find convincing evidence: That is a Type II error: HaH_a is true and we fail to reject H0H_0.
  • The proportion is greater than 0.10, and the test finds convincing evidence of that: That is a correct decision.
  • The sample proportion turns out to be greater than 0.10: An error is about the decision compared with the truth, not about the sample result.

2. Which describes a Type II error in this context?

  1. The proportion is 0.10, and the test finds convincing evidence that it is greater
  2. Over 10% of homes are above the limit, but the test finds no convincing evidence
  3. The test fails to reject H0H_0 when exactly 10% of homes are above the limit
  4. The department tests too few homes to find anything
Show the answer

A Type II error is failing to reject a false H0H_0: more than 10% of homes really are above the limit, but the test does not find convincing evidence of it.

  • The proportion is 0.10, and the test finds convincing evidence that it is greater: That is a Type I error.
  • Correct: Over 10% of homes are above the limit, but the test finds no convincing evidence: Right: HaH_a is true and we fail to reject H0H_0.
  • The test fails to reject H0H_0 when exactly 10% of homes are above the limit: If H0H_0 is true, failing to reject it is the correct decision.
  • The department tests too few homes to find anything: A small sample can make a Type II error more likely, but the error itself is a wrong decision about H0H_0.

3. What is a consequence of a Type II error here?

  1. The city spends money replacing pipes that did not need replacing
  2. The city replaces the pipes, as it should
  3. The city does not replace the pipes, and residents keep drinking unsafe water
  4. The city has to test a second random sample
Show the answer

After a Type II error the city does not replace the pipes, even though more than 10% of homes have lead above the limit. Residents keep drinking water with too much lead.

  • The city spends money replacing pipes that did not need replacing: That is the consequence of a Type I error.
  • The city replaces the pipes, as it should: That follows a correct decision to reject H0H_0 when HaH_a is true.
  • Correct: The city does not replace the pipes, and residents keep drinking unsafe water: Right: the problem exists but the test misses it.
  • The city has to test a second random sample: Nothing in the plan calls for a second sample; the decision is made from this test.

4. Build the description of a Type I error and its consequence in this context.

Write the conclusion in context.

Show the answer

State the condition first (what is true), then the wrong decision, then what happens because of it.

  • A full-credit answer: A Type I error would occur if the true proportion of all the city's homes with lead above the limit is 0.10, but the test finds convincing evidence that it is greater than 0.10. The city would then spend money replacing pipes that did not need replacing.

5. What is the probability that the test makes a Type I error?

  1. 0.05, the significance level
  2. 0.11, the area to the left of the cutoff under the curve for p=0.60p = 0.60
  3. 0.89, the area to the right of the cutoff under the curve for p=0.60p = 0.60
  4. 0.558, the cutoff for rejecting H0H_0
Show the answer

A Type I error can happen only when H0H_0 is true, and then the test rejects with probability α\alpha. Here α=0.05\alpha = 0.05: the dark area to the right of the cutoff under the null curve.

  • Correct: 0.05, the significance level: Right: P(Type I error)=αP(\text{Type I error}) = \alpha.
  • 0.11, the area to the left of the cutoff under the curve for p=0.60p = 0.60: That area is β\beta, the probability of a Type II error when p=0.60p = 0.60.
  • 0.89, the area to the right of the cutoff under the curve for p=0.60p = 0.60: That is the power of the test against p=0.60p = 0.60.
  • 0.558, the cutoff for rejecting H0H_0: The cutoff is a value of p^\hat{p}, not a probability.

7. The power against p=0.60p = 0.60 is about 0.89. Which interpretation is correct?

  1. If 60% prefer it, the test has an 89% chance of finding convincing evidence that over half do
  2. There is an 89% chance that more than half of the company's customers prefer the new recipe
  3. About 89% of customers will prefer the new recipe
  4. If half of customers prefer it, the test has an 89% chance of a Type I error
Show the answer

Power is the probability of correctly rejecting H0H_0 when a particular alternative is true. If 60% of customers really prefer the new recipe, the test has about an 89% chance of finding convincing evidence that more than half do.

  • Correct: If 60% prefer it, the test has an 89% chance of finding convincing evidence that over half do: Right: power is the chance of detecting this alternative.
  • There is an 89% chance that more than half of the company's customers prefer the new recipe: Power is computed assuming a specific truth, p=0.60p = 0.60; it is not a probability about pp.
  • About 89% of customers will prefer the new recipe: The 0.89 is a probability about the test's decision, not a share of customers.
  • If half of customers prefer it, the test has an 89% chance of a Type I error: If p=0.5p = 0.5, the chance of a Type I error is α=0.05\alpha = 0.05.

Part 9 · Summary

Summary

A Type I error rejects a true H0H_0 (probability α\alpha); a Type II error fails to reject a false H0H_0 (probability β\beta, against a specific alternative). Describe each with the condition first and its consequence in context. Power =1−β= 1 - \beta is the chance of detecting a real effect; it grows with the sample size, with α\alpha, and with the distance between the true value and p0p_0.
