Introduction to Random Variables and Probability Distributions

A random variable is a number from a chance process, defined in context.

Practice 3: Analyze Data

Part 1 · Hook

Why this matters

A highway agency wants to know how many people ride in each car, to plan a carpool lane. One car is chosen at random: it might hold 1 person, or 5. That uncertain count is a random variable, and listing its values with their probabilities answers every question the agency has.

Part 5 · Step by step

How it works, step by step

  1. A chance process produces a number→that number is a random variable, named with a capital letter and defined in context
  2. List every value with its probability→the probability distribution, a table or a probability histogram
  3. Every outcome gives exactly one value→the probabilities are from 0 to 1 and add to 1, which finds a missing value
  4. Add the probabilities up to a boundary→a cumulative probability such as P(X≤3)P(X \le 3); translate "fewer than 3" as X≤2X \le 2

Part 6 · Key ideas

Key ideas

  • A random variable is a number that comes from a chance process. Define it in context: "Let X = the number of people in a randomly chosen car."
  • A probability distribution gives every value of the random variable and its probability, as a table or a probability histogram. The probabilities are from 0 to 1 and add to 1.
  • A discrete random variable has separate values (counts); a continuous one can take any value in an interval.
  • A cumulative probability adds up to a boundary: P(X≤3)P(X \le 3). "Fewer than 3" is X≤2X \le 2; "at least 3" is X≥3X \ge 3.

Part 7 · Misconception

A common mistake

The wrong idea: "Let X = rock songs" defines the random variable.

What actually happens: A random variable is a number. Say what is counted and out of what: "Let X = the number of rock songs among the 12 songs on the playlist."

Type a number. A table answer and a calculator answer are both accepted.

Show the answer

3. What is the probability that a car has fewer than 3 people?

Type a number. A table answer and a calculator answer are both accepted.

Show the answer

"Fewer than 3" means 1 or 2, that is X≤2X \le 2: P(X≤2)P(X \le 2)=0.45+0.30= 0.45 + 0.30=0.75= 0.75.

4. Which is a complete definition of the random variable in this context?

  1. X = the people in the cars at the toll booth
  2. X = the number of people in a randomly chosen car at the toll booth
  3. X = the probability that a car has more than one person
  4. X = the cars that pass through the toll booth on a randomly chosen day
Show the answer

A random variable is a number that comes from a chance process, defined in context: what is counted, and for which randomly chosen individual.

  • X = the people in the cars at the toll booth: People are not a number. Say what is counted: the number of people.
  • Correct: X = the number of people in a randomly chosen car at the toll booth: Right: a count, in context, for one random car.
  • X = the probability that a car has more than one person: X takes values like 1 to 5; probabilities describe how likely each value is.
  • X = the cars that pass through the toll booth on a randomly chosen day: Cars are the individuals, not the numerical value being recorded.

6. What kind of random variable is G?

  1. Continuous, because a game lasts for 90 minutes of playing time
  2. Discrete, because it takes separate whole-number values
  3. Categorical, because each bar is a category
  4. Continuous, because it can be any number from 0 to 4
Show the answer

G takes a list of separate values (0, 1, 2, 3, 4), so it is a discrete random variable.

  • Continuous, because a game lasts for 90 minutes of playing time: The variable is goals, not time.
  • Correct: Discrete, because it takes separate whole-number values: Right: goals are counted.
  • Categorical, because each bar is a category: G is a number from a chance process; the bars are its values.
  • Continuous, because it can be any number from 0 to 4: It cannot be 2.5 goals; only whole numbers are possible.

Part 9 · Summary

Summary

A random variable is a number from a chance process, defined in context. Its probability distribution lists each value with its probability; the probabilities are from 0 to 1 and add to 1. Probabilities of events like "at least 3" or "fewer than 3" come from adding the right values, and cumulative probabilities add everything up to a boundary.
