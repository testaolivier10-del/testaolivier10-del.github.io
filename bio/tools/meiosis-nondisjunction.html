Meiosis and nondisjunction

Walk one cell through meiosis and see where extra or missing chromosomes come from.

About this tool

Take one cell through meiosis, one step at a time. Choose how many homologous pairs it has, switch crossing over on or off, decide which way each pair lines up in metaphase I, and make one pair fail to separate in meiosis I or in meiosis II. Then read the four gametes: how many chromosomes each one carries, and what a zygote would get if that gamete met a normal one. Compare the result with mitosis of the same cell, then answer the questions below about the same model.

How it works

The cell is diploid (2n): every chromosome has a homolog. One homolog of each pair came from the organism’s mother (maternal: solid orange-red, label M) and one from its father (paternal: blue with stripes, label P). Pair 1 is the longest, pair 3 the shortest. The steps (each effect is the cause of the next):

  1. Interphase, G1. Each chromosome is one DNA molecule (one chromatid).
  2. S phase. DNA is copied, so each chromosome is two identical sister chromatids joined at the centromere. The chromosome number stays 2n; the DNA doubles.
  3. Prophase I. Homologs pair up along their length (synapsis). With crossing over on, two nonsister chromatids of each pair swap matching tips.
  4. Metaphase I. The pairs line up at the middle of the cell. For each pair, one homolog faces the cell 1 side and the other the cell 2 side; you choose which. Each pair’s choice does not depend on the others (independent assortment).
  5. Anaphase I. Homologs separate; sister chromatids stay together.
  6. End of meiosis I. Two cells, each with n chromosomes (one of each pair), each still made of two chromatids.
  7. Metaphase II and anaphase II. In each cell the chromosomes line up again and the sister chromatids separate.
  8. Gametes. Four haploid cells, each with one chromatid of each pair.

The model’s rules:

  • Crossing over: one crossover per pair, always between the same two nonsister chromatids (maternal chromatid 2 and paternal chromatid 1) and at the same point, so the swapped tip is the far end of each arm. Real cells place crossovers at different points in different cells, and a pair can have more than one, so real meiosis makes far more kinds of gametes than the model.
  • Meiosis II: sister chromatid 1 of each chromosome goes to the first gamete of its cell. Without crossing over the sisters are identical, so this choice does not matter; Try every line-up also tries the other arrangements.
  • Nondisjunction in meiosis I: both homologs of the chosen pair go to cell 1. In meiosis II: in the chosen cell, both sister chromatids of the chosen pair go to that cell’s first gamete. The model allows one nondisjunction at a time.
  • Gamete labels: n is the normal number (one of each pair), n+1 has an extra copy of one pair, n−1 lacks one. A zygote gets the gamete’s chromosomes plus those of a normal gamete (n), so 2n, 2n+1 (three copies of one chromosome: trisomy) or 2n−1 (one copy: monosomy).
  • Combinations: with n pairs, independent assortment alone can give 2n different gametes (2 choices for each pair). One cell lines up only one way, so without crossing over it makes just 2 kinds; it takes many cells to make all 2n. Two line-ups that are mirror images give the same gametes in swapped cells. For humans, n = 23, so 223 = 8,388,608.
  • DNA per cell: every chromatid counts as the same amount of DNA, scaled so a G1 cell holds 2 units: 4 after S phase, 2 in each cell after meiosis I, 1 in each gamete. (Real chromosomes differ in size.)
  • Mitosis of the same cell, for comparison: after S phase the sister chromatids of every chromosome separate, homologs never pair and there is no crossing over in the model, so two daughter cells each get 2n chromosomes, identical to the parent cell.
  • Sex chromosomes are not shown. The model has no randomness: the same settings always give the same gametes.
