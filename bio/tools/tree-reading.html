Phylogenetic tree reading

Learn to read and build evolutionary trees by rotating, tapping and grouping.

About this tool

Read a family tree of species. Turn branches around a branch point and see that the relationships stay the same, find the most recent common ancestor of any taxa, test whether a group is a clade, mark where each shared derived character evolved, and build a tree yourself from a table of characters. Every step works with buttons and lists, and every tree has a written description. The questions below use the same trees.

How it works

A phylogenetic tree is a hypothesis about how species are related. Read it from the root (the oldest common ancestor, at the left) toward the tips (the living taxa, at the right).

  • Each node (branch point) stands for a common ancestor that split into two or more lineages. The nodes here are numbered so you can name them; node 1 is the root.
  • The most recent common ancestor of a set of taxa is the node closest to the tips that has all of them among its descendants.
  • A clade (a monophyletic group) is an ancestor and all of its descendants: every tip beyond one node. Two clades that split from the same node are sister groups.
  • A group that is not a clade: the tool calls it paraphyletic when it leaves out one clade of its common ancestor's descendants (like "fish" without the four-limbed animals), and polyphyletic when its members come from separate branches and their common ancestor's other descendants are scattered among them.
  • Rotating a node swaps the order of the branches that come out of it, like spinning a mobile. The tips move up or down the page, but every node keeps the same descendants, so the relationships do not change. Taxa next to each other on the page are not necessarily close relatives.
  • A shared derived character is a trait that appeared in a common ancestor and is inherited by all its descendants (unless lost later). Each one is marked on the branch leading to the clade that has it. A character only one taxon has marks that taxon's own branch and says nothing about grouping. A trait every taxon in the table shares, or one the outgroup also has, does not help either.
  • The outgroup branched off before all the others. It shows which state of each character is the older one: whatever the outgroup has is treated as ancestral.
  • Building a tree from a table: the taxa sharing a derived character form a clade, and a character shared by fewer taxa marks a clade nested inside. The tool accepts your tree if it has exactly the clades the table supports, in any rotation.
  • Branch lengths. In a cladogram (the body-character trees) only the branching order matters; the tips are lined up on the right. In the DNA tree each branch is drawn to scale: its length is the percent of DNA bases that changed along it.
  • A tree is a hypothesis: new data can move a branch. The tool has no randomness, so the same steps always give the same results.
