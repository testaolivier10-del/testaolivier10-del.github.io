Model Studio

Build the model piece by piece, then test it on a case.

About this tool

Every model the exam names, built by hand. Pick a model, see how it works piece by piece, then build it yourself. In Test yourself you build it, apply it to a case and pick out one of its limits.

Models are simplified ideas, not facts: each one here says what it assumes and where it fails.

How this trainer works

Build it. Tap a piece, then the place it belongs (or drag it). Some pieces belong to other models. Check grades every place, and the first mistake is named.

Apply it. A map, a graph or a table to read with the model. Invented places are labeled invented; real places come with the date of what is said about them.

Find a limit. One statement is a real limitation; the others are what the model claims or a misreading of it.

Free: Explore for every model and the demographic transition drills. The other drills are part of Premium.
