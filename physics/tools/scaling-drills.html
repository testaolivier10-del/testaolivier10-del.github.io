Scaling drills

Predict how one quantity changes when another is scaled.

About this tool

How does one quantity change when another is doubled, tripled or halved? Pick a relation, drag the factor and see the change: the picture and the bars resize as you go. Then practice: functional-dependence questions from the units you have reached, unit checks in kg, m and s, and SI conversions.

Functional dependence in three steps

  1. Find the power. Write the relation and read the power of the variable that changes: K = ½mv² has v², so K ∝ v². A square root is a power of ½ (T = 2π√(L/g), so T ∝ √L); a variable in the denominator has a negative power (Fg ∝ 1/r²).
  2. Raise the factor to that power. If v triples, K changes by 3² = 9. If L is 4 times as long, T changes by √4 = 2. If r doubles, Fg changes by 1/2² = ¼.
  3. Multiply independent changes. Double m and triple v: K changes by 2 × 9 = 18.

Unit checks: write every quantity in kg, m and s (N = kg·m/s², J = kg·m²/s², W = kg·m²/s³, Pa = kg/(m·s²)) and add the powers. Conversions: an area converts with the square of the length factor and a volume with its cube (1 m³ = 10⁶ cm³).

Factors count within about 1%; conversions within 0.6%.
