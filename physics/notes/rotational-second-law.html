6Energy and Momentum of Rotating Systems

A net force changes an object's velocity; a net torque changes its angular velocity. This page puts a number on that. It is the rotational version of Newton's second law, and it is what lets you predict how a pulley, a drum or a door speeds up when something pushes it.

α = τnet / I

For translation, a = Fnet/m: more force, more acceleration; more mass, less. For rotation, swap in the partners: torque for force, rotational inertia for mass, angular acceleration for acceleration.

α = τnet / I   or   τnet = Iα

The angular acceleration has the direction of the net torque: a counterclockwise net torque speeds up a wheel turning counterclockwise, or slows one turning clockwise. With zero net torque, α = 0 and ω stays constant, which is the first law again.

Worked example 1. A grindstone with I = 0.25 kg·m² starts from rest. A net torque of 1.5 N·m acts on it. How long until it turns at 24 rad/s?

α = τnet/I = (1.5 N·m)/(0.25 kg·m²) = 6.0 rad/s².

From rest, ω = αt, so t = ω/α = (24 rad/s)/(6.0 rad/s²) = 4.0 s.

Rotational inertia now shows why it matters. Apply the same torque to a hoop and a disk of the same mass and radius. The hoop's I = MR² is twice the disk's ½MR², so the hoop gets half the angular acceleration.

Two analyses for one system

Many problems have a part that moves and a part that turns. A block hangs from a string wound on a pulley with mass. The block falls; the pulley spins. To describe the whole thing you need one equation for each.

  • The block (translation), down positive: mg − FT = ma.
  • The pulley (rotation): of the forces on it, only the string's pull has a lever arm, R. So FTR = Iα.
  • The link: the string does not slip, so a = Rα.

Worked example 2. A 0.200 kg block hangs from a light string wound on a uniform disk pulley (M = 1.20 kg, R = 0.080 m, I = ½MR², given) on a frictionless axle. Find the block's acceleration and the tension. Use g = 9.8 m/s².

Pulley: FTR = (½MR²)(a/R), so FT = ½Ma = (0.600 kg)a. R cancels.

Block: mg − FT = ma, so mg = (m + ½M)a.

a = (0.200 kg)(9.8 m/s²)/(0.200 kg + 0.600 kg) = 2.45 m/s².

FT = (0.600 kg)(2.45 m/s²) = 1.47 N. Check with the block: (0.200 kg)(9.8 − 2.45) m/s² = 1.47 N.

Two features of that answer are worth remembering. The tension (1.47 N) is less than the block's weight (1.96 N): the block speeds up downward, so the net force on it must be down. And the acceleration is less than g, because part of gravity's pull goes into spinning up the pulley.

Strings over a pulley with mass

With an ideal (massless) pulley, the tension is the same on both sides of the string. That stops being true once the pulley has mass. To give the pulley an angular acceleration, the two sides must pull with different tensions: (FT1 − FT2)R = Iα. The heavier block's side has the larger tension, but still less than that block's weight.

Reading data

If you apply several known torques to a wheel and measure α, then α = (1/I)τ says a graph of α against τ is a line through the origin with slope 1/I. If friction at the axle exerts a constant torque, the line keeps its slope but shifts: the wheel only starts to speed up once the applied torque exceeds the friction torque.
