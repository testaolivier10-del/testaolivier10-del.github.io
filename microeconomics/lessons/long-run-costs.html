Unit 3 · Topic 3.3

Long-Run Production Costs

In the long run every input can change, so a firm chooses the plant size with the lowest cost for each output; long-run average total cost traces those lowest costs.

Practice 1: Principles and ModelsPractice 2: Interpretation

Part 1 · Hook

Why this matters

A neighborhood brewery that triples in size can buy grain by the truckload, run a bottling line instead of filling bottles by hand, and spread its marketing over far more cans. Each can gets cheaper. Grow it into a giant with plants on three continents, though, and meetings, paperwork and missed messages can push the cost of each can back up.

Part 5 · Step by step

How it works, step by step

  1. A small firm grows by adding every input→it can use specialized workers and machines and buy in bulk
  2. Specialization and bulk buying make output grow faster than costs→long-run average total cost falls: economies of scale
  3. The firm reaches minimum efficient scale→LRATC hits its lowest level and may stay flat for a range: constant returns to scale
  4. The firm grows so large that it is hard to coordinate→costs grow faster than output, so LRATC rises: diseconomies of scale

Part 6 · Key ideas

Key ideas

  • In the long run every input can change. LRATC is the lowest average cost of each output when the firm picks the best plant size.
  • Returns to scale: double every input; if output more than doubles, increasing returns; exactly doubles, constant; less than doubles, decreasing.
  • LRATC falls with economies of scale, is flat with constant returns to scale and rises with diseconomies of scale.
  • Minimum efficient scale is the smallest output with the lowest LRATC. Large next to market demand: few firms. Small: many firms.

Part 7 · Misconception

A common mistake

The wrong idea: Diseconomies of scale are just diminishing marginal returns in a big firm.

What actually happens: Diminishing marginal returns are a short-run idea: one input is fixed. Diseconomies of scale are a long-run idea: every input grows, and cost per unit rises from the problems of running a very large firm.

  2. The average cost of each output with the plant held fixed
  3. The extra cost of one more unit with a fixed plant
  4. The total cost of the largest plant the firm could build
Show the answer

In the long run every input can change, so for each output the firm chooses the plant size with the lowest cost. LRATC traces those lowest average costs.

  • Correct: The lowest average cost of each output, any plant size: Right: LRATC lets the firm pick the best plant size for each output.
  • The average cost of each output with the plant held fixed: That is a short-run ATC curve.
  • The extra cost of one more unit with a fixed plant: That is short-run marginal cost.
  • The total cost of the largest plant the firm could build: LRATC is an average for each output, not one plant's total.

Scenario

Sunmere Solar grows its factory

Sunmere Solar doubles every input it uses: workers, assembly lines, floor space and machines. Its weekly output of solar panels rises from 1,000 to 2,500. Years later, at a much larger size, it doubles every input again, and weekly output rises from 4,000 to 7,000. Input prices stay the same throughout. (An invented business, for practice.)

5. In the scenario, the first doubling of inputs shows

  1. increasing returns to scale, because output more than doubles
  2. decreasing returns to scale, because output rises by less than inputs
  3. constant returns to scale, because each input doubled
  4. diminishing marginal returns, because one input is fixed
Show the answer

Returns to scale compare output growth with input growth when every input changes. Output going from 1,000 to 2,500 (2.5 times) when inputs double is increasing returns to scale.

  • Correct: increasing returns to scale, because output more than doubles: Right: output rises 2.5 times when every input doubles.
  • decreasing returns to scale, because output rises by less than inputs: Output rose by more than double (1,000 to 2,500), not less.
  • constant returns to scale, because each input doubled: Constant returns would mean output exactly doubles, to 2,000.
  • diminishing marginal returns, because one input is fixed: No input is fixed here; every input doubled.

6. In the scenario, input prices do not change. What happens to the firm's long-run average total cost after the first doubling?

  1. It rises: the firm has diseconomies of scale
  2. It stays the same: total cost doubled
  3. It falls: the firm has economies of scale
  4. It falls: the firm has diminishing marginal returns
Show the answer

With input prices fixed, doubling every input doubles total cost. Output rises 2.5 times, so cost per unit falls to 22.5=0.8\frac{2}{2.5} = 0.8 of what it was: economies of scale.

  • It rises: the firm has diseconomies of scale: Cost per panel rises only if output grows by less than the inputs.

  • Correct: It falls: the firm has economies of scale: Right: costs double but output rises 2.5 times, so cost per panel falls.
  • It falls: the firm has diminishing marginal returns: Diminishing marginal returns would raise costs, and they need a fixed input.

Part 9 · Summary

Summary

In the long run every input can change, so a firm chooses the plant size with the lowest cost for each output; long-run average total cost traces those lowest costs. Returns to scale compare the growth of output with the growth of all inputs. With input prices unchanged, increasing returns bring economies of scale (falling LRATC), constant returns a flat LRATC and decreasing returns diseconomies of scale (rising LRATC). Minimum efficient scale, the smallest output at the lowest LRATC, compared with market demand, helps decide how many firms an industry can hold.
