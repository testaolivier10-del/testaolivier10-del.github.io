A delivery van uses 6 gallons of fuel per 100 miles at 20 miles per hour, only 3.4 gallons at 50, and 4.4 again at 70. Plot those numbers and the curve falls, bottoms out and rises: a U. The shape tells you more than any single number does: where the van is most fuel-efficient, and how fast things change on either side. Economics reads graphs the same way, and its main tool for that is the slope.

Rise over run

The slope of a line measures how steeply it rises or falls. Pick two points on the line. The rise is the change in the vertical value between them; the run is the change in the horizontal value. Then

$\text{slope} = \frac{\text{rise}}{\text{run}} = \frac{\text{change in vertical value}}{\text{change in horizontal value}}$

Subtract in the same order on top and bottom: second point minus first point for both. The slope tells you how much the vertical variable changes for each one-unit change in the horizontal variable.

Worked example: the slope of a straight line. A line passes through (20, 8) and (60, 4).

  1. Rise (vertical change, second minus first): $4 - 8 = -4$.
  2. Run (horizontal change, in the same order): $60 - 20 = 40$.
  3. Divide: $\frac{-4}{40} = -0.1$.
  4. Check the sign. The line falls as you move right, so a negative slope makes sense. For each one unit across, the vertical value falls by 0.1.

Dividing the other way, $\frac{40}{-4} = -10$, is the common slip. Rise always goes on top.

Reading the sign

ShapeSlopeWhat it says
Rises to the rightpositiveboth variables rise together: a direct relationship
Falls to the rightnegativeone rises as the other falls: an inverse relationship
Horizontal0the vertical value stays the same whatever the horizontal value
Verticaltoo steep for a numberthe horizontal value stays the same whatever the vertical value

Steepness is the size of the slope, ignoring its sign. A line with slope -3 is steeper than one with slope -0.33, even though both fall. When a question asks which line is "steeper", compare sizes; when it asks whether the relationship is direct or inverse, look at the sign.

Straight lines and curves

A straight line has one slope everywhere: pick any two points and you get the same rise over run. A curve is different. Its slope changes as you move along it. A curve that gets steeper as it goes up has a slope that grows; one that flattens out has a slope that moves toward 0. To describe a curve's slope over a range, take two points at the ends of the range and work out rise over run between them.

U-shaped curves and the minimum point

A U-shaped curve falls, reaches a lowest point, then rises. Its slope is negative on the left side, positive on the right side, and 0 at the bottom, the minimum point, where the curve stops falling and starts rising. The van's fuel curve is U-shaped with its minimum point at 50 miles per hour.

Worked example: slopes on a U-shaped curve. The van uses 6.0 gallons per 100 miles at 20 miles per hour, 3.8 at 40, 3.4 at 50 and 4.4 at 70.

  1. From 20 to 40: rise $3.8 - 6.0 = -2.2$, run $40 - 20 = 20$, slope $\frac{-2.2}{20} = -0.11$. Negative: the curve is falling.
  2. From 50 to 70: rise $4.4 - 3.4 = 1.0$, run $70 - 50 = 20$, slope $\frac{1.0}{20} = 0.05$. Positive: the curve is rising.
  3. Minimum point: 50 miles per hour, the lowest fuel use, where the slope changes from negative to positive.

Several important curves in this course are U-shaped, and the exam checks that you put their minimum points in the right place. Get used to spotting where a curve stops falling and starts rising, and to reading which way the slope runs on each side.
