To use the Fundamental Theorem you need antiderivatives, and lots of them. This page collects the basic rules, introduces the notation for "all the antiderivatives at once," and shows how a single known point picks out the function you want.

A family, not a single function

$x^3/3 - x$ has derivative $x^2 - 1$. So does $x^3/3 - x + 5$, and $x^3/3 - x - 2$: a constant has derivative 0. On an interval, these are the only antiderivatives; two functions with the same derivative differ by a constant. Graphically they are vertical shifts of one curve, as the figure shows.

The indefinite integral names the whole family:

$$\int (x^2 - 1)\,dx = \frac{x^3}{3} - x + C.$$

$C$ is the constant of integration. Leaving it off says "this one function," which is wrong: the scoring guidelines take a point for a missing $+ C$.

Constant factors come out and sums split: $\int (kf + g)\,dx = k\int f\,dx + \int g\,dx$. Products and quotients do not split, so rewrite them first.

Worked example 1. Find $\int \left(\sqrt{x} + \frac{4}{x^3} - 2\cos x\right)dx$.

Rewrite as powers: $\sqrt{x} = x^{1/2}$ and $\frac{4}{x^3} = 4x^{-3}$.

$\int x^{1/2}\,dx = \frac{x^{3/2}}{3/2} = \frac{2}{3}x^{3/2}$. $\int 4x^{-3}\,dx = 4\cdot\frac{x^{-2}}{-2} = -\frac{2}{x^2}$. $\int 2\cos x\,dx = 2\sin x$.

Answer: $\frac{2}{3}x^{3/2} - \frac{2}{x^2} - 2\sin x + C$. Check: differentiating gives back $x^{1/2} + 4x^{-3} - 2\cos x$.

Two more rewrites: expand a power of a sum, $(x^2 + 1)^2 = x^4 + 2x^2 + 1$, and split a fraction over a single term, $\frac{x^3 - 2x}{x} = x^2 - 2$. Never integrate the top and bottom of a fraction separately.

Picking one function: use a known point

Worked example 2. $f'(x) = 3x^2 - 4x + 1$ and $f(2) = 5$. Find $f(x)$.

Antidifferentiate: $f(x) = x^3 - 2x^2 + x + C$.

Substitute the point right away: $f(2) = 8 - 8 + 2 + C = 2 + C = 5$, so $C = 3$.

$f(x) = x^3 - 2x^2 + x + 3$.

With a second derivative, antidifferentiate twice; each step brings its own constant, and each needs its own piece of information, such as $f'(0)$ and then $f(0)$.

Some functions have no formula for an antiderivative

Every continuous function has antiderivatives (the accumulation function $\int_a^x f(t)\,dt$ is one), but some cannot be written with familiar functions: $e^{-x^2}$ and $\sin(x^2)$ are examples. On the exam, integrals of such functions appear on calculator questions, and the calculator evaluates them numerically.
