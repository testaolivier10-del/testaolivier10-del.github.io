Separation of variables hands you a general solution: a family of curves with a constant CC in it. A real question usually wants one curve. The coffee was 90 °C at noon; the population was 200 at the start; the curve passes through (1,−3)(1, -3). That one fact is an initial condition, and the single curve it selects is a particular solution. A differential equation together with an initial condition is called an initial value problem.

The procedure

  1. Separate and integrate, adding +C+ C (exactly as before).
  2. Substitute the initial condition immediately. An initial condition y(x0)=y0y(x_0) = y_0 means: replace xx by x0x_0 and yy by y0y_0. Solve for CC.
  3. Put the value of CC back and solve for yy. If a square root or an absolute value appears, keep the sign that matches y0y_0.
  4. State the domain of the solution (below).

Why substitute before solving for yy? Because the equation right after integrating is the simplest place to find CC. Solving for yy first means exponentiating or taking roots with CC still unknown, where most sign and algebra slips happen.

Worked example 1. Solve dydx=2xy\frac{dy}{dx} = \frac{2x}{y} with y(1)=−3y(1) = -3.

Separate and integrate: ydy=2xdxy\,dy = 2x\,dx, so y22=x2+C\frac{y^2}{2} = x^2 + C.

Use the condition now: (−3)22=12+C\frac{(-3)^2}{2} = 1^2 + C, so C=92−1=72C = \frac{9}{2} - 1 = \frac{7}{2}.

Solve: y2=2x2+7y^2 = 2x^2 + 7, so y=±2x2+7y = \pm\sqrt{2x^2 + 7}. The point (1,−3)(1, -3) has a negative yy, so take the negative root: y=−2x2+7y = -\sqrt{2x^2 + 7}.

Check: at x=1x = 1, y=−9=−3y = -\sqrt{9} = -3. Good.

Worked example 2. Coffee cools by dTdt=−0.05(T−20)\frac{dT}{dt} = -0.05(T - 20), with T(0)=90T(0) = 90. Find T(t)T(t).

Use the condition: ln⁡|90−20|=0+C\ln|90 - 20| = 0 + C, so C=ln⁡70C = \ln 70.

Solve: |T−20||T - 20|=e−0.05t+ln⁡70= e^{-0.05t + \ln 70}=70e−0.05t= 70e^{-0.05t}. At t=0t = 0, T−20=70>0T - 20 = 70 > 0, so T−20=70e−0.05tT - 20 = 70e^{-0.05t} and

T(t)=20+70e−0.05t.T(t) = 20 + 70e^{-0.05t}.

The domain of a particular solution

A solution must be differentiable at every point where you claim it works, and it must be one connected piece. So the domain of a particular solution is the largest open interval that contains x0x_0 and on which the formula is defined and differentiable (and makes the differential equation meaningful).

Worked example 3. Solve dydx=y2\frac{dy}{dx} = y^2 with y(0)=1y(0) = 1, and give the domain.

Separate and integrate: y−2dy=dxy^{-2}\,dy = dx, so −1y=x+C-\frac{1}{y} = x + C.

Condition: −1=0+C-1 = 0 + C, so C=−1C = -1. Then −1y=x−1-\frac{1}{y} = x - 1, and y=11−xy = \frac{1}{1 - x}.

The formula breaks at x=1x = 1. The interval containing x0=0x_0 = 0 is x<1x < 1, so the particular solution is y=11−xy = \frac{1}{1 - x} for x<1x < 1.

Notice what happened. The equation dydx=y2\frac{dy}{dx} = y^2 looks harmless, yet the solution through (0,1)(0, 1) shoots to infinity at x=1x = 1. You could not have seen that from the equation alone; the formula shows it.

Watch for three ways a formula breaks: a division by 0, an even root of a negative number, and a logarithm of a number that is not positive. Also look at the differential equation itself: for dydx=−xy\frac{dy}{dx} = -\frac{x}{y} with y(0)=3y(0) = 3, the solution y=9−x2y = \sqrt{9 - x^2} reaches y=0y = 0 at x=±3x = \pm 3, where −xy-\frac{x}{y} divides by 0. So the domain is the open interval −3<x<3-3 < x < 3.

Common slips

  • Adding the constant after solving: from ln⁡|y|=sin⁡x+C\ln|y| = \sin x + C, writing y=esin⁡x+Cy = e^{\sin x} + C. Exponentiating gives y=Aesin⁡xy = Ae^{\sin x}.
  • Substituting the condition the wrong way round: y(0)=2y(0) = 2 means x=0x = 0 and y=2y = 2.
  • Keeping the wrong sign after a square root.
  • Giving the formula without its domain, or a domain that does not contain x0x_0.
