Choosing a Differentiation Rule

3 min read · freeNot practiced

Share to Google Classroom (opens in a new tab)

By now you know every differentiation rule on the AP® Calculus AB exam: the power rule, the derivatives of sine, cosine, exe^x and ln⁡x\ln x, the product, quotient and chain rules, implicit differentiation and the inverse rules. The hard part is no longer a rule. It is deciding, in front of a long expression, which rule goes first. This page gives one question that always answers that, and practices it on the kinds of expressions the exam likes.

The one question: what is the last operation?

Imagine evaluating the expression at a number with a calculator. The operation you would do last is the outermost layer, and it names the first rule.

x2sin⁡(3x)x^2\sin(3x)multiplying x2x^2 by sin⁡(3x)\sin(3x)product rule
e2xx+1\frac{e^{2x}}{x + 1}dividingquotient rule
(xex)3\left(xe^x\right)^3cubingchain rule
sin2⁡(x3)\sin^2\left(x^3\right)squaringchain rule
ln⁡(x2+1)\ln\left(x^2 + 1\right)taking the logchain rule

After the first rule, each piece is a smaller expression. Ask the same question of each piece. Keep going until only basic derivatives remain. Each layer gets exactly one rule.

Worked examples

Worked example 1. Differentiate y=x2sin⁡(3x)y = x^2\sin(3x).

Last operation: a product. Product rule: y′y'=(x2)′sin⁡(3x)+x2(sin⁡(3x))′= (x^2)'\sin(3x) + x^2\left(\sin(3x)\right)'.

The piece sin⁡(3x)\sin(3x) is a composition: chain rule, (sin⁡(3x))′=3cos⁡(3x)\left(\sin(3x)\right)' = 3\cos(3x).

So y′y'=2xsin⁡(3x)+3x2cos⁡(3x)= 2x\sin(3x) + 3x^2\cos(3x).

Worked example 2. Differentiate y=(xex)3y = \left(xe^x\right)^3.

Last operation: cubing. Chain rule: y′=3(xex)2⋅(xex)′y' = 3\left(xe^x\right)^2 \cdot \left(xe^x\right)'.

The inside xexxe^x is a product: (xex)′=ex+xex\left(xe^x\right)' = e^x + xe^x.

So y′y'=3(xex)2(ex+xex)= 3\left(xe^x\right)^2\left(e^x + xe^x\right). There is no need to simplify further; the exam accepts this form, and extra algebra only adds risk.

Worked example 3. Values from a table: f(1)=2f(1) = 2, f′(1)=3f'(1) = 3. Find D′(1)D'(1) for D(x)=x⋅f(x2)D(x) = x \cdot f(x^2).

Last operation: multiplying xx by f(x2)f(x^2). Product rule: D′(x)D'(x)=1⋅f(x2)+x⋅(f(x2))′= 1 \cdot f(x^2) + x \cdot \left(f(x^2)\right)'.

The piece f(x2)f(x^2) is a composition: (f(x2))′=f′(x2)⋅2x\left(f(x^2)\right)' = f'(x^2) \cdot 2x.

At x=1x = 1: D′(1)D'(1)=f(1)= f(1)+1⋅f′(1)⋅2+ 1 \cdot f'(1) \cdot 2=2= 2+6+ 6=8= 8.

Rewrite first, when it removes a rule

Some quotients are really sums of powers in disguise. Before reaching for the quotient rule, check whether the bottom is a single power of xx or a constant:

  • 5x3=5x−3\frac{5}{x^3} = 5x^{-3}, so its derivative is −15x−4-15x^{-4}. No quotient rule.
  • x2+3x\frac{x^2 + 3}{\sqrt{x}}=x3/2= x^{3/2}+3x−1/2+ 3x^{-1/2}, so its derivative is 32x1/2−32x−3/2\frac{3}{2}x^{1/2} - \frac{3}{2}x^{-3/2}.
  • sin⁡x4=14sin⁡x\frac{\sin x}{4} = \frac{1}{4}\sin x, so its derivative is 14cos⁡x\frac{1}{4}\cos x.

Logarithm rules can help too: ln⁡(x3)=3ln⁡x\ln\left(x^3\right) = 3\ln x. But do not rewrite just to rewrite. If the quotient rule is quick, use it.

Beyond formulas

Two more situations name their own method. An equation that mixes xx and yy, such as x2+xy+y2=7x^2 + xy + y^2 = 7, calls for implicit differentiation. A question about the slope of an inverse, (f−1)′(a)\left(f^{-1}\right)'(a), calls for 1f′(f−1(a))\frac{1}{f'\left(f^{-1}(a)\right)}. And when the functions come as a table or a graph, the rules are the same; you simply read each value at the right input. A corner on a graph (where the function has no derivative) means a rule that needs f′f' there cannot be used.

Slips that cost points

  • Multiplying derivatives. (fg)′≠f′g′(fg)' \ne f'g' and (fg)′≠f′g′\left(\frac{f}{g}\right)' \ne \frac{f'}{g'}.
  • Reversing the quotient rule's numerator. It is f′g−fg′f'g - fg'; the derivative of the top comes first.
  • Missing a layer. Count the layers and check that your answer has one factor or term for each.
  • Three-factor products. (fgh)′(fgh)'=f′gh+fg′h+fgh′= f'gh + fg'h + fgh': each factor takes a turn being differentiated.
