Inverse Functions

4 min read · freeNot practiced

Share to Google Classroom (opens in a new tab)

A function takes an input and produces an output. Very often, though, the question runs the other way: the thermometer reads 70 °F, so what time is it? The sine of an angle is 0.8, so what is the angle? Running a function backward is the job of an inverse function. Unit 3 asks how fast an inverse changes, and the answer comes straight out of one picture on this page.

What an inverse does

If ff sends aa to bb, its inverse f−1f^{-1} sends bb back to aa: f−1(b)=aexactly whenf(a)=bf^{-1}(b) = a \quad \text{exactly when} \quad f(a) = b Doing one and then the other gets you back where you started: f−1(f(x))=xf^{-1}(f(x)) = x and f(f−1(x))=xf(f^{-1}(x)) = x.

From a table, read an inverse backward: find the output in the output row and read the input above it. If f(3)=9f(3) = 9, then f−1(9)=3f^{-1}(9) = 3.

One warning, repeated because it costs so many points: f−1(x)f^{-1}(x) is not 1f(x)\frac{1}{f(x)}. The −1-1 here means "undo," not "reciprocal." If you mean the reciprocal, write 1f(x)\frac{1}{f(x)} or [f(x)]−1[f(x)]^{-1}.

When an inverse exists

An inverse must send each output back to exactly one input. So ff needs to be one-to-one: no two inputs share an output. On a graph, that is the horizontal line test: every horizontal line meets the graph at most once. Functions that only increase, or only decrease, are one-to-one.

f(x)=x2f(x) = x^2 fails, since f(2)=f(−2)=4f(2) = f(-2) = 4. The fix is to restrict the domain. On x≥0x \ge 0, x2x^2 is one-to-one and its inverse is x\sqrt{x}. That is why 9\sqrt{9} is 3 and not −3-3.

Finding a formula

To find f−1f^{-1}, write the equation x=f(y)x = f(y) (inputs and outputs swapped) and solve for yy.

Worked example 1. Find the inverse of f(x)=2x+1x−3f(x) = \frac{2x + 1}{x - 3}.

Swap: x=2y+1y−3x = \frac{2y + 1}{y - 3}. Clear the fraction: x(y−3)=2y+1x(y - 3) = 2y + 1, so xy−3x=2y+1xy - 3x = 2y + 1.

Collect the yy terms: xy−2y=3x+1xy - 2y = 3x + 1, so y(x−2)=3x+1y(x - 2) = 3x + 1, and f−1(x)=3x+1x−2f^{-1}(x) = \frac{3x + 1}{x - 2}.

Check with a number: f(0)=−13f(0) = -\frac{1}{3}, and f−1(−13)f^{-1}\left(-\frac{1}{3}\right) =−1+1−13−2= \frac{-1 + 1}{-\frac{1}{3} - 2} =0= 0. It undoes ff.

The graph of an inverse

Every point (a,b)(a, b) on the graph of ff becomes the point (b,a)(b, a) on the graph of f−1f^{-1}. Swapping coordinates is a reflection across the line y=xy = x.

Look at the slopes in the figure. Reflecting swaps the roles of rise and run, so a line of slope 2 through (1,3)(1, 3) reflects to a line of slope 12\frac{1}{2} through (3,1)(3, 1). In general, at matching points the slopes of ff and f−1f^{-1} are reciprocals. You can see it in a table too: if ff rises 3 while xx moves 1, then f−1f^{-1} rises 1 while its input moves 3.

Worked example 2. f(2)=7f(2) = 7, and the graph of ff has slope 4 at (2,7)(2, 7). Describe f−1f^{-1} there.

The graph of f−1f^{-1} passes through (7,2)(7, 2), so f−1(7)=2f^{-1}(7) = 2.

Its slope at (7,2)(7, 2) is 14\frac{1}{4}. Topic 3.3 turns exactly this into a formula.
