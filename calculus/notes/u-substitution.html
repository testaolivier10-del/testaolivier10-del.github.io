The basic rules handle cos⁡x\cos x and x5x^5, but not 2xcos⁡(x2)2x\cos(x^2) or x(1+x2)3x(1 + x^2)^3. Those integrands came from the chain rule, and u-substitution is the chain rule run backward.

Spotting the chain rule in an integrand

By the chain rule, ddxsin⁡(x2)\frac{d}{dx}\sin(x^2)=cos⁡(x2)⋅2x= \cos(x^2) \cdot 2x. So

∫2xcos⁡(x2)dx=sin⁡(x2)+C.\int 2x\cos(x^2)\,dx = \sin(x^2) + C.

The pattern: an inside function g(x)=x2g(x) = x^2, an outside function applied to it, and the inside's derivative g′(x)=2xg'(x) = 2x as a factor. Whenever you see f(g(x))g′(x)f(g(x))\,g'(x), the answer is F(g(x))+CF(g(x)) + C, where FF is an antiderivative of ff.

The method

  1. Choose uu: an inside function whose derivative is also in the integrand (up to a constant factor).
  2. Find du=g′(x)dxdu = g'(x)\,dx.
  3. Rewrite the whole integral in uu. No xx may remain.
  4. Integrate in uu, then substitute u=g(x)u = g(x) back.
  5. Check by differentiating.

Worked example 1. Find ∫xx2+4dx\int \frac{x}{x^2 + 4}\,dx.

Inside: u=x2+4u = x^2 + 4, so du=2xdxdu = 2x\,dx and xdx=12dux\,dx = \frac{1}{2}du.

Rewrite: ∫1u⋅12du\int \frac{1}{u}\cdot\frac{1}{2}\,du=12ln⁡|u|+C= \frac{1}{2}\ln|u| + C.

Back to xx: 12ln⁡(x2+4)+C\frac{1}{2}\ln(x^2 + 4) + C (no absolute value needed: x2+4>0x^2 + 4 > 0).

Check: ddx[12ln⁡(x2+4)]\frac{d}{dx}\left[\frac{1}{2}\ln(x^2 + 4)\right]=12⋅2xx2+4= \frac{1}{2}\cdot\frac{2x}{x^2 + 4}=xx2+4= \frac{x}{x^2 + 4}.

A missing constant factor is fine: multiply and divide by it, as with the 12\frac{1}{2} above. A missing variable factor is not: ∫(x2+1)5dx\int (x^2 + 1)^5\,dx has no xx to match du=2xdxdu = 2x\,dx, so substitution fails (expand the power instead).

Linear inside functions

When the inside is kxkx or kx+bkx + b, du=kdxdu = k\,dx, so the rule is just "divide by kk":

∫e3xdx=13e3x+C,∫cos⁡(5x)dx=15sin⁡(5x)+C.\int e^{3x}\,dx = \frac{1}{3}e^{3x} + C, \qquad \int \cos(5x)\,dx = \frac{1}{5}\sin(5x) + C.

Check by differentiating: the chain rule puts the kk back.

Definite integrals: change the limits

In a definite integral, the limits are values of the variable. When the variable changes from xx to uu, the limits must change too: x=ax = a becomes u=g(a)u = g(a) and x=bx = b becomes u=g(b)u = g(b). The figure shows the idea: the region under 2xcos⁡(x2)2x\cos(x^2) on [0,π/2][0, \sqrt{\pi/2}] and the region under cos⁡u\cos u on [0,π2][0, \frac{\pi}{2}] have the same area.

Worked example 2. Evaluate ∫01x(1+x2)3dx\int_0^1 x(1 + x^2)^3\,dx.

u=1+x2u = 1 + x^2, du=2xdxdu = 2x\,dx, so xdx=12dux\,dx = \frac{1}{2}du.

Limits: x=0→u=1x = 0 \to u = 1; x=1→u=2x = 1 \to u = 2.

12∫12u3du\frac{1}{2}\int_1^2 u^3\,du=12⋅u44|12= \frac{1}{2}\cdot\frac{u^4}{4}\Big|_1^2=18(16−1)= \frac{1}{8}(16 - 1)=158= \frac{15}{8}.

The common wrong answer, 18\frac{1}{8}, comes from evaluating u48\frac{u^4}{8} at the old limits 0 and 1.

Write the uu-limits on the integral sign as soon as you change variables. Mixing a uu-integrand with xx-limits is a linkage error the scoring guidelines penalize.

Substitution with tables

The same idea works with functions given only by values. Since ddxf(g(x))\frac{d}{dx}f(g(x))=f′(g(x))g′(x)= f'(g(x))g'(x),

∫13f′(g(x))g′(x)dx=f(g(3))−f(g(1)).\int_1^3 f'(g(x))\,g'(x)\,dx = f(g(3)) - f(g(1)).

Read g(3)g(3) and g(1)g(1) from the table first, then ff at those inputs.
