Disc Method About Other Lines

4 min read · freeNot practiced

Share to Google Classroom (opens in a new tab)

Same discs, a different center

In the last topic every solid spun around the xx-axis or the yy-axis. Nothing in the disc method needs the axis of rotation to be one of the coordinate axes. A region can be revolved about the line y=1y = 1, or y=−2y = -2, or x=3x = 3. The slices perpendicular to that line are still discs, as long as the region touches the line all the way across. What changes is the radius.

The radius of a disc is the distance from its center, on the axis, to its edge, on the curve. When the axis was the xx-axis, that distance happened to be f(x)f(x), the curve's height. When the axis is the line y=ky = k, the distance is the gap between the heights kk and f(x)f(x):

r=k−f(x) if the line is above the curve,r=f(x)−k if it is below.r = k - f(x) \text{ if the line is above the curve}, \qquad r = f(x) - k \text{ if it is below.}

Always subtract the smaller height from the larger, so the radius is positive. (Since the radius is squared, a sign slip does not change the volume, but it is a sign you have lost track of the picture.)

Worked example. The region between y=x2y = x^2 and y=1y = 1 is revolved about the line y=1y = 1. Find the volume.

Limits. x2=1x^2 = 1 at x=±1x = \pm 1.

Radius. The axis y=1y = 1 is above the parabola, so r=1−x2r = 1 - x^2.

Volume.

V=π∫−11(1−x2)2dx=π∫−11(1−2x2+x4)dx=π(2−43+25)=16π15.V = \pi\int_{-1}^{1} \left(1 - x^2\right)^2\,dx = \pi\int_{-1}^{1} \left(1 - 2x^2 + x^4\right)\,dx = \pi\left(2 - \frac{4}{3} + \frac{2}{5}\right) = \frac{16\pi}{15}.

Two ways to get it wrong

Measuring from the wrong place. Using r=x2r = x^2 in the example measures from the xx-axis. That would spin the region under the parabola about the xx-axis, a different solid (2π5\frac{2\pi}{5}).

Squaring each term. π∫(12−(x2)2)dx\pi\int (1^2 - (x^2)^2)\,dx is not the same as π∫(1−x2)2dx\pi\int (1 - x^2)^2\,dx. The first gives 8π5\frac{8\pi}{5}. It looks tempting because it resembles a formula you will meet next topic, but for a solid disc the radius is one quantity: square the whole difference.

Negative kk. About y=−2y = -2, the radius to the curve y=2−x2y = 2 - x^2 is (2−x2)−(−2)=4−x2(2 - x^2) - (-2) = 4 - x^2. Write the subtraction with parentheses before simplifying.

Vertical lines

When the axis is a vertical line x=hx = h, the slices perpendicular to it are horizontal, stacked in yy. Write the curve as xx in terms of yy; the radius is the horizontal gap between hh and x(y)x(y).

Worked example. The region bounded by y=xy = x, y=0y = 0 and x=3x = 3 is revolved about the line x=3x = 3. Find the volume.

Slices. Horizontal, from y=0y = 0 to y=3y = 3. At height yy the region runs from the line x=yx = y to the axis x=3x = 3.

Radius. r=3−yr = 3 - y.

Volume. VV =π∫03(3−y)2dy= \pi\int_0^3 (3 - y)^2\,dy =π[−(3−y)33]03= \pi\left[-\frac{(3 - y)^3}{3}\right]_0^3 =π⋅273= \pi \cdot \frac{27}{3} =9π= 9\pi.

The solid is a cone with radius 3 and height 3, and 13π(3)2(3)=9π\frac{1}{3}\pi(3)^2(3) = 9\pi agrees.

A quick check: the radius is 0 where the curve meets the axis, and largest where the curve is farthest from it. If your formula says otherwise, you are measuring from the wrong line.

With a calculator, find any crossing with the axis line numerically, store it, write the setup with the radius in parentheses, for example π∫0c(4−ex/2)2dx\pi\int_0^c \left(4 - e^{x/2}\right)^2\,dx, and report three decimal places.
