Functions and Their Graphs

6 min read · freeNot practiced

Share to Google Classroom (opens in a new tab)

Calculus is the study of how functions change and how they add up. Every exam question hands you a function in some form: a formula, a graph, a table of values or a sentence about a real situation. If you are a little rusty from precalculus, this page is for you. It covers exactly the function skills the course uses, with the habits that save points later.

A function is a rule with one output per input

A function takes an input and gives back exactly one output. We write f(x)f(x) for the output when the input is xx. The letter xx is just a placeholder: f(x)=x2−3xf(x) = x^2 - 3x means "square the input, then subtract three times the input."

To evaluate, replace every xx with the input, in parentheses. The parentheses matter most when the input is negative or is itself an expression. That habit, kept all year, prevents a whole family of sign mistakes.

Worked example 1. Let f(x)=x2−3xf(x) = x^2 - 3x. Find f(−2)f(-2) and f(a+1)f(a + 1).

f(−2)f(-2) =(−2)2−3(−2)= (-2)^2 - 3(-2) =4+6= 4 + 6 =10= 10. Without parentheses, −22-2^2 would read as −4-4, which is wrong.

f(a+1)f(a + 1) =(a+1)2−3(a+1)= (a + 1)^2 - 3(a + 1) =a2+2a+1−3a−3= a^2 + 2a + 1 - 3a - 3 =a2−a−2= a^2 - a - 2.

Notice that f(a+1)f(a + 1) is not f(a)+1f(a) + 1. A function acts on the whole input at once.

Domain and range

The domain is the set of inputs the rule accepts. The range is the set of outputs it actually produces. For the functions in this course, two things shrink a domain:

  • A denominator can never be 0.
  • A square root (or any even root) needs a number that is 0 or more.

Worked example 2. Find the domain of h(x)=x+4x−1h(x) = \frac{\sqrt{x + 4}}{x - 1}.

The root needs x+4≥0x + 4 \ge 0, so x≥−4x \ge -4. The denominator needs x−1≠0x - 1 \ne 0, so x≠1x \ne 1.

Domain: x≥−4x \ge -4 and x≠1x \ne 1. Notice that x=−4x = -4 is allowed: 0=0\sqrt{0} = 0 is fine on top.

Reading a graph

The graph of ff is every point (x,f(x))(x, f(x)). So f(a)f(a) is a height: go to x=ax = a on the horizontal axis and read how high the graph is there.

Graphs in calculus often have pieces, so learn the two kinds of dot. A filled dot is a point on the graph. An open circle marks a point the graph comes close to but does not include. In the figure, the open circle at (1,3.5)(1, 3.5) is not on the graph; the filled dot at (1,5)(1, 5) is, so f(1)=5f(1) = 5.

Three more readings you will use constantly:

  • Solve f(x)=kf(x) = k: draw the horizontal line y=ky = k and read the xx-values where it meets the graph.
  • Where is ff positive? Where the graph is above the xx-axis.
  • Range: the lowest and highest heights, minding open circles at the ends.

Piecewise functions

A piecewise function uses different formulas on different parts of its domain: f(x)={x2x<23x−1x≥2f(x) = \begin{cases} x^2 & x < 2 \\ 3x - 1 & x \ge 2 \end{cases} To evaluate, first decide which piece the input belongs to, then use only that formula. The boundary value goes wherever the "or equal to" sign is. Here f(2)f(2) uses 3x−13x - 1, so f(2)=5f(2) = 5, while f(1.9)=3.61f(1.9) = 3.61 uses x2x^2. Calculus cares a lot about what happens at boundaries like x=2x = 2, so slow down there.

Lines and slope

The slope of a line is rise over run. Through (x1,y1)(x_1, y_1) and (x2,y2)(x_2, y_2): m=y2−y1x2−x1m = \frac{y_2 - y_1}{x_2 - x_1} Subtract in the same order on top and bottom. A positive slope means the line goes up to the right; a negative slope, down.

Calculus writes lines in point-slope form, because it usually knows one point and the slope there: y−y1=m(x−x1)y - y_1 = m(x - x_1) You do not need to rearrange it into y=mx+by = mx + b unless a question asks; the exam accepts point-slope form.

Worked example 3. Find the line through (1,4)(1, 4) and (3,−2)(3, -2).

Slope: mm =−2−43−1= \frac{-2 - 4}{3 - 1} =−62= \frac{-6}{2} =−3= -3.

Point-slope form with (1,4)(1, 4): y−4=−3(x−1)y - 4 = -3(x - 1). If you want it: y=−3x+7y = -3x + 7.

Check with the other point: −3(3)+7=−2-3(3) + 7 = -2. Correct.

Composite functions

A composite function feeds the output of one function into another. f(g(x))f(g(x)) means: apply gg first, then apply ff to the result. Work from the inside out.

Worked example 4. Let f(x)=x2f(x) = x^2 and g(x)=3x−1g(x) = 3x - 1. Find f(g(x))f(g(x)) and g(f(x))g(f(x)).

f(g(x))f(g(x)) =f(3x−1)= f(3x - 1) =(3x−1)2= (3x - 1)^2. Square the whole input.

g(f(x))=g(x2)=3x2−1g(f(x)) = g(x^2) = 3x^2 - 1. Different! The order of composition matters.

Going backward is just as useful. h(x)=x2+1h(x) = \sqrt{x^2 + 1} is f(g(x))f(g(x)) with inside g(x)=x2+1g(x) = x^2 + 1 and outside f(x)=xf(x) = \sqrt{x}. In Unit 3 you will split functions this way all the time.

Moving graphs

A graph transformation changes a known graph in a predictable way:

FormulaWhat happens to the graph of ff
f(x)+kf(x) + kmoves up kk (down if k<0k < 0): a vertical shift
f(x−h)f(x - h)moves right hh (left if h<0h < 0): a horizontal shift
−f(x)-f(x)flips over the xx-axis
af(x)a f(x)stretches vertically by the factor aa

The horizontal shift feels backward: x−2x - 2 moves the graph right. Here is why. The new graph reaches the old graph's lowest point when x−2=0x - 2 = 0, that is, at x=2x = 2.

Polynomials, rational functions and asymptotes

A polynomial is a sum of terms like 5x35x^3 or −2x-2x, with whole-number powers. Its domain is every real number. A rational function is one polynomial divided by another, such as r(x)=2x+1x−4r(x) = \frac{2x + 1}{x - 4}. Its domain leaves out every zero of the denominator.

An asymptote is a line the graph approaches. For a rational function:

  • Where the denominator is 0 and the numerator is not, there is a vertical asymptote. For rr, that is x=4x = 4 (the numerator is 9 there).
  • When top and bottom have the same degree, the outputs settle near the ratio of the leading coefficients as |x||x| grows large: a horizontal asymptote. For rr, that is y=21=2y = \frac{2}{1} = 2. When the top has lower degree, the horizontal asymptote is y=0y = 0.

When the top and bottom are both 0 at the same xx, something more interesting happens. Unit 1 is largely about that case.
