Washers around any line

You now have both tools this topic needs. From the disc method about other lines you know that a radius is a distance from the axis of rotation, whatever line that is. From the washer method you know that a slice with a hole has area π(R2−r2)\pi(R^2 - r^2). Put them together: when a region is revolved about a line y=ky = k or x=hx = h that it does not touch, each slice is a washer centered on that line, and both radii are measured from it.

V=π∫ab(R2−r2)dx,R=axis to far edge,r=axis to near edge.V = \pi\int_a^b \left(R^2 - r^2\right)\,dx, \qquad R = \text{axis to far edge}, \quad r = \text{axis to near edge}.

Axis below the region

If the axis y=ky = k is below the region, the top curve is the far edge and the bottom curve is the near edge. Each radius is a curve's height minus kk. With kk negative, that means adding: about y=−1y = -1, a height f(x)f(x) becomes the radius f(x)−(−1)=f(x)+1f(x) - (-1) = f(x) + 1.

Worked example. The region between y=xy = \sqrt{x} and y=1y = 1 for 1≤x≤41 \le x \le 4 is revolved about the line y=−1y = -1. Find the volume.

Radii. Far edge, the curve: R=x−(−1)=x+1R = \sqrt{x} - (-1) = \sqrt{x} + 1. Near edge, the line y=1y = 1: r=1−(−1)=2r = 1 - (-1) = 2.

Integrand. R2−r2R^2 - r^2=(x+2x+1)−4= (x + 2\sqrt{x} + 1) - 4=x= x+2x−3+ 2\sqrt{x} - 3.

Volume.

V=π∫14(x+2x−3)dx=π[x22+43x3/2−3x]14=π(203−(−76))=47π6.V = \pi\int_1^4 \left(x + 2\sqrt{x} - 3\right)\,dx = \pi\left[\frac{x^2}{2} + \frac{4}{3}x^{3/2} - 3x\right]_1^4 = \pi\left(\frac{20}{3} - \left(-\frac{7}{6}\right)\right) = \frac{47\pi}{6}.

About the xx-axis the same region gave 9π2=27π6\frac{9\pi}{2} = \frac{27\pi}{6}. Moving the axis down puts every washer farther out, where it sweeps a wider ring.

Axis above the region: the edges trade roles

If the axis y=ky = k is above the region, the far edge is the bottom curve, because it is farther from a line overhead. So R=k−g(x)R = k - g(x) (bottom) and r=k−f(x)r = k - f(x) (top). This is the step students most often miss: "top curve is the outer radius" is only true when the axis is below.

Worked example. The region between y=xy = x and y=x2y = x^2 is revolved about the line y=1y = 1. Find the volume.

Picture. On (0,1)(0, 1) the line y=xy = x is on top and the parabola below. The axis y=1y = 1 is above both.

Radii. Far edge, the parabola: R=1−x2R = 1 - x^2. Near edge, the line: r=1−xr = 1 - x.

Volume.

V=π∫01[(1−x2)2−(1−x)2]dx=π∫01(x4−3x2+2x)dx=π(15−1+1)=π5.V = \pi\int_0^1 \left[(1 - x^2)^2 - (1 - x)^2\right]\,dx = \pi\int_0^1 \left(x^4 - 3x^2 + 2x\right)\,dx = \pi\left(\frac{1}{5} - 1 + 1\right) = \frac{\pi}{5}.

Vertical lines

For an axis x=hx = h, the washers are horizontal: write the curves as xx in terms of yy and integrate in dydy. If the axis is to the left of the region, the right curve is the far edge, and each radius is x(y)−hx(y) - h. If the axis is to the right, the left curve is the far edge, and each radius is h−x(y)h - x(y). About x=−1x = -1, the region between x=yx = y and x=yx = \sqrt{y} gives R=y+1R = \sqrt{y} + 1 and r=y+1r = y + 1, and V=π2V = \frac{\pi}{2}.

Three checks catch most errors: both radii are positive, R>rR > r between the limits, and R−rR - r equals the region's height (or width). If the last check fails, you measured one radius from the wrong place.

With a calculator, find the crossings, store them, and write the setup with each radius in parentheses, for example π∫ab[(4−ex)2−(2−x)2]dx\pi\int_a^b \left[(4 - e^x)^2 - (2 - x)^2\right]\,dx. Report three decimal places.
