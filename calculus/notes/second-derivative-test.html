The First Derivative Test needs the sign of f′f' on both sides of a critical point. Often there is a quicker way: look at the concavity right at the point. A flat spot at the bottom of a cup is a valley; a flat spot at the top of a cap is a peak. That is the Second Derivative Test.

The test

Suppose f′(c)=0f'(c) = 0 and f″(c)f''(c) exists.

  • If f″(c)>0f''(c) > 0, the graph is concave up at cc, and ff has a relative minimum at cc.
  • If f″(c)<0f''(c) < 0, the graph is concave down at cc, and ff has a relative maximum at cc.
  • If f″(c)=0f''(c) = 0, the test gives no conclusion.

Why it works: if f″(c)>0f''(c) > 0, then f′f' is increasing near cc. Since f′(c)=0f'(c) = 0, f′f' must be negative just before cc and positive just after. That is the First Derivative Test's condition for a minimum.

Worked example 1. Find and classify the critical points of f(x)f(x)=2x3+3x2−12x+1= 2x^3 + 3x^2 - 12x + 1.

f′(x)f'(x)=6x2= 6x^2+6x−12+ 6x - 12=6(x+2)(x−1)= 6(x + 2)(x - 1), zero at x=−2x = -2 and x=1x = 1.

f″(x)=12x+6f''(x) = 12x + 6.

f″(−2)=−18<0f''(-2) = -18 < 0: relative maximum, f(−2)f(-2)=−16+12+24+1= -16 + 12 + 24 + 1=21= 21.

f″(1)=18>0f''(1) = 18 > 0: relative minimum, f(1)f(1)=2+3−12+1= 2 + 3 - 12 + 1=−6= -6.

The justification needs both facts: "f′(1)=0f'(1) = 0 and f″(1)>0f''(1) > 0, so ff has a relative minimum at x=1x = 1." Saying only "f″(1)>0f''(1) > 0" is not enough: a graph can be concave up at a point where it is still rising.

When the test is silent

If f″(c)=0f''(c) = 0, anything can happen. At x=0x = 0, the functions x4x^4, −x4-x^4 and x3x^3 all have f′(0)=0f'(0) = 0 and f″(0)=0f''(0) = 0, yet the first has a minimum, the second a maximum and the third neither. The test also does not apply where f′(c)f'(c) does not exist (a corner or cusp). In those cases, go back to the First Derivative Test.

Worked example 2. f(x)=x4−4x3f(x) = x^4 - 4x^3. Classify the critical point x=0x = 0.

f′(x)=4x2(x−3)f'(x) = 4x^2(x - 3) and f″(x)=12x2−24xf''(x) = 12x^2 - 24x, so f′(0)=0f'(0) = 0 and f″(0)=0f''(0) = 0: the Second Derivative Test gives no conclusion.

First Derivative Test: f′(x)<0f'(x) < 0 just left and just right of 0 (the factor 4x24x^2 is positive, x−3x - 3 is negative). No sign change: no extremum at x=0x = 0.

One critical point on an interval

The Second Derivative Test finds relative extrema. But there is a useful case where a relative extremum is also absolute. If a continuous function has exactly one critical point on an interval, and it is a relative minimum (or maximum), then it is the absolute minimum (or maximum) on that interval. The graph cannot turn around again to go lower, because turning around would need another critical point.

Worked example 3. Find the absolute minimum of f(x)=x+1xf(x) = x + \frac{1}{x} on (0,∞)(0, \infty).

f′(x)=1−1x2=0f'(x) = 1 - \frac{1}{x^2} = 0 at x=1x = 1, the only critical point in (0,∞)(0, \infty).

f″(x)=2x3f''(x) = \frac{2}{x^3}, so f″(1)=2>0f''(1) = 2 > 0: a relative minimum.

One critical point, and it is a relative minimum, so f(1)=2f(1) = 2 is the absolute minimum on (0,∞)(0, \infty), even though the interval has no endpoints to compare with.

This argument is the second way, besides the Candidates Test, to justify an absolute extremum. It is the one you will use most when a later problem asks for the best value on an open interval.
