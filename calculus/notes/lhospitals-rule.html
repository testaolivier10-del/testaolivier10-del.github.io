5Analytical Applications of Differentiation

In Unit 1 you met limits like limx→0sin⁡xx\lim_{x \to 0}\frac{\sin x}{x}, where both the top and the bottom approach 0. The form 00\frac{0}{0} tells you nothing by itself: the limit might be 1, or 7, or not exist. Back then you needed algebra tricks or a squeeze. Now that you have derivatives, one rule handles most of these limits, and it comes from the idea you just used for tangent line approximations.

Why slopes decide a 00\frac{0}{0} limit

Suppose f(a)=0f(a) = 0 and g(a)=0g(a) = 0, both differentiable. Near aa, each function is close to its tangent line:

f(x)≈f′(a)(x−a),g(x)≈g′(a)(x−a)f(x) \approx f'(a)(x - a), \qquad g(x) \approx g'(a)(x - a)

So their quotient is close to f′(a)(x−a)g′(a)(x−a)\frac{f'(a)(x - a)}{g'(a)(x - a)}=f′(a)g′(a)= \frac{f'(a)}{g'(a)}. Both functions shrink to 0, but at rates set by their slopes, and the ratio of the slopes is what survives.

L'Hospital's rule

If limx→af(x)=0\lim_{x \to a}f(x) = 0 and limx→ag(x)=0\lim_{x \to a}g(x) = 0, or if both limits are infinite, then

limx→af(x)g(x)=limx→af′(x)g′(x)\lim_{x \to a}\frac{f(x)}{g(x)} = \lim_{x \to a}\frac{f'(x)}{g'(x)}

provided the limit on the right exists (or is infinite). The same holds for limits as x→∞x \to \infty. Three warnings:

  • Check the form first. The rule needs 00\frac{0}{0} or ∞∞\frac{\infty}{\infty}. On the exam, show it: write both limits.
  • Differentiate the top and the bottom separately. This is not the quotient rule.
  • Never write "=00= \frac{0}{0}". It is a form, not a number. Write "lim(1−cos⁡x)=0\lim(1 - \cos x) = 0 and limx2=0\lim x^2 = 0" instead.

Worked example 1. Find limx→0e3x−1x\lim_{x \to 0}\frac{e^{3x} - 1}{x}.

Form: limx→0(e3x−1)\lim_{x \to 0}(e^{3x} - 1)=0= 0 and limx→0x=0\lim_{x \to 0}x = 0.

By L'Hospital's rule, the limit equals limx→03e3x1\lim_{x \to 0}\frac{3e^{3x}}{1}=3= 3.

Worked example 2. Find limx→01−cos⁡xx2\lim_{x \to 0}\frac{1 - \cos x}{x^2}.

Form: both limits are 0. First application: limx→0sin⁡x2x\lim_{x \to 0}\frac{\sin x}{2x}.

Check again: sin⁡0=0\sin 0 = 0 and 2⋅0=02 \cdot 0 = 0, still 00\frac{0}{0}. Second application: limx→0cos⁡x2\lim_{x \to 0}\frac{\cos x}{2}=12= \frac{1}{2}.

When the form is not indeterminate

Using the rule on a limit that is not 00\frac{0}{0} or ∞∞\frac{\infty}{\infty} gives wrong answers. For limx→1x2+1x+1\lim_{x \to 1}\frac{x^2 + 1}{x + 1}, the form is 22\frac{2}{2}, so the limit is simply 1. Blindly differentiating gives lim2x1=2\lim\frac{2x}{1} = 2, which is wrong. A check of the form takes five seconds and saves the point.

From a table of values

Worked example 3. ff and gg are differentiable with f(2)=0f(2) = 0, g(2)=0g(2) = 0, f′(2)=5f'(2) = 5 and g′(2)=−2g'(2) = -2. Find limx→2f(x)g(x)\lim_{x \to 2}\frac{f(x)}{g(x)}.

Differentiable functions are continuous, so limx→2f(x)\lim_{x \to 2}f(x)=f(2)= f(2)=0= 0 and limx→2g(x)\lim_{x \to 2}g(x)=g(2)= g(2)=0= 0.

By L'Hospital's rule, the limit is limx→2f′(x)g′(x)\lim_{x \to 2}\frac{f'(x)}{g'(x)}=5−2= \frac{5}{-2}=−52= -\frac{5}{2} (using that f′f' and g′g' are continuous at 2, as exam questions state or imply).

The form ∞∞\frac{\infty}{\infty}: comparing growth

As x→∞x \to \infty, the rule compares how fast two functions grow.

Slips that cost points

  • Applying the rule without showing that both limits are 0 (or both infinite).
  • Using the quotient rule instead of differentiating top and bottom separately.
  • Writing 00=\frac{0}{0} = a number, or "=00= \frac{0}{0}" as if it were a value.
  • Forgetting the chain rule inside: ddxsin⁡(5x)\frac{d}{dx}\sin(5x)=5cos⁡(5x)= 5\cos(5x).
  • Stopping after one round when the new limit is still indeterminate.
