SMath you need

From area under a curve to area between curves

You already know that ∫abf(x)dx\int_a^b f(x)\,dx adds up thin rectangles that stand on the xx-axis and reach up to the graph of ff. Now the region you care about has a curve on top and a different curve on the bottom. The xx-axis is not part of the story at all.

The idea is the same as before. Cut the region into thin vertical rectangles. Each rectangle stands at some xx, has a small width Δx\Delta x, and reaches from the bottom curve up to the top curve. If ff is the top and gg is the bottom, the rectangle's height is

height=f(x)−g(x).\text{height} = f(x) - g(x).

So one rectangle has area (f(x)−g(x))Δx\left(f(x) - g(x)\right)\Delta x. Adding all of them is a Riemann sum for the function f−gf - g, and letting the rectangles get thinner turns the sum into a definite integral.

The area between curves. If f(x)≥g(x)f(x) \ge g(x) for every xx in [a,b][a, b], the area of the region between their graphs from x=ax = a to x=bx = b is

A=∫ab(f(x)−g(x))dx.A = \int_a^b \left(f(x) - g(x)\right)\,dx.

Read it as "top minus bottom, from left to right." The formula does not care whether the curves are above or below the xx-axis. Move both graphs down 10 units and every height f(x)−g(x)f(x) - g(x) stays the same, so the area stays the same.

The three steps

  1. Find the limits. When a region is "bounded by" two curves, it starts and ends where they meet. Solve f(x)=g(x)f(x) = g(x). The solutions are xx-values, which is what an integral in dxdx needs.
  2. Decide which curve is on top. Pick any xx between the limits and evaluate both functions. The larger value is the top.
  3. Set up and integrate top minus bottom. Put the bottom function in parentheses before subtracting, so every one of its terms changes sign.

Worked example. Find the area of the region bounded by y=6−x2y = 6 - x^2 and y=xy = x (the figure above).

Limits. Set the functions equal: 6−x2=x6 - x^2 = x, so x2+x−6=0x^2 + x - 6 = 0, which factors as (x+3)(x−2)=0(x + 3)(x - 2) = 0. The curves meet at x=−3x = -3 and x=2x = 2.

Top. Test x=0x = 0: the parabola gives 6 and the line gives 0. The parabola is on top.

Integral. Top minus bottom is (6−x2)−x(6 - x^2) - x:

A=∫−32(6−x2−x)dx=[6x−x33−x22]−32.A = \int_{-3}^{2} \left(6 - x^2 - x\right)\,dx = \left[6x - \frac{x^3}{3} - \frac{x^2}{2}\right]_{-3}^{2}.

Parentheses and other places points go missing

The most common algebra slip is dropping parentheses. With top y=x+1y = x + 1 and bottom y=x2−1y = x^2 - 1, the height is

(x+1)−(x2−1)=x+1−x2+1=x+2−x2.(x + 1) - (x^2 - 1) = x + 1 - x^2 + 1 = x + 2 - x^2.

Writing x+1−x2−1x + 1 - x^2 - 1 forgets that subtracting −1-1 adds 1, and every number after that is wrong.

Worked example. Find the area of the region bounded by y=exy = e^x, y=1y = 1 and x=ln⁡3x = \ln 3.

Limits. This time one boundary is a vertical line, so one limit is given: x=ln⁡3x = \ln 3. The other is where ex=1e^x = 1, which is x=0x = 0.

Top. For x>0x > 0, ex>1e^x > 1, so exe^x is on top and the line y=1y = 1 is the bottom (not the xx-axis).

Integral.

A=∫0ln⁡3(ex−1)dx=[ex−x]0ln⁡3=(3−ln⁡3)−(1−0)=2−ln⁡3.A = \int_0^{\ln 3} \left(e^x - 1\right)\,dx = \Big[e^x - x\Big]_0^{\ln 3} = (3 - \ln 3) - (1 - 0) = 2 - \ln 3.

Limits like the yy-values where the curves meetLimits in the wrong variableWith dxdx, use xx-values

A quick size check helps too. The region is never taller than the largest gap between the curves and never wider than b−ab - a, so the area is less than that height times that width.

With a calculator

When f(x)=g(x)f(x) = g(x) cannot be solved by algebra, as with 2cos⁡x=x2−12\cos x = x^2 - 1, use the calculator to find the crossings (intersect or a solver, in radian mode). Store each crossing in the calculator instead of retyping a rounded value. Then write the setup, for example ∫−aa(2cos⁡x−(x2−1))dx\int_{-a}^{a} \left(2\cos x - (x^2 - 1)\right)\,dx, and let the calculator evaluate it. Report the answer correct to three decimal places, and round only at the end.
