Some quantities grow or shrink by the same percentage in each equal stretch of time: a savings account, a bacteria culture, a drug leaving the blood, the gap between a cup of coffee's temperature and the room's. These are modeled by exponential functions, and calculus has a favorite one, exe^x. Its partner, the natural logarithm ln⁡x\ln x, lets you solve for a time hidden in an exponent. This page reviews both and the rules that connect them.

Exponential functions and the number ee

An exponential function has the variable in the exponent: f(x)=bxf(x) = b^x, with a positive base b≠1b \ne 1. Each step of 1 in xx multiplies the output by bb. With b>1b > 1 the function shows exponential growth; with 0<b<10 < b < 1, exponential decay.

Calculus works best with one particular base, e≈2.71828e \approx 2.71828. The reason will appear in Unit 2: exe^x is the function whose rate of change equals its own value, which makes every formula involving it clean. For now, know its graph and its rules:

  • e0=1e^0 = 1, so the graph passes through (0,1)(0, 1).
  • ex>0e^x > 0 for every xx. The graph never touches the xx-axis; the xx-axis is a horizontal asymptote on the left.
  • All the exponent rules apply: eaeb=ea+be^a e^b = e^{a + b}, eaeb=ea−b\frac{e^a}{e^b} = e^{a - b}, (ea)b=eab(e^a)^b = e^{ab}, e−x=1exe^{-x} = \frac{1}{e^x}.

The natural logarithm

The natural logarithm ln⁡x\ln x answers one question: what power of ee gives xx? ln⁡x=ymeansey=x\ln x = y \quad \text{means} \quad e^y = x So ln⁡e=1\ln e = 1, ln⁡1=0\ln 1 = 0, and ln⁡(e5)=5\ln(e^5) = 5. Since eye^y is always positive, ln⁡x\ln x is defined only for x>0x > 0.

Because ln⁡\ln undoes exe^x and exe^x undoes ln⁡\ln, they cancel each other: eln⁡x=x(x>0)ln⁡(ex)=x(every x)e^{\ln x} = x \;(x > 0) \qquad \ln(e^x) = x \;(\text{every } x)

Log rules

Every log rule is an exponent rule read backward. Multiplying powers adds exponents, so the log of a product is a sum:

ln⁡(ab)=ln⁡a+ln⁡b\ln(ab) = \ln a + \ln bln⁡12=ln⁡3+ln⁡4\ln 12 = \ln 3 + \ln 4
ln⁡ab=ln⁡a−ln⁡b\ln\frac{a}{b} = \ln a - \ln bln⁡x3y=3ln⁡x−ln⁡y\ln\frac{x^3}{y} = 3\ln x - \ln y
ln⁡(ap)=pln⁡a\ln(a^p) = p\ln aln⁡x=12ln⁡x\ln\sqrt{x} = \frac{1}{2}\ln x

Worked example 1. Simplify ln⁡(x2x)\ln\left(x^2\sqrt{x}\right) and e2ln⁡3e^{2\ln 3}.

x2xx^2\sqrt{x}=x2⋅x1/2= x^2 \cdot x^{1/2}=x5/2= x^{5/2}, so ln⁡(x5/2)=52ln⁡x\ln\left(x^{5/2}\right) = \frac{5}{2}\ln x.

2ln⁡3=ln⁡32=ln⁡92\ln 3 = \ln 3^2 = \ln 9, so e2ln⁡3=eln⁡9=9e^{2\ln 3} = e^{\ln 9} = 9. Move the coefficient into the log before canceling ee and ln⁡\ln.

Solving exponential and log equations

To free a variable from an exponent, isolate the exponential, then take ln⁡\ln of both sides. To free a variable from inside a log, isolate the log, then raise ee to both sides.

Worked example 2. Solve 3e2x=213e^{2x} = 21.

Isolate: e2x=7e^{2x} = 7. Take ln⁡\ln: 2x=ln⁡72x = \ln 7. Solve: x=ln⁡72x = \frac{\ln 7}{2}.

A common slip is dividing by 2 inside the log: ln⁡72\ln\frac{7}{2} is a different number.

Worked example 3. Solve ln⁡(x−1)=3\ln(x - 1) = 3.

Raise ee to both sides: x−1=e3x - 1 = e^3, so x=e3+1x = e^3 + 1.

Check the domain: x−1=e3>0x - 1 = e^3 > 0, so the solution is valid.

Growth and decay with ee

A quantity that starts at AA and grows or decays continuously at a steady percentage rate is written AektA e^{kt}. The number kk sets the speed: k>0k > 0 for growth, k<0k < 0 for decay. Two questions come up constantly: when does it reach a level, and how long does it take to double or halve?

Worked example 4. A sample of A(t)=80ektA(t) = 80e^{kt} grams halves every 5 hours. Find kk.

80e5k=4080e^{5k} = 40, so e5k=12e^{5k} = \frac{1}{2}, so 5k=ln⁡12=−ln⁡25k = \ln\frac{1}{2} = -\ln 2.

k=−ln⁡25≈−0.139k = -\frac{\ln 2}{5} \approx -0.139 per hour. The negative sign confirms decay.

On a calculator question, store ln⁡2\ln 2 and other intermediate values rather than rounding them, and give the final answer to three decimal places.
