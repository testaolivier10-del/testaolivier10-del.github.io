Unit 1 · Topic 1.2

What a Limit Is and How to Write It

lim as x → a, f(x) = L says that f(x) closes in on L as x approaches a from both sides.

Practice 1: Implementing Mathematical ProcessesPractice 4: Communication and Notation

Part 1 · Hook

Why this matters

In Topic 1.1, a falling stone's average speeds 48, 40, 33.6, 32.16, 32.016 kept closing in on 32. Calculus turns "closing in" into a precise idea with its own notation, the limit. Every later idea in this course is built on it, so learning to write it and read it now pays off in every unit.

Part 5 · Step by step

How it works, step by step

  1. Let xx get close to aa from both sides, but never equal aa→watch where the outputs f(x)f(x) go
  2. If the outputs close in on a single number LL→we write limx→af(x)=L\lim_{x \to a} f(x) = L: the limit of f(x)f(x) as xx approaches aa is LL
  3. The definition never uses x=ax = a itself→the limit can differ from f(a)f(a), or exist when f(a)f(a) is not defined
  4. A limit can be read from a graph, a table or a formula→the next four topics teach each way

Part 6 · Key ideas

Key ideas

  • limx→af(x)=L\lim_{x \to a} f(x) = L means: as xx gets close to aa (from both sides, x≠ax \ne a), f(x)f(x) gets close to LL, as close as we like.
  • The limit at aa and the value f(a)f(a) are different questions. A hole can have a limit and no value; a filled dot off the curve gives a value that is not the limit.
  • Read the notation from the bottom up: the input heads to aa, the output heads to LL.
  • Write "lim" with its arrow on every line until the line where you substitute and get a number; then drop it.

Part 7 · Misconception

A common mistake

The wrong idea: limx→af(x)\lim_{x \to a} f(x) is just f(a)f(a), the value of the function at aa.

What actually happens: The limit describes where f(x)f(x) heads for inputs near aa, never at aa. It equals f(a)f(a) for many functions, but not when the graph has a hole or a dot off the curve, and it can exist when f(a)f(a) does not.

Part 8 · Check yourself

Check yourself

Exam-style questions. Anything you miss goes into your review queue.

Graph

The graph of ff

The graph of ff on −1≤x≤4-1 \le x \le 4 follows a curve with an open circle at (1,1)(1, 1). The function's value at x=1x = 1 is the separate filled dot at (1,3)(1, 3).

1. What is limx→1f(x)\lim_{x \to 1} f(x)?

  1. 11
  2. 33
  3. 22
  4. 00
Show the answer

As xx gets close to 1 from either side, the heights of the graph get close to 1, the height of the open circle. The filled dot at (1,3)(1, 3) is the value f(1)f(1), which the limit ignores.

  • Correct: 11: The curve heads to height 1 from both sides.
  • 33: 3 is f(1)f(1), the value at x=1x = 1. A limit is about where the heights head as xx approaches 1.
  • 22: No part of the graph near x=1x = 1 heads to 2.
  • 00: The graph near x=1x = 1 stays at heights near 1, not 0.

2. What is f(1)f(1)?

  1. 33
  2. 11
  3. f(1)f(1) is not defined
  4. 22
Show the answer

f(1)f(1) is the height of the filled dot above x=1x = 1: 3.

  • Correct: 33: The filled dot is at (1,3)(1, 3).
  • 11: The open circle at (1,1)(1, 1) is not on the graph; 1 is the limit, not the value.
  • f(1)f(1) is not defined: There is a filled dot at x=1x = 1, so f(1)f(1) is defined.
  • 22: No point of the graph is at (1,2)(1, 2).

3. What is limx→3f(x)\lim_{x \to 3} f(x)?

  1. 33
  2. 11
  3. 5.55.5
  4. 22
Show the answer

Near x=3x = 3 the graph is an ordinary unbroken curve through (3,3)(3, 3), so the heights close in on 3. Here the limit and the value f(3)=3f(3) = 3 agree.

  • Correct: 33: The curve passes through (3,3)(3, 3) with no gap.
  • 11: 1 is the limit at x=1x = 1, not at x=3x = 3.
  • 5.55.5: 5.5 is the height at x=4x = 4.
  • 22: Read the height above x=3x = 3: it is 3.

4. Which statement about ff is true?

  1. limx→1f(x)≠f(1)\lim_{x \to 1} f(x) \ne f(1)
  2. limx→1f(x)\lim_{x \to 1} f(x)=f(1)= f(1)
  3. limx→3f(x)≠f(3)\lim_{x \to 3} f(x) \ne f(3)
  4. limx→4f(x)=3\lim_{x \to 4} f(x) = 3
Show the answer

At x=1x = 1 the limit is 1 but the value is 3, so they are not equal.

  • Correct: limx→1f(x)≠f(1)\lim_{x \to 1} f(x) \ne f(1): 1 and 3 differ.
  • limx→1f(x)\lim_{x \to 1} f(x)=f(1)= f(1): The limit is 1 and f(1)=3f(1) = 3.
  • limx→3f(x)≠f(3)\lim_{x \to 3} f(x) \ne f(3): At x=3x = 3 both the limit and the value are 3.
  • limx→4f(x)=3\lim_{x \to 4} f(x) = 3: Near x=4x = 4 the curve is at height about 5.5, not 3.

5. Which sentence reads limx→4f(x)=7\lim_{x \to 4} f(x) = 7 correctly?

  1. As xx approaches 4, f(x)f(x) approaches 7.
  2. As xx approaches 7, f(x)f(x) approaches 4.
  3. f(4)=7f(4) = 7.
  4. As f(x)f(x) approaches 4, xx approaches 7.
Show the answer

The number under "lim" is where the input goes (x→4x \to 4); the number after the equals sign is where the output goes (7).

  • Correct: As xx approaches 4, f(x)f(x) approaches 7.: Input heads to 4, output heads to 7.
  • As xx approaches 7, f(x)f(x) approaches 4.: The input and output numbers are swapped.
  • f(4)=7f(4) = 7.: A limit statement says nothing certain about the value at x=4x = 4.
  • As f(x)f(x) approaches 4, xx approaches 7.: The roles of xx and f(x)f(x) are swapped.

6. A student says: "limx→2h(x)=5\lim_{x \to 2} h(x) = 5, so h(2)=5h(2) = 5." Is the student right?

  1. Not necessarily: h(2)h(2) could be a different number or not defined at all.
  2. Yes: a limit is the value of the function at the point.
  3. No: if the limit is 5, then h(2)h(2) is some other number.
  4. Yes: whenever a limit exists, the function is defined there.
Show the answer

The limit is about inputs near 2, never at 2. h(2)h(2) might be 5, might be another number, or might not exist. The graph of ff in this topic, with limit 1 and value 3 at x=1x = 1, is an example.

  • Correct: Not necessarily: h(2)h(2) could be a different number or not defined at all.: The limit ignores x=2x = 2 itself.
  • Yes: a limit is the value of the function at the point.: The limit and the value are different ideas; they agree only for some functions.
  • No: if the limit is 5, then h(2)h(2) is some other number.: They can be equal; for many functions they are.
  • Yes: whenever a limit exists, the function is defined there.: A function with a hole has a limit at the hole but no value there.

7. A function kk has k(3)=8k(3) = 8, and as xx approaches 3 from either side, the values k(x)k(x) close in on 6. Which is correct?

  1. limx→3k(x)=6\lim_{x \to 3} k(x) = 6 and k(3)=8k(3) = 8
  2. limx→3k(x)=8\lim_{x \to 3} k(x) = 8 and k(3)=6k(3) = 6
  3. limx→3k(x)=8\lim_{x \to 3} k(x) = 8 and k(3)=8k(3) = 8
  4. limx→6k(x)=3\lim_{x \to 6} k(x) = 3 and k(3)=8k(3) = 8
Show the answer

The limit is where the values head (6); the value at 3 is what kk actually gives there (8).

  • Correct: limx→3k(x)=6\lim_{x \to 3} k(x) = 6 and k(3)=8k(3) = 8: Limit 6 from the trend, value 8 at the point.
  • limx→3k(x)=8\lim_{x \to 3} k(x) = 8 and k(3)=6k(3) = 6: The two numbers are swapped.
  • limx→3k(x)=8\lim_{x \to 3} k(x) = 8 and k(3)=8k(3) = 8: The value at the point does not set the limit.
  • limx→6k(x)=3\lim_{x \to 6} k(x) = 3 and k(3)=8k(3) = 8: The input target is 3, not 6.

Part 9 · Summary

Summary

limx→af(x)=L\lim_{x \to a} f(x) = L says that f(x)f(x) closes in on LL as xx approaches aa from both sides. The value at aa never enters: the limit can equal f(a)f(a), differ from it, or exist where f(a)f(a) is undefined. Limits can be found from graphs, tables and formulas, and the rest of Unit 1 shows how.
