Estimating Area with Riemann Sums

A Riemann sum estimates accumulated change by adding width times height over subintervals; a trapezoidal sum averages the two end heights.

Question set for this topic

Part 1 · Hook

Why this matters

A rain gauge logs the flow into a tank only every hour or two, and some readings are three hours apart. Nobody knows how fast it flowed between readings, yet the city still needs to know how much water was collected. Rectangles and trapezoids built on the readings give an honest estimate, and the shape of the data tells you whether that estimate is too high or too low.

Part 5 · Step by step

How it works, step by step

  1. You only know a rate at a few times→treat it as roughly constant on each subinterval and add up width times height
  2. The table has times 0, 1, 3, 4, 7→the widths are 1, 2, 1 and 3; each product uses its own width
  3. The function is increasing on the interval→left ends give the smallest heights, so a left sum underestimates and a right sum overestimates
  4. The graph is concave up→chords lie above the graph, so a trapezoidal sum overestimates

Part 6 · Key ideas

Key ideas

  • A Riemann sum adds (width) times (height) over the subintervals: left, right or midpoint heights.
  • A trapezoidal sum uses width times the average of the two end heights; it equals (left + right) / 2.
  • From a table, each width is the difference of two times. Never assume equal widths.
  • Increasing function: left sum under, right sum over. Decreasing: the reverse. Concave up: trapezoid over, midpoint under.

Part 7 · Misconception

A common mistake

The wrong idea: With 4 subintervals on [0,7][0, 7], every width is 74\frac{7}{4}.

What actually happens: Only when the subintervals are equal. A table with times 0, 1, 3, 4, 7 has widths 1, 2, 1 and 3, and each product must use its own width.

4. Is the left Riemann sum of 207 gallons an overestimate or an underestimate of the water that flows in, and why?

  1. An overestimate, because the rates in the table are positive
  2. An underestimate, because R is increasing on each subinterval
  3. An overestimate, because R is increasing on each subinterval
  4. An underestimate, because the subintervals have unequal widths
Show the answer

Because RR is increasing, on each subinterval RR is smallest at the left end. Every left rectangle lies below the graph, so the left sum underestimates.

  • An overestimate, because the rates in the table are positive: Positive rates make the amount grow, but they say nothing about whether rectangles are too tall or too short.
  • Correct: An underestimate, because R is increasing on each subinterval: Correct: the left end has the smallest rate on each subinterval, so each rectangle is too short.
  • An overestimate, because R is increasing on each subinterval: For an increasing rate the left end has the smallest value on each subinterval, so the rectangles fall short.
  • An underestimate, because the subintervals have unequal widths: Unequal widths do not decide the direction; the monotonicity of R does.

5. For which function is a right Riemann sum on [1,4][1, 4] sure to be an overestimate of the area under its graph?

  1. a positive function that is increasing on [1, 4]
  2. a positive function that is decreasing on [1, 4]
  3. a positive function that is concave down on [1, 4]
  4. a positive function with a maximum at x = 2.5
Show the answer

If ff is increasing, the right end of each subinterval gives the largest value of ff on it. Each rectangle covers its piece of the region and more, so the right sum is an overestimate.

  • Correct: a positive function that is increasing on [1, 4]: Correct: the right end has the largest value on each subinterval, so every rectangle is too tall.
  • a positive function that is decreasing on [1, 4]: Then the right end has the smallest value on each subinterval: a right sum underestimates.
  • a positive function that is concave down on [1, 4]: Concavity decides trapezoids and midpoints. For right sums the deciding fact is whether f increases or decreases.
  • a positive function with a maximum at x = 2.5: Such a function rises and then falls, so some right rectangles are too tall and some too short: no conclusion.

Part 9 · Summary

Summary

A Riemann sum estimates accumulated change by adding width times height over subintervals; a trapezoidal sum averages the two end heights. Take every width from the table. Left and right sums under- or overestimate according to whether the function increases or decreases; trapezoids and midpoints according to its concavity.
