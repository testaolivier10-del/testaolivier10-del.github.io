Unit 5 · Topic 5.1 Beta

The Mean Value Theorem

If f is continuous on [a, b] and differentiable on (a, b) , some c inside has f′(c) equal to the average rate of change: a tangent line parallel to the secant line.

Practice 3: Justification

Part 1 · Hook

Why this matters

On some toll roads, a ticket stamped at the entrance and the exit gives your average speed. If it says 75 miles per hour, the police know more than that: at some instant your speedometer read exactly 75. The Mean Value Theorem is the reason.

Part 5 · Step by step

How it works, step by step

  1. ff is continuous on [a,b][a, b] and differentiable on (a,b)(a, b)→the graph is one unbroken, smooth curve from (a,f(a))(a, f(a)) to (b,f(b))(b, f(b)), with a tangent line at each inside point
  2. Slide a line parallel to the secant line across the curve→the last place it touches the curve is a point where the tangent line is parallel to the secant line
  3. Parallel lines have equal slopes→some cc in (a,b)(a, b) has f′(c)f'(c)=f(b)−f(a)b−a= \frac{f(b) - f(a)}{b - a}
  4. A hypothesis fails (a jump, an asymptote, a corner or cusp inside)→the theorem promises nothing, and the conclusion may be false

Part 6 · Key ideas

Key ideas

  • Mean Value Theorem: if ff is continuous on [a,b][a, b] and differentiable on (a,b)(a, b), then f′(c)f'(c)=f(b)−f(a)b−a= \frac{f(b) - f(a)}{b - a} for at least one cc in (a,b)(a, b).
  • In words: somewhere inside, the instantaneous rate of change equals the average rate of change.
  • "ff is differentiable" covers both hypotheses, because differentiable implies continuous. Say it.
  • The theorem says a cc exists. It does not say where, and there may be more than one.
  • A corner at an endpoint is fine: differentiability is needed only on the open interval.

Part 7 · Misconception

A common mistake

The wrong idea: The Mean Value Theorem works whenever the average rate of change can be computed.

What actually happens: It needs both hypotheses: continuous on [a,b][a, b] and differentiable on (a,b)(a, b). For |x||x| on [−1,1][-1, 1] the average rate is 00, but the slope is ±1\pm 1 everywhere it exists. A justification must state the hypotheses before the conclusion.

1. Using the table, which statement is guaranteed for some time cc with 0<c<120 < c < 12?

  3. h′(c)=2h'(c) = 2 for a cc between 3 and 7

h(12)−h(0)12−0\frac{h(12) - h(0)}{12 - 0}=40−4012= \frac{40 - 40}{12}=0= 0. Since hh is differentiable, it is continuous on [0,12][0, 12] and differentiable on (0,12)(0, 12), so by the Mean Value Theorem some cc in (0,12)(0, 12) has h′(c)=0h'(c) = 0.

  • h(c)=35h(c) = 35: 35 is below every value in the table. The IVT only promises values between two known values, such as between 38 and 46.

2. On which interval does the Mean Value Theorem guarantee a time cc with h′(c)=−2h'(c) = -2?

  1. 3<c<73 < c < 7
  2. 0<c<30 < c < 3
  3. 7<c<127 < c < 12
  4. 0<c<70 < c < 7
Show the answer

The Mean Value Theorem gives h′(c)h'(c) equal to the average rate of change over an interval. On [3,7][3, 7] that rate is 38−467−3=−2\frac{38 - 46}{7 - 3} = -2 feet per day, and hh is differentiable, so it is continuous there.

  • Correct: 3<c<73 < c < 7: h(7)−h(3)7−3\frac{h(7) - h(3)}{7 - 3}=38−464= \frac{38 - 46}{4}=−2= -2.
  • 0<c<30 < c < 3: 46−403=2\frac{46 - 40}{3} = 2: the right size, the wrong sign.
  • 7<c<127 < c < 12: 40−385=25\frac{40 - 38}{5} = \frac{2}{5}.
  • 0<c<70 < c < 7: 38−407=−27\frac{38 - 40}{7} = -\frac{2}{7}. The theorem promises the average rate over the interval you choose, and this one is not −2-2.

3. The Mean Value Theorem guarantees a time cc in (7,12)(7, 12) at which h′(c)h'(c) equals what value? Include units.

Show the answer

4. A student writes: "h′(c)=0h'(c) = 0 for some cc in (0,12)(0, 12) by the Mean Value Theorem, because h(0)=h(12)h(0) = h(12)." What does this justification still need to earn the point?

  1. The value of cc, found from the table
  2. A check that h(t)>0h(t) > 0 on the interval
  3. That hh is continuous on [0,12][0, 12] and differentiable on (0,12)(0, 12)
  4. A second pair of times at which hh takes equal values, to confirm the first pair
Show the answer

A Mean Value Theorem justification names the theorem and checks both hypotheses: continuous on the closed interval, differentiable on the open one. "hh is differentiable, so it is also continuous" does both.

  • The value of cc, found from the table: The theorem says a cc exists; it does not ask you to find it, and the table cannot give it.
  • A check that h(t)>0h(t) > 0 on the interval: The sign of hh has nothing to do with the theorem's hypotheses.
  • Correct: That hh is continuous on [0,12][0, 12] and differentiable on (0,12)(0, 12): The theorem's hypotheses must be stated and checked. Here they follow from "hh is differentiable", which the problem gives.
  • A second pair of times at which hh takes equal values, to confirm the first pair: One interval with equal endpoint values is enough.

6. ff is differentiable everywhere, with f(1)=3f(1) = 3 and f(5)=3f(5) = 3. Which must be true?

  1. f(3)=3f(3) = 3
  2. f′(3)=0f'(3) = 0, at the midpoint of the interval
  3. f(c)=0f(c) = 0 for some cc in (1,5)(1, 5)
  4. f′(c)=0f'(c) = 0 for some cc in (1,5)(1, 5)
Show the answer

ff is differentiable, so it is continuous on [1,5][1, 5] and differentiable on (1,5)(1, 5). The average rate of change is 00, so by the Mean Value Theorem f′(c)=0f'(c) = 0 for some cc in (1,5)(1, 5).

  • f(3)=3f(3) = 3: Equal values at the ends say nothing about the value in the middle.
  • f′(3)=0f'(3) = 0, at the midpoint of the interval: A flat tangent line is guaranteed somewhere in (1,5)(1, 5), not at the midpoint.
  • f(c)=0f(c) = 0 for some cc in (1,5)(1, 5): No value below 3 is known, so the IVT gives no zero.
  • Correct: f′(c)=0f'(c) = 0 for some cc in (1,5)(1, 5): The average rate on [1,5][1, 5] is 3−34=0\frac{3 - 3}{4} = 0, and the Mean Value Theorem applies.

Part 9 · Summary

Summary

If ff is continuous on [a,b][a, b] and differentiable on (a,b)(a, b), some cc inside has f′(c)f'(c) equal to the average rate of change: a tangent line parallel to the secant line. Check the hypotheses every time ("ff is differentiable, so it is continuous") and name the theorem.
