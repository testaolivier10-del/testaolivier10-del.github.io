Inverse Functions

An inverse function runs a one-to-one function backward: f⁻¹(b) = a exactly when f(a) = b .

Part 1 · Hook

Why this matters

A function turns inputs into outputs. Often you know the output and need the input: what time gave this temperature, what angle has this sine. That is the job of an inverse function. In Unit 3 you will find how fast an inverse changes, using one fact you can see in a picture: reflecting a graph across y=xy = x flips its slopes.

Part 5 · Step by step

How it works, step by step

  1. ff sends each input aa to an output bb, and no two inputs share an output (one-to-one)→the inverse function f−1f^{-1} sends bb back to aa: f−1(b)=af^{-1}(b) = a exactly when f(a)=bf(a) = b
  2. Swapping inputs and outputs→swaps the coordinates of every point, reflecting the graph across y=xy = x
  3. Swapping coordinates swaps rise and run→slopes at matching points are reciprocals
  4. Sine, cosine and tangent repeat, so they are not one-to-one→their inverses use restricted ranges: arcsine and arctangent give angles from −π/2 to π/2, arccosine from 0 to π

Part 6 · Key ideas

Key ideas

  • f−1(b)=af^{-1}(b) = a means f(a)=bf(a) = b. So f(f−1(x))=xf(f^{-1}(x)) = x and f−1(f(x))=xf^{-1}(f(x)) = x on the right domains.
  • f−1(x)f^{-1}(x) is not 1f(x)\frac{1}{f(x)}. The −1-1 means "undo", not "reciprocal".
  • Only a one-to-one function (each output from one input; passes the horizontal line test) has an inverse. Restrict the domain if needed.
  • To find a formula: write x=f(y)x = f(y) and solve for yy.
  • arcsin⁡x\arcsin x and arctan⁡x\arctan x return angles in [−π2,π2]\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]; arccos⁡x\arccos x returns angles in [0,π][0, \pi].

Part 7 · Misconception

A common mistake

The wrong idea: f−1(x)=1f(x)f^{-1}(x) = \frac{1}{f(x)}, and sin−1⁡x=1sin⁡x\sin^{-1} x = \frac{1}{\sin x}.

What actually happens: f−1f^{-1} undoes ff: if f(2)=7f(2) = 7 then f−1(7)=2f^{-1}(7) = 2. The reciprocal 1f(x)\frac{1}{f(x)} is a different function. sin−1⁡x\sin^{-1} x is arcsin⁡x\arcsin x; 1sin⁡x\frac{1}{\sin x} is csc⁡x\csc x.

3. Which statement about ff is true?

  1. f−1(3)=0f^{-1}(3) = 0
  2. f−1(3)=1f(3)=19f^{-1}(3) = \frac{1}{f(3)} = \frac{1}{9}
  3. f−1(3)=f(3)=9f^{-1}(3) = f(3) = 9

Show the answer

f(0)=3f(0) = 3, so f−1(3)=0f^{-1}(3) = 0. The superscript −1-1 means "inverse", not "reciprocal".

  • Correct: f−1(3)=0f^{-1}(3) = 0: f(0)=3f(0) = 3 read backward.
  • f−1(3)=1f(3)=19f^{-1}(3) = \frac{1}{f(3)} = \frac{1}{9}: f−1f^{-1} is the inverse function; 1f(3)\frac{1}{f(3)} is a reciprocal, a different thing.

7. The point (2,7)(2, 7) is on the graph of a one-to-one function ff, and the slope of the graph of ff there is 4. Which is true about the graph of f−1f^{-1}?

  1. It passes through (7,2)(7, 2), with slope 14\frac{1}{4} there.
  2. It passes through (7,2)(7, 2), with slope 4 there.
  3. It passes through (2,7)(2, 7), with slope 14\frac{1}{4} there.
  4. It passes through (−2,−7)(-2, -7), with slope −4-4 there.
Show the answer

Reflecting across y=xy = x swaps coordinates, so (2,7)(2, 7) becomes (7,2)(7, 2), and swaps rise and run, so slope 4 becomes 14\frac{1}{4}.

  • Correct: It passes through (7,2)(7, 2), with slope 14\frac{1}{4} there.: Swap the point and flip the slope.
  • It passes through (7,2)(7, 2), with slope 4 there.: The reflection swaps rise and run, so the slope flips to its reciprocal.
  • It passes through (2,7)(2, 7), with slope 14\frac{1}{4} there.: The point must be swapped too.
  • It passes through (−2,−7)(-2, -7), with slope −4-4 there.: Reflection across y=xy = x swaps coordinates; it does not negate them.

Part 9 · Summary

Summary

An inverse function runs a one-to-one function backward: f−1(b)=af^{-1}(b) = a exactly when f(a)=bf(a) = b. Its graph is the reflection of ff across y=xy = x, so points swap coordinates and slopes become reciprocals. Find a formula by solving x=f(y)x = f(y) for yy. The inverse trig functions use restricted ranges, and f−1f^{-1} never means 1f\frac{1}{f}.
