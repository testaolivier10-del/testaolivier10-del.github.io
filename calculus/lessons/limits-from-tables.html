Estimating Limits from Tables

A table estimates a limit when it lists outputs for inputs closing in on a from both sides.

Practice 1: Implementing Mathematical ProcessesPractice 2: Connecting Representations

Part 1 · Hook

Why this matters

Sometimes you have no graph and no simple algebra, just a function you can evaluate, or a set of measurements. Then you test: plug in inputs closer and closer to the point, from both sides, and watch the outputs. A well-chosen table can reveal a limit in seconds, and a badly read one can mislead. This topic shows both.

Part 5 · Step by step

How it works, step by step

  1. Choose inputs closer and closer to aa from the left, and from the right (never aa itself)→the outputs show each one-sided trend
  2. Both sides settle on the same number→that number is a numerical estimate of the limit
  3. The sides settle on different numbers, grow without bound, or keep jumping around→the table suggests the limit does not exist
  4. A table checks only finitely many inputs→it suggests a limit but cannot prove it; confirm with a graph or algebra

Part 6 · Key ideas

Key ideas

  • To estimate limx→af(x)\lim_{x \to a} f(x), evaluate ff at inputs like a−0.1,a−0.01,a−0.001a - 0.1, a - 0.01, a - 0.001 and a+0.001,a+0.01,a+0.1a + 0.001, a + 0.01, a + 0.1.
  • Read each side separately, exactly as on a graph: the left-hand limit uses inputs below aa, the right-hand limit inputs above aa.
  • The estimate is the number the outputs approach, not the last value in the table. A value f(a)f(a) in the table never decides the limit.
  • A table can mislead if it stops too early. If the values have not settled, test inputs even closer to aa.

Part 7 · Misconception

A common mistake

The wrong idea: The limit is the table value at the input closest to aa.

What actually happens: The limit is the number the values approach. The closest value, such as 27.009001, is only an approximation of the limit, 27.

2. Which table values are evidence for the estimate of limx→3−f(x)\lim_{x \to 3^-} f(x)?

  1. 26.11, 26.9101 and 26.991001
  2. 27.91, 27.0901 and 27.009001
  3. 26.991001 and 27.009001, the two closest values
  4. The value of f(3)f(3)

A left-hand limit uses only x<3x < 3: the inputs 2.9, 2.99 and 2.999, whose outputs are 26.11, 26.9101 and 26.991001.

  • 27.91, 27.0901 and 27.009001: Those come from x>3x > 3: evidence for the right-hand limit.

3. What does the table tell you about f(3)f(3)?

  1. Nothing; it shows only the trend near 3.
  2. f(3)=27f(3) = 27, because the values close in on 27.
  3. f(3)f(3) is about 27.009, the closest value in the table.
  4. f(3)=0f(3) = 0, because 3 is not in the table.
Show the answer

A table near x=3x = 3 shows a trend, which estimates the limit. It does not give the value at 3; the caption says ff is not defined there.

  • Correct: Nothing; it shows only the trend near 3.: Trend near 3 versus value at 3.
  • f(3)=27f(3) = 27, because the values close in on 27.: A limit and a value can differ; here the value does not exist.
  • f(3)f(3) is about 27.009, the closest value in the table.: f(3.001)f(3.001) is a value at 3.001, not at 3.
  • f(3)=0f(3) = 0, because 3 is not in the table.: A missing table entry is not a zero.

4. Which additional input would best strengthen the estimate of limx→3+f(x)\lim_{x \to 3^+} f(x)?

  1. 3.0001
  2. 3.5
  3. 2.9999
  4. 4
Show the answer

A right-hand limit needs inputs above 3, closer than any already in the table. 3.0001 is the closest such input.

  • Correct: 3.0001: Above 3, and closer than 3.001.
  • 3.5: 3.5 is farther from 3 than the table's values; it adds little.
  • 2.9999: 2.9999 is below 3: it helps the left-hand limit, not the right-hand one.
  • 4: 4 is far from 3.

The two one-sided limits differ, 5.25 versus 7.40, so the two-sided limit does not exist. The cost jumps at 2 pounds.

  • Correct: It does not exist: 5.25 from the left, 7.40 from the right.: Unequal one-sided limits.

  • It is 7.40, because the cost goes up once a package passes 2 pounds.: That is only the right-hand limit.

6. For x=0.9,0.99,0.999x = 0.9, 0.99, 0.999 the values of g(x)g(x) are 100, 10,000 and 1,000,000. For x=1.1,1.01,1.001x = 1.1, 1.01, 1.001 they are also 100, 10,000 and 1,000,000. What does the table suggest about limx→1g(x)\lim_{x \to 1} g(x)?

  1. It does not exist: the values grow without bound from both sides.
  2. 1,000,000, the largest value in the table
  3. 1, the input being approached
  4. It exists, because both sides show exactly the same values at matching distances.
Show the answer

Each step closer to 1 multiplies the output by 100. The outputs are unbounded, so they approach no number and the limit does not exist.

  • Correct: It does not exist: the values grow without bound from both sides.: Unbounded outputs approach no number.
  • 1,000,000, the largest value in the table: The values keep growing past any number, including 1,000,000.
  • 1, the input being approached: 1 is the input, not a value the outputs approach.
  • It exists, because both sides show exactly the same values at matching distances.: Matching sides only help when they close in on a number; these grow without bound.

7. For x=1.1,1.01x = 1.1, 1.01 and 1.0011.001, a function kk gives 2.0001, 2.0099 and 2.5. A student says, "The first two values show the limit as x→1+x \to 1^+ is 2." Which response is best?

  1. The values have not settled; the third moved away from 2, so test closer inputs.
  2. The student is right: two values that agree are enough evidence to decide a limit like this one.
  3. The limit is 2.5, because that is the value at the input closest to 1.
  4. The limit is 2.17, the average of the three values in the table.
Show the answer

A table only suggests a limit, and it can mislead if you stop too early. Here the values jump from about 2.01 to 2.5 at the closest input, so the trend has not settled. Try 1.0001, 1.00001 and so on.

  • Correct: The values have not settled; the third moved away from 2, so test closer inputs.: A trend must hold as the inputs get closer, not just at the start.
  • The student is right: two values that agree are enough evidence to decide a limit like this one.: The values closest to 1 matter most, and they have not settled yet.
  • The limit is 2.5, because that is the value at the input closest to 1.: One value is not a trend either; check closer inputs.
  • The limit is 2.17, the average of the three values in the table.: Averaging table values does not give a limit.

Part 9 · Summary

Summary

A table estimates a limit when it lists outputs for inputs closing in on aa from both sides. If both sides settle on the same number, that is the estimate; if they differ, grow without bound or never settle, the limit appears not to exist. A table suggests; it does not prove, so check closer inputs or use algebra when in doubt.
