The Intermediate Value Theorem

If f is continuous on [a, b] and d is between f(a) and f(b) , then f(c) = d for at least one c in (a, b) .

Practice 3: Justification

Part 1 · Hook

Why this matters

If you were 50 cm tall at birth and 170 cm tall at 16, then at some moment you were exactly 1 meter tall. Nobody measured it, but height does not jump, so it had to pass through every value in between. The Intermediate Value Theorem turns that common sense into a tool, and the exam rewards you for saying exactly why it applies.

Part 5 · Step by step

How it works, step by step

  1. ff is continuous on the closed interval [a,b][a, b]→its graph has no break from (a,f(a))(a, f(a)) to (b,f(b))(b, f(b))
  2. A number dd lies between f(a)f(a) and f(b)f(b)→the horizontal line y=dy = d separates the two endpoints of the graph
  3. An unbroken graph joins points on opposite sides of a line→it must cross the line: f(c)=df(c) = d for at least one cc in (a,b)(a, b)
  4. Either hypothesis fails (a break, or dd outside the range of the endpoint values)→the theorem promises nothing; the value may or may not be reached

Part 6 · Key ideas

Key ideas

  • Intermediate Value Theorem (IVT): if ff is continuous on [a,b][a, b] and dd is between f(a)f(a) and f(b)f(b), then f(c)=df(c) = d for at least one cc in (a,b)(a, b).
  • Hypotheses come first: continuity on the closed interval, with a reason ("polynomial", "stated in the problem"), and dd between the endpoint values, with the numbers.
  • The conclusion is existence: at least one cc. The theorem does not say where, or how many.
  • With a table, apply the theorem on each pair of neighboring inputs; non-overlapping intervals give separate solutions.
  • Finding cc is a separate job: algebra, or a calculator (three decimal places).

Part 7 · Misconception

A common mistake

The wrong idea: f(0)=−1f(0) = -1 and f(4)=3f(4) = 3, so by the IVT, f(c)=1f(c) = 1 for some cc in (0,4)(0, 4).

What actually happens: The theorem needs ff to be continuous on [0,4][0, 4], and the justification must say so. A function with a jump can have f(0)<1<f(4)f(0) < 1 < f(4) and never equal 1. Write: "ff is continuous on [0,4][0, 4] and f(0)<1<f(4)f(0) < 1 < f(4), so by the IVT ..."

  • Yes, at t=3.5t = 3.5, halfway between 2 and 5: The theorem says such a time exists, not where it is.

4. g(0)=−1g(0) = -1 and g(4)=3g(4) = 3. Does the Intermediate Value Theorem guarantee some cc in (0,4)(0, 4) with g(c)=1g(c) = 1?

  1. Yes: 1 is between g(0)=−1g(0) = -1 and g(4)=3g(4) = 3
  2. Yes: gg is defined at each single point of the interval [0,4][0, 4]
  3. No: 1 is not between g(0)=−1g(0) = -1 and g(4)=3g(4) = 3
  4. No: gg is not continuous on [0,4][0, 4], since it jumps at x=2x = 2
Show the answer

The theorem needs gg continuous on [0,4][0, 4]. At x=2x = 2 the one-sided limits are 0.5 and 2, so gg is not continuous there, and the theorem does not apply.

  • Yes: 1 is between g(0)=−1g(0) = -1 and g(4)=3g(4) = 3: Being between the endpoint values is only one of the two hypotheses.
  • Yes: gg is defined at each single point of the interval [0,4][0, 4]: Defined is not the same as continuous.
  • No: 1 is not between g(0)=−1g(0) = -1 and g(4)=3g(4) = 3: 1 is between −1-1 and 3; the problem is continuity.
  • Correct: No: gg is not continuous on [0,4][0, 4], since it jumps at x=2x = 2: The continuity hypothesis fails at the jump, so no guarantee.

5. Let f(x)=x3−4x+1f(x) = x^3 - 4x + 1. Then f(0)=1f(0) = 1 and f(1)=−2f(1) = -2. Which statement justifies that ff has a zero in (0,1)(0, 1)?

  1. f(0)=1f(0) = 1 is positive and f(1)=−2f(1) = -2 is negative, so the graph of ff crosses the xx-axis at x=0.5x = 0.5
  2. ff is a polynomial, so it has a zero; since f(0)f(0) and f(1)f(1) differ, that zero lies between 0 and 1
  3. ff is continuous on [0,1][0, 1], so by the Intermediate Value Theorem it equals 0 somewhere in (0,1)(0, 1)
  4. ff is a polynomial, so it is continuous on [0,1][0, 1]; since −2<0<1-2 < 0 < 1, the IVT gives f(c)=0f(c) = 0 for some cc in (0,1)(0, 1)
Show the answer

Name why ff is continuous on the closed interval (polynomial), show 0 is between f(0)f(0) and f(1)f(1), name the theorem, and conclude with some cc in (0,1)(0, 1).

  • f(0)=1f(0) = 1 is positive and f(1)=−2f(1) = -2 is negative, so the graph of ff crosses the xx-axis at x=0.5x = 0.5: It never mentions continuity, and the theorem does not give the location 0.5.
  • ff is a polynomial, so it has a zero; since f(0)f(0) and f(1)f(1) differ, that zero lies between 0 and 1: Not every polynomial has a real zero, and "differ" is not enough; 0 must lie between the values.
  • ff is continuous on [0,1][0, 1], so by the Intermediate Value Theorem it equals 0 somewhere in (0,1)(0, 1): It never shows that 0 is between f(0)=1f(0) = 1 and f(1)=−2f(1) = -2.
  • Correct: ff is a polynomial, so it is continuous on [0,1][0, 1]; since −2<0<1-2 < 0 < 1, the IVT gives f(c)=0f(c) = 0 for some cc in (0,1)(0, 1): Reason for continuity, the value between the endpoint values, the theorem, and the conclusion.

6. f(x)=1xf(x) = \frac{1}{x} has f(−1)=−1f(-1) = -1 and f(1)=1f(1) = 1, yet f(x)=0f(x) = 0 has no solution. Why does this not contradict the Intermediate Value Theorem?

  1. 0 is not between f(−1)=−1f(-1) = -1 and f(1)=1f(1) = 1
  2. ff is not continuous on [−1,1][-1, 1]; it is undefined at x=0x = 0
  3. The theorem applies to polynomials, and 1x\frac{1}{x} is not one
  4. The theorem needs f(−1)f(-1) and f(1)f(1) to have the same sign
Show the answer

The theorem's hypothesis is continuity on the closed interval [−1,1][-1, 1]. 1x\frac{1}{x} has an infinite discontinuity at 0, so the hypothesis fails and the theorem promises nothing.

  • 0 is not between f(−1)=−1f(-1) = -1 and f(1)=1f(1) = 1: 0 is between −1-1 and 11; that hypothesis holds.
  • Correct: ff is not continuous on [−1,1][-1, 1]; it is undefined at x=0x = 0: A failed hypothesis means no conclusion, so no contradiction.
  • The theorem applies to polynomials, and 1x\frac{1}{x} is not one: The theorem applies to every function continuous on [a,b][a, b], polynomial or not.
  • The theorem needs f(−1)f(-1) and f(1)f(1) to have the same sign: Opposite signs are what put 0 between them.

Part 9 · Summary

Summary

If ff is continuous on [a,b][a, b] and dd is between f(a)f(a) and f(b)f(b), then f(c)=df(c) = d for at least one cc in (a,b)(a, b). A justification states both hypotheses with reasons and numbers, names the theorem, and concludes "for some cc in (a,b)(a, b)". Without continuity on the closed interval, the conclusion can fail.
