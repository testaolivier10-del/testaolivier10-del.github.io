Part 1 · Hook

Why this matters

Type x2−9x−3\frac{x^2 - 9}{x - 3} into a calculator at x=3x = 3 and it shows an error. Yet the values near 3 settle down on 6. The error is a message, not an answer: it tells you which tool to pick next. This lesson turns the result of one substitution into a plan.

Part 4 · See it

See it first

Part 5 · Step by step

How it works, step by step

  1. You substitute x=cx = c and get a number→that number is the limit, as long as the expression is defined near cc
  2. You get 00\frac{0}{0}→the numerator and denominator share a hidden zero factor, so rewrite (factor, conjugate, common denominator) and substitute again
  3. You get a nonzero number over 0→the denominator shrinks while the numerator does not, so the function is unbounded near cc and the limit does not exist
  4. The function changes formula at x=cx = c (piecewise or absolute value)→find the left-hand and right-hand limits separately; equal means the limit exists

Part 6 · Key ideas

Key ideas

  • Substitute first. It is the fastest test, and its result tells you what to do next.
  • 00\frac{0}{0} is an indeterminate form: not an answer, a signal to rewrite.
  • A nonzero number over 0 means the function is unbounded near cc; no algebra will make the limit a number.
  • At a break point, the two sides can follow different rules. Find both one-sided limits.
  • Write the limit symbol on every line until you substitute: the simplified expression equals the original only for x≠cx \ne c.

Part 7 · Misconception

A common mistake

The wrong idea: Substituting gives 00\frac{0}{0}, so the limit does not exist.

What actually happens: 00\frac{0}{0} is indeterminate: the limit may be any number or may not exist. Rewrite the expression and substitute again. For x2−9x−3\frac{x^2 - 9}{x - 3} the limit is 6.

1. Substituting x=3x = 3 into which function gives a nonzero number divided by 00?

  1. hh
  2. ff
  3. gg
  4. kk
Show the answer

At x=3x = 3, hh gives 60\frac{6}{0}: a nonzero numerator over a zero denominator.

  • Correct: hh: h(3)h(3) would be 3+33−3=60\frac{3 + 3}{3 - 3} = \frac{6}{0}, so hh is unbounded near 3.
  • ff: ff gives 9−15+60=00\frac{9 - 15 + 6}{0} = \frac{0}{0}, an indeterminate form, not a nonzero number over 0.
  • gg: gg gives 4−20=00\frac{\sqrt{4} - 2}{0} = \frac{0}{0}, an indeterminate form.
  • kk: kk gives 106\frac{10}{6}; its denominator is not 0 at x=3x = 3.

2. Find limx→3f(x)\lim_{x \to 3} f(x).

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

Substitution gives 00\frac{0}{0}, so factor: (x−2)(x−3)x−3\frac{(x - 2)(x - 3)}{x - 3}=x−2= x - 2 for x≠3x \ne 3. Then limx→3(x−2)\lim_{x \to 3} (x - 2)=1= 1.

  • Answer: 1

3. What can you conclude about limx→3h(x)\lim_{x \to 3} h(x)?

  1. It equals 66, the value of the numerator at x=3x = 3
  2. It does not exist; hh is unbounded near x=3x = 3
  3. It equals 11, after the x−3x - 3 terms cancel
  4. It can be found by factoring and cancelling first
Show the answer

A nonzero number over 0 means the denominator shrinks while the numerator stays near 6, so |h(x)||h(x)| grows without bound. Left of 3, hh is very negative; right of 3, very positive. The limit does not exist.

  • It equals 66, the value of the numerator at x=3x = 3: The numerator's value alone ignores the denominator, which is heading to 0.
  • Correct: It does not exist; hh is unbounded near x=3x = 3: Near 3 the numerator is about 6 and the denominator is tiny, so hh is unbounded and the limit does not exist.
  • It equals 11, after the x−3x - 3 terms cancel: Nothing cancels: x+3x + 3 and x−3x - 3 are different factors.
  • It can be found by factoring and cancelling first: Factoring helps with 00\frac{0}{0}. Here the numerator is not 0 at x=3x = 3, so there is no common factor to cancel.

4. Let q(x)=|x−5|x−5q(x) = \frac{|x - 5|}{x - 5}. Which is true about limx→5q(x)\lim_{x \to 5} q(x)?

  1. It equals 11, because |x−5||x - 5| is not negative for any xx
  2. It equals 00, because the numerator approaches 00
  3. It does not exist, because qq grows without bound near x=5x = 5
  4. It does not exist; qq is −1-1 on the left, 11 on the right
Show the answer

For x>5x > 5, |x−5|=x−5|x - 5| = x - 5 and q(x)=1q(x) = 1. For x<5x < 5, |x−5|=−(x−5)|x - 5| = -(x - 5) and q(x)=−1q(x) = -1. The one-sided limits, −1-1 and 11, differ, so the limit does not exist.

  • It equals 11, because |x−5||x - 5| is not negative for any xx: The numerator is not negative, but the denominator x−5x - 5 is negative left of 5, which makes q=−1q = -1 there.
  • It equals 00, because the numerator approaches 00: Both numerator and denominator approach 0; that is 00\frac{0}{0}, which needs more work, not the answer 0.
  • It does not exist, because qq grows without bound near x=5x = 5: The limit does fail to exist, but not by growing: qq only takes the values −1-1 and 11.
  • Correct: It does not exist; qq is −1-1 on the left, 11 on the right: Split at the break: q=−1q = -1 for x<5x < 5 and q=1q = 1 for x>5x > 5. Unequal one-sided limits, so no limit.

5. A student writes: "limx→1x2−1x−1\lim_{x \to 1} \frac{x^2 - 1}{x - 1}: substituting gives 00\frac{0}{0}, so the limit does not exist." Which correction is right?

  1. Rewrite: x2−1x−1=x+1\frac{x^2 - 1}{x - 1} = x + 1, so the limit is 2
  2. 00\frac{0}{0} equals 1, so the limit of the quotient is 1
  3. 00\frac{0}{0} equals 0, so the limit of the quotient is 0
  4. It does not exist, but because of a jump at x=1x = 1
Show the answer

00\frac{0}{0} is an indeterminate form: it tells you nothing yet. Here (x−1)(x+1)x−1\frac{(x - 1)(x + 1)}{x - 1}=x+1= x + 1 for x≠1x \ne 1, so the limit is 2.

  • Correct: Rewrite: x2−1x−1=x+1\frac{x^2 - 1}{x - 1} = x + 1, so the limit is 2: Factor and cancel: x+1→2x + 1 \to 2. Writing "00=2\frac{0}{0} = 2" would be wrong too; the 2 comes from the rewritten expression.
  • 00\frac{0}{0} equals 1, so the limit of the quotient is 1: 00\frac{0}{0} is not a number. Treating it as 1 skips the rewriting step.
  • 00\frac{0}{0} equals 0, so the limit of the quotient is 0: 00\frac{0}{0} is not 0. A zero numerator only gives 0 when the denominator is not also 0.
  • It does not exist, but because of a jump at x=1x = 1: The expression equals x+1x + 1 on both sides of 1, so there is no jump and the limit exists.

6. Find limx→−1x2+3x+2x2−1\lim_{x \to -1} \frac{x^2 + 3x + 2}{x^2 - 1}.

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

Both parts are 0 at x=−1x = -1. Factor: (x+1)(x+2)(x+1)(x−1)\frac{(x + 1)(x + 2)}{(x + 1)(x - 1)}=x+2x−1= \frac{x + 2}{x - 1} for x≠−1x \ne -1. Substitute: 1−2=−12\frac{1}{-2} = -\frac{1}{2}.

  • Answer: −12\frac{-1}{2} ≈ -0.500

Part 9 · Summary

Summary

Substitute first and read the result. A number is the limit. 00\frac{0}{0} means rewrite: factor and cancel, multiply by a conjugate, or combine fractions, then substitute again. A nonzero number over 0 means the function is unbounded there. At a break point, compare the one-sided limits.
