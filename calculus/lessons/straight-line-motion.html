Unit 4 · Topic 4.2 Beta

Straight-Line Motion: Position, Velocity, Acceleration

For a particle on a line, v(t) = x′(t) and a(t) = v′(t) = x″(t) .

Practice 1: Implementing Mathematical ProcessesPractice 3: Justification

Part 1 · Hook

Why this matters

A runner jogs east, slows, turns around and sprints back. Her position, velocity and acceleration are a function and its first two derivatives. The exam asks about this kind of motion every year: which way is the particle going, is it speeding up, when does it turn around. Each answer comes from a sign.

Part 5 · Step by step

How it works, step by step

  1. Position x(t)x(t) changes with time→its rate of change is the velocity, v(t)=x′(t)v(t) = x'(t)
  2. Velocity changes with time→its rate of change is the acceleration, a(t)=v′(t)=x″(t)a(t) = v'(t) = x''(t)
  3. The sign of vv→gives the direction: right (or up) when v>0v > 0, left when v<0v < 0; a direction change needs vv to change sign
  4. Compare the signs of vv and aa→same sign: speeding up; opposite signs: slowing down

Part 6 · Key ideas

Key ideas

  • Velocity has a sign; speed is |v(t)||v(t)| and is never negative.
  • The particle is at rest when v(t)=0v(t) = 0, and changes direction only where vv changes sign.
  • Speeding up when vv and aa have the same sign. State both signs in a justification.
  • Units: position in meters gives velocity in meters per second and acceleration in meters per second per second.

Part 7 · Misconception

A common mistake

The wrong idea: Negative acceleration means the particle is slowing down.

What actually happens: It depends on the velocity too. With v<0v < 0 and a<0a < 0, the particle moves left faster and faster: it is speeding up. Slowing down needs vv and aa with opposite signs.

Position of a particle: x(t)=t3−6t2+9tx(t) = t^3 - 6t^2 + 9t

1. A particle moves along the xx-axis with position x(t)=t3−6t2+9tx(t) = t^3 - 6t^2 + 9t meters at time tt seconds, as graphed. Find its velocity at t=2t = 2, with units.

No calculator. Type the exact value (a fraction, π, e or a root is fine), then its unit.

Show the answer

v(t)v(t)=x′(t)= x'(t)=3t2−12t+9= 3t^2 - 12t + 9, so v(2)=12−24+9=−3v(2) = 12 - 24 + 9 = -3 meters per second.

  • Answer: -3 meters per second

2. Find the acceleration of the particle at t=3t = 3, with units.

No calculator. Type the exact value (a fraction, π, e or a root is fine), then its unit.

Show the answer

a(t)=v′(t)=6t−12a(t) = v'(t) = 6t - 12, so a(3)=6a(3) = 6 meters per second per second.

  • Answer: 6 meters per second per second

3. At t=2.5t = 2.5 seconds, is the particle speeding up or slowing down?

  1. Slowing down, because v(2.5)<0v(2.5) < 0 and a(2.5)>0a(2.5) > 0
  2. Speeding up, because a(2.5)>0a(2.5) > 0
  3. Speeding up, because v(2.5)v(2.5) and a(2.5)a(2.5) are both negative
  4. Slowing down, because v(2.5)<0v(2.5) < 0
Show the answer

v(2.5)v(2.5)=3(2.5)2−12(2.5)= 3(2.5)^2 - 12(2.5)+9+ 9=−2.25= -2.25 and a(2.5)=3a(2.5) = 3. They have opposite signs, so the speed is decreasing: slowing down.

  • Correct: Slowing down, because v(2.5)<0v(2.5) < 0 and a(2.5)>0a(2.5) > 0: v(2.5)=−2.25v(2.5) = -2.25 and a(2.5)=3a(2.5) = 3: opposite signs.
  • Speeding up, because a(2.5)>0a(2.5) > 0: A positive acceleration speeds the particle up only if it is moving in the positive direction.
  • Speeding up, because v(2.5)v(2.5) and a(2.5)a(2.5) are both negative: a(2.5)=6(2.5)−12=3a(2.5) = 6(2.5) - 12 = 3 is positive.
  • Slowing down, because v(2.5)<0v(2.5) < 0: The sign of vv alone gives the direction of motion, not whether speed grows.

4. On which interval is the particle moving to the left?

  1. 2<t<42 < t < 4
  2. 1<t<31 < t < 3
  3. 0<t<20 < t < 2
  4. 3<t<43 < t < 4
Show the answer

Moving left means v(t)<0v(t) < 0. Since v(t)=3(t−1)(t−3)v(t) = 3(t - 1)(t - 3), that is 1<t<31 < t < 3, where the graph of xx falls.

  • 2<t<42 < t < 4: vv is positive for t>3t > 3; the acceleration is positive on 2<t<42 < t < 4.
  • Correct: 1<t<31 < t < 3: v(t)v(t)=3(t−1)(t−3)<0= 3(t - 1)(t - 3) < 0 there, and the graph of xx falls.
  • 0<t<20 < t < 2: The particle moves right until t=1t = 1.
  • 3<t<43 < t < 4: v>0v > 0 there: the position increases.

5. At which times does the particle change direction, and why?

  1. t=2t = 2, because a(2)=0a(2) = 0
  2. t=0t = 0 and t=3t = 3, because x=0x = 0 there
  3. t=1t = 1 and t=3t = 3, because vv changes sign there
  4. t=1t = 1 and t=3t = 3, because x(t)=4x(t) = 4 or x(t)=0x(t) = 0 there
Show the answer

The direction changes where vv changes sign. v(t)=3(t−1)(t−3)v(t) = 3(t - 1)(t - 3) changes sign at t=1t = 1 (positive to negative) and t=3t = 3 (negative to positive).

  • t=2t = 2, because a(2)=0a(2) = 0: A zero of aa is where the velocity stops falling; the particle still moves left.
  • t=0t = 0 and t=3t = 3, because x=0x = 0 there: Being at the origin says nothing about the direction of motion.
  • Correct: t=1t = 1 and t=3t = 3, because vv changes sign there: vv goes from positive to negative at 1 and from negative to positive at 3.
  • t=1t = 1 and t=3t = 3, because x(t)=4x(t) = 4 or x(t)=0x(t) = 0 there: The right times, but the reason must be about vv: it changes sign.

6. At t=3t = 3, a particle has v(3)=−4v(3) = -4 and a(3)=−2a(3) = -2. The particle is

  1. slowing down, because a(3)a(3) is negative
  2. slowing down, because v(3)v(3) is negative
  3. at rest, because v(3)v(3) and a(3)a(3) are both negative
  4. speeding up, because v(3)v(3) and a(3)a(3) share a sign
Show the answer

Speeding up when vv and aa share a sign; slowing down when they differ. Here both are negative: speeding up while moving left.

  • slowing down, because a(3)a(3) is negative: A negative acceleration speeds up a particle moving in the negative direction.
  • slowing down, because v(3)v(3) is negative: The sign of vv alone gives direction only.
  • at rest, because v(3)v(3) and a(3)a(3) are both negative: At rest means v=0v = 0; here the particle moves left.
  • Correct: speeding up, because v(3)v(3) and a(3)a(3) share a sign: Both negative: the acceleration points the way the particle moves.

Part 9 · Summary

Summary

For a particle on a line, v(t)=x′(t)v(t) = x'(t) and a(t)=v′(t)=x″(t)a(t) = v'(t) = x''(t). The sign of vv gives the direction, and the direction changes only where vv changes sign. Speed is |v||v|; it increases when vv and aa have the same sign and decreases when their signs differ.
