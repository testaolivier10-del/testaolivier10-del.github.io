Behavior of Accumulation Functions

A definite integral is a signed area: regions below the axis subtract.

Practice 2: Connecting RepresentationsPractice 3: Justification

Part 1 · Hook

Why this matters

On a free-response question you are handed a graph of ff made of lines and half-circles, and asked about a function gg you never see. Where does gg peak? Where does it bend? How big does it get? Everything is in the graph of ff, once you know that gg's slope is ff and gg's value is the area so far.

Part 5 · Step by step

How it works, step by step

  1. g(x)g(x)=∫axf(t)dt= \int_a^x f(t)\,dt→g′(x)=f(x)g'(x) = f(x) and g″(x)=f′(x)g''(x) = f'(x)
  2. f>0f > 0 (graph of ff above the axis)→gg is increasing; where ff changes sign, gg has a relative extremum
  3. ff is increasing (graph of ff rising)→gg is concave up; where ff turns around, gg has a point of inflection
  4. Regions below the axis count as negative→values of gg are signed areas: add what is above, subtract what is below

Part 6 · Key ideas

Key ideas

  • Signed area: ∫abf(x)dx\int_a^b f(x)\,dx = (area above the axis) minus (area below).
  • g′=fg' = f: gg increases where f>0f > 0, decreases where f<0f < 0, and has a relative extremum where ff changes sign.
  • g″=f′g'' = f': gg is concave up where ff increases and concave down where ff decreases; inflection points sit where ff changes direction.
  • For an absolute extremum of g, compare g at the endpoints and at the sign changes of f (the candidates test).

Part 7 · Misconception

A common mistake

The wrong idea: gg has its inflection points where f(x)=0f(x) = 0.

What actually happens: Where f=0f = 0 and changes sign, gg has a relative extremum. Inflection points of gg are where f′=g″f' = g'' changes sign: where the graph of ff turns from rising to falling or back.

2. At what value of xx in (0,8)(0, 8) does gg have a relative maximum? Why?

  1. x=3x = 3, because ff has its largest value on [0,8][0, 8] there
  2. x=1x = 1, because g′=fg' = f changes sign from −- to ++ there
  3. x=7x = 7, because ff stops decreasing there
  4. x=5x = 5: there g′=fg' = f changes from positive to negative
Show the answer

g′(x)=f(x)g'(x) = f(x). f>0f > 0 on (1,5)(1, 5) and f<0f < 0 on (5,8)(5, 8), so g′g' changes from positive to negative at x=5x = 5: a relative maximum.

  • x=3x = 3, because ff has its largest value on [0,8][0, 8] there: At x=3x = 3, g′=fg' = f is largest, so gg is rising fastest. gg keeps rising until ff turns negative.
  • x=1x = 1, because g′=fg' = f changes sign from −- to ++ there: At x=1x = 1, ff changes from negative to positive, so gg stops falling and starts rising: a relative minimum.

  • Correct: x=5x = 5: there g′=fg' = f changes from positive to negative: Correct: area stops adding and starts subtracting at x=5x = 5.

3. At what value of xx in (0,8)(0, 8) does the graph of gg have a point of inflection?

  1. x=5x = 5, where ff changes from positive to negative
  2. x=7x = 7, where ff stops decreasing and becomes constant
  3. x=3x = 3, where ff changes from increasing to decreasing
  4. x=1x = 1, where ff changes from negative to positive
Show the answer

g″=f′g'' = f'. ff increases on (0,3)(0, 3) and decreases on (3,7)(3, 7), so gg changes from concave up to concave down at x=3x = 3.

  • x=5x = 5, where ff changes from positive to negative: That is where gg has its relative maximum. ff is decreasing on both sides of 5, so gg stays concave down there.
  • x=7x = 7, where ff stops decreasing and becomes constant: On (5,7)(5, 7), ff decreases so gg is concave down; on (7,8)(7, 8), ff is constant so g″=0g'' = 0. Concavity does not change from down to up.
  • Correct: x=3x = 3, where ff changes from increasing to decreasing: Correct: g″=f′g'' = f' changes from positive to negative at 3.
  • x=1x = 1, where ff changes from negative to positive: A sign change of f=g′f = g' makes an extremum of gg. An inflection point needs g″=f′g'' = f' to change sign.

6. For the function gg in a free-response question, g(x)g(x)=∫0xf(t)dt= \int_0^x f(t)\,dt and ff is graphed. Which sentence earns the point for "gg has a relative maximum at x=5x = 5"?

  1. f(5)=0f(5) = 0, so g′(5)=0g'(5) = 0.
  2. ff is decreasing at x=5x = 5, so gg is concave down.
  3. The graph changes from going up to going down at x=5x = 5.
  4. g′(x)=f(x)g'(x) = f(x) changes from positive to negative at x=5x = 5.
Show the answer

A relative maximum of gg needs g′g' to change from positive to negative, said in words and tied to the given function: "g′(x)=f(x)g'(x) = f(x) changes from positive to negative at x=5x = 5."

  • f(5)=0f(5) = 0, so g′(5)=0g'(5) = 0.: A zero of the derivative only makes x = 5 a candidate; the sign change is the reason.
  • ff is decreasing at x=5x = 5, so gg is concave down.: Concave down at a point does not make it a maximum unless g prime is also 0 there, and this sentence does not connect the two.
  • The graph changes from going up to going down at x=5x = 5.: This does not say which graph. The scoring guidelines need the function named: g prime, which equals f.
  • Correct: g′(x)=f(x)g'(x) = f(x) changes from positive to negative at x=5x = 5.: Correct: it names g prime, says what changes sign and in which direction.

Part 9 · Summary

Summary

A definite integral is a signed area: regions below the axis subtract. For g(x)g(x)=∫axf(t)dt= \int_a^x f(t)\,dt, read gg's values from signed areas, its direction from the sign of ff, and its concavity from whether ff rises or falls. Justify with g′=fg' = f named, and use the candidates test for absolute extrema.
