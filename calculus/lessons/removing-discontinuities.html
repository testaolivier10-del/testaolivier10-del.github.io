Removing a Discontinuity

A removable discontinuity is removed by defining f(c) to be the limit at c .

Question set for this topic

Part 1 · Hook

Why this matters

A bridge crew can fill a single pothole with one shovel of asphalt, but no shovel fills a canyon. Some discontinuities are potholes: one point, set to the right height, repairs them. Others, jumps and asymptotes, cannot be fixed that way. This lesson is about choosing the right value, or the right constant, to make a function whole.

Part 5 · Step by step

How it works, step by step

  1. ff has a removable discontinuity at cc, with limx→cf(x)=L\lim_{x \to c} f(x) = L→defining (or redefining) f(c)=Lf(c) = L makes ff continuous at cc
  2. A piecewise function has a constant kk in one or both pieces→continuity at the break point gives an equation: the left-hand limit equals the right-hand limit equals the value
  3. There are two unknown constants and two break points→each break point gives one equation; solve them together
  4. The discontinuity is a jump or infinite→no single value can fix it, because the two-sided limit does not exist

Part 6 · Key ideas

Key ideas

  • To remove a removable discontinuity, find L=limx→cf(x)L = \lim_{x \to c} f(x) and define f(c)=Lf(c) = L.
  • At a break point of a piecewise function, set the left-hand limit, the right-hand limit and the value equal. Each break point gives one equation.
  • A constant can only move its own piece. If the value at the point and the other piece already disagree, no constant fixes it.
  • A jump or an infinite discontinuity cannot be removed: the limit does not exist, so no value can equal it.
  • Write the result as a check: substitute your constant back and show both sides give the same number.

Part 7 · Misconception

A common mistake

The wrong idea: To make ff continuous at cc, just define f(c)f(c) to be any number, since the problem is that f(c)f(c) is undefined.

What actually happens: The value must equal the limit: f(c)=limx→cf(x)f(c) = \lim_{x \to c} f(x). And this works only when that limit exists. For a jump or an asymptote, no value of f(c)f(c) makes the function continuous.

5. Which discontinuity can be removed by defining or changing a single value of the function?

  1. |x−1|x−1\frac{|x - 1|}{x - 1} at x=1x = 1
  2. x+1x−1\frac{x + 1}{x - 1} at x=1x = 1

A single value can fix a discontinuity only when the limit exists. x2−1x−1=x+1\frac{x^2 - 1}{x - 1} = x + 1 near 1, so its limit is 2; defining the value 2 there removes the break.

  • |x−1|x−1\frac{|x - 1|}{x - 1} at x=1x = 1: The one-sided limits are −1-1 and 11: a jump. No single value makes them agree.
  • x+1x−1\frac{x + 1}{x - 1} at x=1x = 1: It is unbounded near 1; no value can fix that.

Part 9 · Summary

Summary

A removable discontinuity is removed by defining f(c)f(c) to be the limit at cc. A piecewise function is made continuous at a break point by choosing constants so the two one-sided limits and the value agree; each break point gives one equation. Jumps and infinite discontinuities cannot be removed by choosing a value.
