Unit 5 · Topic 5.7 Beta

The Second Derivative Test

At a critical point where f′(c) = 0 , the sign of f″(c) decides: positive gives a relative minimum, negative a relative maximum, zero gives no conclusion.

Practice 3: Justification

Part 1 · Hook

Why this matters

A skateboarder at the bottom of a half-pipe is at a flat spot, and the ramp curves up on both sides. At the lip of a hill the board is also flat, but the ground curves down. Flatness plus the direction of the curve tells you which you have: that is the Second Derivative Test.

Part 5 · Step by step

How it works, step by step

  1. f′(c)=0f'(c) = 0 and f″(c)>0f''(c) > 0→the tangent line at cc is flat and the graph bends up away from it, so f(c)f(c) is a relative minimum
  2. f′(c)=0f'(c) = 0 and f″(c)<0f''(c) < 0→the graph bends down from a flat point, so f(c)f(c) is a relative maximum
  3. f′(c)=0f'(c) = 0 and f″(c)=0f''(c) = 0 (or f″(c)f''(c) does not exist)→the test is inconclusive; go back to the First Derivative Test
  4. A continuous ff has exactly one critical point on an interval, and it is a relative extremum→that relative extremum is also the absolute extremum on the interval

Part 6 · Key ideas

Key ideas

  • Second Derivative Test: if f′(c)=0f'(c) = 0 and f″(c)>0f''(c) > 0, ff has a relative minimum at cc; if f′(c)=0f'(c) = 0 and f″(c)<0f''(c) < 0, a relative maximum.
  • It says nothing when f″(c)=0f''(c) = 0 or when f′(c)f'(c) does not exist. Then use the First Derivative Test.
  • Justify with both facts: "f′(1)=0f'(1) = 0 and f″(1)>0f''(1) > 0."
  • One critical point on an interval, and it is a relative minimum (maximum)? Then it is the absolute minimum (maximum) there, even on an open interval.

Part 7 · Misconception

A common mistake

The wrong idea: f″(c)>0f''(c) > 0, so ff has a relative minimum at cc.

What actually happens: Concave up alone is not a minimum: f(x)=x2f(x) = x^2 at x=1x = 1 is concave up and rising. The test needs a critical point first, f′(c)=0f'(c) = 0, and then the sign of f″(c)f''(c). And when f″(c)=0f''(c) = 0, the test says nothing at all.

1. At which value of xx in the table does ff have a relative maximum?

  1. x=1x = 1
  2. x=−2x = -2
  3. x=4x = 4
  4. x=3x = 3, where f″(3)<0f''(3) < 0
Show the answer

Second Derivative Test: f′(−2)=0f'(-2) = 0 and f″(−2)<0f''(-2) < 0, so ff has a relative maximum at x=−2x = -2.

  • x=1x = 1: f′(1)=0f'(1) = 0 and f″(1)>0f''(1) > 0: a relative minimum.
  • Correct: x=−2x = -2: f′(−2)=0f'(-2) = 0 and f″(−2)=−3<0f''(-2) = -3 < 0: concave down at a flat point.
  • x=4x = 4: f″(4)=0f''(4) = 0: the test gives no answer at x=4x = 4.
  • x=3x = 3, where f″(3)<0f''(3) < 0: f′(3)=2≠0f'(3) = 2 \ne 0, so x=3x = 3 is not a critical point.

2. Which justification earns credit for "ff has a relative minimum at x=1x = 1"?

  1. "f′(1)=0f'(1) = 0 and f″(1)>0f''(1) > 0."
  2. "f″(1)>0f''(1) > 0."
  3. "f′(1)=0f'(1) = 0."
  4. "f′(0)<0f'(0) < 0 and f′(3)>0f'(3) > 0, so f′f' changes sign."
Show the answer

The Second Derivative Test needs both: f′(1)=0f'(1) = 0 (critical point) and f″(1)=4>0f''(1) = 4 > 0 (concave up there), so ff has a relative minimum at x=1x = 1.

  • Correct: "f′(1)=0f'(1) = 0 and f″(1)>0f''(1) > 0.": Both conditions of the Second Derivative Test.
  • "f″(1)>0f''(1) > 0.": Concave up alone is not a minimum; ff must also have a flat tangent line there.
  • "f′(1)=0f'(1) = 0.": A critical point alone is only a candidate.
  • "f′(0)<0f'(0) < 0 and f′(3)>0f'(3) > 0, so f′f' changes sign.": Values of f′f' at two separate points do not show a sign change at x=1x = 1; f′f' might change sign more than once.

3. What does the Second Derivative Test say about ff at x=4x = 4?

  1. A relative maximum, because f″(4)≤0f''(4) \le 0
  2. A point of inflection, because f″(4)=0f''(4) = 0 and f″f'' is continuous
  3. A relative minimum, because f′(4)=0f'(4) = 0
  4. Nothing, because f″(4)=0f''(4) = 0 makes the test inconclusive
Show the answer

The Second Derivative Test needs f″(c)≠0f''(c) \ne 0. Here f″(4)=0f''(4) = 0, so it gives no conclusion; check the sign of f′f' on each side instead.

  • A relative maximum, because f″(4)≤0f''(4) \le 0: The test needs f″(4)<0f''(4) < 0 strictly.
  • A point of inflection, because f″(4)=0f''(4) = 0 and f″f'' is continuous: f″(4)=0f''(4) = 0 does not show a sign change of f″f''.
  • A relative minimum, because f′(4)=0f'(4) = 0: f′(4)=0f'(4) = 0 only makes 4 a critical point.
  • Correct: Nothing, because f″(4)=0f''(4) = 0 makes the test inconclusive: With f″(4)=0f''(4) = 0, the point could be a maximum, a minimum or neither. Use the First Derivative Test.

4. Which describes the graph of ff at x=3x = 3?

  1. Increasing and concave up
  2. Decreasing and concave down
  3. Increasing and concave down
  4. A relative maximum, because f″(3)<0f''(3) < 0
Show the answer

f′(3)=2>0f'(3) = 2 > 0, so ff is increasing; f″(3)=−1<0f''(3) = -1 < 0, so it is concave down.

  • Increasing and concave up: f″(3)<0f''(3) < 0 means concave down.
  • Decreasing and concave down: f′(3)>0f'(3) > 0 means increasing.
  • Correct: Increasing and concave down: f′(3)=2>0f'(3) = 2 > 0 and f″(3)=−1<0f''(3) = -1 < 0.
  • A relative maximum, because f″(3)<0f''(3) < 0: x=3x = 3 is not a critical point, so the test does not apply.

5. Find the absolute minimum value of f(x)=x+1xf(x) = x + \frac{1}{x} on (0,∞)(0, \infty).

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

f′(x)=1−1x2=0f'(x) = 1 - \frac{1}{x^2} = 0 at x=1x = 1 (the one critical point in (0,∞)(0, \infty)). f″(x)=2x3f''(x) = \frac{2}{x^3}, so f″(1)=2>0f''(1) = 2 > 0: a relative minimum, and as the only critical point it is the absolute minimum, f(1)=2f(1) = 2.

  • Answer: 2

6. A company's profit is P(x)P(x) dollars when it makes xx units. P′(50)=0P'(50) = 0 and P″(50)=−0.4P''(50) = -0.4. What can you conclude?

  1. Making 50 units gives a relative maximum of profit
  2. Making 50 units gives a relative minimum of profit
  3. Profit is increasing at a decreasing rate at 50 units
  4. At 50 units, profit is −0.4-0.4 dollars
Show the answer

P′(50)=0P'(50) = 0 and P″(50)<0P''(50) < 0: by the Second Derivative Test, PP has a relative maximum at x=50x = 50.

  • Correct: Making 50 units gives a relative maximum of profit: A flat point where the graph is concave down: a peak.
  • Making 50 units gives a relative minimum of profit: P″<0P'' < 0 means concave down: a maximum, not a minimum.
  • Profit is increasing at a decreasing rate at 50 units: P′(50)=0P'(50) = 0, so profit is not increasing at 50 units.
  • At 50 units, profit is −0.4-0.4 dollars: −0.4-0.4 is the value of P″P'', not of PP.

Part 9 · Summary

Summary

At a critical point where f′(c)=0f'(c) = 0, the sign of f″(c)f''(c) decides: positive gives a relative minimum, negative a relative maximum, zero gives no conclusion. State both conditions in a justification. With exactly one critical point on an interval, a relative extremum there is absolute.
