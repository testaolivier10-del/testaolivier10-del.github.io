Derivatives of tan, cot, sec and csc

Write tangent, cotangent, secant and cosecant in terms of sine and cosine, apply the quotient rule, and simplify with sin² x + cos² x = 1 .

Question set for this topic

Part 1 · Hook

Why this matters

A surveyor tilts a sight toward a mountaintop, and the height she reads grows with the tangent of the angle. Near flat angles the height barely changes; near straight up it explodes. How fast it changes is the derivative of tan⁡x\tan x, and the quotient rule finds it, along with the other three trigonometric derivatives, from sine and cosine alone.

Part 5 · Step by step

How it works, step by step

  1. tan⁡x=sin⁡xcos⁡x\tan x = \frac{\sin x}{\cos x}→the quotient rule gives cos⁡xcos⁡x−sin⁡x(−sin⁡x)cos2⁡x\frac{\cos x \cos x - \sin x(-\sin x)}{\cos^2 x}
  2. The numerator is cos2⁡x+sin2⁡x=1\cos^2 x + \sin^2 x = 1→ddx(tan⁡x)\frac{d}{dx}(\tan x) =1cos2⁡x= \frac{1}{\cos^2 x} =sec2⁡x= \sec^2 x
  3. sec⁡x=1cos⁡x\sec x = \frac{1}{\cos x} and csc⁡x=1sin⁡x\csc x = \frac{1}{\sin x}→the quotient rule with a constant top gives sec⁡xtan⁡x\sec x\tan x and −csc⁡xcot⁡x-\csc x\cot x
  4. Each "co-" function is built from cosine where its partner uses sine→its derivative carries a minus sign: −csc2⁡x-\csc^2 x, −csc⁡xcot⁡x-\csc x\cot x

Part 6 · Key ideas

Key ideas

  • ddx(tan⁡x)=sec2⁡x\frac{d}{dx}(\tan x) = \sec^2 x and ddx(cot⁡x)=−csc2⁡x\frac{d}{dx}(\cot x) = -\csc^2 x.
  • ddx(sec⁡x)=sec⁡xtan⁡x\frac{d}{dx}(\sec x) = \sec x\tan x and ddx(csc⁡x)=−csc⁡xcot⁡x\frac{d}{dx}(\csc x) = -\csc x\cot x.
  • Every one comes from writing the function with sin⁡x\sin x and cos⁡x\cos x, using the quotient rule and the identity sin2⁡x+cos2⁡x=1\sin^2 x + \cos^2 x = 1.
  • The three "co-" functions (cosine, cotangent, cosecant) have derivatives with a minus sign.
  • All of these hold in radians, wherever the function is defined.

Part 7 · Misconception

A common mistake

The wrong idea: ddx(sec⁡x)=tan2⁡x\frac{d}{dx}(\sec x) = \tan^2 x, or ddx(cot⁡x)=csc2⁡x\frac{d}{dx}(\cot x) = \csc^2 x.

What actually happens: Rebuild them instead of guessing: sec⁡x=1cos⁡x\sec x = \frac{1}{\cos x}, so its derivative is 0−1(−sin⁡x)cos2⁡x\frac{0 - 1(-\sin x)}{\cos^2 x} =sin⁡xcos2⁡x= \frac{\sin x}{\cos^2 x} =sec⁡xtan⁡x= \sec x\tan x. For cot⁡x=cos⁡xsin⁡x\cot x = \frac{\cos x}{\sin x}, the numerator is −sin2⁡x−cos2⁡x=−1-\sin^2 x - \cos^2 x = -1, so the derivative is −csc2⁡x-\csc^2 x, negative like every "co-" derivative.

Show the answer

Dividing 1 by a number between 0 and 1 gives a number of at least 1, with equality at x=0x = 0.

  • Correct: The slope is sec2⁡x=1cos2⁡x\sec^2 x = \frac{1}{\cos^2 x}, and 0<cos2⁡x≤10 < \cos^2 x \le 1 there.: cos2⁡x\cos^2 x is at most 1, so its reciprocal is at least 1.

6. Deriving ddx(tan⁡x)=sec2⁡x\frac{d}{dx}(\tan x) = \sec^2 x with the quotient rule, which identity simplifies the numerator?

  1. sin2⁡x+cos2⁡x=1\sin^2 x + \cos^2 x = 1
  2. tan⁡x=sin⁡xcos⁡x\tan x = \frac{\sin x}{\cos x}
  3. sin⁡(2x)=2sin⁡xcos⁡x\sin(2x) = 2\sin x\cos x
  4. sec⁡x=1cos⁡x\sec x = \frac{1}{\cos x}
Show the answer

The numerator is cos2⁡x+sin2⁡x\cos^2 x + \sin^2 x, which is 1.

  • Correct: sin2⁡x+cos2⁡x=1\sin^2 x + \cos^2 x = 1: The Pythagorean identity collapses the numerator to 1.
  • tan⁡x=sin⁡xcos⁡x\tan x = \frac{\sin x}{\cos x}: That identity sets up the quotient; it does not simplify the numerator.
  • sin⁡(2x)=2sin⁡xcos⁡x\sin(2x) = 2\sin x\cos x: No 2sin⁡xcos⁡x2\sin x\cos x appears in the numerator.
  • sec⁡x=1cos⁡x\sec x = \frac{1}{\cos x}: That identity rewrites the final answer; the numerator needs the Pythagorean identity.

Part 9 · Summary

Summary

Write tangent, cotangent, secant and cosecant in terms of sine and cosine, apply the quotient rule, and simplify with sin2⁡x+cos2⁡x=1\sin^2 x + \cos^2 x = 1. The results: (tan⁡x)′=sec2⁡x(\tan x)' = \sec^2 x, (cot⁡x)′=−csc2⁡x(\cot x)' = -\csc^2 x, (sec⁡x)′=sec⁡xtan⁡x(\sec x)' = \sec x\tan x, (csc⁡x)′=−csc⁡xcot⁡x(\csc x)' = -\csc x\cot x. The "co-" functions get the minus signs.
