Unit 1 · Topic 1.9

Limits Across Graphs, Tables and Formulas

A limit can be read from a graph (the height the curve approaches), estimated from a table (values on both sides), found exactly from a formula (algebra), and stated in words or notation.

Practice 2: Connecting Representations

Part 1 · Hook

Why this matters

A doctor reads a heartbeat as a trace on a screen, as numbers on a chart, and as a written note. All three describe the same heart. A limit works the same way: one function can come as a graph, a table, a formula or a sentence, and you should be able to read the limit from any of them.

Part 5 · Step by step

How it works, step by step

  1. A graph shows the function near cc→follow the curve toward x=cx = c from each side and read the height it approaches; ignore any dot exactly at cc
  2. A table lists values at inputs closing in on cc from both sides→the values suggest the limit, but a table cannot prove it
  3. A formula is available→algebra (substitute, factor, rationalize) gives the exact limit and confirms the estimate
  4. A limit involves a composition f(g(x))f(g(x))→find where g(x)g(x) goes and from which side, then read ff near that input

Part 6 · Key ideas

Key ideas

  • The same limit can be read from a graph, a table, a formula or words. Each answer must agree.
  • On a graph, the limit is the height the curve approaches, not the closed dot at the point.
  • A table suggests a limit; a formula confirms it. Cleverly chosen inputs can make a table mislead, as with sin⁡(πx)\sin\left(\frac{\pi}{x}\right).
  • Translate words exactly: "from values less than 4" is x→4−x \to 4^-; the number the outputs approach goes after the equals sign.
  • For f(g(x))f(g(x)), find the inner limit first and note the side it comes from.

Part 7 · Misconception

A common mistake

The wrong idea: If every value in a table is close to 3, the limit is 3.

What actually happens: A table shows finitely many inputs. The function can behave differently between them; sin⁡(πx)\sin\left(\frac{\pi}{x}\right) is 0 at x=1,0.1,0.01x = 1, 0.1, 0.01 but has no limit at 0. Use the table to estimate and a formula or a graph to confirm.

1. Use the graph to find limx→−1f(x)\lim_{x \to -1} f(x).

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

From the left, y=x+3y = x + 3 approaches 2; from the right, y=1−xy = 1 - x approaches 2. Both sides agree, so the limit is 2, even though f(−1)=4f(-1) = 4.

  • Answer: 2

2. Which is true about limx→2f(x)\lim_{x \to 2} f(x)?

  1. It does not exist; the sides head to −1-1 and 11
  2. It equals 11, the height of the closed dot at x=2x = 2
  3. It equals −1-1, the height of the open circle at x=2x = 2
  4. It equals 00, halfway between the two one-sided limits
Show the answer

limx→2−f(x)=−1\lim_{x \to 2^-} f(x) = -1 and limx→2+f(x)=1\lim_{x \to 2^+} f(x) = 1. The one-sided limits differ, so the two-sided limit does not exist.

  • Correct: It does not exist; the sides head to −1-1 and 11: Left of 2 the graph follows 1−x1 - x down to −1-1; right of 2 it starts at 1. Different, so no limit.
  • It equals 11, the height of the closed dot at x=2x = 2: The closed dot is f(2)f(2) and the right-hand limit, but the left side does not head there.
  • It equals −1-1, the height of the open circle at x=2x = 2: That is the left-hand limit; the right side heads to 1.
  • It equals 00, halfway between the two one-sided limits: One-sided limits are compared, never averaged.

3. Find limx→0f(f(x))\lim_{x \to 0} f(f(x)).

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

Inside: near x=0x = 0, f(x)=1−xf(x) = 1 - x, which approaches 1. Outside: for inputs near 1 (on both sides), f(u)=1−uf(u) = 1 - u, which approaches 0. So limx→0f(f(x))\lim_{x \to 0} f(f(x))=0= 0.

  • Answer: 0

4. Which formula could produce the table?

  1. g(x)=x2−4x−2g(x) = \frac{x^2 - 4}{x - 2}
  2. g(x)g(x)=x3−8x2−2x= \frac{x^3 - 8}{x^2 - 2x}
  3. g(x)=x3−8x2−4g(x) = \frac{x^3 - 8}{x^2 - 4}
  4. g(x)=x+1g(x) = x + 1
Show the answer

x3−8x2−4\frac{x^3 - 8}{x^2 - 4}=(x−2)(x2+2x+4)(x−2)(x+2)= \frac{(x - 2)(x^2 + 2x + 4)}{(x - 2)(x + 2)}=x2+2x+4x+2= \frac{x^2 + 2x + 4}{x + 2}. At x=1.9x = 1.9 this is 11.413.9≈2.92564\frac{11.41}{3.9} \approx 2.92564, matching the table.

  • g(x)=x2−4x−2g(x) = \frac{x^2 - 4}{x - 2}: This simplifies to x+2x + 2, which is 3.9 at x=1.9x = 1.9 and approaches 4.
  • g(x)g(x)=x3−8x2−2x= \frac{x^3 - 8}{x^2 - 2x}: This simplifies to x2+2x+4x\frac{x^2 + 2x + 4}{x}, which approaches 6.
  • Correct: g(x)=x3−8x2−4g(x) = \frac{x^3 - 8}{x^2 - 4}: It simplifies to x2+2x+4x+2\frac{x^2 + 2x + 4}{x + 2}, which gives 2.92564 at 1.9 and approaches 3.
  • g(x)=x+1g(x) = x + 1: It approaches 3, but gives exactly 2.9 at x=1.9x = 1.9, not 2.92564.

5. A table gives sin⁡(πx)=0\sin\left(\frac{\pi}{x}\right) = 0 at x=1,0.1,0.01x = 1, 0.1, 0.01 and 0.0010.001. What is true about limx→0+sin⁡(πx)\lim_{x \to 0^+} \sin\left(\frac{\pi}{x}\right)?

  1. It equals 0, since each value in the table is 0
  2. It does not exist; the values swing between −1-1 and 11
  3. It equals 1, the largest value the sine function reaches
  4. It equals 0, but from the right side of 0 alone
Show the answer

The chosen inputs make πx\frac{\pi}{x} a multiple of π\pi, where sine is 0. Other inputs, such as x=25x = \frac{2}{5}, give sin⁡(5π2)=1\sin\left(\frac{5\pi}{2}\right) = 1. Near 0 the function hits −1-1 and 11 again and again, so it has no limit.

  • It equals 0, since each value in the table is 0: The table's inputs were unlucky: they all land on zeros of sine. A table can mislead.
  • Correct: It does not exist; the values swing between −1-1 and 11: Inputs like 25,29,213,…\frac{2}{5}, \frac{2}{9}, \frac{2}{13}, \ldots give 1, and others give −1-1, arbitrarily close to 0.
  • It equals 1, the largest value the sine function reaches: The function reaches 1 near 0 but does not settle there.
  • It equals 0, but from the right side of 0 alone: The table is from the right side already, and the values there oscillate.

6. Let g(x)=x2+1g(x) = x^2 + 1. Suppose limu→1−f(u)=2\lim_{u \to 1^-} f(u) = 2 and limu→1+f(u)=5\lim_{u \to 1^+} f(u) = 5. What is limx→0f(g(x))\lim_{x \to 0} f(g(x))?

  1. 22
  2. 3.53.5
  3. 55
  4. It does not exist
Show the answer

As x→0x \to 0, g(x)=x2+1→1g(x) = x^2 + 1 \to 1, and g(x)>1g(x) > 1 for every x≠0x \ne 0. So the inputs of ff approach 1 from the right, and f(g(x))→5f(g(x)) \to 5.

  • 22: That would need g(x)g(x) to approach 1 from below, but x2+1≥1x^2 + 1 \ge 1.
  • 3.53.5: Limits are not averaged.
  • Correct: 55: x2+1x^2 + 1 is above 1 on both sides of x=0x = 0, so only the right-hand limit of ff matters.
  • It does not exist: Both sides of x=0x = 0 send g(x)g(x) to 1 from above, so the limit exists and is 5.

7. A function has f(3)=1f(3) = 1 and limx→3f(x)=4\lim_{x \to 3} f(x) = 4. What does its graph show at x=3x = 3?

  1. A closed dot at (3,4)(3, 4) and an open circle at (3,1)(3, 1)
  2. A closed dot at (3,1)(3, 1) and a vertical asymptote
  3. Two closed dots, one at (3,1)(3, 1) and one at (3,4)(3, 4)
  4. An open circle at (3,4)(3, 4) and a closed dot at (3,1)(3, 1)
Show the answer

The curve heads to height 4 from both sides but the point there is missing (open circle). The function's value, 1, sits elsewhere as a closed dot.

  • A closed dot at (3,4)(3, 4) and an open circle at (3,1)(3, 1): That would make f(3)=4f(3) = 4, and the curve would head toward 1.
  • A closed dot at (3,1)(3, 1) and a vertical asymptote: An asymptote means unbounded behavior, but the limit is the number 4.
  • Two closed dots, one at (3,1)(3, 1) and one at (3,4)(3, 4): A function has one value at x=3x = 3, so there is one closed dot.
  • Correct: An open circle at (3,4)(3, 4) and a closed dot at (3,1)(3, 1): The curve approaches (3,4)(3, 4), which is not on the graph, and the actual point is (3,1)(3, 1).

Part 9 · Summary

Summary

A limit can be read from a graph (the height the curve approaches), estimated from a table (values on both sides), found exactly from a formula (algebra), and stated in words or notation. Move between them: estimate with a table, confirm with a formula, and check the sides when one function sits inside another.
