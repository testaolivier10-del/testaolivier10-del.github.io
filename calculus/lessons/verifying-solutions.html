Unit 7 · Topic 7.2 Beta

Verifying Solutions to Differential Equations

To verify a solution to a differential equation, differentiate the function, substitute into both sides and show they agree for every x in an interval.

Practice 1: Implementing Mathematical ProcessesPractice 3: Justification

Part 1 · Hook

Why this matters

A friend claims that y=3e2xy = 3e^{2x} fits the rule "the slope is always twice the height". You do not need to take her word for it, and you do not need any new method. Differentiate, substitute, and see whether the two sides match. That check is the whole topic, and it is how you will test every answer in this unit.

Part 5 · Step by step

How it works, step by step

  1. A function is proposed for a differential equation→compute every derivative the equation uses
  2. Substitute the function and its derivatives into both sides→simplify each side separately, never moving terms across the == sign
  3. The two sides agree for every xx in an interval→the function is a solution on that interval
  4. They disagree for even one value of x in the interval→the function is not a solution there
  5. An added constant has derivative 0→one differential equation usually has infinitely many solutions

Part 6 · Key ideas

Key ideas

  • A solution to a differential equation is a function, not a number. It makes the equation true for every xx in an interval.
  • To verify a solution: differentiate, substitute into both sides, simplify each side, compare.
  • Checking a single point is not enough: two different expressions can agree at one xx.
  • One equation can have a whole family of solutions, such as y=Ce3xy = Ce^{3x} for dydx=3y\frac{dy}{dx} = 3y.
  • A solution may live on an interval only: y=1xy = \frac{1}{x} solves dydx=−y2\frac{dy}{dx} = -y^2 on x>0x > 0 and on x<0x < 0, not across x=0x = 0.

Part 7 · Misconception

A common mistake

The wrong idea: y=x+1+2exy = x + 1 + 2e^x solves dydx=y−x\frac{dy}{dx} = y - x because at x=0x = 0 both sides equal 3.

What actually happens: One matching point proves nothing. Compare the sides as functions: dydx=1+2ex\frac{dy}{dx} = 1 + 2e^x and y−x=1+2exy - x = 1 + 2e^x for every xx. That is the verification.

2. Why does y3y_3 fail to satisfy dydx=3y\frac{dy}{dx} = 3y?

  1. Its derivative is 3e3x+23e^{3x} + 2, which is not 3y33y_3.
  2. At x=0x = 0, y3=3y_3 = 3, and 3 is not a rate.
  3. It has the same derivative as y1y_1, so it is the same function.
  4. Its derivative is 3e3x3e^{3x}, but 3y3=3e3x+63y_3 = 3e^{3x} + 6.
Show the answer

dy3dx=3e3x\frac{dy_3}{dx} = 3e^{3x} while 3y3=3e3x+63y_3 = 3e^{3x} + 6; the sides differ by 6 for every xx.

  • Its derivative is 3e3x+23e^{3x} + 2, which is not 3y33y_3.: The derivative of the constant 2 is 0, not 2.
  • At x=0x = 0, y3=3y_3 = 3, and 3 is not a rate.: Values and rates are both numbers; the test is whether the two sides agree.
  • It has the same derivative as y1y_1, so it is the same function.: Equal derivatives mean the functions differ by a constant, here 2.
  • Correct: Its derivative is 3e3x3e^{3x}, but 3y3=3e3x+63y_3 = 3e^{3x} + 6.: The constant 2 drops out of the derivative but is tripled on the right side.

3. Which work verifies that every curve y=x+1+Cexy = x + 1 + Ce^x satisfies dydx=y−x\frac{dy}{dx} = y - x?

  1. At x=0x = 0, dydx=1+C\frac{dy}{dx} = 1 + C and y−x=1+Cy - x = 1 + C.
  2. dydx\frac{dy}{dx}=1= 1+Cex+ Ce^x=x= x+1+ 1+Cex+ Ce^x=y= y.
  3. dydx=Cex\frac{dy}{dx} = Ce^x and y−x=1+Cexy - x = 1 + Ce^x, so they differ by 1.
  4. dydx=1+Cex\frac{dy}{dx} = 1 + Ce^x and y−x=1+Cexy - x = 1 + Ce^x, equal for every xx.
Show the answer

Differentiate: dydx=1+Cex\frac{dy}{dx} = 1 + Ce^x. Substitute: y−xy - x=(x+1+Cex)−x= (x + 1 + Ce^x) - x=1= 1+Cex+ Ce^x. The sides agree for every xx.

  • At x=0x = 0, dydx=1+C\frac{dy}{dx} = 1 + C and y−x=1+Cy - x = 1 + C.: Agreement at one point does not show agreement for every x.
  • dydx\frac{dy}{dx}=1= 1+Cex+ Ce^x=x= x+1+ 1+Cex+ Ce^x=y= y.: This chain writes == between unequal things: 1+Cex≠x+1+Cex1 + Ce^x \ne x + 1 + Ce^x.
  • dydx=Cex\frac{dy}{dx} = Ce^x and y−x=1+Cexy - x = 1 + Ce^x, so they differ by 1.: The derivative of xx is 1, which was dropped.
  • Correct: dydx=1+Cex\frac{dy}{dx} = 1 + Ce^x and y−x=1+Cexy - x = 1 + Ce^x, equal for every xx.: Both sides are computed separately and agree as functions.

4. The curve through (0,3)(0, 3) is y=x+1+2exy = x + 1 + 2e^x. Find dydx\frac{dy}{dx} at (0,3)(0, 3).

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

From the differential equation, dydx\frac{dy}{dx}=y−x= y - x=3−0= 3 - 0=3= 3; from the formula, 1+2e0=31 + 2e^0 = 3. They agree.

  • Answer: 3

5. Is y=x2y = x^2 a solution to xdydx=2yx\frac{dy}{dx} = 2y for x>0x > 0?

  1. No: dydx=2x\frac{dy}{dx} = 2x, which is not 2y2y.
  2. Yes: at x=1x = 1 both sides equal 2.
  3. No: an xx on the left side is not allowed.
  4. Yes: x⋅2x=2x2x \cdot 2x = 2x^2 and 2y=2x22y = 2x^2.
Show the answer

Left: x⋅2x=2x2x \cdot 2x = 2x^2. Right: 2x22x^2. They agree for every x>0x > 0, so y=x2y = x^2 is a solution.

  • No: dydx=2x\frac{dy}{dx} = 2x, which is not 2y2y.: The left side is xdydxx\frac{dy}{dx}, not dydx\frac{dy}{dx}.
  • Yes: at x=1x = 1 both sides equal 2.: The conclusion is right, but one point does not verify it.
  • No: an xx on the left side is not allowed.: A differential equation may contain x anywhere.
  • Correct: Yes: x⋅2x=2x2x \cdot 2x = 2x^2 and 2y=2x22y = 2x^2.: Both sides simplify to the same function.

6. For which positive constant kk does y=ekxy = e^{kx} satisfy y″−y′−6y=0y'' - y' - 6y = 0?

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

y′=kekxy' = ke^{kx}, y″=k2ekxy'' = k^2e^{kx}. Then ekx(k2−k−6)=0e^{kx}(k^2 - k - 6) = 0, and ekx≠0e^{kx} \ne 0, so (k−3)(k+2)=0(k - 3)(k + 2) = 0: k=3k = 3.

  • Answer: 3

Part 9 · Summary

Summary

To verify a solution to a differential equation, differentiate the function, substitute into both sides and show they agree for every xx in an interval. One equation can have infinitely many solutions, and a solution may hold only on an interval where everything is defined.
