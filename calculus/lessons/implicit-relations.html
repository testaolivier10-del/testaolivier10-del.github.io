Unit 5 · Topic 5.12

Behavior of Implicit Relations

For an implicit curve, dy/dx = N/D .

Practice 1: Implementing Mathematical ProcessesPractice 3: Justification

Part 1 · Hook

Why this matters

A race track is not the graph of a function: it loops back, and at some points it runs straight up the page. Designers still need to know where the track runs exactly east-west or north-south. Implicit differentiation gives the slope at every point of such a curve, and the slope formula shows where it is flat or vertical.

Part 5 · Step by step

How it works, step by step

  1. Differentiate both sides of the curve's equation with respect to xx, then solve→dydx\frac{dy}{dx}=N(x,y)D(x,y)= \frac{N(x, y)}{D(x, y)}, a slope at each point (x,y)(x, y) of the curve
  2. N=0N = 0, D≠0D \ne 0, and the point is on the curve→the tangent line is horizontal there
  3. D=0D = 0, N≠0N \ne 0, and the point is on the curve→the tangent line is vertical there
  4. N=0N = 0 and D=0D = 0 at once→the formula decides nothing at that point
  5. dydx=0\frac{dy}{dx} = 0 and the sign of d2ydx2\frac{d^2y}{dx^2} is known→the curve has a local high point (<0< 0) or low point (>0> 0)

Part 6 · Key ideas

Key ideas

  • Horizontal tangent: numerator of dydx\frac{dy}{dx} is 0, denominator is not, point is on the curve. Vertical tangent: denominator 0, numerator not 0, point on the curve.
  • To find the points: set the numerator (or denominator) to 0, solve for one variable, substitute into the curve's equation, then check the other part is not 0.
  • d2ydx2\frac{d^2y}{dx^2}: differentiate dydx\frac{dy}{dx} (quotient rule), then substitute the point and the value of dydx\frac{dy}{dx} there.
  • Write "=0= 0" after differentiating, and apply ddx\frac{d}{dx} to both sides.

Part 7 · Misconception

A common mistake

The wrong idea: The tangent line is vertical where dydx=0\frac{dy}{dx} = 0.

What actually happens: dydx=0\frac{dy}{dx} = 0 means a horizontal tangent. A vertical tangent is where the slope is undefined because the denominator is 0 and the numerator is not. And every candidate point must satisfy the curve's equation; a point that only makes the numerator zero may not be on the curve at all.

6. For a curve with dydx\frac{dy}{dx}=N(x,y)D(x,y)= \frac{N(x, y)}{D(x, y)}, which statement earns credit for "the tangent line is vertical at PP"?

  1. "dydx=0\frac{dy}{dx} = 0 at PP."
  2. "D=0D = 0 and N≠0N \ne 0 at PP, and PP is on the curve."
  3. "D=0D = 0 at PP."
  4. "N=0N = 0 and D≠0D \ne 0 at PP, and the point PP is on the curve."
Show the answer

Vertical tangent: the denominator is 0, the numerator is not, and the point lies on the curve. Chief readers see "dydx=0\frac{dy}{dx} = 0" used for vertical tangents every year; it is the condition for horizontal ones.

  • "dydx=0\frac{dy}{dx} = 0 at PP.": That is a horizontal tangent.
  • Correct: "D=0D = 0 and N≠0N \ne 0 at PP, and PP is on the curve.": All three conditions.
  • "D=0D = 0 at PP.": If N=0N = 0 too, nothing is decided; and PP must be on the curve.
  • "N=0N = 0 and D≠0D \ne 0 at PP, and the point PP is on the curve.": That is a horizontal tangent.

Part 9 · Summary

Summary

For an implicit curve, dydx=ND\frac{dy}{dx} = \frac{N}{D}. Horizontal tangents: N=0N = 0, D≠0D \ne 0, on the curve. Vertical tangents: D=0D = 0, N≠0N \ne 0, on the curve. Both zero: no conclusion. At a horizontal tangent, the sign of d2ydx2\frac{d^2y}{dx^2} tells whether the curve has a local high or low point.
