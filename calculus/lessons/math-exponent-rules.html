Exponent Rules and Rewriting Powers

Exponent rules let you write every root and fraction as a power: 1/(x^n) = x^(−n) and n√(x^m) = x^(m/n) .

Practice 1: Implementing Mathematical Processes

Part 1 · Hook

Why this matters

A single rule in Unit 2 will handle x5x^5, 1x3\frac{1}{x^3} and x4\sqrt[4]{x} in one stroke, but only if they are written as powers of xx first. Rewriting roots and fractions as exponents is the quiet skill behind half of the algebra in calculus, and the place where many small sign slips start. Ten minutes here pays off all year.

Part 4 · Step by step

How it works, step by step

  1. xm⋅xnx^m \cdot x^n multiplies mm copies of xx by nn more→so xm⋅xn=xm+nx^m \cdot x^n = x^{m + n}, and xmxn=xm−n\frac{x^m}{x^n} = x^{m - n}
  2. x0xn=x0−n\frac{x^0}{x^n} = x^{0 - n} and x0=1x^0 = 1→a negative exponent is a reciprocal: x−n=1xnx^{-n} = \frac{1}{x^n}
  3. (x1/2)2=x1\left(x^{1/2}\right)^2 = x^1→a fractional exponent is a root: x1/2=xx^{1/2} = \sqrt{x} and xm/n=(xn)mx^{m/n} = \left(\sqrt[n]{x}\right)^m
  4. Every root and reciprocal can be written as a power→expressions like 3x2+2x\frac{3}{x^2} + 2\sqrt{x} become 3x−2+2x1/23x^{-2} + 2x^{1/2}, ready for calculus

Part 5 · Key ideas

Key ideas

  • Multiply powers of the same base: add exponents. Divide: subtract. Power of a power: multiply.
  • x−n=1xnx^{-n} = \frac{1}{x^n}. A negative exponent means reciprocal, never a negative number.
  • xm/n=(xn)mx^{m/n} = \left(\sqrt[n]{x}\right)^m. Take the root first to keep numbers small: 82/3=22=48^{2/3} = 2^2 = 4.
  • An exponent applies only to what it touches: 3x−2=3x23x^{-2} = \frac{3}{x^2}, but (3x)−2=19x2(3x)^{-2} = \frac{1}{9x^2}.
  • Exponents do not split over sums: (x+3)−1≠x−1+3−1(x + 3)^{-1} \ne x^{-1} + 3^{-1} and x2+9≠x+3\sqrt{x^2 + 9} \ne x + 3.

Part 6 · Misconception

A common mistake

The wrong idea: 1x+3=x−1+3−1\frac{1}{x + 3} = x^{-1} + 3^{-1}, so a fraction can be split into separate powers.

What actually happens: Only a single base can be raised to a power. 1x+3=(x+3)−1\frac{1}{x + 3} = (x + 3)^{-1}; test x=1x = 1: 14\frac{1}{4} is not 1+131 + \frac{1}{3}.

Part 7 · Check yourself

Check yourself

Exam-style questions. Anything you miss goes into your review queue.

1. Which expression equals 3x2\frac{3}{x^2} written as a power of xx?

  1. 3x−23x^{-2}
  2. (3x)−2(3x)^{-2}
  3. 13x−2\frac{1}{3}x^{-2}
  4. 3x23x^{2}
Show the answer

Only x2x^2 is in the denominator, so only it moves up: 3x2=3⋅1x2=3x−2\frac{3}{x^2} = 3 \cdot \frac{1}{x^2} = 3x^{-2}.

  • Correct: 3x−23x^{-2}: The 3 stays where it is; 1x2=x−2\frac{1}{x^2} = x^{-2}.
  • (3x)−2(3x)^{-2}: (3x)−2=19x2(3x)^{-2} = \frac{1}{9x^2}: the exponent would apply to the 3 as well.
  • 13x−2\frac{1}{3}x^{-2}: That is 13x2\frac{1}{3x^2}. The 3 was in the numerator, so it stays a multiplier of 3.
  • 3x23x^{2}: Moving a power out of the denominator flips the sign of its exponent: x−2x^{-2}, not x2x^2.

2. Which expression equals 1x\frac{1}{\sqrt{x}}?

  1. x−1/2x^{-1/2}
  2. x1/2x^{1/2}
  3. −x1/2-x^{1/2}
  4. x−2x^{-2}
Show the answer

x=x1/2\sqrt{x} = x^{1/2}, and one over a power is the power with the opposite sign: 1x1/2=x−1/2\frac{1}{x^{1/2}} = x^{-1/2}.

  • Correct: x−1/2x^{-1/2}: Root means exponent 12\frac{1}{2}; in the denominator it becomes −12-\frac{1}{2}.
  • x1/2x^{1/2}: That is x\sqrt{x} itself. Being in the denominator makes the exponent negative.
  • −x1/2-x^{1/2}: A negative exponent is not a negative number: x−1/2x^{-1/2} is positive for x>0x > 0.
  • x−2x^{-2}: A square root is the power 12\frac{1}{2}, not 2.

3. Evaluate 82/38^{2/3} exactly.

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

82/38^{2/3}=(81/3)2= \left(8^{1/3}\right)^2=22= 2^2=4= 4. Take the root first: the numbers stay small.

  • Answer: 4

4. Evaluate 16−3/416^{-3/4} exactly.

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

16−3/416^{-3/4}=1163/4= \frac{1}{16^{3/4}}=1(164)3= \frac{1}{\left(\sqrt[4]{16}\right)^3}=123= \frac{1}{2^3}=18= \frac{1}{8}.

  • Answer: 18\frac{1}{8} ≈ 0.125

5. Which expression equals x2+1x\frac{x^2 + 1}{\sqrt{x}} for x>0x > 0, written as a sum of powers of xx?

  1. x3/2+x−1/2x^{3/2} + x^{-1/2}
  2. x3/2+1x^{3/2} + 1
  3. x4+x−1/2x^{4} + x^{-1/2}
  4. x2+x−1/2x^{2} + x^{-1/2}
Show the answer

Split the fraction so each term is divided by x=x1/2\sqrt{x} = x^{1/2}: x2x1/2\frac{x^2}{x^{1/2}}+1x1/2+ \frac{1}{x^{1/2}}=x3/2= x^{3/2}+x−1/2+ x^{-1/2}.

  • Correct: x3/2+x−1/2x^{3/2} + x^{-1/2}: x2−1/2+x−1/2x^{2 - 1/2} + x^{-1/2}.
  • x3/2+1x^{3/2} + 1: Both terms are divided by x\sqrt{x}, including the 1: 1x=x−1/2\frac{1}{\sqrt{x}} = x^{-1/2}.
  • x4+x−1/2x^{4} + x^{-1/2}: Dividing by x1/2x^{1/2} subtracts 12\frac{1}{2} from the exponent; it does not multiply it by 2.
  • x2+x−1/2x^{2} + x^{-1/2}: The x2x^2 term is divided by x\sqrt{x} too: x2−1/2=x3/2x^{2 - 1/2} = x^{3/2}.

6. Which expression is NOT equal to 1(2x)3\frac{1}{(2x)^3} for x≠0x \ne 0?

  1. 2x−32x^{-3}
  2. (2x)−3(2x)^{-3}
  3. 18x3\frac{1}{8x^3}
  4. 18x−3\frac{1}{8}x^{-3}
Show the answer

(2x)3=8x3(2x)^3 = 8x^3, so the expression is 18x3=18x−3\frac{1}{8x^3} = \frac{1}{8}x^{-3}. But 2x−3=2x32x^{-3} = \frac{2}{x^3}: the exponent there applies only to xx, so it is 16 times too big.

  • Correct: 2x−32x^{-3}: 2x−3=2x32x^{-3} = \frac{2}{x^3}, which is not 18x3\frac{1}{8x^3}.
  • (2x)−3(2x)^{-3}: A negative exponent on the whole base (2x)(2x) is one over (2x)3(2x)^3: equal.
  • 18x3\frac{1}{8x^3}: (2x)3=23x3=8x3(2x)^3 = 2^3x^3 = 8x^3: equal.
  • 18x−3\frac{1}{8}x^{-3}: 18⋅1x3=18x3\frac{1}{8} \cdot \frac{1}{x^3} = \frac{1}{8x^3}: equal.

7. Which expression equals (x+3)−1(x + 3)^{-1} for x≠−3x \ne -3?

  1. 1x+3\frac{1}{x + 3}
  2. 1x+13\frac{1}{x} + \frac{1}{3}
  3. −x−3-x - 3
  4. 1x+3\frac{1}{x} + 3
Show the answer

The exponent −1-1 applies to the whole sum: (x+3)−1=1x+3(x + 3)^{-1} = \frac{1}{x + 3}. It cannot be split into separate terms.

  • Correct: 1x+3\frac{1}{x + 3}: One over the whole base x+3x + 3.
  • 1x+13\frac{1}{x} + \frac{1}{3}: Exponents do not distribute over a sum. Test x=1x = 1: 14\frac{1}{4}, but 11+13=43\frac{1}{1} + \frac{1}{3} = \frac{4}{3}.
  • −x−3-x - 3: The exponent −1-1 means reciprocal, not negative.
  • 1x+3\frac{1}{x} + 3: The exponent applies to the whole base x+3x + 3, not only to xx.

Part 8 · Summary

Summary

Exponent rules let you write every root and fraction as a power: 1xn=x−n\frac{1}{x^n} = x^{-n} and xmn=xm/n\sqrt[n]{x^m} = x^{m/n}. Add exponents to multiply, subtract to divide, multiply for a power of a power, and remember an exponent applies only to the base it touches and never splits over a sum.
