5.1 The Mean Value Theorem

If f is continuous on [a, b] and differentiable on (a, b) , some c inside has f′(c) equal to the average rate of change: a tangent line parallel to the secant line. Check the hypotheses every time (" f is differentiable, so it is continuous") and name the theorem.

  • Mean Value Theorem: if ff is continuous on [a,b][a, b] and differentiable on (a,b)(a, b), then f′(c)f'(c)=f(b)−f(a)b−a= \frac{f(b) - f(a)}{b - a} for at least one cc in (a,b)(a, b).
  • In words: somewhere inside, the instantaneous rate of change equals the average rate of change.
  • "ff is differentiable" covers both hypotheses, because differentiable implies continuous. Say it.
  • The theorem says a cc exists. It does not say where, and there may be more than one.
  • A corner at an endpoint is fine: differentiability is needed only on the open interval.

the graph is one unbroken, smooth curve from (a, f(a)) to (b, f(b)) , with a tangent line at each inside point → the last place it touches the curve is a point where the tangent line is parallel to the secant line → some c in (a, b) has f′(c) = (f(b) − f(a))/(b − a) → the theorem promises nothing, and the conclusion may be false

Mean Value Theorem
If ff is continuous on [a,b][a, b] and differentiable on (a,b)(a, b), then there is at least one cc in (a,b)(a, b) with f′(c)f'(c)=f(b)−f(a)b−a= \frac{f(b) - f(a)}{b - a}: the tangent line at cc is parallel to the secant line.

5.2 Extreme Value Theorem, Global and Local Extrema, Critical Points

A function continuous on a closed interval reaches an absolute maximum and minimum there (Extreme Value Theorem). Look for them at the endpoints and at critical points, interior points where f′ is 0 or does not exist. A critical point is a candidate, not a guarantee of an extremum.

  • Extreme Value Theorem: if ff is continuous on [a,b][a, b], then ff has at least one absolute maximum value and at least one absolute minimum value on [a,b][a, b].
  • Absolute (global) maximum: f(c)≥f(x)f(c) \ge f(x) for every xx in the domain or interval. Relative (local) maximum: f(c)≥f(x)f(c) \ge f(x) for every xx near cc, on an open interval around cc. Minimums the same way.
  • Critical point: an interior point cc of the domain where f′(c)=0f'(c) = 0 or f′(c)f'(c) does not exist.
  • Relative extrema happen only at critical points. Absolute extrema on [a,b][a, b] happen at critical points or at endpoints.
  • If a hypothesis fails (a jump, an open interval), the theorem promises nothing; extrema may or may not exist.

the Extreme Value Theorem guarantees an absolute maximum value and an absolute minimum value on [a, b] → it is also a relative extremum, where the tangent line is flat or does not exist → those interior points, the critical points, plus the endpoints, are the only places to look → some critical points ( x³ at 0, a corner on a rising graph) are not extrema at all

Extreme Value Theorem
If ff is continuous on a closed interval [a,b][a, b], then ff has at least one absolute maximum value and at least one absolute minimum value on [a,b][a, b].
critical point
An interior point cc of the domain of ff where f′(c)=0f'(c) = 0 or f′(c)f'(c) does not exist. Relative extrema can occur only at critical points.
absolute maximum
An absolute (global) maximum is a value f(c)f(c) with f(c)≥f(x)f(c) \ge f(x) for every xx in the domain or interval considered; an absolute minimum has f(c)≤f(x)f(c) \le f(x) for every such xx.
relative maximum
A relative (local) maximum is a value f(c)f(c) with f(c)≥f(x)f(c) \ge f(x) for every xx in some open interval around cc; a relative minimum has f(c)≤f(x)f(c) \le f(x) there. It is a peak or valley compared with nearby points only.

5.3 Where a Function Increases or Decreases

The sign of the derivative gives the direction of a function: f′ > 0 on an interval means f is increasing there, f′ < 0 means decreasing. Split the domain at the critical points, test each piece, and justify with the sign of f′ by name. On a graph of f′ , read the sign, not the slope.

  • Increasing on an interval: f(x1)<f(x2)f(x_1) < f(x_2) whenever x1<x2x_1 < x_2 in the interval. If f′(x)>0f'(x) > 0 on the interval, ff is increasing there; if f′(x)<0f'(x) < 0, decreasing.
  • Method: find f′f', find where it is 0 or undefined, test the sign of f′f' on each interval between those points.
  • On a graph of f′f': above the xx-axis means ff increasing; below means ff decreasing.
  • Justify with the sign of f′f' by name: "f′(x)>0f'(x) > 0 for −2<x<1-2 < x < 1, so ff is increasing there."

each tangent line slopes up, so f is increasing on that interval → f is decreasing on that interval → the critical points split the line into intervals, and one test value per interval gives the sign → read the sign (above or below the axis), not whether the graph of f′ goes up or down

increasing on an interval
ff is increasing on an interval if f(x1)<f(x2)f(x_1) < f(x_2) whenever x1<x2x_1 < x_2 in the interval, and decreasing if f(x1)>f(x2)f(x_1) > f(x_2). If f′(x)>0f'(x) > 0 on an interval, ff is increasing there; if f′(x)<0f'(x) < 0, it is decreasing.

5.4 The First Derivative Test

At a critical point, look at the sign of f′ on each side. + to − : relative maximum. − to + : relative minimum. No change: no extremum. The test works where f′ is undefined too. Justify in words that name f′ and the direction of its sign change; a sign chart alone does not earn the point.

  • First Derivative Test: at a critical point cc where ff is continuous, if f′f' changes from ++ to −-, f(c)f(c) is a relative maximum; from −- to ++, a relative minimum; no change, neither.
  • It works where f′f' does not exist (corners, cusps) as well as where f′=0f' = 0.
  • A sign chart of f′f' organizes the work, but it is not a justification by itself: write the sentence.
  • On a graph of f′f': a relative maximum of ff is where the graph of f′f' crosses the axis going down; a minimum, crossing going up. Touching without crossing gives nothing.

f rises up to c and falls after it, so f(c) is a relative maximum → f falls then rises, so f(c) is a relative minimum → f keeps rising (or falling) through c : no relative extremum, even if f′(c) = 0 → write the sentence: " f′ changes from negative to positive at x = c , so f has a relative minimum there"

First Derivative Test
At a critical point cc where ff is continuous: if f′f' changes from positive to negative at cc, ff has a relative maximum at cc; from negative to positive, a relative minimum; if f′f' does not change sign, no relative extremum. A sign chart of f′f' organizes the test; the justification is a sentence naming f′f' and its sign change.

5.5 The Candidates Test

On a closed interval, a continuous function has absolute extrema, and they sit at endpoints or critical points. The Candidates Test evaluates f at each of those and compares. A sign change of f′ shows only a relative extremum; an absolute one needs the comparison.

  • Candidates Test (closed interval method): for ff continuous on [a,b][a, b], list the endpoints and the critical points in (a,b)(a, b), compute ff at each, and compare.
  • No derivative signs needed: just values. Show the table of candidates and values in your answer.
  • The absolute extrema can be at endpoints. A relative maximum can lose to an endpoint.
  • On a calculator problem, find critical points with the graph or solver, store them, and evaluate the model at each candidate.

by the Extreme Value Theorem, an absolute maximum and minimum exist → if inside, it is at a critical point, where f′ is 0 or undefined → evaluate f at each one and compare: the largest value is the absolute maximum, the smallest the absolute minimum → that proves a relative extremum, a local fact, not an absolute one

Candidates Test
A way to find the absolute extrema of a function continuous on [a,b][a, b]: evaluate ff at the endpoints aa, bb and at every critical point in (a,b)(a, b); the largest value is the absolute maximum and the smallest the absolute minimum. Also called the closed interval method.

5.6 Concavity and Points of Inflection

The sign of f″ gives the concavity: f″ > 0 (equivalently f′ increasing) means concave up, f″ < 0 means concave down. A point of inflection is where the concavity changes, so f″ must change sign; f″(c) = 0 alone is not enough. On a graph of f′ , look at where f′ turns.

  • Concave up on an interval: f′f' is increasing there (f″>0f'' > 0). Concave down: f′f' is decreasing (f″<0f'' < 0).
  • Point of inflection: a point on the graph where the concavity changes, that is, where f″f'' changes sign, or where f′f' changes from increasing to decreasing or back.
  • On a graph of f′f': inflection points of ff are at the high and low points of f′f', not at its zeros.
  • Candidates are where f″=0f'' = 0 or f″f'' does not exist; then check the sign of f″f'' on each side.

f′ is increasing there, the slopes grow, and the graph of f is concave up → f′ is decreasing, the slopes shrink, and the graph is concave down → the concavity changes, so (c, f(c)) is a point of inflection → no change of concavity, so no point of inflection

point of inflection
A point on the graph of a continuous function where the concavity changes, from concave up to concave down or the reverse. For a twice-differentiable ff, f″f'' changes sign there; equivalently, f′f' changes from increasing to decreasing or back.

5.7 The Second Derivative Test

At a critical point where f′(c) = 0 , the sign of f″(c) decides: positive gives a relative minimum, negative a relative maximum, zero gives no conclusion. State both conditions in a justification. With exactly one critical point on an interval, a relative extremum there is absolute.

  • Second Derivative Test: if f′(c)=0f'(c) = 0 and f″(c)>0f''(c) > 0, ff has a relative minimum at cc; if f′(c)=0f'(c) = 0 and f″(c)<0f''(c) < 0, a relative maximum.
  • It says nothing when f″(c)=0f''(c) = 0 or when f′(c)f'(c) does not exist. Then use the First Derivative Test.
  • Justify with both facts: "f′(1)=0f'(1) = 0 and f″(1)>0f''(1) > 0."
  • One critical point on an interval, and it is a relative minimum (maximum)? Then it is the absolute minimum (maximum) there, even on an open interval.

the tangent line at c is flat and the graph bends up away from it, so f(c) is a relative minimum → the graph bends down from a flat point, so f(c) is a relative maximum → the test is inconclusive; go back to the First Derivative Test → that relative extremum is also the absolute extremum on the interval

Second Derivative Test
If f′(c)=0f'(c) = 0 and f″(c)>0f''(c) > 0, then ff has a relative minimum at cc; if f′(c)=0f'(c) = 0 and f″(c)<0f''(c) < 0, a relative maximum. If f″(c)=0f''(c) = 0, the test gives no conclusion.

5.8 Sketching f, f' and f''

Sketch a derivative feature by feature: where f rises, f′ is positive; where f is flat at a peak or valley, f′ crosses zero; where f is concave up, f′ rises; where f inflects, f′ turns; where f has a corner, f′ jumps. Read the same links backward to sketch f from f′ .

  • Read a graph of ff for features, not values: where it rises, falls, peaks, bends. Each feature becomes a feature of the graph of the derivative.
  • ff (sign of slope) →\to f′f' (sign of value). ff (concavity) →\to f′f' (rising or falling). Inflection of ff →\to peak or valley of f′f'.
  • Going the other way, from f′f' to ff: zeros of f′f' where its sign changes are extrema of ff; turns of f′f' are inflection points of ff; a constant f′f' means ff is a straight line.
  • The same pattern links f′f' and f″f'': the slope of the graph of f′f' is f″f''.

the graph of f′ is above (below) the x -axis there → the graph of f′ crosses the x -axis there → the graph of f′ is rising (falling) → the graph of f′ has a peak or valley there → the graph of f′ jumps, with no value at that point

graph of the derivative
The graph of y=f′(x)y = f'(x), whose height at each xx is the slope of ff there. It is above the axis where ff rises, crosses zero at the flat peaks and valleys of ff, rises where ff is concave up, and turns at the inflection points of ff.

5.9 Connecting f, f' and f''

The three graphs carry one story. f′ gives the direction of f , and its sign changes give extrema. f″ (or whether f′ rises or falls) gives the concavity of f , and its sign changes give inflection points. Read from whichever representation you have, and name the function in every justification.

  • Graphical analysis: given any one of ff, f′f', f″f'' (graph, table or formula), read the features of the others.
  • From a graph of f′f': sign of f′f' (above or below the axis) gives increasing or decreasing; direction of f′f' (rising or falling) gives concavity.
  • From a table: f′(a)=0f'(a) = 0 and the sign of f″(a)f''(a) give the Second Derivative Test; a continuous f″f'' that changes from positive to negative between two inputs gives a point of inflection between them.
  • Words: "increasing at a decreasing rate" means f′>0f' > 0 and f″<0f'' < 0.

tells whether f is increasing or decreasing; a sign change of f′ is a relative extremum of f → tells the concavity of f ; a sign change of f″ is a point of inflection of f → give the tangent line, and the sign of f″ near a says whether it overestimates or underestimates → names the function whose sign or direction you read: " f′ changes from positive to negative", " f′ is decreasing"

graphical analysis
Reading the behavior of a function from any representation of ff, f′f' or f″f'': the sign of f′f' gives where ff increases or decreases, the sign of f″f'' (or whether f′f' rises or falls) gives concavity, and sign changes locate relative extrema and points of inflection.

5.10 Introduction to Optimization

Optimization finds the absolute maximum or minimum of a quantity in context. Write the objective function, reduce it to one variable using the given facts, find its domain, find the critical points, and justify the absolute extremum with candidates or one-critical-point reasoning. Answer in context, with units.

  • Optimization: finding the absolute maximum or minimum of a quantity in context.
  • The objective function is the quantity to optimize, written in one variable with a domain.
  • Justify the absolute extremum: Candidates Test on a closed interval, or one critical point that is a relative extremum.
  • Answer the question asked: the dimensions or the price, with units, not just xx.

name that quantity and write the objective function for it → use the given fact (a fixed perimeter, a fixed product) to write one variable in terms of the other → find the domain: lengths and amounts are not negative → the absolute extremum, justified, answered in context with units

optimization
Finding the absolute maximum or minimum value of a quantity in context. The quantity is written as an objective function of one variable on a sensible domain, and its absolute extremum is found and justified with derivatives.

5.11 Solving Optimization Problems

Solve an optimization problem in a fixed order: draw and label, write the objective function, use the constraint to reduce it to one variable, find the domain, find the critical points, justify the absolute extremum with candidates or one-critical-point reasoning, and answer in context with units.

  • Constraint: a fixed condition (a perimeter, a volume, a budget) that links the variables. Use it to write the objective in one variable.
  • Steps: draw, label, objective, constraint, one variable, domain, critical points, justify, answer in context.
  • Reject critical points outside the domain (the cut x=203x = \frac{20}{3} inches on a 10-inch side).
  • Calculator problems: solve C′(x)=0C'(x) = 0 with the solver or a graph, store the value, and compare candidates.

you can see which quantities are fixed and which change → the constraint lets you eliminate a variable: the objective becomes a function of one variable → you know the endpoints and which critical points count → the absolute extremum, justified, stated in context with units

constraint
In an optimization problem, a fixed condition that links the variables, such as a given perimeter, volume or budget. It is used to write the objective function in terms of one variable.

5.12 Behavior of Implicit Relations

For an implicit curve, dy/dx = N/D . Horizontal tangents: N = 0 , D ≠ 0 , on the curve. Vertical tangents: D = 0 , N ≠ 0 , on the curve. Both zero: no conclusion. At a horizontal tangent, the sign of d²y/dx² tells whether the curve has a local high or low point.

  • Horizontal tangent: numerator of dydx\frac{dy}{dx} is 0, denominator is not, point is on the curve. Vertical tangent: denominator 0, numerator not 0, point on the curve.
  • To find the points: set the numerator (or denominator) to 0, solve for one variable, substitute into the curve's equation, then check the other part is not 0.
  • d2ydx2\frac{d^2y}{dx^2}: differentiate dydx\frac{dy}{dx} (quotient rule), then substitute the point and the value of dydx\frac{dy}{dx} there.
  • Write "=0= 0" after differentiating, and apply ddx\frac{d}{dx} to both sides.
