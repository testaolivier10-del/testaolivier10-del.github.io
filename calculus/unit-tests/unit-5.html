The graph of f(x)=sin⁡x+x2f(x) = \sin x + \frac{x}{2}

1. On which interval is the graph of ff concave up?

  1. (π,2π)(\pi, 2\pi)
  2. (0,π)(0, \pi)
  3. (2π3,4π3)\left(\frac{2\pi}{3}, \frac{4\pi}{3}\right)
  4. (4π3,2π)\left(\frac{4\pi}{3}, 2\pi\right)
Show the answer

f′(x)=cos⁡x+12f'(x) = \cos x + \frac{1}{2} and f″(x)=−sin⁡xf''(x) = -\sin x. On (π,2π)(\pi, 2\pi), sin⁡x<0\sin x < 0, so f″(x)>0f''(x) > 0 and the graph is concave up.

  • Correct: (π,2π)(\pi, 2\pi): f″(x)=−sin⁡x>0f''(x) = -\sin x > 0 when sin⁡x<0\sin x < 0.
  • (0,π)(0, \pi): There sin⁡x>0\sin x > 0, so f″<0f'' < 0: concave down.
  • (2π3,4π3)\left(\frac{2\pi}{3}, \frac{4\pi}{3}\right): That is where ff is decreasing (f′=cos⁡x+12<0f' = \cos x + \frac{1}{2} < 0).
  • (4π3,2π)\left(\frac{4\pi}{3}, 2\pi\right): ff is concave up on this piece, but also on (π,4π3)\left(\pi, \frac{4\pi}{3}\right).

2. What is the sign of f″(π2)f''\left(\frac{\pi}{2}\right), and what does the graph show there?

  1. Positive: the graph is rising there from left to right
  2. Zero: the graph is steepest there
  3. Negative: the graph bends down there
  4. Positive: the graph bends up there
Show the answer

f″(π2)=−1<0f''\left(\frac{\pi}{2}\right) = -1 < 0: the graph is concave down there, as it is on all of (0,π)(0, \pi).

  • Positive: the graph is rising there from left to right: Rising is about f′f', not f″f''.
  • Zero: the graph is steepest there: f″f'' is zero at π\pi, not π2\frac{\pi}{2}.
  • Correct: Negative: the graph bends down there: f″(π2)=−sin⁡π2=−1f''\left(\frac{\pi}{2}\right) = -\sin\frac{\pi}{2} = -1, concave down.
  • Positive: the graph bends up there: The graph bends down on (0,π)(0, \pi).

3. Is f′f' increasing or decreasing at x=3π2x = \frac{3\pi}{2}?

  1. Decreasing, because ff is concave up there
  2. Increasing, because ff is concave up there
  3. Increasing, because f(3π2)>0f\left(\frac{3\pi}{2}\right) > 0
  4. Decreasing, because ff has a low point near there
Show the answer

f″(3π2)f''\left(\frac{3\pi}{2}\right)=−sin⁡3π2= -\sin\frac{3\pi}{2}=1>0= 1 > 0, so f′f' is increasing there: the graph is concave up.

  • Decreasing, because ff is concave up there: Concave up goes with f′f' increasing, not decreasing.
  • Correct: Increasing, because ff is concave up there: Concave up means f″>0f'' > 0, so f′f' is increasing.
  • Increasing, because f(3π2)>0f\left(\frac{3\pi}{2}\right) > 0: The sign of ff says nothing about f′f'.
  • Decreasing, because ff has a low point near there: A low point of ff is about f′=0f' = 0; whether f′f' rises depends on f″f''.

4. Does the Extreme Value Theorem guarantee that hh has an absolute maximum on [0,4][0, 4]?

  1. Yes, because [0,4][0, 4] is a closed interval
  2. Yes, because hh is defined at each point of [0,4][0, 4]
  3. No, because hh is not differentiable at x=0x = 0
  4. No, because hh is not continuous at x=2x = 2
Show the answer

The Extreme Value Theorem needs hh continuous on [0,4][0, 4]. hh jumps at x=2x = 2 (limx→2−h(x)=2\lim_{x \to 2^-} h(x) = 2 but h(2)=−1h(2) = -1), so the theorem guarantees nothing.

  • Yes, because [0,4][0, 4] is a closed interval: A closed interval is half the hypothesis; hh must also be continuous on it.
  • Yes, because hh is defined at each point of [0,4][0, 4]: Defined is not enough: hh jumps from values near 2 down to −1-1.
  • No, because hh is not differentiable at x=0x = 0: Differentiability is not a hypothesis of the Extreme Value Theorem, and x=0x = 0 is an endpoint.
  • Correct: No, because hh is not continuous at x=2x = 2: The theorem needs continuity on the closed interval; the jump at 2 breaks it.

5. Which statement about hh on [0,4][0, 4] is true?

  1. hh has neither, because the Extreme Value Theorem does not apply
  2. hh has an absolute maximum of 22, at x=2x = 2
  3. hh has an absolute minimum, −1-1, but no absolute maximum
  4. hh has an absolute maximum of 11, at the endpoint x=4x = 4
Show the answer

The lowest value is h(2)=−1h(2) = -1. For a maximum, h(x)=xh(x) = x gets as close to 2 as you like as x→2−x \to 2^- but never equals 2, and no value is larger, so there is no absolute maximum.

  • hh has neither, because the Extreme Value Theorem does not apply: When a hypothesis fails, the theorem promises nothing; extrema may still exist. Here the minimum does.
  • hh has an absolute maximum of 22, at x=2x = 2: h(2)=−1h(2) = -1, not 2: the open circle at (2,2)(2, 2) is not on the graph.
  • Correct: hh has an absolute minimum, −1-1, but no absolute maximum: h(2)=−1h(2) = -1 is the lowest value. Values near x=2x = 2 from the left get close to 2 but never reach it, and every value of hh is less than 2.
  • hh has an absolute maximum of 11, at the endpoint x=4x = 4: h(1.5)=1.5h(1.5) = 1.5 is larger than h(4)=1h(4) = 1, so 1 is not the largest value.

6. What does the Extreme Value Theorem say about hh on [2,4][2, 4]?

  1. Nothing, because hh jumps at x=2x = 2
  2. hh is continuous there, so it has both: maximum 11, minimum −1-1
  3. hh has an absolute maximum there but perhaps no absolute minimum
  4. hh has a critical point in (2,4)(2, 4) where its extremes occur
Show the answer

On [2,4][2, 4], h(x)=x−3h(x) = x - 3 is continuous (including h(2)=−1h(2) = -1). The Extreme Value Theorem guarantees both extremes: minimum h(2)=−1h(2) = -1, maximum h(4)=1h(4) = 1.

  • Nothing, because hh jumps at x=2x = 2: The jump is approached from the left of 2, outside [2,4][2, 4]. On [2,4][2, 4] itself hh is continuous.
  • Correct: hh is continuous there, so it has both: maximum 11, minimum −1-1: On [2,4][2, 4], h(x)=x−3h(x) = x - 3 with h(2)=−1h(2) = -1: no jump inside or at the ends of this interval.
  • hh has an absolute maximum there but perhaps no absolute minimum: The theorem gives both: an absolute maximum and an absolute minimum.
  • hh has a critical point in (2,4)(2, 4) where its extremes occur: h′(x)=1h'(x) = 1 on (2,4)(2, 4); there are no critical points. The extremes are at the endpoints.

7. For f(x)=x2f(x) = x^2 on [1,3][1, 3], find the value of cc guaranteed by the Mean Value Theorem.

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

ff is a polynomial, so it is continuous on [1,3][1, 3] and differentiable on (1,3)(1, 3). Average rate: 9−13−1=4\frac{9 - 1}{3 - 1} = 4. Then f′(c)=2c=4f'(c) = 2c = 4 gives c=2c = 2.

  • Answer: 2

8. On which intervals is f(x)=x3−12xf(x) = x^3 - 12x increasing?

  1. (−2,2)(-2, 2)
  2. (0,∞)(0, \infty)
  3. (−∞,−23)(-\infty, -2\sqrt{3}) and (23,∞)(2\sqrt{3}, \infty)
  4. (−∞,−2)(-\infty, -2) and (2,∞)(2, \infty)
Show the answer

f′(x)f'(x)=3x2−12= 3x^2 - 12=3(x−2)(x+2)= 3(x - 2)(x + 2). It is positive for x<−2x < -2 and for x>2x > 2, so ff increases on (−∞,−2)(-\infty, -2) and (2,∞)(2, \infty).

  • (−2,2)(-2, 2): f′<0f' < 0 there: ff decreases.
  • (0,∞)(0, \infty): f′(1)=−9<0f'(1) = -9 < 0, so ff decreases on part of (0,∞)(0, \infty).
  • (−∞,−23)(-\infty, -2\sqrt{3}) and (23,∞)(2\sqrt{3}, \infty): ±23\pm 2\sqrt{3} are the zeros of ff, not of f′f'.
  • Correct: (−∞,−2)(-\infty, -2) and (2,∞)(2, \infty): f′(x)f'(x)=3(x−2)(x+2)>0= 3(x - 2)(x + 2) > 0 outside [−2,2][-2, 2].

9. Find the relative minimum value of f(x)=xexf(x) = x e^x. Give an exact answer.

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

f′(x)f'(x)=ex+xex= e^x + xe^x=(1+x)ex= (1 + x)e^x, which changes from negative to positive at x=−1x = -1. The relative minimum value is f(−1)=−e−1=−1ef(-1) = -e^{-1} = -\frac{1}{e}.

  • Answer: −1e\frac{-1}{e} ≈ -0.368

No calculator. Type the exact value (a fraction, π, e or a root is fine).

f′(x)=1−2sin⁡x=0f'(x) = 1 - 2\sin x = 0 at x=π6,5π6x = \frac{\pi}{6}, \frac{5\pi}{6}. 11. For f(x)=sin⁡x+cos⁡xf(x) = \sin x + \cos x, what does ff have at x=π4x = \frac{\pi}{4}?

  1. A relative maximum: f′(π4)=0f'\left(\frac{\pi}{4}\right) = 0 and f″(π4)=−2f''\left(\frac{\pi}{4}\right) = -\sqrt{2}
  2. A relative minimum: f′(π4)=0f'\left(\frac{\pi}{4}\right) = 0 and f″(π4)=2f''\left(\frac{\pi}{4}\right) = \sqrt{2}
  3. A point of inflection: f′(π4)=0f'\left(\frac{\pi}{4}\right) = 0 and f″(π4)=−2f''\left(\frac{\pi}{4}\right) = -\sqrt{2}
  4. No extremum: f′(π4)=0f'\left(\frac{\pi}{4}\right) = 0 and f″(π4)=0f''\left(\frac{\pi}{4}\right) = 0
Show the answer

f′(π4)f'\left(\frac{\pi}{4}\right)=22−22= \frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2}=0= 0 and f″(π4)=−2<0f''\left(\frac{\pi}{4}\right) = -\sqrt{2} < 0: a relative maximum, f(π4)=2f\left(\frac{\pi}{4}\right) = \sqrt{2}.

  • Correct: A relative maximum: f′(π4)=0f'\left(\frac{\pi}{4}\right) = 0 and f″(π4)=−2f''\left(\frac{\pi}{4}\right) = -\sqrt{2}: f′(x)=cos⁡x−sin⁡xf'(x) = \cos x - \sin x and f″(x)=−sin⁡x−cos⁡xf''(x) = -\sin x - \cos x.
  • A relative minimum: f′(π4)=0f'\left(\frac{\pi}{4}\right) = 0 and f″(π4)=2f''\left(\frac{\pi}{4}\right) = \sqrt{2}: A sign slip: f″(π4)f''\left(\frac{\pi}{4}\right)=−22−22= -\frac{\sqrt{2}}{2} - \frac{\sqrt{2}}{2}=−2= -\sqrt{2}.
  • A point of inflection: f′(π4)=0f'\left(\frac{\pi}{4}\right) = 0 and f″(π4)=−2f''\left(\frac{\pi}{4}\right) = -\sqrt{2}: f′=0f' = 0 is about extrema, not inflection.
  • No extremum: f′(π4)=0f'\left(\frac{\pi}{4}\right) = 0 and f″(π4)=0f''\left(\frac{\pi}{4}\right) = 0: f″(π4)=−2f''\left(\frac{\pi}{4}\right) = -\sqrt{2}, not 0.

12. The graph of ff is continuous and has a corner at x=ax = a. What does the graph of f′f' show at x=ax = a?

  1. A zero: f′(a)=0f'(a) = 0
  2. A vertical asymptote
  3. A jump: f′(a)f'(a) does not exist
  4. Nothing special: f′f' is continuous at aa
Show the answer

At a corner the slope from the left differs from the slope from the right. The graph of f′f' jumps there, with no value at x=ax = a.

  • A zero: f′(a)=0f'(a) = 0: A corner is a point where f′f' is undefined, not zero.
  • A vertical asymptote: At a corner the slopes stay finite; a vertical tangent line would give an asymptote-like spike.
  • Correct: A jump: f′(a)f'(a) does not exist: The slopes on the two sides differ, so the derivative jumps from one value to another.
  • Nothing special: f′f' is continuous at aa: f′f' cannot be continuous where its left and right values differ.
