1. Based on the graph, which describes gg near x=−2x = -2?

  1. limx→−2g(x)=−∞\lim_{x \to -2} g(x) = -\infty
  2. limx→−2−g(x)=−∞\lim_{x \to -2^-} g(x) = -\infty and limx→−2+g(x)=∞\lim_{x \to -2^+} g(x) = \infty
  3. limx→−2g(x)=0\lim_{x \to -2} g(x) = 0
  4. limx→−2g(x)=∞\lim_{x \to -2} g(x) = \infty
Show the answer

On both sides of x=−2x = -2 the graph rises without bound, so limx→−2g(x)=∞\lim_{x \to -2} g(x) = \infty.

  • limx→−2g(x)=−∞\lim_{x \to -2} g(x) = -\infty: The graph goes up, not down, near −2-2.
  • limx→−2−g(x)=−∞\lim_{x \to -2^-} g(x) = -\infty and limx→−2+g(x)=∞\lim_{x \to -2^+} g(x) = \infty: The left side also rises near −2-2.
  • limx→−2g(x)=0\lim_{x \to -2} g(x) = 0: Near −2-2 the values are huge, not near 0.
  • Correct: limx→−2g(x)=∞\lim_{x \to -2} g(x) = \infty: Both sides go up: the two-sided behavior is ∞\infty.

2. Which describes gg near x=1x = 1?

  1. limx→1−g(x)=−∞\lim_{x \to 1^-} g(x) = -\infty and limx→1+g(x)=∞\lim_{x \to 1^+} g(x) = \infty
  2. limx→1−g(x)=∞\lim_{x \to 1^-} g(x) = \infty and limx→1+g(x)=−∞\lim_{x \to 1^+} g(x) = -\infty
  3. limx→1g(x)=∞\lim_{x \to 1} g(x) = \infty from both sides of x=1x = 1
  4. limx→1g(x)=0\lim_{x \to 1} g(x) = 0, since the graph crosses the axis
Show the answer

Left of 1 the graph plunges down; right of 1 it shoots up. Each one-sided limit is infinite, with opposite signs.

  • Correct: limx→1−g(x)=−∞\lim_{x \to 1^-} g(x) = -\infty and limx→1+g(x)=∞\lim_{x \to 1^+} g(x) = \infty: Down on the left, up on the right.
  • limx→1−g(x)=∞\lim_{x \to 1^-} g(x) = \infty and limx→1+g(x)=−∞\lim_{x \to 1^+} g(x) = -\infty: The directions are reversed.
  • limx→1g(x)=∞\lim_{x \to 1} g(x) = \infty from both sides of x=1x = 1: The left side heads down, not up.
  • limx→1g(x)=0\lim_{x \to 1} g(x) = 0, since the graph crosses the axis: Near 1 the graph is unbounded; crossing the axis elsewhere does not matter.

3. What does the statement limx→−2g(x)=∞\lim_{x \to -2} g(x) = \infty mean?

  1. g(−2)g(-2) equals ∞\infty, a very large number that the graph reaches
  2. g(x)g(x) grows without bound near −2-2; the limit is not a number
  3. The limit exists and equals the largest value of gg on the graph
  4. gg approaches the horizontal line y=∞y = \infty as xx nears −2-2
Show the answer

∞\infty is not a number. Writing =∞= \infty is a precise way of saying how the limit fails to exist: the values grow beyond every bound.

  • g(−2)g(-2) equals ∞\infty, a very large number that the graph reaches: g(−2)g(-2) is undefined, and ∞\infty is not a number a function can equal.
  • Correct: g(x)g(x) grows without bound near −2-2; the limit is not a number: An infinite limit is a kind of limit that does not exist, described by its direction.
  • The limit exists and equals the largest value of gg on the graph: gg has no largest value near −2-2; that is the point.
  • gg approaches the horizontal line y=∞y = \infty as xx nears −2-2: There is no line y=∞y = \infty; the graph runs along the vertical asymptote x=−2x = -2.

4. To find limx→1g(x)\lim_{x \to 1} g(x) exactly, what should you multiply the top and bottom of g(x)g(x) by?

  1. x+8+3\sqrt{x + 8} + 3
  2. x+8−3\sqrt{x + 8} - 3
  3. x+1x + 1
  4. x+8\sqrt{x + 8}
Show the answer

The conjugate of x+8−3\sqrt{x + 8} - 3 is x+8+3\sqrt{x + 8} + 3; their product is (x+8)−9=x−1(x + 8) - 9 = x - 1, which cancels with the bottom.

  • Correct: x+8+3\sqrt{x + 8} + 3: The conjugate flips the middle sign.
  • x+8−3\sqrt{x + 8} - 3: Multiplying by the same expression gives (x+8−3)2(\sqrt{x + 8} - 3)^2, which keeps the square root.
  • x+1x + 1: x+1x + 1 does not remove the square root.
  • x+8\sqrt{x + 8}: This gives x+8−3x+8x + 8 - 3\sqrt{x + 8}, which still has a square root.

5. How does the table compare with the exact limit?

  1. They agree: both sides close in on 16=0.1666…\frac{1}{6} = 0.1666\ldots
  2. They disagree: the table suggests 0.17, the largest value shown.
  3. The table shows the limit does not exist, because the values differ on each side.
  4. The table shows g(1)=16g(1) = \frac{1}{6}.
Show the answer

Left values (0.167132, 0.166713, 0.166671) fall toward 0.1666…0.1666\ldots and right values (0.166662, 0.166620, 0.166206) rise toward it. The algebra gives exactly 16\frac{1}{6}: two representations of the same limit.

  • Correct: They agree: both sides close in on 16=0.1666…\frac{1}{6} = 0.1666\ldots: Both sides head to 16\frac{1}{6}.
  • They disagree: the table suggests 0.17, the largest value shown.: The trend matters, not one value: the values keep closing in on 0.1666…0.1666\ldots.
  • The table shows the limit does not exist, because the values differ on each side.: Values on each side differ slightly but head to the same number.
  • The table shows g(1)=16g(1) = \frac{1}{6}.: The table does not include x=1x = 1, where gg is undefined.

6. Why does the table have no entry for x=1x = 1?

  1. g(1)g(1) is not defined: substituting gives 00\frac{0}{0}.
  2. g(1)=0g(1) = 0, which is not interesting.
  3. g(1)g(1) equals the limit, so the table does not need to show it.
  4. Tables of values skip whole-number inputs.
Show the answer

At x=1x = 1 the top is 9−3=0\sqrt{9} - 3 = 0 and the bottom is 0, so the formula has no value there. A limit does not need one.

  • Correct: g(1)g(1) is not defined: substituting gives 00\frac{0}{0}.: Zero over zero has no value.
  • g(1)=0g(1) = 0, which is not interesting.: The formula does not give 0 at x=1x = 1; it gives no value at all.
  • g(1)g(1) equals the limit, so the table does not need to show it.: g(1)g(1) does not exist, so it cannot equal the limit.
  • Tables of values skip whole-number inputs.: Any input near the target can appear; the target itself is skipped.

7. What is the average rate of change of f(x)=x2−4xf(x) = x^2 - 4x over the interval [1,5][1, 5]?

  1. 22
  2. 88
  3. −2-2
  4. 12\frac{1}{2}
Show the answer

f(5)=25−20=5f(5) = 25 - 20 = 5 and f(1)=1−4=−3f(1) = 1 - 4 = -3. Average rate =5−(−3)5−1=84=2= \frac{5 - (-3)}{5 - 1} = \frac{8}{4} = 2.

  • Correct: 22: f(5)−f(1)5−1=84\frac{f(5) - f(1)}{5 - 1} = \frac{8}{4}.
  • 88: 8 is the change in ff; divide by the change in xx, 4.
  • −2-2: Keep the order the same on top and bottom: f(5)−f(1)f(5) - f(1) over 5−15 - 1.
  • 12\frac{1}{2}: That is the change in xx over the change in ff, upside down.

8. Which statement says "as xx approaches 5, the values of 3x−13x - 1 approach 14"?

  1. limx→5(3x−1)=14\lim_{x \to 5} (3x - 1) = 14
  2. limx→14(3x−1)=5\lim_{x \to 14} (3x - 1) = 5
  3. limx→514=3x−1\lim_{x \to 5} 14 = 3x - 1
  4. limx→5=3x−1=14\lim_{x \to 5} = 3x - 1 = 14
Show the answer

Write "lim", put x→5x \to 5 under it, then the expression, then "=14= 14".

  • Correct: limx→5(3x−1)=14\lim_{x \to 5} (3x - 1) = 14: The approach goes under "lim" and the target after the equals sign.
  • limx→14(3x−1)=5\lim_{x \to 14} (3x - 1) = 5: This swaps the input target and the output target.
  • limx→514=3x−1\lim_{x \to 5} 14 = 3x - 1: The expression whose values change goes after "lim", not the number.
  • limx→5=3x−1=14\lim_{x \to 5} = 3x - 1 = 14: "lim" is followed by the expression, not an equals sign; this chains unequal things with "=".

9. For a function pp, limx→4−p(x)=7\lim_{x \to 4^-} p(x) = 7, limx→4+p(x)=7\lim_{x \to 4^+} p(x) = 7 and p(4)=2p(4) = 2. What is limx→4p(x)\lim_{x \to 4} p(x)?

  1. 77
  2. 22
  3. 4.54.5
  4. The limit does not exist.
Show the answer

Both one-sided limits are 7, so the two-sided limit is 7. The value p(4)=2p(4) = 2 does not change that.

  • Correct: 77: Equal one-sided limits give the limit.
  • 22: 2 is the value at 4; the limit ignores it.
  • 4.54.5: Limits are not averages of the value and the trend.
  • The limit does not exist.: The one-sided limits agree, so the limit exists.

11. Find limx→5(x−3)x+4\lim_{x \to 5} (x - 3)\sqrt{x + 4}.

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

Product law, then root law: (5−3)⋅5+4=2⋅3=6(5 - 3) \cdot \sqrt{5 + 4} = 2 \cdot 3 = 6.

  • Answer: 6
