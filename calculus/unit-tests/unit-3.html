The circle x2+y2=25x^2 + y^2 = 25

1. A student differentiates the circle in the graph and writes 2x+2y=02x + 2y = 0. What went wrong?

  1. The derivative of 2525 should be 2525
  2. The derivative of x2x^2 should be 2xdydx2x\frac{dy}{dx}
  3. Both sides should be divided by 22 before differentiating
  4. yy depends on xx, so ddxy2=2ydydx\frac{d}{dx}y^2 = 2y\frac{dy}{dx}
Show the answer

Treat yy as a function of xx. Then ddx(x2+y2)=2x+2ydydx=0\frac{d}{dx}\left(x^2 + y^2\right) = 2x + 2y\frac{dy}{dx} = 0, so dydx=−xy\frac{dy}{dx} = -\frac{x}{y}.

  • The derivative of 2525 should be 2525: 25 is a constant, so its derivative is 0; that part was right.
  • The derivative of x2x^2 should be 2xdydx2x\frac{dy}{dx}: Differentiating with respect to xx, the derivative of x2x^2 is just 2x2x.
  • Both sides should be divided by 22 before differentiating: Dividing by 2 changes nothing important; the missing dydx\frac{dy}{dx} is the error.
  • Correct: yy depends on xx, so ddxy2=2ydydx\frac{d}{dx}y^2 = 2y\frac{dy}{dx}: The chain rule applies to every term that holds yy; the student dropped the factor dydx\frac{dy}{dx}.

2. What happens to dydx\frac{dy}{dx} at the point (−5,0)(-5, 0) of the circle?

  1. It is undefined, because y=0y = 0 makes the denominator 0
  2. It equals 0, because y=0y = 0
  3. It equals −5-5, the value of xx
  4. It equals 1, because the circle is round
Show the answer

With dydx=−xy\frac{dy}{dx} = -\frac{x}{y}, a zero denominator and a nonzero numerator mean no slope: the tangent line at (−5,0)(-5, 0) is vertical, as the graph shows.

  • Correct: It is undefined, because y=0y = 0 makes the denominator 0: −xy=−−50-\frac{x}{y} = -\frac{-5}{0} has no value; the tangent line there is vertical.
  • It equals 0, because y=0y = 0: A zero denominator does not make a fraction 0. The slope is 0 where the numerator xx is 0, at (0,±5)(0, \pm 5).
  • It equals −5-5, the value of xx: The slope is −xy-\frac{x}{y}, not xx.
  • It equals 1, because the circle is round: The slope changes from point to point; at (−5,0)(-5, 0) the formula gives a zero denominator.

3. At which point of the circle is the slope of the tangent line 34\frac{3}{4}?

  1. (3,4)(3, 4)
  2. (3,−4)(3, -4)
  3. (4,3)(4, 3)
  4. (−4,−3)(-4, -3)
Show the answer

Solve −xy=34-\frac{x}{y} = \frac{3}{4} on the circle: (3,−4)(3, -4) works, since −3−4=34-\frac{3}{-4} = \frac{3}{4} and 9+16=259 + 16 = 25.

  • (3,4)(3, 4): −34-\frac{3}{4}: the sign is wrong.
  • Correct: (3,−4)(3, -4): −3−4=34-\frac{3}{-4} = \frac{3}{4}.
  • (4,3)(4, 3): −43-\frac{4}{3} at this point.
  • (−4,−3)(-4, -3): −−4−3=−43-\frac{-4}{-3} = -\frac{4}{3} at this point.

  1. 434\sqrt{3}
  2. −233-\frac{2\sqrt{3}}{3}
  3. −43-4\sqrt{3}
  4. −245-\frac{24}{5}
Show the answer

m′(x)=−g′(x)1−[g(x)]2m'(x) = -\frac{g'(x)}{\sqrt{1 - [g(x)]^2}}, so m′(4)=−61−14=−63/2=−43m'(4) = -\frac{6}{\sqrt{1 - \frac{1}{4}}} = -\frac{6}{\sqrt{3}/2} = -4\sqrt{3}.

  • −233-\frac{2\sqrt{3}}{3}: This is −13/2-\frac{1}{\sqrt{3}/2} without the inside derivative g′(4)=6g'(4) = 6.
  • Correct: −43-4\sqrt{3}: −63/2=−123=−43-\frac{6}{\sqrt{3}/2} = -\frac{12}{\sqrt{3}} = -4\sqrt{3}.
  • −245-\frac{24}{5}: This uses 1+u21 + u^2 in the denominator, the arctangent pattern, instead of 1−u2\sqrt{1 - u^2}.

6. Why does the chain rule give no value for the derivative of arcsin⁡(g(x))\arcsin(g(x)) at x=3x = 3?

  1. g′(3)=2g'(3) = 2 is greater than 1, outside the domain of arcsine
  2. arcsin⁡1\arcsin 1 is not defined
  3. The table gives no value of gg near 3
  4. g(3)=1g(3) = 1, so 1−[g(3)]2=0\sqrt{1 - [g(3)]^2} = 0 and the formula divides by 0
Show the answer

The derivative of arcsin⁡u\arcsin u is 11−u2\frac{1}{\sqrt{1 - u^2}}, defined for −1<u<1-1 < u < 1. At x=3x = 3, u=g(3)=1u = g(3) = 1 and the denominator is 0.

  • g′(3)=2g'(3) = 2 is greater than 1, outside the domain of arcsine: The domain condition is on the inside value g(3)g(3), not on g′(3)g'(3).
  • arcsin⁡1\arcsin 1 is not defined: arcsin⁡1=π2\arcsin 1 = \frac{\pi}{2} is defined; it is the derivative that fails at u=1u = 1.
  • The table gives no value of gg near 3: The formula itself breaks: its denominator 1−[g(3)]2\sqrt{1 - [g(3)]^2} is 0.
  • Correct: g(3)=1g(3) = 1, so 1−[g(3)]2=0\sqrt{1 - [g(3)]^2} = 0 and the formula divides by 0: The derivative of arcsin⁡u\arcsin u exists only for −1<u<1-1 < u < 1; here u=1u = 1.

7. Let f(x)=1+4xf(x) = \sqrt{1 + 4x}. Find f′(2)f'(2).

Show the answer

f′(x)=12(1+4x)−1/2⋅4=21+4xf'(x) = \frac{1}{2}(1 + 4x)^{-1/2} \cdot 4 = \frac{2}{\sqrt{1 + 4x}}, so f′(2)=29=23f'(2) = \frac{2}{\sqrt{9}} = \frac{2}{3}.

9. Which first step is most efficient for differentiating y=x2+3xy = \frac{x^2 + 3}{\sqrt{x}}?

  1. Apply the quotient rule to the fraction as written
  2. Apply the chain rule to x\sqrt{x} first
  3. Multiply the derivatives of x2+3x^2 + 3 and 1x\frac{1}{\sqrt{x}}
  4. Rewrite as x3/2+3x−1/2x^{3/2} + 3x^{-1/2} and use the power rule
Show the answer

Dividing each term by x1/2x^{1/2} turns the quotient into a sum of powers, x3/2+3x−1/2x^{3/2} + 3x^{-1/2}, which the power rule handles directly.

  • Apply the quotient rule to the fraction as written: This works, but it is longer and gives more chances for algebra slips.
  • Apply the chain rule to x\sqrt{x} first: x\sqrt{x} has no inside function to differentiate; the fraction is the structure to deal with.
  • Multiply the derivatives of x2+3x^2 + 3 and 1x\frac{1}{\sqrt{x}}: The derivative of a product is not the product of derivatives.
  • Correct: Rewrite as x3/2+3x−1/2x^{3/2} + 3x^{-1/2} and use the power rule: Two power rules, no quotient: 32x1/2−32x−3/2\frac{3}{2}x^{1/2} - \frac{3}{2}x^{-3/2}.
