Adding fractions is easy: $\frac{2}{x - 1} - \frac{1}{x + 3} = \frac{2(x + 3) - (x - 1)}{(x - 1)(x + 3)} = \frac{x + 7}{(x - 1)(x + 3)}$. The method of partial fractions runs that addition backward. It turns a rational function whose denominator factors into a sum of simple fractions, each of which integrates to a natural log. The BC course uses denominators with distinct linear factors, such as $(x - 1)(x + 3)$.

Splitting a fraction

For a fraction $\frac{p(x)}{(x - a)(x - b)}$ with $a \ne b$ and the top of degree below 2, write

$$\frac{p(x)}{(x - a)(x - b)} = \frac{A}{x - a} + \frac{B}{x - b}.$$

Multiply both sides by $(x - a)(x - b)$: $p(x) = A(x - b) + B(x - a)$. This is an identity, true for every $x$, so you may substitute any value. Substituting $x = a$ removes the $B$ term and gives $A$; substituting $x = b$ removes the $A$ term and gives $B$. The figure shows a fraction and its two pieces.

Worked example 1. Find $\int \frac{x + 7}{(x - 1)(x + 3)}\,dx$.

Form: $\frac{x + 7}{(x - 1)(x + 3)} = \frac{A}{x - 1} + \frac{B}{x + 3}$, so $x + 7 = A(x + 3) + B(x - 1)$.

At $x = 1$: $8 = 4A$, so $A = 2$. At $x = -3$: $4 = -4B$, so $B = -1$.

Check by adding back: $\frac{2}{x - 1} - \frac{1}{x + 3} = \frac{2x + 6 - x + 1}{(x - 1)(x + 3)} = \frac{x + 7}{(x - 1)(x + 3)}$.

Integrate: $\int \left(\frac{2}{x - 1} - \frac{1}{x + 3}\right)dx = 2\ln|x - 1| - \ln|x + 3| + C$.

A second way to find $A$ and $B$ is to match coefficients: $x + 7 = (A + B)x + (3A - B)$, so $A + B = 1$ and $3A - B = 7$. Substituting the zeros is usually faster.

Definite integrals

Worked example 2. Evaluate $\int_0^1 \frac{2}{x^2 + 4x + 3}\,dx$.

Factor: $x^2 + 4x + 3 = (x + 1)(x + 3)$. Then $2 = A(x + 3) + B(x + 1)$: $x = -1$ gives $A = 1$; $x = -3$ gives $B = -1$.

$\int_0^1 \left(\frac{1}{x + 1} - \frac{1}{x + 3}\right)dx = \left(\ln(x + 1) - \ln(x + 3)\right)\Big|_0^1 = (\ln 2 - \ln 4) - (\ln 1 - \ln 3) = \ln\frac{3}{2}.$

The value at the lower bound is $-\ln 3$, not 0; dropping it is the most common slip. Log rules tidy the answer: $\ln 2 - \ln 4 + \ln 3 = \ln\frac{2 \cdot 3}{4}$.

When the top is too big: divide first

Partial fractions need the top's degree to be below the bottom's. If it is not, use long division (6.10) first and split only the remainder.

Worked example 3. Find $\int \frac{x^2 + x}{x^2 - 4}\,dx$.

Divide: $\frac{x^2 + x}{x^2 - 4} = 1 + \frac{x + 4}{x^2 - 4}$.

Split: $x + 4 = A(x + 2) + B(x - 2)$; $x = 2$ gives $A = \frac{3}{2}$, $x = -2$ gives $B = -\frac{1}{2}$.

Integrate: $x + \frac{3}{2}\ln|x - 2| - \frac{1}{2}\ln|x + 2| + C$.

Which method?

Rational integrands look alike. Ask in order: is the top the derivative of the bottom (substitution)? Is the top's degree too big (divide)? Does the bottom factor into distinct linear factors (partial fractions)? Does it have no real zeros (complete the square, arctan)?

Always check a decomposition by adding the pieces back over the common denominator. It takes a few seconds and catches a wrong sign on $B$, the slip that most often costs the answer.

A repeated factor such as $(x - 1)^2$ or a factor with no real zeros such as $x^2 + 1$ needs a longer form of the method. Those cases are outside the BC course.
