Unit 7 · Topic 7.5

Euler's Method

Euler's method approximates a solution of dy/dx = F(x, y) by short tangent steps: from a known point, y_new = y + F(x, y) Δx , then repeat from the new point.

Practice 1: Implementing Mathematical ProcessesPractice 2: Connecting Representations

Part 1 · Hook

Why this matters

Some differential equations, such as dydx=x+y\frac{dy}{dx} = x + y, cannot be solved by the methods of this unit. You can still find out roughly where a solution goes: stand at a known point, walk a short way along the slope the equation gives, read the new slope, and repeat. That walk is Euler's method.

Part 5 · Step by step

How it works, step by step

  1. The differential equation gives the slope at every point→at a known point you know the direction of the solution curve
  2. Follow that slope for a short run Δx\Delta x→the rise is Δy=dydxΔx\Delta y = \frac{dy}{dx}\,\Delta x, and the new point is (x+Δx,y+Δy)(x + \Delta x, y + \Delta y)
  3. At the new point, read a new slope from the equation→take the next step; repeat until you reach the xx you want
  4. The solution curves are concave up (or down) along the way→each step falls below (or above) them, so the estimate is too small (or too large)

Part 6 · Key ideas

Key ideas

  • One step: ynewy_{\text{new}}=y+dydx|(x,y)⋅Δx= y + \frac{dy}{dx}\Big|_{(x, y)} \cdot \Delta x, using the slope at the point you are at.
  • Lay the work out in a table with columns xx, yy, dydx\frac{dy}{dx}, Δx\Delta x, Δy\Delta y; take exactly the steps asked for.
  • Smaller steps give better estimates. A negative Δx\Delta x steps to the left.
  • Over or under: find d2ydx2\frac{d^2y}{dx^2} by differentiating the equation. Concave up curves lie above their tangent steps (underestimate); concave down, below (overestimate).

Part 7 · Misconception

A common mistake

The wrong idea: For dydx=x+y\frac{dy}{dx} = x + y from (0,1)(0, 1) with Δx=0.5\Delta x = 0.5: the slope is 1, so y(0.5)≈1.5y(0.5) \approx 1.5 and y(1)≈2y(1) \approx 2.

What actually happens: Each step needs a new slope at its own point. At (0.5,1.5)(0.5, 1.5) the slope is 0.5+1.5=20.5 + 1.5 = 2, so y(1)y(1)≈1.5+2(0.5)\approx 1.5 + 2(0.5)=2.5= 2.5. Reusing the first slope is just one long tangent line.

3. For x≥0x \ge 0 and y>0y > 0, d2ydx2=1+x+y\frac{d^2y}{dx^2} = 1 + x + y. Is the estimate of f(1)f(1) too large or too small?

  1. Too large: the slopes increase from one step to the next
  2. Too small: dydx=x+y>0\frac{dy}{dx} = x + y > 0, so the solution is increasing
  3. No conclusion is possible without solving the equation
  4. Too small: d2ydx2>0\frac{d^2y}{dx^2} > 0, so the solution curves are concave up and the steps fall below them
Show the answer

d2ydx2\frac{d^2y}{dx^2}=ddx(x+y)= \frac{d}{dx}(x + y)=1= 1+dydx+ \frac{dy}{dx}=1= 1+x+ x+y+ y, positive in this region, where every Euler point lies. So every solution curve there is concave up and lies above its tangent segments: the first step ends below f(0.5)f(0.5), and the second step ends below the solution curve through (0.5,1.5)(0.5, 1.5), which stays below ff (solution curves do not cross). So 2.5 underestimates f(1)f(1).

  • Too large: the slopes increase from one step to the next: Increasing slopes mean concave up, and a tangent segment lies below a concave up curve, so the estimate is too small.
  • Too small: dydx=x+y>0\frac{dy}{dx} = x + y > 0, so the solution is increasing: The conclusion is right but the reason is not: increasing says nothing about the gap. Concavity, from d2ydx2\frac{d^2y}{dx^2}, decides it.
  • No conclusion is possible without solving the equation: d2ydx2\frac{d^2y}{dx^2} comes from the differential equation itself, so its sign can be read without solving.
  • Correct: Too small: d2ydx2>0\frac{d^2y}{dx^2} > 0, so the solution curves are concave up and the steps fall below them: Right: each tangent step lies below the concave up solution curve it starts on, and a curve that starts lower stays below the graph of ff, since solution curves do not cross.

5. For dydx=F(x,y)\frac{dy}{dx} = F(x, y) and step size Δx\Delta x, which formula is one Euler step?

  1. ynew=y⋅F(x,y)Δxy_{\text{new}} = y \cdot F(x, y)\,\Delta x
  2. ynewy_{\text{new}}=y+F(x+Δx,y)Δx= y + F(x + \Delta x, y)\,\Delta x
  3. ynew=y+F(x,y)Δxy_{\text{new}} = y + F(x, y)\,\Delta x
  4. ynew=y+Δxy_{\text{new}} = y + \Delta x
Show the answer

Follow the tangent line: new yy = old yy + slope × Δx\Delta x, with the slope from the differential equation at the current point.

  • ynew=y⋅F(x,y)Δxy_{\text{new}} = y \cdot F(x, y)\,\Delta x: The change is added to yy, not multiplied by it.
  • ynewy_{\text{new}}=y+F(x+Δx,y)Δx= y + F(x + \Delta x, y)\,\Delta x: Euler's method uses the slope at the point you are at, (x,y)(x, y), not ahead of it.
  • Correct: ynew=y+F(x,y)Δxy_{\text{new}} = y + F(x, y)\,\Delta x: Right: the slope at the current point times the run gives the rise.
  • ynew=y+Δxy_{\text{new}} = y + \Delta x: That adds the run, not the rise. Multiply the run by the slope first.

6. A solution y=f(x)y = f(x) has f(2)=4f(2) = 4 and f′(2)=0.6f'(2) = 0.6, and its graph is concave down for 2≤x≤2.52 \le x \le 2.5. One Euler step gives f(2.5)≈4.3f(2.5) \approx 4.3. Which is true?

  1. 4.34.3 is an overestimate: the tangent step lies above the graph
  2. 4.34.3 is an underestimate, because f′(2)>0f'(2) > 0 means ff is increasing
  3. 4.34.3 is exact, because one step of Euler's method is exactly the tangent line
  4. 4.34.3 is an underestimate, because the graph is concave down
Show the answer

One Euler step from (2,4)(2, 4) is the tangent line: 4+0.6(0.5)=4.34 + 0.6(0.5) = 4.3. A concave down graph lies below its tangent lines, so f(2.5)<4.3f(2.5) < 4.3.

  • Correct: 4.34.3 is an overestimate: the tangent step lies above the graph: Right: a concave down graph lies below its tangent lines, so the estimate is too large.
  • 4.34.3 is an underestimate, because f′(2)>0f'(2) > 0 means ff is increasing: Increasing is not the reason. Concave down puts the graph below its tangent line, so the estimate is too large.
  • 4.34.3 is exact, because one step of Euler's method is exactly the tangent line: It is the tangent line value, which differs from f(2.5)f(2.5) whenever the graph bends.
  • 4.34.3 is an underestimate, because the graph is concave down: Concave down graphs lie below their tangent lines, which makes a tangent estimate too large.

Part 9 · Summary

Summary

Euler's method approximates a solution of dydx=F(x,y)\frac{dy}{dx} = F(x, y) by short tangent steps: from a known point, ynew=y+F(x,y)Δxy_{\text{new}} = y + F(x, y)\,\Delta x, then repeat from the new point. Smaller steps follow the curve more closely. The sign of d2ydx2\frac{d^2y}{dx^2} tells whether the steps fall below the solution (concave up, an underestimate) or above it (concave down, an overestimate).
