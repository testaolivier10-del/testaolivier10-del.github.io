The growth rate dPdt\frac{dP}{dt} graphed against PP

A population PP follows a logistic model dPdt=kP(K−P)\frac{dP}{dt} = kP(K - P). The graph shows dPdt\frac{dP}{dt}, in animals per year, as a function of PP: a parabola through (0,0)(0, 0) and (800,0)(800, 0) with its highest point at (400,32)(400, 32).

1. What is the carrying capacity KK?

  1. 0
  2. 800
  3. 400
  4. 32
Show the answer

kP(K−P)=0kP(K - P) = 0 at P=0P = 0 and P=KP = K; the graph returns to 0 at 800.

  • 0: P=0P = 0 is the other equilibrium: no animals, no growth. The carrying capacity is the positive one.
  • Correct: 800: Right: the rate returns to 0 at P=800P = 800, the positive equilibrium the population approaches.
  • 400: 400 is where the rate is largest, half of KK.
  • 32: 32 animals per year is the largest rate, not a population.

2. Which differential equation matches the graph?

  1. dPdt=32P(800−P)\frac{dP}{dt} = 32P(800 - P)
  2. dPdt=0.0002P(P−800)\frac{dP}{dt} = 0.0002P(P - 800)
  3. dPdt=0.0002P(800−P)\frac{dP}{dt} = 0.0002P(800 - P)
  4. dPdt=0.0002P(400−P)\frac{dP}{dt} = 0.0002P(400 - P)
Show the answer

From the zeros, K=800K = 800. From the top point, k⋅400⋅400=32k \cdot 400 \cdot 400 = 32, so kk=32160,000= \frac{32}{160{,}000}=0.0002= 0.0002.

  • dPdt=32P(800−P)\frac{dP}{dt} = 32P(800 - P): 32 is the largest rate, not kk. At P=400P = 400 this formula gives over 5 million.
  • dPdt=0.0002P(P−800)\frac{dP}{dt} = 0.0002P(P - 800): This rate is negative for 0<P<8000 < P < 800, but the graph is above the axis there.
  • Correct: dPdt=0.0002P(800−P)\frac{dP}{dt} = 0.0002P(800 - P): Right: K=800K = 800, and at P=400P = 400: k(400)(400)=32k(400)(400) = 32 gives k=0.0002k = 0.0002.
  • dPdt=0.0002P(400−P)\frac{dP}{dt} = 0.0002P(400 - P): This rate is 0 at P=400P = 400, but the graph is highest there and returns to 0 at 800.

3. Compare the growth rate when P=200P = 200 with the growth rate when P=600P = 600.

  1. The rate is larger at P=600P = 600, since there are more animals
  2. The rate is larger at P=200P = 200, since there is more room to grow
  3. The graph alone does not allow a comparison
  4. They are equal: 24 animals per year each
Show the answer

The rate kP(K−P)kP(K - P) is symmetric about K2=400\frac{K}{2} = 400, so P=200P = 200 and P=600P = 600 give the same rate, 24 animals per year.

  • The rate is larger at P=600P = 600, since there are more animals: More animals means more births, but less room: 800−600=200800 - 600 = 200. The two effects balance exactly.
  • The rate is larger at P=200P = 200, since there is more room to grow: More room, but fewer animals to grow. The graph has the same height at 200 and 600.
  • The graph alone does not allow a comparison: Read the heights of the graph, or use the model: both rates are 24.
  • Correct: They are equal: 24 animals per year each: Right: the parabola is symmetric about P=400P = 400; 0.0002(200)(600)0.0002(200)(600)=0.0002(600)(200)= 0.0002(600)(200)=24= 24.

4. Where is the graph of the population P(t)P(t) concave up, for a population that starts between 0 and 800?

  1. Concave up while P<400P < 400, concave down while 400<P<800400 < P < 800
  2. Concave down while P<400P < 400, concave up while 400<P<800400 < P < 800
  3. Concave up throughout 0<P<8000 < P < 800
  4. Neither: the graph of P(t)P(t) is a straight line
Show the answer

d2Pdt2\frac{d^2P}{dt^2}=ddP(kP(K−P))⋅dPdt= \frac{d}{dP}\left(kP(K - P)\right) \cdot \frac{dP}{dt}=k(K−2P)dPdt= k(K - 2P)\frac{dP}{dt}. With dPdt>0\frac{dP}{dt} > 0, the sign is that of K−2PK - 2P: positive for P<400P < 400, negative above. P=400P = 400 is a point of inflection.

  • Correct: Concave up while P<400P < 400, concave down while 400<P<800400 < P < 800: Right: dPdt\frac{dP}{dt} increases as PP grows toward 400 and decreases after, so P(t)P(t) bends up and then down.
  • Concave down while P<400P < 400, concave up while 400<P<800400 < P < 800: Reversed: below 400 the rate is rising as PP rises, so the graph of PP gets steeper (concave up).
  • Concave up throughout 0<P<8000 < P < 800: Above 400 the rate falls as PP rises, so the graph of PP flattens out: concave down.
  • Neither: the graph of P(t)P(t) is a straight line: A straight line has a constant rate. Here the rate changes with PP, from 0 up to 32 and back to 0.

5. Which is the particular solution of dydx=2y2\frac{dy}{dx} = 2y^2 with y(0)=12y(0) = \frac{1}{2}?

  1. y=12+2xy = \frac{1}{2 + 2x}
  2. y=−12x+12y = -\frac{1}{2x} + \frac{1}{2}
  3. y=21−xy = \frac{2}{1 - x}
  4. y=12−2xy = \frac{1}{2 - 2x}
Show the answer

y−2dy=2dxy^{-2}\,dy = 2\,dx, so −1y=2x+C-\frac{1}{y} = 2x + C. At (0,12)(0, \frac{1}{2}): −2=C-2 = C. Then 1y=2−2x\frac{1}{y} = 2 - 2x.

  • y=12+2xy = \frac{1}{2 + 2x}: ∫y−2dy=−1y\int y^{-2}\,dy = -\frac{1}{y}: the minus sign flips the 2x2x.
  • y=−12x+12y = -\frac{1}{2x} + \frac{1}{2}: The constant was added after solving for yy.
  • y=21−xy = \frac{2}{1 - x}: At x=0x = 0 this is 2, not 12\frac{1}{2}.
  • Correct: y=12−2xy = \frac{1}{2 - 2x}: −1y=2x+C-\frac{1}{y} = 2x + C; at (0,12)(0, \frac{1}{2}), C=−2C = -2, so y=12−2xy = \frac{1}{2 - 2x}.

6. What is the domain of this particular solution?

  1. x≠1x \ne 1
  2. x>1x > 1
  3. x<1x < 1
  4. (−∞,∞)(-\infty, \infty)
Show the answer

y=12−2xy = \frac{1}{2 - 2x} is undefined at x=1x = 1. The largest open interval containing x=0x = 0 is x<1x < 1.

  • x≠1x \ne 1: A solution's domain is one interval; the piece with x>1x > 1 is not connected to (0,12)(0, \frac{1}{2}).
  • x>1x > 1: The initial point x=0x = 0 must be in the domain.
  • Correct: x<1x < 1: The formula breaks at x=1x = 1; the solution lives on the interval containing x=0x = 0.
  • (−∞,∞)(-\infty, \infty): At x=1x = 1 the formula divides by 0.

7. What happens to this solution as x→1−x \to 1^-?

  1. yy increases without bound.
  2. yy approaches 12\frac{1}{2}.
  3. yy approaches 0.
  4. yy decreases without bound.
Show the answer

As x→1−x \to 1^-, 2−2x→02 - 2x \to 0 through positive values, so y→∞y \to \infty: a vertical asymptote ends the solution.

  • Correct: yy increases without bound.: 2−2x→0+2 - 2x \to 0^+, so 12−2x→∞\frac{1}{2 - 2x} \to \infty.
  • yy approaches 12\frac{1}{2}.: 12\frac{1}{2} is the value at x=0x = 0, not near x=1x = 1.
  • yy approaches 0.: The denominator shrinks to 0, so the fraction grows.
  • yy decreases without bound.: For x<1x < 1 the denominator is positive.

8. A population of fish F decreases at a rate proportional to the square root of the population. With k > 0, which equation models this?

  1. dFdt=kF\frac{dF}{dt} = k\sqrt{F}
  2. dFdt=−kt\frac{dF}{dt} = -k\sqrt{t}
  3. dFdt=−kF\frac{dF}{dt} = -k\sqrt{F}
  4. F=−ktF = -k\sqrt{t}
Show the answer

"Decreases at a rate proportional to F\sqrt{F}": dFdt=−kF\frac{dF}{dt} = -k\sqrt{F} with k>0k > 0.

  • dFdt=kF\frac{dF}{dt} = k\sqrt{F}: With k>0k > 0 this rate is positive: the population would grow.
  • dFdt=−kt\frac{dF}{dt} = -k\sqrt{t}: The rate depends on the population, not on the time.
  • Correct: dFdt=−kF\frac{dF}{dt} = -k\sqrt{F}: Proportional to F\sqrt{F}, and the minus sign with k>0k > 0 makes the population decrease.
  • F=−ktF = -k\sqrt{t}: The sentence is about the rate of change of F, so a derivative is needed.

9. Which differential equation does y=sin⁡(2x)y = \sin(2x) satisfy?

  1. d2ydx2=4y\frac{d^2y}{dx^2} = 4y
  2. d2ydx2=−2y\frac{d^2y}{dx^2} = -2y
  3. d2ydx2=−4y\frac{d^2y}{dx^2} = -4y
  4. dydx=2y\frac{dy}{dx} = 2y
Show the answer

y′=2cos⁡(2x)y' = 2\cos(2x), y″=−4sin⁡(2x)=−4yy'' = -4\sin(2x) = -4y.

  • d2ydx2=4y\frac{d^2y}{dx^2} = 4y: The second derivative of sine brings a minus sign.
  • d2ydx2=−2y\frac{d^2y}{dx^2} = -2y: The chain rule gives a factor 2 twice: 2⋅2=42 \cdot 2 = 4.
  • Correct: d2ydx2=−4y\frac{d^2y}{dx^2} = -4y: y″=−4sin⁡(2x)=−4yy'' = -4\sin(2x) = -4y.
  • dydx=2y\frac{dy}{dx} = 2y: dydx=2cos⁡(2x)\frac{dy}{dx} = 2\cos(2x), not 2sin⁡(2x)2\sin(2x).

10. Where are the segments of the slope field for dydx=y2−1\frac{dy}{dx} = y^2 - 1 horizontal?

  1. On the line y=1y = 1 alone
  2. On the lines x=1x = 1 and x=−1x = -1
  3. On the lines y=1y = 1 and y=−1y = -1
  4. On the xx-axis
Show the answer

Horizontal segments have slope 0: y2−1=0y^2 - 1 = 0 gives y=1y = 1 or y=−1y = -1, for every xx.

  • On the line y=1y = 1 alone: (−1)2−1=0(-1)^2 - 1 = 0 as well.
  • On the lines x=1x = 1 and x=−1x = -1: The slope depends on yy, not xx.
  • Correct: On the lines y=1y = 1 and y=−1y = -1: y2−1=0y^2 - 1 = 0 when y=±1y = \pm 1.
  • On the xx-axis: At y=0y = 0 the slope is −1-1.

11. For dydx=3−y2\frac{dy}{dx} = \frac{3 - y}{2}, why does the solution curve through (0,1)(0, 1) stay below y=3y = 3 for every xx?

  1. Because dydx<0\frac{dy}{dx} < 0 below y=3y = 3.
  2. Because the curve starts at y=1y = 1, which is below 3.
  3. y=3y = 3 is itself a solution, and solution curves of this equation do not cross.
  4. Because d2ydx2>0\frac{d^2y}{dx^2} > 0 below y=3y = 3.
Show the answer

The constant y=3y = 3 solves the equation, and two solution curves of this equation never meet, so the curve rises toward 3 without reaching it.

  • Because dydx<0\frac{dy}{dx} < 0 below y=3y = 3.: Below y=3y = 3, 3−y2>0\frac{3 - y}{2} > 0: the curve rises.
  • Because the curve starts at y=1y = 1, which is below 3.: Starting below a level does not by itself keep a curve below it.
  • Correct: y=3y = 3 is itself a solution, and solution curves of this equation do not cross.: Two solution curves cannot share a point here, so the curve stays below the equilibrium line.
  • Because d2ydx2>0\frac{d^2y}{dx^2} > 0 below y=3y = 3.: d2ydx2=−12dydx<0\frac{d^2y}{dx^2} = -\frac{1}{2}\frac{dy}{dx} < 0 there, and concavity alone would not settle it.
