1. What does the table tell you about the tangent lines at t=1t = 1 and at t=2t = 2?

  1. Horizontal at t=1t = 1; vertical at t=2t = 2
  2. Vertical at t=1t = 1; horizontal at t=2t = 2
  3. Horizontal at both times
  4. Slope 2 at t=1t = 1; slope 34\frac{3}{4} at t=2t = 2
Show the answer

At t=1t = 1: y′(1)=0y'(1) = 0 and x′(1)=1≠0x'(1) = 1 \ne 0, so the slope is 0 (horizontal). At t=2t = 2: x′(2)=0x'(2) = 0 and y′(2)=2≠0y'(2) = 2 \ne 0, so the tangent is vertical.

  • Correct: Horizontal at t=1t = 1; vertical at t=2t = 2: Right: a zero numerator (y′y') gives a horizontal tangent; a zero denominator (x′x') with a nonzero y′y' gives a vertical one.
  • Vertical at t=1t = 1; horizontal at t=2t = 2: This swaps the two cases. dydx=y′x′\frac{dy}{dx} = \frac{y'}{x'} is 0 when y′=0y' = 0: horizontal.
  • Horizontal at both times: At t=2t = 2 it is x′x' that is 0, not y′y': that tangent is vertical.
  • Slope 2 at t=1t = 1; slope 34\frac{3}{4} at t=2t = 2: These divide the coordinates y(t)y(t) by x(t)x(t); slopes come from the derivatives.

2. In which direction is the point moving at t=3t = 3?

  1. Right and up
  2. Left and up
  3. Left and down
  4. Right and down
Show the answer

x′(3)=−4<0x'(3) = -4 < 0, so xx is decreasing: the point moves left. y′(3)=3>0y'(3) = 3 > 0, so yy is increasing: it moves up.

  • Right and up: x′(3)=−4x'(3) = -4 is negative, so xx is decreasing: left, not right.
  • Correct: Left and up: Right: x′<0x' < 0 (left) and y′>0y' > 0 (up).
  • Left and down: y′(3)=3y'(3) = 3 is positive, so the point moves up.
  • Right and down: Both signs are reversed here: x′(3)<0x'(3) < 0 and y′(3)>0y'(3) > 0.

3. A curve is given by x=t3x = t^3, y=t2+1y = t^2 + 1 for t≠0t \ne 0. Which describes its concavity?

  1. Concave down for t<0t < 0 and for t>0t > 0
  2. Concave up for t<0t < 0 and for t>0t > 0
  3. Concave up for t>0t > 0, concave down for t<0t < 0
  4. Concave down for t>0t > 0, concave up for t<0t < 0
Show the answer

dydx=2t3t2=23t\frac{dy}{dx} = \frac{2t}{3t^2} = \frac{2}{3t}, whose tt-derivative is −23t2-\frac{2}{3t^2}. Dividing by dxdt=3t2\frac{dx}{dt} = 3t^2 gives d2ydx2=−29t4\frac{d^2y}{dx^2} = -\frac{2}{9t^4}, negative on both sides of t=0t = 0.

  • Correct: Concave down for t<0t < 0 and for t>0t > 0: Right: −29t4<0-\frac{2}{9t^4} < 0 for t≠0t \ne 0.
  • Concave up for t<0t < 0 and for t>0t > 0: The sign of −29t4-\frac{2}{9t^4} is negative; t4>0t^4 > 0 cannot make it positive.
  • Concave up for t>0t > 0, concave down for t<0t < 0: Even powers of tt have one sign on both sides of 0, so the concavity does not change.
  • Concave down for t>0t > 0, concave up for t<0t < 0: −29t4-\frac{2}{9t^4} is negative for t<0t < 0 as well: t4t^4 is positive there too.

5. Which vector is the best estimate of the robot's velocity vector at t=2t = 2, in meters per second?

  1. ⟨6,−4⟩\left\langle 6, -4 \right\rangle
  2. ⟨5,2⟩\left\langle 5, 2 \right\rangle
  3. ⟨−2,3⟩\left\langle -2, 3 \right\rangle
  4. ⟨3,−2⟩\left\langle 3, -2 \right\rangle
Show the answer

Estimate each component over [1,3][1, 3]: 8−22=3\frac{8 - 2}{2} = 3 and 0−42=−2\frac{0 - 4}{2} = -2. The velocity vector is ⟨x′(2),y′(2)⟩≈⟨3,−2⟩\left\langle x'(2), y'(2) \right\rangle \approx \left\langle 3, -2 \right\rangle.

  • ⟨6,−4⟩\left\langle 6, -4 \right\rangle: These are the changes over 2 seconds; divide each by 2 to get rates.
  • ⟨5,2⟩\left\langle 5, 2 \right\rangle: This averages the positions at t=1t = 1 and t=3t = 3: an estimate of where the robot is, not how fast it moves.
  • ⟨−2,3⟩\left\langle -2, 3 \right\rangle: The components are swapped: the xx-rate comes first.
  • Correct: ⟨3,−2⟩\left\langle 3, -2 \right\rangle: Right: one difference quotient per component.

6. Based on the table, in which direction is the robot most likely moving at t=5t = 5?

  1. Right and up
  2. Right and down
  3. Left and up
  4. Left and down
Show the answer

Over [4,6][4, 6]: x′(5)x'(5)≈10−92\approx \frac{10 - 9}{2}=12>0= \frac{1}{2} > 0 and y′(5)y'(5)≈2−(−1)2\approx \frac{2 - (-1)}{2}=32>0= \frac{3}{2} > 0. Both components of the velocity are positive: right and up.

  • Correct: Right and up: Right: both estimated components are positive.
  • Right and down: yy goes from −1-1 to 22 over [4,6][4, 6], so y′(5)y'(5) is estimated as positive: up.
  • Left and up: xx goes from 9 to 10, so x′(5)≈12>0x'(5) \approx \frac{1}{2} > 0: right.
  • Left and down: Both coordinates increase over [4,6][4, 6], so the estimated velocity points right and up.

7. Find ∫01⟨3t2,4t3+1⟩dt\int_0^1 \left\langle 3t^2, 4t^3 + 1 \right\rangle\,dt.

  1. ⟨6,12⟩\left\langle 6, 12 \right\rangle
  2. ⟨1,1⟩\left\langle 1, 1 \right\rangle
  3. ⟨3,5⟩\left\langle 3, 5 \right\rangle
  4. ⟨1,2⟩\left\langle 1, 2 \right\rangle
Show the answer

Integrate each component: ∫013t2dt\int_0^1 3t^2\,dt=1= 1 and ∫01(4t3+1)dt\int_0^1 (4t^3 + 1)\,dt=(t4+t)|01= (t^4 + t)\Big|_0^1=2= 2.

  • ⟨6,12⟩\left\langle 6, 12 \right\rangle: These are the derivatives at t=1t = 1; integrate instead.
  • ⟨1,1⟩\left\langle 1, 1 \right\rangle: The +1+ 1 in the second component integrates to tt, which adds 1.
  • ⟨3,5⟩\left\langle 3, 5 \right\rangle: These are the integrand's values at t=1t = 1, not the integrals.
  • Correct: ⟨1,2⟩\left\langle 1, 2 \right\rangle: Right: ⟨1,2⟩\left\langle 1, 2 \right\rangle.

8. A particle has position r(t)=⟨t2,t3⟩\mathbf{r}(t) = \left\langle t^2, t^3 \right\rangle. What is its speed at t=1t = 1?

  1. 32\frac{3}{2}
  2. 13\sqrt{13}
  3. 55
  4. 2\sqrt{2}
Show the answer

v(t)=⟨2t,3t2⟩\mathbf{v}(t) = \left\langle 2t, 3t^2 \right\rangle, so v(1)=⟨2,3⟩\mathbf{v}(1) = \left\langle 2, 3 \right\rangle and the speed is 4+9=13\sqrt{4 + 9} = \sqrt{13}.

  • 32\frac{3}{2}: That is dydx=32\frac{dy}{dx} = \frac{3}{2}, the slope of the path. Speed is the magnitude of the velocity.
  • Correct: 13\sqrt{13}: Right: 22+32\sqrt{2^2 + 3^2}.
  • 55: That adds the components 2+32 + 3; use 22+32\sqrt{2^2 + 3^2}.
  • 2\sqrt{2}: That is the length of the position ⟨1,1⟩\left\langle 1, 1 \right\rangle; speed uses the velocity.

9. The rose r=2cos⁡(3θ)r = 2\cos(3\theta) passes through the pole at θ=π6\theta = \frac{\pi}{6}. Find the slope of its tangent line there.

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

At θ=π6\theta = \frac{\pi}{6}, r=0r = 0 and drdθ=−6sin⁡π2=−6\frac{dr}{d\theta} = -6\sin\frac{\pi}{2} = -6. Then dxdθ\frac{dx}{d\theta}=−6cos⁡π6−0= -6\cos\frac{\pi}{6} - 0=−33= -3\sqrt{3} and dydθ\frac{dy}{d\theta}=−6sin⁡π6+0= -6\sin\frac{\pi}{6} + 0=−3= -3, so dydx\frac{dy}{dx}=−3−33= \frac{-3}{-3\sqrt{3}}=33= \frac{\sqrt{3}}{3}. At the pole the curve is tangent to the ray θ=π6\theta = \frac{\pi}{6}, whose slope is tan⁡π6\tan\frac{\pi}{6}.

  • Answer: 33\frac{\sqrt{3}}{3} ≈ 0.577

12. Find the area of the region inside r=2cos⁡θr = 2\cos\theta and outside r=1r = 1.

No calculator. Type the exact value (a fraction, π, e or a root is fine).

Show the answer

The curves meet where 2cos⁡θ=12\cos\theta = 1: θ=±π3\theta = \pm\frac{\pi}{3}. 12∫−π/3π/3(4cos2⁡θ−1)dθ\frac{1}{2}\int_{-\pi/3}^{\pi/3} \left(4\cos^2\theta - 1\right)d\theta=12∫−π/3π/3(1+2cos⁡(2θ))dθ= \frac{1}{2}\int_{-\pi/3}^{\pi/3} \left(1 + 2\cos(2\theta)\right)d\theta=12[θ+sin⁡(2θ)]−π/3π/3= \frac{1}{2}\Big[\theta + \sin(2\theta)\Big]_{-\pi/3}^{\pi/3}=π3= \frac{\pi}{3}+32+ \frac{\sqrt{3}}{2}.

  • Answer: π3+32\frac{\pi}{3} + \frac{\sqrt{3}}{2} ≈ 1.913
