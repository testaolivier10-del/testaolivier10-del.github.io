In 9.1 you found the slope of a parametric curve, dydx=dy/dtdx/dt\frac{dy}{dx} = \frac{dy/dt}{dx/dt}. The next question is how that slope changes as you move along the curve: the second derivative d2ydx2\frac{d^2y}{dx^2}, which tells you whether the curve bends up or down. It takes one idea, used twice.

The slope rule, applied to the slope

The rule from 9.1 works for any quantity that depends on tt: its rate of change with respect to xx is its rate with respect to tt, divided by dxdt\frac{dx}{dt}. The slope dydx\frac{dy}{dx} is such a quantity. So

d2ydx2=ddx(dydx)=ddt(dydx)dx/dt,dxdt≠0.\frac{d^2y}{dx^2} = \frac{d}{dx}\left(\frac{dy}{dx}\right) = \frac{\frac{d}{dt}\left(\frac{dy}{dx}\right)}{dx/dt}, \qquad \frac{dx}{dt} \ne 0.

That gives a three-step method:

  1. Find dydx=dy/dtdx/dt\frac{dy}{dx} = \frac{dy/dt}{dx/dt} and simplify it as a function of tt.
  2. Differentiate that function with respect to tt.
  3. Divide the result by dxdt\frac{dx}{dt}.

Worked example 1. A curve is given by x=t2x = t^2, y=t3−3ty = t^3 - 3t for t>0t > 0. Find d2ydx2\frac{d^2y}{dx^2} and the concavity of the curve.

Step 1: dydx\frac{dy}{dx}=3t2−32t= \frac{3t^2 - 3}{2t}=3t2−32t= \frac{3t}{2} - \frac{3}{2t}. Splitting the fraction makes step 2 a power rule instead of a quotient rule.

Step 2: ddt(3t2−32t−1)\frac{d}{dt}\left(\frac{3t}{2} - \frac{3}{2}t^{-1}\right)=32= \frac{3}{2}+32t2+ \frac{3}{2t^2}.

Step 3: divide by dxdt=2t\frac{dx}{dt} = 2t: d2ydx2\frac{d^2y}{dx^2}=3/2+3/(2t2)2t= \frac{3/2 + 3/(2t^2)}{2t}=34t= \frac{3}{4t}+34t3+ \frac{3}{4t^3}=3(t2+1)4t3= \frac{3(t^2 + 1)}{4t^3}.

For t>0t > 0 every factor is positive, so the curve is concave up there. At t=1t = 1 the value is 3⋅24=32\frac{3 \cdot 2}{4} = \frac{3}{2}.

Why the extra division matters

ddt(dydx)\frac{d}{dt}\left(\frac{dy}{dx}\right) measures how fast the slope changes per unit of time. Concavity is about how fast the slope changes per unit of xx. Dividing by dxdt\frac{dx}{dt} converts one into the other, and it can change the sign.

The figure shows the circle x=cos⁡tx = \cos t, y=sin⁡ty = \sin t. Its slope is −cot⁡t-\cot t, and ddt(−cot⁡t)=csc2⁡t\frac{d}{dt}(-\cot t) = \csc^2 t, positive for every tt. If you stopped there, you would call the whole circle concave up. Dividing by dxdt=−sin⁡t\frac{dx}{dt} = -\sin t gives d2ydx2=−1sin3⁡t\frac{d^2y}{dx^2} = -\frac{1}{\sin^3 t}: negative on the upper half, where sin⁡t>0\sin t > 0, and positive on the lower half. That matches the picture.

The other tempting shortcut, d2y/dt2d2x/dt2\frac{d^2y/dt^2}{d^2x/dt^2}, is simply not the second derivative. For x=etx = e^t, y=e3ty = e^{3t} it gives 9e3tet=9e2t\frac{9e^{3t}}{e^t} = 9e^{2t}, but the curve is y=x3y = x^3, whose second derivative is 6x=6et6x = 6e^t. The three steps give the same 6et6e^t: dydx\frac{dy}{dx}=3e3tet= \frac{3e^{3t}}{e^t}=3e2t= 3e^{2t}, its tt-derivative is 6e2t6e^{2t}, and 6e2tet=6et\frac{6e^{2t}}{e^t} = 6e^t.

Concavity, inflection points and the second derivative test

Once you have d2ydx2\frac{d^2y}{dx^2} as a function of tt, Unit 5 applies:

FindingConclusion
d2ydx2>0\frac{d^2y}{dx^2} > 0 at ttThe curve is concave up there
d2ydx2<0\frac{d^2y}{dx^2} < 0 at ttThe curve is concave down there
d2ydx2\frac{d^2y}{dx^2} changes sign at t0t_0A point of inflection at (x(t0),y(t0))(x(t_0), y(t_0))
dydx=0\frac{dy}{dx} = 0 and d2ydx2>0\frac{d^2y}{dx^2} > 0 at t0t_0A relative minimum of yy there (second derivative test)
dydx=0\frac{dy}{dx} = 0 and d2ydx2<0\frac{d^2y}{dx^2} < 0 at t0t_0A relative maximum of yy there

Worked example 2. At t=3t = 3, a curve has dxdt=6\frac{dx}{dt} = 6, dydx=0\frac{dy}{dx} = 0 and ddt(dydx)=−12\frac{d}{dt}\left(\frac{dy}{dx}\right) = -12. What happens at that point?

d2ydx2\frac{d^2y}{dx^2}=−126= \frac{-12}{6}=−2<0= -2 < 0. The tangent is horizontal and the curve is concave down, so yy has a relative maximum at the point where t=3t = 3.

Always report a point as (x(t0),y(t0))(x(t_0), y(t_0)), not as t0t_0, and name what changes sign when you claim an inflection point: "d2ydx2\frac{d^2y}{dx^2} changes from negative to positive at t=2t = 2."
