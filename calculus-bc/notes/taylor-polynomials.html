SMath you need

In Unit 4 the tangent line gave a quick estimate of a function near a point: it matched the function's value and slope there. A Taylor polynomial carries that idea further. It matches the value, the slope, the concavity and as many higher derivatives as you like, and the more it matches, the better it follows the function.

From the tangent line to a parabola

Near x=0x = 0, the tangent line to cos⁡x\cos x is y=1y = 1: right value, right slope, but flat, while cos⁡x\cos x bends downward. To copy the bending, add a squared term c(x−a)2c(x - a)^2 chosen so that the second derivatives agree. The second derivative of c(x−a)2c(x - a)^2 is 2c2c, so we need 2c=f″(a)2c = f''(a), that is c=f″(a)2c = \frac{f''(a)}{2}. For cos⁡x\cos x at 0, f″(0)=−1f''(0) = -1, which gives

P2(x)=1−x22.P_2(x) = 1 - \frac{x^2}{2}.

The same reasoning works for every degree: the nnth derivative of (x−a)n(x - a)^n is n!n!, so the coefficient that matches f(n)(a)f^{(n)}(a) is f(n)(a)n!\frac{f^{(n)}(a)}{n!}.

The Taylor polynomial

The Taylor polynomial of degree nn for ff about x=ax = a is

Pn(x)=f(a)+f′(a)(x−a)+f″(a)2!(x−a)2+f‴(a)3!(x−a)3+⋯+f(n)(a)n!(x−a)n.P_n(x) = f(a) + f'(a)(x - a) + \frac{f''(a)}{2!}(x - a)^2 + \frac{f'''(a)}{3!}(x - a)^3 + \cdots + \frac{f^{(n)}(a)}{n!}(x - a)^n.

The number aa is the center. PnP_n and ff have the same value and the same first nn derivatives at aa. A Taylor polynomial about a=0a = 0 is also called a Maclaurin polynomial.

The figure shows P2P_2, P4P_4 and P6P_6 for cos⁡x\cos x. All three agree with cos⁡x\cos x at the center; each extra term keeps the polynomial close for a wider stretch before it peels away.

Reading a Taylor polynomial backward

A Taylor polynomial stores derivatives: the coefficient of (x−a)n(x - a)^n times n!n! is f(n)(a)f^{(n)}(a).

Worked example 2. The third-degree Taylor polynomial for gg about x=2x = 2 is P3(x)P_3(x)=7−4(x−2)2= 7 - 4(x - 2)^2+12(x−2)3+ \frac{1}{2}(x - 2)^3. Find g′(2)g'(2), g″(2)g''(2) and g‴(2)g'''(2), and say what happens at x=2x = 2.

g′(2)=0g'(2) = 0 (there is no (x−2)(x - 2) term). g″(2)=2!⋅(−4)=−8g''(2) = 2! \cdot (-4) = -8. g‴(2)=3!⋅12=3g'''(2) = 3! \cdot \frac{1}{2} = 3.

Since g′(2)=0g'(2) = 0 and g″(2)<0g''(2) < 0, gg has a relative maximum at x=2x = 2 by the second derivative test.
