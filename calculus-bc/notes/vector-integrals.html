In 9.4 you went from position to velocity by differentiating each component. This topic runs the other way: from a velocity vector, and a starting point, back to the position. It is the planar version of what you did for straight-line motion in 8.2, done twice, once for xx and once for yy.

Antiderivatives one component at a time

To integrate a vector-valued function, integrate each component:

∫⟨f(t),g(t)⟩dt=⟨∫f(t)dt,∫g(t)dt⟩=⟨F(t),G(t)⟩+C.\int \left\langle f(t), g(t) \right\rangle\,dt = \left\langle \int f(t)\,dt, \int g(t)\,dt \right\rangle = \left\langle F(t), G(t) \right\rangle + \mathbf{C}.

Each component gets its own constant, so the constant is a vector, C=⟨C1,C2⟩\mathbf{C} = \left\langle C_1, C_2 \right\rangle. Definite integrals work the same way and give a vector of numbers:

∫02⟨3t2,2t+1⟩dt=⟨t3|02,(t2+t)|02⟩=⟨8,6⟩.\int_0^2 \left\langle 3t^2, 2t + 1 \right\rangle\,dt = \left\langle t^3\Big|_0^2, (t^2 + t)\Big|_0^2 \right\rangle = \left\langle 8, 6 \right\rangle.

One velocity, many paths

Knowing the velocity tells you how the particle moves, not where it is. The figure shows two paths with the same velocity v(t)=⟨1,2t−2⟩\mathbf{v}(t) = \left\langle 1, 2t - 2 \right\rangle. Both are antiderivatives, ⟨t,t2−2t⟩+C\left\langle t, t^2 - 2t \right\rangle + \mathbf{C}; they differ by the constant vector, so one is the other shifted. An initial condition picks the path:

r(t)=r(0)+∫0tv(s)ds,or, between two times,r(b)=r(a)+∫abv(t)dt.\mathbf{r}(t) = \mathbf{r}(0) + \int_0^t \mathbf{v}(s)\,ds, \qquad \text{or, between two times,} \qquad \mathbf{r}(b) = \mathbf{r}(a) + \int_a^b \mathbf{v}(t)\,dt.

In components: x(b)x(b)=x(a)= x(a)+∫abx′(t)dt+ \int_a^b x'(t)\,dt and y(b)y(b)=y(a)= y(a)+∫aby′(t)dt+ \int_a^b y'(t)\,dt. The integral is the change in position over the interval; the start is added to it.

Worked example 1. A particle has velocity v(t)=⟨4t3,et⟩\mathbf{v}(t) = \left\langle 4t^3, e^t \right\rangle and starts at r(0)=⟨−1,3⟩\mathbf{r}(0) = \left\langle -1, 3 \right\rangle. Find r(t)\mathbf{r}(t) and r(1)\mathbf{r}(1).

Antiderivatives: ⟨t4,et⟩+C\left\langle t^4, e^t \right\rangle + \mathbf{C}.

At t=0t = 0: ⟨0,1⟩+C=⟨−1,3⟩\left\langle 0, 1 \right\rangle + \mathbf{C} = \left\langle -1, 3 \right\rangle, so C=⟨−1,2⟩\mathbf{C} = \left\langle -1, 2 \right\rangle. Notice e0=1e^0 = 1, so C2C_2 is 22, not 33.

r(t)=⟨t4−1,et+2⟩\mathbf{r}(t) = \left\langle t^4 - 1, e^t + 2 \right\rangle and r(1)=⟨0,e+2⟩\mathbf{r}(1) = \left\langle 0, e + 2 \right\rangle.

From acceleration: two constants

Given the acceleration vector, integrate twice. The initial velocity fixes the first constant vector and the initial position the second.

Worked example 2. a(t)=⟨6t,−4⟩\mathbf{a}(t) = \left\langle 6t, -4 \right\rangle, v(0)=⟨0,8⟩\mathbf{v}(0) = \left\langle 0, 8 \right\rangle, r(0)=⟨2,0⟩\mathbf{r}(0) = \left\langle 2, 0 \right\rangle. Find r(2)\mathbf{r}(2).

Velocity: v(t)\mathbf{v}(t)=⟨3t2,−4t⟩= \left\langle 3t^2, -4t \right\rangle+⟨0,8⟩+ \left\langle 0, 8 \right\rangle=⟨3t2,8−4t⟩= \left\langle 3t^2, 8 - 4t \right\rangle.

Position: r(t)\mathbf{r}(t)=⟨t3,8t−2t2⟩= \left\langle t^3, 8t - 2t^2 \right\rangle+⟨2,0⟩+ \left\langle 2, 0 \right\rangle=⟨t3+2,8t−2t2⟩= \left\langle t^3 + 2, 8t - 2t^2 \right\rangle.

r(2)\mathbf{r}(2)=⟨8+2,16−8⟩= \left\langle 8 + 2, 16 - 8 \right\rangle=⟨10,8⟩= \left\langle 10, 8 \right\rangle.

Velocity from a table

When x′(t)x'(t) and y′(t)y'(t) are known only at some times, approximate each integral with a sum, using the table's own widths, and then add the starting coordinate.

Worked example 3. A cart starts at (0,2)(0, 2), in feet. Its velocity components, in feet per second, are x′=2,5,1x' = 2, 5, 1 and y′=3,−1,4y' = 3, -1, 4 at t=0,1,4t = 0, 1, 4 seconds. Approximate the cart's position at t=4t = 4 with a trapezoidal sum.

∫04x′(t)dt\int_0^4 x'(t)\,dt≈2+52(1)\approx \frac{2 + 5}{2}(1)+5+12(3)+ \frac{5 + 1}{2}(3)=3.5= 3.5+9+ 9=12.5= 12.5, so x(4)≈0+12.5=12.5x(4) \approx 0 + 12.5 = 12.5 feet.

∫04y′(t)dt\int_0^4 y'(t)\,dt≈3+(−1)2(1)\approx \frac{3 + (-1)}{2}(1)+−1+42(3)+ \frac{-1 + 4}{2}(3)=1= 1+4.5+ 4.5=5.5= 5.5, so y(4)≈2+5.5=7.5y(4) \approx 2 + 5.5 = 7.5 feet.

The cart is near (12.5,7.5)(12.5, 7.5).

In context, give each with its units: the integral of a velocity in meters per minute is in meters. And keep the dtdt in every integral you write: the scoring guidelines read an integral without its differential as incomplete.
