Motion in the plane brings together everything in Unit 9 so far: the position vector, its derivatives, its integrals and the length of a path. Every free-response question on a particle in the plane asks some mix of the same five things. This page lists them, shows the tool for each, and points out where points are usually lost.

From position to velocity, speed and distance

A calculator question, start to finish

Worked example 1. A particle moves with x′(t)=2sin⁡(t2)+1x'(t) = 2\sin(t^2) + 1 and y′(t)=e−t+ty'(t) = e^{-t} + t for 0≤t≤30 \le t \le 3, and (x(0),y(0))=(2,5)(x(0), y(0)) = (2, 5).

Speed at t=1t = 1: (x′(1))2+(y′(1))2\sqrt{(x'(1))^2 + (y'(1))^2}=(2sin⁡1+1)2+(e−1+1)2= \sqrt{(2\sin 1 + 1)^2 + (e^{-1} + 1)^2}≈3.012\approx 3.012.

Each answer shows the setup first, then the calculator value to three decimal places, with stored values and no early rounding.

A question may also give a speed and ask for the time: "when is the speed 3?" Then write the equation (x′(t))2+(y′(t))2\sqrt{(x'(t))^2 + (y'(t))^2}=3= 3 and solve it on the calculator. Evaluating the speed at some time does not answer it.

Reading direction and behavior

Many points come from reading signs, and each question has its own derivative:

  • "Is the particle moving left or right?" Read dxdt\frac{dx}{dt}. "Up or down?" Read dydt\frac{dy}{dt}.
  • "Is the yy-coordinate decreasing?" Read dydt<0\frac{dy}{dt} < 0, not dydx\frac{dy}{dx}. A path can fall as xx increases (dydx<0\frac{dy}{dx} < 0) while xx itself is decreasing, so that yy rises in time.
  • "Is the particle at rest?" Both components of the velocity are 0.
  • "Where is the particle farthest left?" A candidates test on x(t)x(t): compare xx at the endpoints and where x′(t)x'(t) changes sign.

Worked example 2. A particle has x(t)=t3−3tx(t) = t^3 - 3t and y(t)=2t2−t4y(t) = 2t^2 - t^4 for −2≤t≤2-2 \le t \le 2. For which tt is the particle moving left and down?

Left: x′(t)=3t2−3<0x'(t) = 3t^2 - 3 < 0, so −1<t<1-1 < t < 1.

Down: y′(t)y'(t)=4t−4t3= 4t - 4t^3=4t(1−t)(1+t)<0= 4t(1 - t)(1 + t) < 0, so −1<t<0-1 < t < 0 or t>1t > 1.

Both: −1<t<0-1 < t < 0.

Two particles

With two particles, label everything with its particle (xAx_A, yBy_B). Their paths cross where the curves share a point; they collide only if they are at that point at the same time. Set the xx-coordinates equal, solve for tt, and check that the yy-coordinates agree at that same tt.
