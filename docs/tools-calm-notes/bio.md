# Calm tools P1: AP® Biology

One line per tool: stage / dock controls / what moved to Why and Details. Engine: `bio/assets/tools/bio-tools.js`
(`studioSim`, `studioCard`, `studioQuestions`, `chalSteps`, `studioMirror`, `studioVirtual`; `studioArrange` for
skills tools). Every simulator also gets a "Questions" mode: stimulus on the stage, one question or FRQ part at a time
in the dock, rubric review after "Show the rubric". Keep going strips land in Why when their card moved.

- Osmosis: stage the beaker scene (pills mass change, water direction) / beaker concentration, beaker choice chips, Play; modes Explore, Predict (two parts stepped, Run on the last), Questions / Why: heading, first-use line, full explanation; Details: ψ calculator link, readouts, equations, graph, trials, data table, more settings.
- Enzyme activity: stage the enzyme scene with Pause and key (pills rate, % of Vmax) / substrate and temperature; Explore, Predict, Questions / Why: explanation; Details: plots, readouts, trials, data, enzyme, inhibitor, pH.
- Signal transduction: stage the cascade (pills glucose release, cAMP) / Play, epinephrine / Why: tap-a-rung hint, explanation; Details: graphs, readouts, trials, drugs, wash-out, read time, G protein, plot step.
- Cell cycle checkpoints: stage the ring (pills cells, phase split) / growth factor, mutation chips; Explore, Diagnose (find the broken checkpoint), Questions / Why: tap tip, gate text; Details: plots, readouts, trials, damage, drug, read time.
- Meiosis and nondisjunction: stage the cell (pills chromosomes per cell, gametes) / Back, Next step, Play, go-to step, nondisjunction and pair; Explore, Challenge, Questions; caption is the step title and text / Why: step head, tap hint; Details: words, graphs, readouts, results, crossing over, cell, orientation.
- Operons: stage the operon with the sugar chips (pills mRNA, CAP–cAMP) / operon choice chips (lac, trp, merodiploid); Explore, Mutant quiz, Questions; caption repressor and polymerase state / Why: tap hint, going further; Details: graphs, readouts, explanation, medium, genes, read time.
- Hardy-Weinberg and drift: stage the allele jar and mini plot (pills p, generation) / Draw generations, p, N; Explore, Guess N, Questions / Why: jar note, summary; Details: scenario presets, trials, plots, readouts, χ², selection, mutation, migration, mating, events.
- Tree reading: modes Read a tree (stage the tree and character chips / tree choice, taxa chips, MRCA, clade, sister buttons; Why: about, hint, description; Details: rotate, character placement), Build a tree (stage character table and your tree / table choice, pieces, join, undo, check), Questions.
- Population growth: stage the field (pills N, dN/dt) / Play with event buttons, growth model chips, rmax and K / Why: explanation; Details: read year, graphs, readouts, explanation, Δt, N₀, run length, events.
- Energy flow: stage the flow diagram (pills NPP, top level) / fraction passed on, toxin / Why: level explanation; Details: show mode, levels, chain, pyramids, readouts, trials, data, ecosystem and respiration settings.
- Descriptive stats: Explore stage dot plot with key (pills mean, n · SD · SE) / add, remove, reset; Practice parts stepped, worked solution to Why / Why: lead, explanation, Try this; Details: readouts.
- Confidence intervals: Explore stage error bars (pill overlap or gap, SEs) / n and SD for both groups / Why: lead, explanation, Try this; Details: verdict and readouts, per-group settings. Practice stepped.
- Rates: Explore stage the line graph (tap two points) / clear triangles / Why: lead, explanation, Try this; Details: triangle log. Practice stepped.
- Water potential: practice only: stage the two compartments on one ψ scale, problem text as caption, parts stepped / Why: worked solution; Details: problem text, problem code, Practice or Worked set.
- Hardy-Weinberg calculations: Explore stage the Punnett area square and key (pills p, genotype frequencies) / p slider / Why: lead, explanation, Try this; Details: readouts. Practice stepped.
- Simpson's diversity: Explore stage the quadrat and meter (pills D, species and N) / species steppers, even out, reset / Why: lead, explanation, Try this; Details: readouts. Practice stepped.
- Graph builder: stage the grid / modes Plot the data, Free plot; the five steps one at a time (graph type, why, axes, labels, scale, points), Check on the last / Why: the data table and, after Check, the feedback (opens itself, pill "n of m criteria met"); Details: data set choice.
- Design drills: stage the scenario (setup and data table) / scenario choice, drills one at a time each with its Check (pill "n of m right"), written answers as the last steps / Why: Keep going; Details: drill filter.
- Chi-square (P0 reference): unchanged.
