The banks hold 145 items in total, 53 of them numeric. Every topic has functional-dependence items, a predict item and stimulus sets of 4-5 items. The set stimuli are scene diagrams, data tables, and graphs drawn from data: a force-position graph for 3.2 and a momentum-time graph for 4.2. Every item that uses g states the value in its stem, so no item uses `gAlt`.

The items target these misses:
- Choosing the system: a one-object system has only K, and energy shows up as U or as external work, never both.
- Energy bar charts that do not add up, or that split bars evenly by default.
- Friction's work counted as positive or as depending only on displacement.
- ΔK written as ½m(Δv)².
- d used instead of the height in mgΔy.
- U belonging to "the object".
- Using energy conservation for a sticky collision.
- Momentum taken as conserved only in elastic collisions.
- Impulse as the area under a force-time graph.
- Subtracting speeds in a bounce.
- v_cm taken as a plain average of the velocities.
- Circular "conserved because of conservation" justifications.

## Open questions (for needs-author)

1. **Runtime key formatting.** `ApPhysQuestions.formatKey` shows keys of 10⁴ and above with 2-3 significant figures as "6.0e+4 J" and "1.18e+3 J", because `toPrecision` falls back to exponent form. 1.8 × 10⁵ J is formatted correctly. The affected keys are kinetic-energy-1, power-1, power-10 and linear-momentum-13. The fix belongs in the runtime (it should use the ×10ⁿ branch whenever `toPrecision` returns exponent form), which I may not edit. Grading itself is correct.
2. **3.3 scope.** U_G = −Gm₁m₂/r is used in one item (potential-energy-12), as the framework's 3.3.A lists. Units 3-4 boundaries come from the transcription, so this needs a check (needs-author ced-exclusions).
3. **Mixed-unit FRQ.** frq-u4-sticky-blocks-ramp lists `units: ["unit-4", "unit-3"]`. Its momentum-then-energy chain is the official Q1 pattern, but it will publish only once both units are published.
4. **Momentum bar chart.** No `drawSpec` kind for momentum bars exists beyond `bars`. Momentum bar charts are taught in notes and items, but no FRQ asks the student to draw one.
5. **Other authors' files (not mine).** One run of the content check printed `collision-lab` tool validator failures (KE created at certain seeds). A later full run showed tools 0 failing, so this may be in progress. Please confirm with the collision-lab author.
