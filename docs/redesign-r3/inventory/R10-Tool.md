## The one tool layout: how every other tool fits it
Frame: short band (breadcrumb, kicker, two-tone headline, hand line, lede, one action) → toolbar (tool name; Why?, Ask the tutor, More; plus the tool's mode switch when it has one) → stage (the thing you look at, dark grid) with the dock under it (the thing you do) → side card with Why and About tabs → note line (scope or credit) → plain footer. Phone: own top row, stage, dock, Why as a bottom sheet.
- NREMT Body Map: stage = the 3D body (turn, tap a region); dock = region name, structures, landmarks, findings; toolbar modes Front/Back; credit in the note line
- NREMT Sound Trainer: stage = the waveform and play button; dock = "What do you hear?" answer choices and the result; modes Lungs/Heart
- NREMT Flow Diagrams: stage = the diagram; dock = the 10 sequence picker and step list; scope note in the note line
- NREMT Drug Formulary: stage = the open drug card (dose, indications, contraindications); dock = the seven drugs as chips
- NREMT Reference Cards: stage = the open table (pediatric vitals, GCS, APGAR, assessment triangle); dock = the vital sign lookup input
- NREMT Skill Sheets: stage = the station sheet; dock = the checklist and "what fails it"; scope note in the note line
- NREMT Mnemonics: stage = the letters; dock = Fill the letters; list of 21 in the side card
- Ochem tools (all 8, R5-Ochem-ToolSet.md): stage = the molecule canvas; dock = the tool's controls (pick a reagent, push an arrow, compare acids); Free or Premium tag in the toolbar; 3D Viewer uses the stage as the viewer
- AP® tools (all 19 per course, R5-AP-Tool.md): Explore/Practice becomes the toolbar mode switch; stage = the simulation or graph; dock = sliders in Explore, the question in Practice; Water potential and Experimental design use the dock for their steps and drills; Premium lock shows in the dock like the scenario panel
- A&P tools (word root builder and the rest): same frame; stage = the term or figure; dock = the builder
