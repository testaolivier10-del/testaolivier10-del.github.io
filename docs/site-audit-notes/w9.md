## Decisions

- **Organometallics split, not moved whole.** Gilman, organolithium and cross-coupling are each taught through
  what they do to carbonyls or acid derivatives, so moving them before Carbonyl would only move the problem.
  Klein and Wade also teach Grignard (and its C=O, ester and CO₂ reactions) before their carbonyl chapters.
- **Chapter ids.** New ids `grignard` and `ir-mass-spec`; the old ids `organometallics` and `spectroscopy` stay
  on the later chapters, so `learn.html#m-…`, `?chapter=…` and saved prefs still resolve (to the chapter holding
  most of the old content). No topic id changed, so every lesson/notes URL and all topic-keyed progress is intact.
- **Free chapters** are keyed by chapter id (`assets/premium.js` `freeChapters`: foundations, electron-movement,
  nomenclature, acids-bases), and those four are still the first four. No change needed.
- **Position-keyed state.** Only the exam page's midterm range was saved as chapter numbers. It is now saved as ids
  (`fromId`/`toId`); an old numeric save is read against the pre-reorder order (`OchemExamCore.LEGACY_ORDER`).
  Everything else (progress, flashcard prefs, textbook position, exam runs and history, `?topic=`, hashes) was
  already keyed by id. Tests: `scripts/test/ochem-url-compat.test.mjs`.
- **One pericyclic topic, with a lesson.** "A short pericyclic section" became one topic covering electrocyclic and
  sigmatropic reactions; every other topic has an interactive lesson, so these two do too (a notes-only topic would
  hold mastery below 100%).
- **New check** `scripts/site-rules/ochem-sequencing.mjs`: order invariants, no new glossary-term forward reference
  beyond `scripts/ochem-forward-refs-baseline.json` (971 reviewed pairs, mostly group names Foundations already
  introduces and labeled previews), no contradicting direction words next to chapter links (4 confirmed false
  positives listed in the rule), chapter-link labels and lesson breadcrumb data must match the curriculum. The
  term scan is a heuristic: it knows glossary terms only, and it blanks already-taught terms first so "Claisen
  rearrangement" is not read as "Claisen".
- **Weight budgets** raised for content growth only: `ochem/index.html` 11.3 → 11.6 (two more chapters and
  topics on the generated path), tutor-bank 328 → 332 and practice-bank-why 248 → 250 (40 questions and two
  sections). Shell held at 110.5 by trimming curriculum.js comments; exam-core.js held at 4 by a shorter comment.
- `docs/concept-map.json` (the evidence behind the 2026-09 reorder) was not regenerated; it describes the old
  order. `docs/proposed-order.md` has a note pointing here.
