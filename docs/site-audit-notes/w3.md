## Decisions

- **AI endpoint: Supabase session, not Turnstile.** It works with what is already configured (the Worker already
  verifies sessions for Premium); Turnstile needs a site key and secret first. Signed-out visitors get the course's
  own material and the panel says "sign in for AI answers". The token is sent only to the site's own Worker, never
  to an endpoint set by hand (which the CSP now blocks anyway).
- **Members see locks for a moment on page load** until the session restores; that is the cost of never trusting the
  cache without a user. `refresh()` unlocks as soon as the user is known, before `my_premium` answers.
- **Locks:** pass creation and refunds take a per-user advisory lock. The once-per-person ledger's lock row is the
  normalized address, or the account id when there is no address.
- **Normalization:** +tags dropped for every domain; dots dropped only for gmail.com/googlemail.com.
- **Legacy exam history** still counts if dated before `EXAM_LOG_SINCE` (2026-10-15, `worker/src/premium.js`).
- **Push 401/403** counts as that row's failure (FCM answers 403 for a subscription made under an old VAPID key);
  only a VAPID key that will not import stops the run.
- **Umami:** the sandbox could not reach cloud.umami.is or jsDelivr, so the tracker is the unmodified
  `src/tracker/index.js` of the npm package `umami@2.10.0` (sha256 in the file header), posting to
  `https://cloud.umami.is/api/send`. It has no Do-Not-Track option, so analytics.js checks DNT itself.
- **Weight budgets moved:** site shell 249 → 250 KB, index.html 6 → 6.1, ochem/index.html 11 → 11.2 (the longer CSP
  on every page, the session/refresh code and the update toast; reasons in `scripts/check-weight.mjs`).
- **SQL verified** against a real Postgres (PGlite 0.2 with stand-ins for Supabase's auth/extensions): schema.sql twice,
  the migration on the old schema twice (including a `count` column and a `(day, path)` key), queued pass + refund +
  guarantee behaviour, exam throttle, push allowlist/clamp, path whitelist, grants and default privileges, 2 MB cap.
