## Performance, repo and infrastructure

- Supabase SDK on every page — fixed. `account.js` counts page views with a plain POST to `/rest/v1/rpc/track_pageview`
  (publishable key in the `apikey` header, which Supabase's gateway accepts alone) and loads the SDK only when a session is
  stored (`sb-<ref>-auth-token`), the URL carries a sign-in callback, or the sign-in dialog opens; sign-in buttons wait for
  it ("Connecting…") and retry. Signed-out one-way RPCs (reports, errors) post directly. W4 sync and W3 Premium need the SDK
  only when signed in, which always means a stored session, so they start as before (sync tests pass).
- Tutor in the shell — fixed. `assets/tutor-launcher.js` (2.4 KB gz) draws the button; tutor.js (23 KB gz) loads on hover,
  focus or tap and adopts the button; a tap before it arrives opens the panel when it lands. Rule `lazy-sdk-and-tutor`.
- Shell budget: check-weight now also counts the scripts site-chrome.js mounts on every page (motion, reminders, announcer,
  analytics, launcher), 16.6 KB that were never measured. Budget 260 → 278 is a change of ruler; measured the old way plus
  tutor.js it would be ~298 KB, plus ~45 KB of SDK from jsDelivr that was never counted. No budget could be lowered, because
  neither freed file was inside any measured budget.
- Ochem explanations — fixed: fetched when the first question is shown (Practice/Review) or an exam begins, not with the
  page; feedback answered before they land is redrawn. Rule `ochem-lazy-explanations`.
- ochem learn.html / glossary length — fixed: one section at a time with a previous/next pager (a chapter opens on its
  first unread section; next section prefetched); glossary letters collapse behind toggles (A–Z bar, `#l-`/`#g-` links and
  the filter open them). At 390 px: chapter 1 134,000 → 13,200 px; glossary 94,000 → 2,400 px. Rule `ochem-long-pages`.
- Images — fixed with AVIF only: `scripts/build-figure-variants.py` (Pillow 12.3 has AVIF) writes 480/800/full-width copies
  of the 389 OpenStax JPGs, quality 50 (labels checked by eye): 1,098 files, **27,872,430 bytes added**. Generator and
  anp-questions.js use `<picture>` with the JPG fallback; the lab practical keeps the JPG (it zooms to 300%). WebP skipped:
  ~30 MB more for browsers that already get the JPG. Budgets: A&P shell 46 → 46.5, cardiac-cycle notes 19 → 19.5. Rule
  `figure-variants`. Not in CI as a Python step (CI has no AVIF Pillow); the rule checks the files exist.
