# Question bank fill 2: accuracy review (AP® Precalculus)

Independent reviewer, 2026-11-10. Scope: the 87 items added in fill 2 (ids in the fill list: 25 topic files,
the 11 `alg-*` skills and 14 Unit 1 and 2 topics). Old items were not changed.

## What was checked

- Every item solved from scratch, then compared with the key. Every numeric key (29) was recomputed in node
  from an independent formula; every expr key (6) was compared with an independent function on its domain and
  run through `ApPrecalcExpr.grade`: key right, each authored mistake wrong, equal forms accepted
  (`2-2x`, `4-2(x+1)`, `(x+3)/(x^2+x)`, `4-12x+9x^2`, `5sin(theta)/cos(theta)`), and the starting expression
  refused where the stem asks for a form (`x^2/x^(1/3)`, `(3x-2)^2`, `3/x-2/(x+1)`, `6^x/2^x`).
- Single-answer items (51) and the one order item: one correct option, every per-option `why` true and naming
  the slip that gives that option.
- `docs/apprecalc-authoring-guide.md`: the three-decimal rule (the one calculator item,
  `pcalc-alg-systems-16`, is keyed at full precision, 3.6385135..., and 3.64 is graded wrong with its note);
  exact keys on no-calculator items; no calculus words ("rate of change is increasing" is the allowed
  wording); "undefined"; limit notation only for behaviour; no em dashes.
- Topic fit against each topic's notes page, and overlap with the older items in the same file.

## Result

87 reviewed, 82 clean, 5 fixed (6 strings). No wrong key, no second correct option, no grading problem.

### Fixed (minor, 5 items)

All are explanations that were true but did not name the slip, or said slightly more than is true.

- `pcalc-alg-intervals-13`, options [-2, 3) and (-2, 3]: both explanations blamed "subtract 1 first", which
  does not give those ends. They come from dividing -4 <= -2x < 6 by 2 and losing the negative sign. Both
  rewritten.
- `pcalc-alg-circles-13`, mistake 30: the note only restated the right answer. It now names the slip (one
  sixth of 180 degrees instead of 360).
- `pcalc-alg-quadratics-11`, mistake 2: the note restated the method. It now names the slip: (x - 2)(x + 7),
  the wrong sign on 5x.
- `pcalc-alg-lines-10`, option 1/6: "a run of 0 cannot go on top either" is false (0/6 is 0). Now: the run
  is 0, slope is rise over run, and 6/0 has no value.
- `pcalc-exponential-manipulation-16`, correct explanation: it used "a power of a quotient", a rule the notes
  do not list. It now starts from the listed rule (power of a product: 6^x = 2^x * 3^x) and then states the
  shortcut.

### Noted, not changed

- `pcalc-alg-rational-expressions-16` asks which inputs are left out of the same expression that older item 5
  asks to simplify. The questions differ and neither stem gives the other away.
- `pcalc-alg-rational-expressions-14` (3 - x over x^2 - 9) needs 3 - x = -(x - 3), which the notes do not
  show. One line in the notes would cover it.
- `pcalc-exponential-modeling-16` (doubling every 3 hours): the notes cover changing the time unit of a
  growth factor but never use the word "doubling". The item can be done by counting doublings.
- `pcalc-model-selection-16` gives the first, second and third differences in the stem, so it tests the rule
  (constant third differences mean cubic), not the subtraction. Fine at its level; a harder version would
  give the outputs alone.
- `pcalc-polynomial-end-behavior-16`: the correct option is the only one with a number in it (100,000). The
  other three are refuted by reasoning, so it was kept.
- `pcalc-alg-right-triangle-12` keys 25 from the given tan 40 degrees = 0.84. A student who uses a
  calculator's tangent gets 25.027 and is marked wrong; the stem does say which value to use.

### Older items

Only their stems and keys were read (for overlap). Nothing wrong was seen.
