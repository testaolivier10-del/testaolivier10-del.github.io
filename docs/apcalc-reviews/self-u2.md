The misses the brief named:
- Limit definition read as a derivative at a point: 2.2 (items 3, 5, 13 and the misconception), 2.7 stimulus set of
  four limits that are derivatives (L1-L4) and item 15.
- Differentiable implies continuous, not the converse: 2.4 throughout (corner, cusp, vertical tangent, jump; a
  graph set and a piecewise set); the converse error is item 14 and the lesson misconception.
- Difference quotients from tables with units: 2.1 and 2.3 (askUnit numeric items, an interval that does not contain
  the point, value given instead of rate, averaging values).
- Product rule as product of derivatives: an authored `mistakes` entry on every product-rule numeric/expr item, a
  counterexample item, and the figure. The quotient rule gets the same treatment (reversed numerator, unsquared
  denominator, quotient of derivatives).
