## Answers to the authors' open questions

1. **Solution curves not crossing** (self-u7-8a 2): true for every equation where it is used (smooth right sides), and
   it is the reason teachers and the scoring guidelines' "does not cross the equilibrium" language rely on, but
   uniqueness is not CED content. The FRQ now also accepts, and the sample shows, the explicit solution argument. The
   notes no longer claim it for all course equations (the draining tank is a counterexample at h = 0).
2. **Particular-solution domain wording** (self-u7-8a 3): "the largest open interval containing x₀ on which the
   solution is defined and differentiable and the differential equation is defined" matches how released scoring
   guidelines state domains; −3 < x < 3 for y = √(9 − x²) with dy/dx = −x/y is right. Not verified against the CED
   text (download blocked).
3. **Isosceles right triangles with the hypotenuse in the base** (self-u8b 2): in scope; 8.8 covers triangle cross
   sections generally and s²/4 is correct geometry. Kept.
4. **Hard no-calculator part (d)** (self-u8b 1): kept the vertical axis, added the inverse x = 3 − √(9 − y) to the
   prompt so the part tests the washer setup, not completing the square.
5. **Dark-mode inversion of shaded 3D solids** (self-u8b 3): checked; fine.
6. Accept lines with math (self-u7-8a 1): `frq-kit.js` now renders them (`richText`), so math in accept lines is safe.
