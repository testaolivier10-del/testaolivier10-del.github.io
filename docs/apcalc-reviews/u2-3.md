## Numeric and expression recheck

Scratch scripts (not committed): `truth.mjs` computes every value from the stem, not from the keys: table entries
re-typed from the stimuli, graph values from the piecewise formulas, derivatives by central differences of the
original function, inverse-function values by bisection on $f(x) = y$, implicit slopes as $-F_x/F_y$ and second
derivatives numerically. `verify.mjs` loads `calc-expr.js`, `calc-math.js` and `calc-questions.js` in the test
harness and grades through `ApCalcQuestions.grade`.

- 79 numeric keys: all equal the independent value; each graded right as typed, as a three-decimal decimal (and
  truncated for the 3 calculator items: $f'(2) = 0.29556$, $g'(1) = -0.30117$, $k'(1) = 0.19470$), and with every
  listed unit spelling on the 3 `askUnit` items.
- 49 expr keys: equal the independent derivative at 25 points in their domains (two-variable keys at 25 $(x, y)$
  pairs); each graded right.
- 274 authored mistakes (numeric and expr): every one graded wrong and matched to its own feedback. Each feedback
  was also read against the slip it names; the two that did not match are fixed above.
- 107 equivalent forms a student might type (factored and expanded, negative and fractional exponents, `sec^2 x`,
  `1 + tan(x)^2`, `cbrt`, `exp`, `-x/4/y`, `(2x+y)/(-x-2y)`, `x/4 + 1/4` for a tangent line, and so on): all
  accepted. Two forms are refused, both acceptably: `1/2sqrt(x)` reads as $\frac{1}{2}\sqrt{x}$ (standard
  precedence) and `root(x,3)` is not in the function list (`cbrt` and `x^(1/3)` work).
- Singles with numeric options (tangent lines, chain-rule table values, inverse slopes, orderings): each option
  recomputed by hand; every distractor value matches the error its explanation names.
- FRQs: `frq-u2-fg-table-rules` $h'(2) = 7$, $k'(3) = \frac{1}{4}$, $m(1) = 16$, $m'(1) = -9$, the limit $= f'(4) = 1$,
  IVT on $g(1) = 1$, $g(4) = -1$. `frq-u3-implicit-oval`: all four marked points on the curve, the plotted halves
  $\frac{x + 1 \pm \sqrt{3(1 - x)(x + 3)}}{2}$ solve the equation, $\frac{dy}{dx} = \frac{y - 2x - 2}{2y - x - 1}$,
  slope 1 at $(0, -1)$, horizontal tangents $(0, 2)$ and $(-2, -2)$ with denominators $3$ and $-3$, $\frac{dx}{dt} = 0$ at
  $(1, 1)$ with numerator $-3$, denominator 0 (vertical tangent).

## Open questions (for a person)

1. **Notes worked examples reuse item data.** Several notes pages work the exact numbers of an item, so the
   answer is printed in the notes: `quotient-rule` WE3 = items 1 and 4; `product-rule` WE3 = item 1;
   `basic-derivative-rules` WE3 = item 8; `chain-rule` "from a table" = item 1; `choosing-derivative-rules` WE3 =
   item 4; `inverse-trig-derivatives` WE3 = item 5; `implicit-differentiation` WE2 = items 1-2;
   `higher-order-derivatives` WE3 = items 6-7; `derivative-definition` WE1 = item 13; `differentiability` WE1-2 =
   items 6 and 16. Fine for learning, but if the practice exams draw these ids, a student can look the answer up.
   Changing the notes' numbers would be the cheap fix; left for the owner to decide.
2. **Unit 3 CED text** (above): a person should confirm 3.1-3.6 against the PDF, in particular whether FUN-3.E.2
   lists only arcsin, arccos and arctan (the course teaches those three and mentions the other three as derivable).
3. **`inverse-trig-derivatives-16`** explains "$\arcsin x + \arccos x$ is constant" with "a function with
   derivative 0 on an interval is constant", a consequence of the MVT (5.1). It is stated as a fact, not used as a
   required step; acceptable, but the owner may prefer "indeed, $\arcsin x + \arccos x = \frac{\pi}{2}$" alone.
4. **`frq-u3-implicit-oval` (d)** is related rates (4.4), and its `units` list includes unit-4: an exam form should
   place it after Unit 4.
