# LevlPrep (levlprep.com) — source map

Static GitHub Pages site (CNAME levlprep.com), three courses. Stack/tooling: `mem:tech_stack`. Commands: `mem:suggested_commands`. Code/content rules: `mem:conventions`. Done-checklist before commit: `mem:task_completion`.

## Layout
- `/` root: landing + shared pages (index, practice, dashboard, glossary, tools, …), `sw.js` (service worker, root scope), 3 manifests (`manifest.json`, `nremt/manifest.json`, `ochem/manifest.json`).
- `assets/`: shared across courses — `theme.css` (the ONLY design system; no per-course copy), `site-chrome.js` (header), fonts self-hosted.
- `nremt/`: NREMT-EMT exam prep. Bank source `nremt/assets/questions.json`; `questions-core.json` + `explanations.json` are GENERATED splits (positionally aligned).
- `ochem/`: organic chemistry. `ochem/assets/curriculum.js` = single source of truth for topics. Prose in `ochem/notes/*.html` fragments; lessons in `ochem/lessons/`. Practice bank `practice-bank.json` split by `build-ochem-bank.mjs`.
- `anatomy-physiology/`: A&P course. Authored data in `anatomy-physiology/data/` (lessons/notes/questions/glossary/figures/labels/tools JSON). All pages under `anatomy-physiology/` outside `data/` are GENERATED by `scripts/build-anp.mjs` (lib: `scripts/lib/anp-build.mjs`). Only chapters in `data/published.json` ship.
- `docs/`: specs + reports. `docs/anp-spec.md` is source of truth for A&P (read fully before A&P work; update in same commit as plan changes). `docs/anp-dependency-map.json` = concept order enforced by `check-anp-map.mjs`. Open questions → `docs/anp-needs-author.md` / `docs/ochem-needs-author.md` (add there, don't guess).
- `scripts/`: Node ESM build/check scripts (`build-*.mjs`, `check-*.mjs`), `scripts/lib/`, tests in `scripts/test/*.test.mjs`, ochem figure sources `scripts/ochem-figures/<topic>.mjs`.
- `worker/`: Cloudflare Worker (wrangler). `worker/dist` generated from `worker/src` by `build-worker.mjs`.

## Invariants
- Generated files are never hand-edited: edit the source, rerun the `build-*.mjs` script, commit both. CI runs every builder with `--check`.
- Large JSON (question banks, lesson data) — search, never read whole.
